# 高数核心做题思路总纲

> 通用框架 + 分模块解题逻辑，适配数一/数二/数三。数学二重点覆盖模块 1—6 与 9。
> 本页是「做题方法」的索引，具体公式与考法见各考点页与公式页。

---

## 一、拿到任何高数题：固定四步审题法（最关键）

| 步骤 | 动作 | 具体内容 |
|------|------|---------|
| 1. 识别考点 | 判断属于哪一块 | 极限/导数/积分/微分方程/级数/多元函数，圈出已知条件：连续、可导、可积、单调、有界、奇偶性、周期性 |
| 2. 观察所求目标 | **目标决定工具** | 求极限？求导？求值？证明不等式/存在性？判断敛散性？ |
| 3. 判断题型类别 | 计算 vs 证明 | 计算题优先化简；证明题优先考虑中值定理、单调性、凹凸性 |
| 4. 预判坑点 | 先圈雷区 | 定义域、间断点、变限积分求导、积分上下限正负、无穷小替换条件、级数收敛域端点 |

> 底层原则：**先化简，再计算；能定性判断，不硬算**。很多考研题不需要完整算出表达式，用性质直接排除/得到结果。

**「考点 → 首选工具」快速映射**

| 题干信号 | 首选工具 |
|---------|---------|
| 出现 $f'(x)$、变限积分、导数定义差分 | 求导 / 中值定理 |
| 出现对称区间、奇偶函数 | 积分化简（对称性） |
| 出现高阶导数、函数值相等 | 泰勒 / 罗尔 |
| 出现 $\sum$、级数、通项 | 审敛法 / 幂级数 |
| 出现「证明存在 $\xi$」 | 中值定理 |

## 二、各模块解题思路

### 1. 极限（必考，选择+填空+大题第一问）

**类型 → 方法**：详见 [[数学/高数考点/01-极限计算]]

| 未定式 | 处理方法 |
|--------|---------|
| $\frac{0}{0}$、$\frac{\infty}{\infty}$ | 等价无穷小替换（仅乘除）→ 泰勒展开（首选）→ 洛必达（兜底） |
| $0\cdot\infty$ | 化为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ |
| $\infty-\infty$ | 通分、有理化、提取公因子 |
| $1^\infty$、$0^0$、$\infty^0$ | $u^v=e^{v\ln u}$ |
| 数列极限 | 单调有界准则 / 夹逼准则 / 转化为函数极限 |

> 提醒：**泰勒优先于洛必达**，考研很多极限题洛必达越算越复杂。
> 加减法中的等价无穷小不可随意替换，改用泰勒展开到同阶。等价替换公式见 [[数学/基础公式/04-等价无穷小与泰勒展开]]。

**核心工具优先级**：等价无穷小（乘除） → 泰勒（通用） → 洛必达（最后）。

---

### 2. 一元函数导数与微分

详见 [[数学/高数考点/02-导数与微分]]

- **求导**：复合链式法则；隐函数两边同时求导；参数方程求导公式；变限积分求导（高频坑）。
- **变限积分求导公式**（必背）：
  $$\frac{d}{dx}\int_{a}^{x} f(t)\,dt = f(x), \qquad \frac{d}{dx}\int_{\varphi(x)}^{\psi(x)} f(t)\,dt = f(\psi)\psi' - f(\varphi)\varphi'$$
- **导数定义题**：看到 $f(x_0+\Delta x)-f(x_0)$ 结构，立刻想到导数定义，**不要直接求导**（题目未必给可导）。
- **应用**：切线法线、单调性（一阶导符号）、极值点（一阶导为 0 或不存在且左右变号）、凹凸拐点（二阶导）、最值、不等式证明。
- **不等式证明**：移项构造辅助函数 → 求导看单调性 → 比较端点值。

---

### 3. 一元积分（不定积分、定积分、变限积分）

详见 [[数学/高数考点/03-不定积分与定积分]]、[[数学/高数考点/08-定积分应用]]

- **不定积分**：凑微分（第一类换元）→ 三角代换/倒代换 → 分部积分。两类不同函数相乘优先分部：幂×三角、幂×指数、幂×对数。
- **定积分**：**优先利用奇偶、周期、区间再现化简，再计算**，不要上来硬算原函数。
  - 区间再现：$\int_0^a f(x)\,dx = \int_0^a f(a-x)\,dx$；对称区间 $\int_{-a}^{a}f(x)\,dx$ 先看奇偶。
- **变限积分**：先求导。上限下限是函数要链式求导；被积函数含 $x$ 要先把 $x$ 分离到积分号外。
- **反常积分**：先找瑕点/无穷端点，拆分积分，判断敛散性，再求值。

---

### 4. 微分中值定理（证明大题高频）

详见 [[数学/高数考点/04-中值定理证明]]

**结论形态 → 定理选择**

| 结论形态 | 定理 |
|---------|------|
| 含一个 $\xi$ | 罗尔 / 拉格朗日 |
| 含 $\xi$ 和 $\eta$ 两个不同中值点 | 两次拉格朗日，或拉格朗日 + 柯西 |
| 含二阶导数 | 多次罗尔 / 泰勒 |

> 核心动作：**构造辅助函数**。看到 $f'+P(x)f$ 形式，考虑积分因子 $e^{\int P(x)dx}$ 构造。

---

### 5. 多元函数微分学

详见 [[数学/高数考点/06-多元函数微分]]

- **求偏导**：链式法则，分清自变量与中间变量；隐函数组求偏导，方程组两边求导。
- **关系链**（选择题高频）：**偏导连续 ⇒ 可微 ⇒ 连续、偏导存在**，反向均不成立。
- **极值**：驻点取一阶偏导为 0；二阶判别 $AC-B^2$；闭区域最值 = 内部驻点 + 边界最值。

---

### 6. 重积分（二重/三重，数一考三重）

详见 [[数学/高数考点/07-二重积分]]

固定流程：
1. 画图，判断积分区域；看对称性（奇偶、轮换对称），**先化简**。
2. 选坐标系：直角 / 极坐标（二重）；柱坐标、球坐标（三重）。
3. 定积分次序；**交换积分次序是必考题型**。

> 口诀：**对称性优先，选对坐标系，后定限**。

---

### 7. 曲线曲面积分（仅数一）

- **第一类（对弧长/面积）**：无方向，用对称性化简。
- **第二类（对坐标）**：有方向。优先 **格林公式（平面）/ 高斯公式（空间闭曲面）**；不满足条件时补线补面再减去；再不行用参数方程。斯托克斯公式多用于空间曲线。

---

### 8. 无穷级数（数一、数三）

1. **常数项级数敛散性**：正项级数用比较/比值/根值；交错级数用莱布尼茨；任意项看绝对收敛与条件收敛。
2. **幂级数**：求收敛半径、收敛域；展开幂级数；求和函数（逐项求导/积分，注意收敛域端点）。

> 求和函数思路：先求导/积分消去系数，化成简单等比级数，再还原。

---

### 9. 常微分方程

详见 [[数学/高数考点/05-微分方程]]、[[数学/基础公式/06-微分方程公式汇总]]

1. **识别类型**：可分离变量 → 齐次方程 → 一阶线性（公式法）→ 伯努利；高阶线性先求齐次通解，再设特解。
2. **二阶常系数线性**：熟记特征方程；非齐次特解形式按右端类型（多项式、指数、三角函数）设。
3. **几何应用**：由切线、面积、弧长条件列微分方程。

## 三、证明题通用套路（卡点集中区）

1. 把要证式子变形，**构造辅助函数 $F(x)$**。
2. 检查 $F(x)$ 是否满足定理条件（连续、可导、端点值）。
3. 选用对应定理（罗尔 / 拉格朗日 / 泰勒）。
4. **泰勒证明**：条件有高阶导数时优先泰勒展开，一般在中点、端点处展开。

> 关键判断：条件只给「连续」→ 用介值/零点定理；给「可导」→ 罗尔/拉格朗日；给「高阶可导」→ 泰勒。

## 四、考场避坑通用清单

| 场景 | 坑点 | 正确做法 |
|------|------|---------|
| 极限 | 加减法乱用等价无穷小 | 加减用泰勒展开到同阶 |
| 积分 | 对称区间忘记看奇偶 | 先判断奇偶/周期，再计算 |
| 变限积分 | 上下限是函数忘记链式求导 | 用公式 $\psi' f(\psi) - \varphi' f(\varphi)$ |
| 中值定理 | 忘记 $\xi\in$ 开区间 | 结论写 $\xi\in(a,b)$ |
| 多元极值 | $AC-B^2=0$ 时强行下结论 | 判别失效，改用定义判断 |
| 级数 | 逐项求导/积分改端点敛散性 | 端点单独验证 |
| 微分方程 | 漏掉常数 $C$、特解形式写错 | 最后补 $C$，按右端类型设特解 |

## 五、刷题复盘思路（不是单纯堆题）

做完每道题问自己 3 个问题：

1. 我一开始**有没有识别对考点**？
2. 哪个步骤卡住？是公式不熟，还是想不到这个方法？
3. 有没有更快的方法（性质 / 泰勒 / 对称性）？

> 复盘的本质：把「这道题」抽象成「这一类题的方法」，沉淀进本页对应的模块。

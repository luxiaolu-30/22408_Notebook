# 考点8：定积分应用（面积/旋转体体积/弧长）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 14/15年必考，分值 10分
>
> **考法**：定积分的几何应用是解答题第 19 题的常考考点，平面图形面积、旋转体体积是核心。

---

## 一、核心知识框架

### 1.1 平面图形的面积

| 情形 | 公式 |
|------|------|
| 直角坐标（由 $y=f(x)$ 和 $x$ 轴围成） | $A = \int_a^b |f(x)| dx$ |
| 直角坐标（由 $y=f(x)$ 和 $y=g(x)$ 围成） | $A = \int_a^b |f(x) - g(x)| dx$ |
| 参数方程（由 $x=\varphi(t), y=\psi(t)$ 围成） | $A = \int_\alpha^\beta |\psi(t) \varphi'(t)| dt$ |
| 极坐标（由 $r=r(\theta)$ 围成） | $A = \frac{1}{2} \int_\alpha^\beta r^2(\theta) d\theta$ |

### 1.2 旋转体的体积

| 情形 | 公式 |
|------|------|
| 绕 $x$ 轴旋转 | $V = \pi \int_a^b [f(x)]^2 dx$ |
| 绕 $y$ 轴旋转 | $V = 2\pi \int_a^b x|f(x)| dx$（柱壳法） |
| 绕 $y$ 轴旋转（反函数形式） | $V = \pi \int_c^d [\varphi(y)]^2 dy$ |

### 1.3 曲线的弧长

| 情形 | 公式 |
|------|------|
| 直角坐标 $y=f(x)$ | $s = \int_a^b \sqrt{1 + [f'(x)]^2} dx$ |
| 参数方程 $x=\varphi(t), y=\psi(t)$ | $s = \int_\alpha^\beta \sqrt{[\varphi'(t)]^2 + [\psi'(t)]^2} dt$ |
| 极坐标 $r=r(\theta)$ | $s = \int_\alpha^\beta \sqrt{r^2(\theta) + [r'(\theta)]^2} d\theta$ |

### 1.4 定积分的物理应用（数学二较少考）

| 应用 | 公式 |
|------|------|
| 变力做功 | $W = \int_a^b F(x) dx$ |
| 液体压力 | $P = \int_a^b \rho g x \cdot f(x) dx$ |
| 引力 | 微元法计算 |

## 三、解题技巧总结

### 3.1 面积计算步骤

1. 画出平面图形
2. 确定交点和边界
3. 选择合适的积分变量（$x$ 或 $y$）
4. 写出面积公式
5. 计算定积分

### 3.2 旋转体体积计算步骤

1. 确定旋转轴
2. 判断使用圆盘法还是柱壳法
3. 写出体积公式
4. 计算定积分

**方法选择**：
- 绕 $x$ 轴 → 圆盘法：$V = \pi \int_a^b [f(x)]^2 dx$
- 绕 $y$ 轴 → 柱壳法：$V = 2\pi \int_a^b x|f(x)| dx$

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 面积忘记取绝对值 | $A = \int |f(x) - g(x)| dx$，注意上下位置 |
| 旋转体体积方法选择错误 | 根据旋转轴选择圆盘法或柱壳法 |
| 弧长公式忘记开方 | $s = \int \sqrt{1 + [f']^2} dx$，根号不能丢 |
| 参数方程弧长公式错误 | 两个导数的平方和开方 |

## 一、核心知识框架

### 1.1 偏导数

**定义**：对某个变量求导，其余变量视为常数

**一阶偏导**：
$$\frac{\partial z}{\partial x} = \lim_{\Delta x \to 0} \frac{z(x+\Delta x, y) - z(x,y)}{\Delta x}$$

**二阶偏导**：
- $\frac{\partial^2 z}{\partial x^2} = f_{xx}$（对 $x$ 求两次）
- $\frac{\partial^2 z}{\partial y^2} = f_{yy}$（对 $y$ 求两次）
- $\frac{\partial^2 z}{\partial x \partial y} = f_{xy}$（先 $x$ 后 $y$）
- $\frac{\partial^2 z}{\partial y \partial x} = f_{yx}$（先 $y$ 后 $x$）

**重要结论**：若 $f_{xy}$ 和 $f_{yx}$ 连续，则 $f_{xy} = f_{yx}$

### 1.2 全微分

**定义**：$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$

**可微的条件**：
- 充分条件：偏导数连续 $\Rightarrow$ 可微
- 必要条件：可微 $\Rightarrow$ 偏导数存在

### 1.3 复合函数求导（链式法则）

| 情形 | 求导公式 |
|------|---------|
| $z=f(u,v), u=\varphi(x,y), v=\psi(x,y)$ | $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$ |
| $z=f(u), u=\varphi(x)$ | $\frac{dz}{dx} = \frac{dz}{du}\frac{du}{dx}$ |
| 隐函数 $F(x,y,z)=0$ | $\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}$ |

### 1.4 多元函数极值

#### 无条件极值

**必要条件**：若 $(x_0, y_0)$ 是极值点且偏导存在，则 $f_x(x_0,y_0) = 0$，$f_y(x_0,y_0) = 0$

**充分条件**：设 $A = f_{xx}$，$B = f_{xy}$，$C = f_{yy}$，$\Delta = B^2 - AC$

| $\Delta$ | $A$ | 结论 |
|---------|-----|------|
| $< 0$ | $> 0$ | 极小值 |
| $< 0$ | $< 0$ | 极大值 |
| $> 0$ | - | 不是极值 |
| $= 0$ | - | 需进一步判断 |

#### 条件极值（拉格朗日乘数法）

**问题**：在约束条件 $\varphi(x,y) = 0$ 下，求 $f(x,y)$ 的极值

**步骤**：
1. 构造拉格朗日函数 $L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$
2. 解方程组：
   - $\frac{\partial L}{\partial x} = 0$
   - $\frac{\partial L}{\partial y} = 0$
   - $\frac{\partial L}{\partial \lambda} = 0$（即 $\varphi(x,y) = 0$）
3. 判断是否为极值

## 三、解题技巧总结

### 3.1 偏导数计算技巧

1. **对 $x$ 求导时**：把 $y$ 当作常数
2. **对 $y$ 求导时**：把 $x$ 当作常数
3. **复合函数**：画链式图，不遗漏任何路径
4. **隐函数**：使用公式 $\frac{dy}{dx} = -\frac{F_x}{F_y}$

### 3.2 极值问题解题步骤

**无条件极值**：
1. 求偏导 $f_x$、$f_y$
2. 解方程组 $f_x = 0$、$f_y = 0$ 得驻点
3. 计算 $A = f_{xx}$、$B = f_{xy}$、$C = f_{yy}$
4. 用充分条件判断

**条件极值**：
1. 构造拉格朗日函数
2. 解方程组
3. 根据实际意义判断最值

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 复合函数求导遗漏中间变量 | 画链式图检查 |
| 隐函数求导符号错误 | 使用公式 $\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}$ |
| 极值判断时 $\Delta$ 计算错误 | $\Delta = B^2 - AC$，不是 $AC - B^2$ |
| 拉格朗日乘数法忘记约束条件 | 方程组必须包含 $\varphi = 0$ |

# 考点7：二重积分（直角坐标/极坐标/交换次序）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 12-15分
>
> **考法**：二重积分是解答题第 22 题的固定考点，直角坐标与极坐标的选择、交换积分次序是核心技能。

---

## 一、核心知识框架

### 1.1 二重积分的概念与性质

**定义**：$\iint_D f(x,y) d\sigma = \lim_{\lambda \to 0} \sum_{i=1}^n f(\xi_i, \eta_i) \Delta\sigma_i$

**几何意义**：以 $D$ 为底、$z=f(x,y)$ 为顶的曲顶柱体体积

**基本性质**：
- 线性性：$\iint_D [af + bg] = a\iint_D f + b\iint_D g$
- 可加性：$D = D_1 \cup D_2 \Rightarrow \iint_D = \iint_{D_1} + \iint_{D_2}$
- 保号性：若 $f \geq 0$，则 $\iint_D f \geq 0$
- 对称性：奇偶性可简化计算

### 1.2 直角坐标系下的计算

**X 型区域**（先 $y$ 后 $x$）：

$$D = \{(x,y) \mid a \leq x \leq b, \varphi_1(x) \leq y \leq \varphi_2(x)\}$$

$$\iint_D f(x,y) dxdy = \int_a^b dx \int_{\varphi_1(x)}^{\varphi_2(x)} f(x,y) dy$$

**Y 型区域**（先 $x$ 后 $y$）：

$$D = \{(x,y) \mid c \leq y \leq d, \psi_1(y) \leq x \leq \psi_2(y)\}$$

$$\iint_D f(x,y) dxdy = \int_c^d dy \int_{\psi_1(y)}^{\psi_2(y)} f(x,y) dx$$

### 1.3 极坐标系下的计算

**极坐标变换**：
- $x = r\cos\theta$
- $y = r\sin\theta$
- $dxdy = r drd\theta$

**极坐标下的积分**：

$$\iint_D f(x,y) dxdy = \iint_D f(r\cos\theta, r\sin\theta) r drd\theta$$

**适用情形**：
- 积分区域是圆、扇形、环形
- 被积函数含 $x^2 + y^2$

### 1.4 交换积分次序

**步骤**：
1. 根据原积分限画出积分区域 $D$
2. 重新描述区域 $D$（换一种类型）
3. 确定新的积分限
4. 写出新积分

### 1.5 对称性的利用

| 对称类型 | 条件 | 结论 |
|---------|------|------|
| 关于 $x$ 轴对称 | $D$ 关于 $x$ 轴对称 | $f(x,-y) = -f(x,y) \Rightarrow \iint = 0$ |
| 关于 $y$ 轴对称 | $D$ 关于 $y$ 轴对称 | $f(-x,y) = -f(x,y) \Rightarrow \iint = 0$ |
| 关于原点对称 | $D$ 关于原点对称 | $f(-x,-y) = -f(x,y) \Rightarrow \iint = 0$ |

## 三、解题技巧总结

### 3.1 坐标系选择指南

| 情形 | 选择 |
|------|------|
| 区域是矩形、三角形 | 直角坐标 |
| 区域是圆、扇形、环形 | 极坐标 |
| 被积函数含 $x^2+y^2$ | 极坐标 |
| 被积函数含 $x/y$ 或 $y/x$ | 极坐标 |

### 3.2 交换积分次序步骤

1. 根据原积分限画出区域 $D$
2. 用另一种方式描述 $D$
3. 确定新积分限
4. 写出新积分

### 3.3 计算技巧

1. **先画图**：画出积分区域，直观理解
2. **看对称性**：利用奇偶性简化
3. **选坐标系**：根据区域和被积函数选择
4. **先积后算**：内层积分算完再算外层

### 3.4 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 极坐标忘记乘 $r$ | $dxdy = r drd\theta$，必须乘 $r$ |
| 积分限确定错误 | 画图确认区域边界 |
| 对称性判断错误 | 同时检查区域和被积函数的对称性 |
| 交换次序后积分限写错 | 画图重新确认 |

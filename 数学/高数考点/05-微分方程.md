# 考点5：微分方程（一阶线性/二阶常系数/可降阶）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 12-15分
>
> **考法**：微分方程是解答题第 20 题的固定考点，一阶线性、二阶常系数线性、可降阶方程是三大核心类型。

---

## 一、核心知识框架

### 1.1 一阶微分方程

#### 可分离变量方程

**形式**：$\frac{dy}{dx} = f(x)g(y)$

**解法**：分离变量 $\frac{dy}{g(y)} = f(x)dx$，两边积分

#### 齐次方程

**形式**：$\frac{dy}{dx} = \varphi(\frac{y}{x})$

**解法**：令 $u = \frac{y}{x}$，则 $y = xu$，$\frac{dy}{dx} = u + x\frac{du}{dx}$

#### 一阶线性微分方程（重点）

**形式**：$y' + P(x)y = Q(x)$

**通解公式**：

$$y = e^{-\int P(x) dx} \left(\int Q(x) e^{\int P(x) dx} dx + C\right)$$

**记忆技巧**：先求积分因子 $\mu = e^{\int P dx}$，然后 $y = \frac{1}{\mu}(\int Q\mu dx + C)$

### 1.2 二阶常系数线性微分方程

#### 二阶常系数齐次方程

**形式**：$y'' + py' + qy = 0$

**特征方程**：$r^2 + pr + q = 0$

**通解形式**：

| 特征根情况 | 通解形式 |
|-----------|---------|
| 两不等实根 $r_1 \neq r_2$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 两相等实根 $r_1 = r_2$ | $y = (C_1 + C_2 x) e^{r_1 x}$ |
| 共轭复根 $\alpha \pm i\beta$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

#### 二阶常系数非齐次方程

**形式**：$y'' + py' + qy = f(x)$

**通解 = 齐次通解 + 非齐次特解**

**特解形式**：

| $f(x)$ 类型 | 特解形式 |
|------------|---------|
| $P_n(x)$（多项式） | $y^* = x^k Q_n(x)$ |
| $e^{\alpha x} P_n(x)$ | $y^* = x^k Q_n(x) e^{\alpha x}$ |
| $e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ | $y^* = x^k e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ |

其中 $k$ 是特征根中 $\alpha$（或 $\alpha \pm i\beta$）的重数（0、1 或 2）

### 1.3 可降阶的高阶微分方程

| 类型 | 形式 | 解法 |
|------|------|------|
| $y^{(n)} = f(x)$ | 缺 $y$ 及低阶导数 | 逐次积分 |
| $y'' = f(x, y')$ | 缺 $y$ | 令 $p = y'$，降为一阶 |
| $y'' = f(y, y')$ | 缺 $x$ | 令 $p = y'$，$y'' = p\frac{dp}{dy}$ |

## 三、解题技巧总结

### 3.1 一阶线性方程解题步骤

1. 确认方程形式 $y' + P(x)y = Q(x)$
2. 计算积分因子 $\mu = e^{\int P(x) dx}$
3. 通解 $y = \frac{1}{\mu}(\int Q\mu dx + C)$
4. 代入初始条件求特解（如有）

### 3.2 二阶常系数方程解题步骤

1. 写出特征方程 $r^2 + pr + q = 0$
2. 求特征根 $r_1, r_2$
3. 写出齐次通解
4. 根据 $f(x)$ 形式设特解
5. 代入原方程确定特解系数
6. 通解 = 齐次通解 + 特解

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 特征根求错 | 仔细解特征方程 |
| 特解形式设错 | 检查 $\alpha$ 是否为特征根，确定 $k$ 值 |
| 非齐次方程忘记加特解 | 通解 = 齐次通解 + 特解 |
| 可降阶方程代换错误 | 明确缺 $y$ 还是缺 $x$ |

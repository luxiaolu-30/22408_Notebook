# 考点3：不定积分与定积分（换元/分部）

> **配套真题**：[[数学/数学二历年真题]] — 出现频率 15/15年必考，分值 15-18分
>
> **考法**：积分计算是数学二的核心能力，不定积分、定积分、变限积分求导每年必考。

---

## 一、核心知识框架

### 1.1 不定积分基本公式

| 基本积分公式 | 说明 |
|-------------|------|
| $\int x^n dx = \frac{x^{n+1}}{n+1} + C$ ($n \neq -1$) | 幂函数积分 |
| $\int \frac{1}{x} dx = \ln|x| + C$ | 对数积分 |
| $\int e^x dx = e^x + C$ | 指数积分 |
| $\int a^x dx = \frac{a^x}{\ln a} + C$ | 一般指数 |
| $\int \sin x dx = -\cos x + C$ | 三角积分 |
| $\int \cos x dx = \sin x + C$ | 三角积分 |
| $\int \frac{1}{1+x^2} dx = \arctan x + C$ | 反三角积分 |
| $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$ | 反三角积分 |
| $\int \sec^2 x dx = \tan x + C$ | 正切积分 |
| $\int \csc^2 x dx = -\cot x + C$ | 余切积分 |

### 1.2 换元积分法

**第一类换元法（凑微分法）**：

$$\int f(\varphi(x)) \varphi'(x) dx = \int f(u) du \quad (u = \varphi(x))$$

**常见凑微分形式**：
- $\int f(ax+b) dx = \frac{1}{a} \int f(ax+b) d(ax+b)$
- $\int f(x^n) x^{n-1} dx = \frac{1}{n} \int f(x^n) d(x^n)$
- $\int f(e^x) e^x dx = \int f(e^x) d(e^x)$
- $\int f(\ln x) \frac{1}{x} dx = \int f(\ln x) d(\ln x)$

**第二类换元法**：

$$\int f(x) dx = \int f(\varphi(t)) \varphi'(t) dt \quad (x = \varphi(t))$$

**常见代换**：
- 含 $\sqrt{a^2 - x^2}$：令 $x = a\sin t$
- 含 $\sqrt{a^2 + x^2}$：令 $x = a\tan t$
- 含 $\sqrt{x^2 - a^2}$：令 $x = a\sec t$

### 1.3 分部积分法

$$\int u dv = uv - \int v du$$

**选择 $u$ 的顺序（反三角、对数、幂函数、三角、指数）**：

| 被积函数类型 | $u$ 的选择 | $dv$ 的选择 |
|-------------|-----------|------------|
| $x^n e^{ax}$ | $x^n$ | $e^{ax} dx$ |
| $x^n \sin x$ | $x^n$ | $\sin x dx$ |
| $x^n \ln x$ | $\ln x$ | $x^n dx$ |
| $e^{ax} \sin bx$ | $\sin bx$ 或 $e^{ax}$ | 循环求解 |

### 1.4 定积分的定义（黎曼和的极限）

将 $[a,b]$ $n$ 等分，每个小区间长度为 $\Delta x = \frac{b-a}{n}$，取每个小区间的**右端点**为 $\xi_i$，则：

$$\boxed{\int_a^b f(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^{n}f\left(a+\frac{b-a}{n}i\right)\frac{b-a}{n}}$$

**构造步骤**：

| 步骤 | 操作 | 说明 |
|------|------|------|
| ① | $n$ 等分区间，取右端点函数值为高 | $\xi_i = a + \frac{b-a}{n}i$ |
| ② | 近似 | 每个小矩形面积 $= f(\xi_i) \cdot \Delta x$ |
| ③ | 求和 | $\sum_{i=1}^{n} f(\xi_i) \cdot \Delta x$ |
| ④ | 取极限 | $n \to \infty$ 得到精确面积 |

**取左端点的形式**（$i$ 从 $0$ 到 $n-1$）：

$$\lim_{n\to\infty}\sum_{i=0}^{n-1}f\left(a+\frac{b-a}{n}i\right)\frac{b-a}{n} = \int_a^b f(x)\,dx$$

**★ 重要特例：区间 $[0,1]$**（考研高频考法）：

$$\boxed{\int_0^1 f(x)\,dx = \lim_{n\to\infty}\sum_{i=1}^{n}f\left(\frac{i}{n}\right)\frac{1}{n}}$$

> **考研应用**：遇到形如 $\displaystyle\lim_{n\to\infty}\frac{1}{n}\sum_{i=1}^{n}f\left(\frac{i}{n}\right)$ 的极限，直接转化为 $\int_0^1 f(x)\,dx$ 计算。

**定积分的值与积分变量字母无关**：

$$\int_a^b f(x)\,dx = \int_a^b f(t)\,dt = \int_a^b f(u)\,du$$

### 1.5 估值定理与积分中值定理

**性质5（估值定理）**：

设 $m$、$M$ 分别是 $f(x)$ 在 $[a,b]$ 上的最小值和最大值，$L = b-a$ 为区间长度，则：

$$mL \leq \int_a^b f(x)\,dx \leq ML$$

> **证明思路**：由 $m \leq f(x) \leq M$，两边积分得 $\int_a^b m\,dx \leq \int_a^b f(x)\,dx \leq \int_a^b M\,dx$，即 $mL \leq \int_a^b f(x)\,dx \leq ML$。

**★ 性质6（积分中值定理）**：

设 $f(x)$ 在 $[a,b]$ 上**连续**，则在 $[a,b]$ 上至少存在一点 $\xi$，使得：

$$\boxed{\int_a^b f(x)\,dx = f(\xi)(b-a), \quad \xi \in [a,b]}$$

> **证明思路**：由估值定理得 $m \leq \dfrac{1}{b-a}\displaystyle\int_a^b f(x)\,dx \leq M$，再由**闭区间上连续函数的介值定理**，存在 $\xi \in [a,b]$ 使 $f(\xi) = \dfrac{1}{b-a}\displaystyle\int_a^b f(x)\,dx$。
>
> **连续性是关键**：若 $f(x)$ 有跳跃间断点，中值定理可能不成立。

**几何意义**：曲边梯形的面积等于以 $f(\xi)$ 为高、$(b-a)$ 为底的矩形面积，$f(\xi)$ 即 $f(x)$ 在 $[a,b]$ 上的**平均值**。

### 例 8.3：原函数存在性与定积分存在性的关系

在区间 $[-1, 2]$ 上考察以下两个函数：

| 函数                                                                                                                | 有原函数？ | 定积分存在？ | 关键点                                   |
| ----------------------------------------------------------------------------------------------------------------- | ----- | ------ | ------------------------------------- |
| ① $f(x) = \begin{cases} 2, & x > 0 \\ 1, & x = 0 \\ -1, & x < 0 \end{cases}$                                      | ✗ 无   | ✓ 存在   | $x=0$ 是跳跃间断点 → 无原函数；但有界 + 有限个间断点 → 可积 |
| ② $f(x) = \begin{cases} 2x\sin\frac{1}{x^2} - \frac{2}{x}\cos\frac{1}{x^2}, & x \neq 0 \\ 0, & x = 0 \end{cases}$ | ✓ 有   | ✗ 不存在  | $x=0$ 附近无界振荡 → 不可积                    |

> **核心结论**：原函数存在与定积分存在是**两个独立的概念**，互不蕴含：
> - 有原函数 $\not\Rightarrow$ 定积分存在（如 ② 无界）
> - 定积分存在 $\not\Rightarrow$ 有原函数（如 ① 有跳跃间断点）
> - 仅当 $f(x)$ **连续**时，两者同时成立（由牛顿-莱布尼茨公式保证）

### 1.6 定积分基本定理

**牛顿-莱布尼茨公式**：

$$\int_a^b f(x) dx = F(b) - F(a) \quad (F'(x) = f(x))$$

**变限积分求导**：

$$\frac{d}{dx} \int_{a(x)}^{b(x)} f(t) dt = f(b(x)) \cdot b'(x) - f(a(x)) \cdot a'(x)$$

### 1.7 定积分计算技巧

| 技巧 | 适用条件 | 方法 |
|------|---------|------|
| 奇偶性 | 对称区间 $[-a, a]$ | 奇函数积分为 0，偶函数积分 = $2\int_0^a$ |
| 周期性 | $f(x)$ 周期为 $T$ | $\int_a^{a+T} f(x) dx = \int_0^T f(x) dx$ |
| 点火公式 | $\int_0^{\pi/2} \sin^n x dx$ | $I_n = \frac{n-1}{n} I_{n-2}$ |
| 分段积分 | 被积函数含绝对值或分段 | 分段计算后求和 |

## 三、解题技巧总结

### 3.1 积分计算优先级

```
1. 观察被积函数形式
2. 尝试凑微分（第一类换元）
3. 若不行，尝试第二类换元（根式代换）
4. 乘积形式考虑分部积分
5. 利用对称性、周期性简化
```

### 3.2 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 不定积分忘记加 $C$ | 必须加上积分常数 |
| 定积分换元不换限 | 换元后必须更换积分上下限 |
| 变限积分求导忘记链式法则 | 上限是函数时要乘以内函数导数 |
| 奇偶性判断错误 | 先确认积分区间是否对称 |

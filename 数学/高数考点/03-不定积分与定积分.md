# 考点3：不定积分与定积分（换元/分部）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 15-18分
>
> **考法**：积分计算是数学二的核心能力，不定积分、定积分、变限积分求导每年必考。

---

## 一、核心知识框架

### 1.1 不定积分基本公式

| 基本积分公式 | 说明 |
|-------------|------|
| $\int x^n dx = \frac{x^{n+1}}{n+1} + C$ ($n \neq -1$) | 幂函数积分 |
| $\int \frac{1}{x} dx = \ln|x| + C$ | 对数积分 |
| $\int e^x dx = e^x + C$ | 指数积分 |
| $\int a^x dx = \frac{a^x}{\ln a} + C$ | 一般指数 |
| $\int \sin x dx = -\cos x + C$ | 三角积分 |
| $\int \cos x dx = \sin x + C$ | 三角积分 |
| $\int \frac{1}{1+x^2} dx = \arctan x + C$ | 反三角积分 |
| $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$ | 反三角积分 |
| $\int \sec^2 x dx = \tan x + C$ | 正切积分 |
| $\int \csc^2 x dx = -\cot x + C$ | 余切积分 |

### 1.2 换元积分法

**第一类换元法（凑微分法）**：

$$\int f(\varphi(x)) \varphi'(x) dx = \int f(u) du \quad (u = \varphi(x))$$

**常见凑微分形式**：
- $\int f(ax+b) dx = \frac{1}{a} \int f(ax+b) d(ax+b)$
- $\int f(x^n) x^{n-1} dx = \frac{1}{n} \int f(x^n) d(x^n)$
- $\int f(e^x) e^x dx = \int f(e^x) d(e^x)$
- $\int f(\ln x) \frac{1}{x} dx = \int f(\ln x) d(\ln x)$

**第二类换元法**：

$$\int f(x) dx = \int f(\varphi(t)) \varphi'(t) dt \quad (x = \varphi(t))$$

**常见代换**：
- 含 $\sqrt{a^2 - x^2}$：令 $x = a\sin t$
- 含 $\sqrt{a^2 + x^2}$：令 $x = a\tan t$
- 含 $\sqrt{x^2 - a^2}$：令 $x = a\sec t$

### 1.3 分部积分法

$$\int u dv = uv - \int v du$$

**选择 $u$ 的顺序（反三角、对数、幂函数、三角、指数）**：

| 被积函数类型 | $u$ 的选择 | $dv$ 的选择 |
|-------------|-----------|------------|
| $x^n e^{ax}$ | $x^n$ | $e^{ax} dx$ |
| $x^n \sin x$ | $x^n$ | $\sin x dx$ |
| $x^n \ln x$ | $\ln x$ | $x^n dx$ |
| $e^{ax} \sin bx$ | $\sin bx$ 或 $e^{ax}$ | 循环求解 |

### 1.4 定积分基本定理

**牛顿-莱布尼茨公式**：

$$\int_a^b f(x) dx = F(b) - F(a) \quad (F'(x) = f(x))$$

**变限积分求导**：

$$\frac{d}{dx} \int_{a(x)}^{b(x)} f(t) dt = f(b(x)) \cdot b'(x) - f(a(x)) \cdot a'(x)$$

### 1.5 定积分计算技巧

| 技巧 | 适用条件 | 方法 |
|------|---------|------|
| 奇偶性 | 对称区间 $[-a, a]$ | 奇函数积分为 0，偶函数积分 = $2\int_0^a$ |
| 周期性 | $f(x)$ 周期为 $T$ | $\int_a^{a+T} f(x) dx = \int_0^T f(x) dx$ |
| 点火公式 | $\int_0^{\pi/2} \sin^n x dx$ | $I_n = \frac{n-1}{n} I_{n-2}$ |
| 分段积分 | 被积函数含绝对值或分段 | 分段计算后求和 |

## 三、解题技巧总结

### 3.1 积分计算优先级

```
1. 观察被积函数形式
2. 尝试凑微分（第一类换元）
3. 若不行，尝试第二类换元（根式代换）
4. 乘积形式考虑分部积分
5. 利用对称性、周期性简化
```

### 3.2 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 不定积分忘记加 $C$ | 必须加上积分常数 |
| 定积分换元不换限 | 换元后必须更换积分上下限 |
| 变限积分求导忘记链式法则 | 上限是函数时要乘以内函数导数 |
| 奇偶性判断错误 | 先确认积分区间是否对称 |

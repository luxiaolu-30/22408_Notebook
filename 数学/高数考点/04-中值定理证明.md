>
> **考法**：中值定理证明是解答题第 18 题的固定考点，难度较大，需要专项突破。

## 一、核心知识框架

### 1.1 三大中值定理

#### 罗尔定理（Rolle's Theorem）

**条件**：
1. $f(x)$ 在 $[a,b]$ 上连续
2. $f(x)$ 在 $(a,b)$ 内可导
3. $f(a) = f(b)$

**结论**：存在 $\xi \in (a,b)$，使得 $f'(\xi) = 0$

#### 拉格朗日中值定理（Lagrange's Theorem）

**条件**：
1. $f(x)$ 在 $[a,b]$ 上连续
2. $f(x)$ 在 $(a,b)$ 内可导

**结论**：存在 $\xi \in (a,b)$，使得 $f(b) - f(a) = f'(\xi)(b-a)$

#### 柯西中值定理（Cauchy's Theorem）

**条件**：
1. $f(x)$、$g(x)$ 在 $[a,b]$ 上连续
2. $f(x)$、$g(x)$ 在 $(a,b)$ 内可导
3. $g'(x) \neq 0$

**结论**：存在 $\xi \in (a,b)$，使得 $\frac{f(b)-f(a)}{g(b)-g(a)} = \frac{f'(\xi)}{g'(\xi)}$

### 1.2 定理之间的关系

```
罗尔定理 ← 拉格朗日定理 ← 柯西定理
（特殊）   （一般）       （更一般）
```

### 1.3 解题框架

**中值定理证明题的一般步骤**：

1. **分析结论**：确定要证的等式中含有什么（导数和差商）
2. **选择定理**：根据结论形式选择合适的中值定理
3. **构造辅助函数**：这是最关键的步骤
4. **验证条件**：确认辅助函数满足定理条件
5. **应用定理**：得出结论

### 1.4 构造辅助函数的常用方法

| 结论形式 | 辅助函数构造方法 | 使用定理 |
|---------|-----------------|---------|
| $f'(\xi) = 0$ | 找 $F(x)$ 使 $F'(x) = f(x)$ | 罗尔定理 |
| $f'(\xi) = k$ | $F(x) = f(x) - kx$ | 罗尔定理 |
| $f(b)-f(a) = f'(\xi)(b-a)$ | 直接用原函数 | 拉格朗日定理 |
| 含 $f(\xi) + f'(\xi)$ | 乘以积分因子 $e^x$ | 罗尔定理 |
| 含 $nf(\xi) + \xi f'(\xi)$ | 乘以 $x^{n-1}$ | 罗尔定理 |

## 三、解题技巧总结

### 3.1 中值定理选择指南

| 题目特征 | 推荐定理 |
|---------|---------|
| 要证 $f'(\xi) = 0$ | 罗尔定理 |
| 要证 $f(b)-f(a) = f'(\xi)(b-a)$ | 拉格朗日定理 |
| 要证含两个函数的商的形式 | 柯西定理 |

### 3.2 常见辅助函数构造

| 目标等式 | 辅助函数 $F(x)$ |
|---------|----------------|
| $f'(\xi) + f(\xi) = 0$ | $F(x) = e^x \cdot f(x)$ |
| $f'(\xi) - f(\xi) = 0$ | $F(x) = e^{-x} \cdot f(x)$ |
| $\xi f'(\xi) + f(\xi) = 0$ | $F(x) = x \cdot f(x)$ |
| $f'(\xi) = k$ | $F(x) = f(x) - kx$ |
| $f'(\xi) = \frac{f(\xi)-f(a)}{b-a}$ | $F(x) = f(x) - f(a) - \frac{f(b)-f(a)}{b-a}(x-a)$ |

### 3.3 证明题常见模板

**类型1：证明存在 $\xi$ 使 $f'(\xi) = 0$**
1. 构造 $F(x)$ 使 $F'(x) = f(x)$
2. 找两点使 $F(a) = F(b)$
3. 应用罗尔定理

**类型2：证明存在 $\xi$ 使含 $f'(\xi)$ 的等式成立**
1. 将等式变形为 $f'(\xi) = k$ 或类似形式
2. 构造辅助函数
3. 验证端点值相等
4. 应用罗尔定理

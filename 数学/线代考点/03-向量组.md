# 线代考点3：向量组（线性相关性/秩/向量空间/基与坐标）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 5-12分
>
> **考法**：向量组是线代的核心理论基础。选择题常考线性相关/无关的判断、向量组的秩；解答题中向量组知识贯穿线性方程组、特征值、相似对角化。

---

## 一、核心知识框架

### 1.1 线性组合与线性表示

**定义**：给定向量组 $\beta, \alpha_1, \alpha_2, \ldots, \alpha_m$，若存在常数 $k_1, k_2, \ldots, k_m$ 使得：

$$\beta = k_1\alpha_1 + k_2\alpha_2 + \cdots + k_m\alpha_m$$

则称 $\beta$ 能由向量组 $\{\alpha_i\}$ **线性表示**（线性组合）。

**充要条件**：$\beta$ 能由 $\alpha_1, \ldots, \alpha_m$ 线性表示 $\Leftrightarrow$ 方程组 $Ax = \beta$ 有解 $\Leftrightarrow$ $r(\alpha_1, \ldots, \alpha_m) = r(\alpha_1, \ldots, \alpha_m, \beta)$

> **推论**：向量组中某向量能由其余向量线性表示 $\Leftrightarrow$ 向量组线性相关。

---

### 1.2 线性相关与线性无关

**定义**：对向量组 $\alpha_1, \alpha_2, \ldots, \alpha_m$，若存在**不全为零**的数 $k_1, \ldots, k_m$ 使得：

$$k_1\alpha_1 + k_2\alpha_2 + \cdots + k_m\alpha_m = 0$$

则称向量组**线性相关**；若只有当 $k_1 = k_2 = \cdots = k_m = 0$ 时等式才成立，则称**线性无关**。

#### 判断方法汇总

| 方法 | 内容 |
|------|------|
| **定义法** | 设 $k_1\alpha_1 + \cdots + k_m\alpha_m = 0$，看是否有非零解 |
| **秩判断** | $r(\alpha_1, \ldots, \alpha_m) = m$ 则无关；$< m$ 则相关 |
| **行列式判断** | $n$ 个 $n$ 维向量：$|A| \neq 0$ 则无关；$= 0$ 则相关 |
| **方程组角度** | 齐次方程组 $Ax = 0$ 只有零解 $\Leftrightarrow$ 列向量组无关 |

#### 常用结论

| 结论 | 说明 |
|------|------|
| 含零向量的向量组 | 必线性相关 |
| 两个向量线性相关 $\Leftrightarrow$ 对应分量成比例 | 几何上共线 |
| $n+1$ 个 $n$ 维向量 | 必线性相关 |
| 向量个数 $>$ 向量维数 | 必线性相关 |
| 整体无关 $\Rightarrow$ 部分无关 | 逆否：部分相关 $\Rightarrow$ 整体相关 |
| 部分无关 $\nRightarrow$ 整体无关 | 需单独判断 |
| 延长（增维）无关 $\Rightarrow$ 原向量组无关 | 无关向量组延长分量仍无关 |
| 缩短相关 $\Rightarrow$ 原向量组相关 | 相关向量组缩短分量仍相关 |

---

### 1.3 向量组的秩

**定义**：向量组的极大线性无关组所含向量的个数，称为这个向量组的**秩**。

**矩阵的秩与向量组秩的关系**：
- 矩阵的秩 = 行向量组的秩 = 列向量组的秩
- 求向量组的秩：将向量排成矩阵，初等行变换化为行阶梯形，非零行数即为秩

#### 极大线性无关组

**定义**：向量组的一个部分组 $\{\alpha_{i_1}, \ldots, \alpha_{i_r}\}$ 若满足：
1. 线性无关
2. 向量组中任意 $r+1$ 个向量（或任一向量添加到该组中）都线性相关

则称为**极大线性无关组**（极大无关组不唯一，但所含向量个数相同）。

**求法**：将向量作为列排成矩阵，初等行变换化为行阶梯形，**主元列对应的原向量**构成一个极大无关组。

---

### 1.4 向量组的等价

**定义**：若向量组 (I) 中每个向量都能由向量组 (II) 线性表示，称 (I) 能由 (II) 线性表示。若两个向量组可以互相线性表示，则称它们**等价**。

**性质**：
- 等价向量组的秩相等（反之不成立）
- 任一向量组和它的极大无关组等价
- 向量组的任意两个极大无关组等价

## 二、向量空间

### 2.1 基本概念

| 概念 | 定义 |
|------|------|
| **向量空间** | 对加法和数乘封闭的非空向量集合 |
| **子空间** | 向量空间的子集，本身也是向量空间 |
| **生成空间** $span(\alpha_1, \ldots, \alpha_m)$ | 由向量组所有线性组合构成的集合 |
| **基** | 向量空间的一个极大线性无关组 |
| **维数** | 基所含向量的个数，记为 $dim(V)$ |
| **坐标** | 向量在给定基下的线性表示系数 $(\lambda_1, \ldots, \lambda_n)^T$ |

### 2.2 基、维数、坐标

**标准基**（自然基）：$\varepsilon_1 = (1,0,\ldots,0)^T, \varepsilon_2 = (0,1,\ldots,0)^T, \ldots, \varepsilon_n = (0,0,\ldots,1)^T$

$n$ 维向量空间的任意 $n$ 个线性无关的向量都可以作为一组基。

**坐标计算**：若 $\alpha = \lambda_1\beta_1 + \lambda_2\beta_2 + \cdots + \lambda_n\beta_n$，则 $\alpha$ 在基 $\{\beta_i\}$ 下的坐标为 $(\lambda_1, \lambda_2, \ldots, \lambda_n)^T$。

### 2.3 过渡矩阵与坐标变换

设 $n$ 维向量空间的两组基为：
- 旧基：$\alpha_1, \alpha_2, \ldots, \alpha_n$
- 新基：$\beta_1, \beta_2, \ldots, \beta_n$

**过渡矩阵** $P$ 满足 $(\beta_1, \beta_2, \ldots, \beta_n) = (\alpha_1, \alpha_2, \ldots, \alpha_n) \cdot P$

**坐标变换公式**：若向量 $\xi$ 在旧基下坐标为 $x$，在新基下坐标为 $y$，则：
$$x = Py \quad \text{或} \quad y = P^{-1}x$$

> **关键**：过渡矩阵 $P$ 的第 $j$ 列是 $\beta_j$ 在旧基 $\alpha_1, \ldots, \alpha_n$ 下的坐标。

## 三、重要定理与结论

### 3.1 核心定理

| 定理 | 内容 |
|------|------|
| **定理1** | 若 $\alpha_1, \ldots, \alpha_m$ 线性无关，而 $\alpha_1, \ldots, \alpha_m, \beta$ 线性相关，则 $\beta$ 可由 $\alpha_1, \ldots, \alpha_m$ **唯一**线性表示 |
| **定理2** | 向量组线性无关 $\Leftrightarrow$ 任一向量都不能由其余向量线性表示 |
| **定理3** | 向量组线性相关 $\Leftrightarrow$ 至少有一个向量可由其余向量线性表示 |
| **定理4** | 若向量组 (I) 可由 (II) 线性表示，且 (I) 的向量个数 $>$ (II) 的，则 (I) 线性相关 |
| **定理5** | 等价向量组的秩相等；反之，秩相等的同维向量组不一定等价 |

### 3.2 向量组秩的不等式

设向量组 (I): $\alpha_1, \ldots, \alpha_s$，秩为 $r_1$；向量组 (II): $\beta_1, \ldots, \beta_t$，秩为 $r_2$：

- $r(\mathrm{I} \cup \mathrm{II}) \leq r_1 + r_2$
- 若 (I) 可由 (II) 线性表示，则 $r_1 \leq r_2$

## 四、解题技巧总结

### 4.1 线性相关性判断流程

```
判断线性相关性
│
├─ 是 n 个 n 维向量？
│   ├─ 是 → 算行列式 |A|
│   │       ├─ |A| ≠ 0 → 线性无关
│   │       └─ |A| = 0 → 线性相关
│   └─ 否 → 继续 ↓
│
├─ 向量个数 > 维数？
│   ├─ 是 → 线性相关（必相关）
│   └─ 否 → 继续 ↓
│
├─ 含零向量？
│   ├─ 是 → 线性相关
│   └─ 否 → 继续 ↓
│
└─ 一般方法：构造矩阵求秩
    ├─ r = 向量个数 → 线性无关
    └─ r < 向量个数 → 线性相关
```

### 4.2 极大无关组求法

1. 将向量作为**列**向量排成矩阵 $A$
2. 对 $A$ 进行初等**行**变换化为行阶梯形
3. 找出主元所在的列号
4. 主元列对应的**原矩阵 $A$ 中的列向量**即构成一个极大无关组

### 4.3 过渡矩阵求法

**已知**：旧基 $\alpha_1, \ldots, \alpha_n$，新基 $\beta_1, \ldots, \beta_n$

**方法**：$P = (\alpha_1, \ldots, \alpha_n)^{-1} \cdot (\beta_1, \ldots, \beta_n)$

即对矩阵 $((\alpha_1, \ldots, \alpha_n) \mid (\beta_1, \ldots, \beta_n))$ 做初等行变换，左边化为单位矩阵时，右边即为 $P$。

## 五、常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 向量组秩相等就认为是等价向量组 | 等价要求能互相线性表示，仅秩相等不够 |
| 延长向量组：无关变长仍无关，相关变长仍相关 | 这是对的！但反过来不成立（无关缩短可能变相关） |
| 混淆行向量组与列向量组的求极大无关组方法 | 列向量求极大无关组用行变换，行向量求极大无关组应做列变换或将行转置为列 |
| 过渡矩阵 $P$ 的方向搞混 | $(\beta_1,\ldots,\beta_n) = (\alpha_1,\ldots,\alpha_n)P$，$P$ 的第 $j$ 列是 $\beta_j$ 在旧基下的坐标 |
| 线性相关判断时忽略"维数 < 个数"的隐含条件 | $n+1$ 个 $n$ 维向量必相关，可直接用 |

# 线代考点4：特征值与特征向量

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 10-12分
>
> **考法**：特征值与特征向量是解答题第 23 题的固定考点，是矩阵相似对角化的基础。

---

## 一、核心知识框架

### 1.1 定义

**特征值**：若 $A\alpha = \lambda\alpha$（$\alpha \neq 0$），则 $\lambda$ 是 $A$ 的特征值。

**特征向量**：上式中的 $\alpha$ 是对应于 $\lambda$ 的特征向量。

### 1.2 特征值与特征向量的求法

**步骤**：
1. 写出特征方程 $|\lambda E - A| = 0$
2. 解特征方程得特征值 $\lambda_1, \lambda_2, \ldots, \lambda_n$
3. 对每个 $\lambda_i$，解 $(\lambda_i E - A)x = 0$ 得特征向量

### 1.3 特征值的性质

| 性质 | 公式 |
|------|------|
| 特征值之和 | $\sum \lambda_i = \sum a_{ii} = tr(A)$（迹）|
| 特征值之积 | $\prod \lambda_i = |A|$ |
| 可逆矩阵的特征值 | 若 $A$ 可逆，则 $\lambda \neq 0$，且 $A^{-1}$ 的特征值为 $1/\lambda$ |
| 幂的特征值 | $A^k$ 的特征值为 $\lambda^k$ |
| 多项式的特征值 | $f(A)$ 的特征值为 $f(\lambda)$ |

### 1.4 特征向量的性质

| 性质 | 内容 |
|------|------|
| 不同特征值对应的特征向量线性无关 | 若 $\lambda_1 \neq \lambda_2$，则 $\alpha_1, \alpha_2$ 线性无关 |
| 重特征值的特征向量 | 可能线性相关，也可能线性无关 |
| 实对称矩阵 | 不同特征值对应的特征向量正交 |

### 1.5 特殊矩阵的特征值

| 矩阵类型 | 特征值特点 |
|---------|-----------|
| 实对称矩阵 | 特征值都是实数 |
| 正交矩阵 | 特征值的模为 1 |
| 正定矩阵 | 特征值全大于 0 |
| 幂等矩阵（$A^2 = A$）| 特征值为 0 或 1 |
| 对合矩阵（$A^2 = E$）| 特征值为 $\pm 1$ |

## 三、解题技巧总结

### 3.1 特征值计算步骤

1. 写出 $|\lambda E - A|$
2. 展开行列式得到特征多项式
3. 解特征方程 $|\lambda E - A| = 0$
4. 得到所有特征值

### 3.2 特征向量计算步骤

1. 对每个特征值 $\lambda_i$
2. 写出 $(\lambda_i E - A)$
3. 解齐次方程组 $(\lambda_i E - A)x = 0$
4. 基础解系的向量就是对应 $\lambda_i$ 的特征向量

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 特征方程写错 | $|\lambda E - A|$，不是 $|A - \lambda E|$（差一个符号 $(-1)^n$）|
| 特征向量计算错误 | 必须解齐次方程组 $(\lambda E - A)x = 0$ |
| 特征值之和/积公式记错 | $\sum \lambda_i = tr(A)$，$\prod \lambda_i = |A|$ |
| 重特征值只写一个特征向量 | 可能有多线性无关的特征向量 |

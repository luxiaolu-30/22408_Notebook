## 一、核心知识框架

### 1.1 矩阵的基本运算

| 运算 | 定义 | 注意 |
|------|------|------|
| 加法 | $(A+B)_{ij} = a_{ij} + b_{ij}$ | 同型矩阵才能相加 |
| 数乘 | $(kA)_{ij} = k \cdot a_{ij}$ | 每个元素都乘 |
| 乘法 | $(AB)_{ij} = \sum_{k=1}^n a_{ik}b_{kj}$ | $A$ 的列数 = $B$ 的行数 |
| 转置 | $(A^T)_{ij} = a_{ji}$ | 行列互换 |

### 1.2 矩阵乘法的性质

**⚠️ 重要提醒**：矩阵乘法**不满足交换律**！

- $AB \neq BA$（一般情况）
- $AB = 0 \nRightarrow A = 0$ 或 $B = 0$
- $AB = AC \nRightarrow B = C$（消去律不成立）

**运算律**：
- $(AB)C = A(BC)$（结合律）
- $A(B+C) = AB + AC$（分配律）
- $(AB)^T = B^T A^T$
- $(AB)^{-1} = B^{-1} A^{-1}$

### 1.3 逆矩阵

**定义**：若 $AB = BA = E$，则 $B = A^{-1}$

**可逆的充要条件**：$|A| \neq 0$

**求逆方法**：

| 方法 | 公式/步骤 |
|------|----------|
| 伴随矩阵法 | $A^{-1} = \frac{1}{|A|} A^*$ |
| 初等行变换 | $(A|E) \xrightarrow{行变换} (E|A^{-1})$ |
| 分块矩阵法 | 对分块矩阵求逆 |

**伴随矩阵的性质**：
- $AA^* = A^*A = |A|E$
- $|A^*| = |A|^{n-1}$
- $(A^*)^{-1} = (A^{-1})^* = \frac{A}{|A|}$

### 1.4 矩阵的秩

**定义**：矩阵中非零子式的最高阶数

**性质**：
- $0 \leq r(A) \leq \min(m, n)$
- $r(A) = r(A^T)$
- $r(A+B) \leq r(A) + r(B)$
- $r(AB) \leq \min(r(A), r(B))$
- 若 $A$ 可逆，则 $r(AB) = r(B)$，$r(CA) = r(A)$

**求秩方法**：初等行变换化为行阶梯形，非零行的个数即为秩。

### 1.5 初等变换与初等矩阵

| 初等变换 | 初等矩阵 |
|---------|---------|
| 交换两行（列）| 交换 $E$ 的两行（列）|
| 某行（列）乘 $k$ | $E$ 的对角线某元素换为 $k$ |
| 某行（列）的 $k$ 倍加到另一行（列）| $E$ 的某个非对角线位置为 $k$ |

**重要结论**：
- 初等矩阵都可逆，其逆矩阵也是初等矩阵
- $A \xrightarrow{行变换} B \Leftrightarrow PA = B$（$P$ 是初等矩阵的乘积）
- $A \xrightarrow{列变换} B \Leftrightarrow AQ = B$（$Q$ 是初等矩阵的乘积）

## 三、解题技巧总结

### 3.1 矩阵求逆步骤

**方法1：伴随矩阵法（适合低阶）**
1. 计算 $|A|$，验证 $|A| \neq 0$
2. 计算所有代数余子式 $A_{ij}$
3. 写出伴随矩阵 $A^* = (A_{ji})$
4. $A^{-1} = \frac{1}{|A|} A^*$

**方法2：初等行变换法（适合高阶）**
1. 写出 $(A|E)$
2. 对 $A$ 部分进行初等行变换化为 $E$
3. 此时 $E$ 部分变为 $A^{-1}$

### 3.2 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 矩阵乘法不满足交换律 | $AB \neq BA$，注意顺序 |
| 逆矩阵公式记错 | $A^{-1} = \frac{A^*}{|A|}$，不要忘记除以 $|A|$ |
| 伴随矩阵元素位置错误 | $A^* = (A_{ji})$，注意转置 |
| 矩阵求秩时变换错误 | 只能用初等行变换，或同时用行和列变换 |

# 线代考点5：矩阵相似对角化

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 14/15年必考，分值 10-12分
>
> **考法**：矩阵相似对角化是解答题第 23 题的核心，判断是否可对角化、求可逆矩阵 $P$ 是重点。

---

## 一、核心知识框架

### 1.1 相似矩阵的定义

**定义**：若存在可逆矩阵 $P$，使 $P^{-1}AP = B$，则称 $A$ 与 $B$ 相似，记作 $A \sim B$。

### 1.2 相似矩阵的性质

| 性质 | 内容 |
|------|------|
| 自反性 | $A \sim A$ |
| 对称性 | $A \sim B \Rightarrow B \sim A$ |
| 传递性 | $A \sim B, B \sim C \Rightarrow A \sim C$ |
| 秩不变 | $r(A) = r(B)$ |
| 特征值相同 | $A$ 与 $B$ 有相同的特征值 |
| 行列式相同 | $|A| = |B|$ |
| 迹相同 | $tr(A) = tr(B)$ |

### 1.3 矩阵可对角化的条件

| 条件 | 结论 |
|------|------|
| 有 $n$ 个线性无关的特征向量 | 可对角化 |
| 有 $n$ 个互异特征值 | 一定可对角化（充分条件）|
| 实对称矩阵 | 一定可对角化，且可正交对角化 |
| $k$ 重特征值有 $k$ 个线性无关特征向量 | 该特征值满足条件 |

**⚠️ 重要提醒**：有 $n$ 个互异特征值是可对角化的**充分不必要条件**！

### 1.4 对角化步骤

1. 求特征值 $\lambda_1, \lambda_2, \ldots, \lambda_n$
2. 对每个特征值，求特征向量
3. 判断是否有 $n$ 个线性无关的特征向量
4. 若可对角化，令 $P = (\alpha_1, \alpha_2, \ldots, \alpha_n)$
5. 则 $P^{-1}AP = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$

### 1.5 实对称矩阵的正交对角化

**步骤**：
1. 求特征值
2. 求特征向量
3. 对重特征值的特征向量进行**正交化**（施密特正交化）
4. 对所有特征向量进行**单位化**
5. 令 $Q = (e_1, e_2, \ldots, e_n)$，则 $Q^{-1}AQ = Q^TAQ = \Lambda$

**施密特正交化公式**：
- $\beta_1 = \alpha_1$
- $\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1$
- $\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2$

## 三、解题技巧总结

### 3.1 对角化判断步骤

1. 求特征值
2. 对每个 $k$ 重特征值 $\lambda_i$
3. 计算 $r(\lambda_i E - A)$
4. 若 $n - r(\lambda_i E - A) = k$，则该特征值满足条件
5. 所有特征值都满足 $\Rightarrow$ 可对角化

### 3.2 正交对角化步骤

1. 求特征值
2. 求特征向量
3. 对重特征值的特征向量正交化
4. 对所有特征向量单位化
5. 写出正交矩阵 $Q$

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 对角化条件判断错误 | 必须有 $n$ 个线性无关特征向量 |
| 正交化忘记单位化 | 正交对角化需要单位化 |
| $P$ 的列向量顺序与 $\Lambda$ 对角线元素不对应 | 注意对应关系 |
| 实对称矩阵特征向量不正交 | 不同特征值的特征向量自然正交，重特征值需要正交化 |

## 一、核心知识框架

### 1.1 二次型的概念

**二次型**：$f(x_1, x_2, \ldots, x_n) = x^TAx$，其中 $A$ 是实对称矩阵。

**标准形**：$f = d_1y_1^2 + d_2y_2^2 + \cdots + d_ny_n^2$（只含平方项）

**规范形**：$f = z_1^2 + \cdots + z_p^2 - z_{p+1}^2 - \cdots - z_r^2$（系数为 $\pm 1$ 或 $0$）

### 1.2 二次型的矩阵表示

$$f(x_1, x_2, \ldots, x_n) = \sum_{i=1}^n \sum_{j=1}^n a_{ij}x_ix_j = x^TAx$$

其中 $A$ 是实对称矩阵（$A = A^T$）。

### 1.3 化二次型为标准形的方法

#### 方法1：正交变换法（重点）

**步骤**：
1. 写出二次型的矩阵 $A$
2. 求 $A$ 的特征值 $\lambda_1, \lambda_2, \ldots, \lambda_n$
3. 求对应的特征向量
4. 正交化、单位化
5. 写出正交矩阵 $Q = (e_1, e_2, \ldots, e_n)$
6. 令 $x = Qy$，则 $f = \lambda_1y_1^2 + \lambda_2y_2^2 + \cdots + \lambda_ny_n^2$

**注意**：正交变换下，标准形的系数就是特征值。

#### 方法2：配方法

**步骤**：
1. 如果含平方项，先集中含该变量的项
2. 配方，消去交叉项
3. 依次对每个变量配方
4. 写出标准形

### 1.4 正定二次型

**定义**：若对任意 $x \neq 0$，都有 $x^TAx > 0$，则称 $f$ 是正定二次型。

**正定的充要条件**：

| 条件 | 内容 |
|------|------|
| 特征值全大于 0 | $\lambda_i > 0$ |
| 顺序主子式全大于 0 | $\Delta_i > 0$ |
| 正惯性指数为 $n$ | $p = n$ |
| 存在可逆矩阵 $C$，使 $A = C^TC$ | 合同于单位矩阵 |

### 1.5 惯性定理

**内容**：二次型的规范形是唯一的。

**正惯性指数**：标准形中正平方项的个数 $p$

**负惯性指数**：标准形中负平方项的个数 $q$

**秩**：$r = p + q$

## 三、解题技巧总结

### 3.1 正交变换法步骤

1. 写出矩阵 $A$
2. 求特征值
3. 求特征向量
4. 正交化、单位化
5. 写出正交矩阵 $Q$
6. 标准形系数 = 特征值

### 3.2 正定性判断方法

| 方法 | 判断条件 |
|------|---------|
| 特征值法 | 所有 $\lambda_i > 0$ |
| 顺序主子式法 | 所有 $\Delta_i > 0$ |
| 定义法 | 对任意 $x \neq 0$，$x^TAx > 0$ |

### 3.3 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 正交变换法忘记正交化 | 重特征值的特征向量需要正交化 |
| 正交变换法忘记单位化 | 所有特征向量都要单位化 |
| 正定性判断用错条件 | 顺序主子式全 $> 0$，不是行列式 $> 0$ |
| 配方法配不完全 | 依次对每个变量配方 |

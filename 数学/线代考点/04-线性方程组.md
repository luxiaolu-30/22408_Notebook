# 线代考点3：线性方程组（解的结构/通解/基础解系）

> **配套真题**：[[计算机基础/数学/数学二历年真题]] — 出现频率 15/15年必考，分值 10-12分
>
> **考法**：线性方程组是解答题的核心考点，解的结构、通解、基础解系是重点。

---

## 一、核心知识框架

### 1.1 线性方程组的形式

**齐次方程组**：$Ax = 0$

**非齐次方程组**：$Ax = b$（$b \neq 0$）

其中 $A$ 是 $m \times n$ 系数矩阵，$x$ 是 $n$ 维未知向量。

### 1.2 解的判定

| 方程组类型 | 有解条件 | 解的唯一性 |
|-----------|---------|-----------|
| 齐次 $Ax = 0$ | 必有零解 | $r(A) = n$ 时只有零解 |
| 齐次 $Ax = 0$ | 必有零解 | $r(A) < n$ 时有非零解 |
| 非齐次 $Ax = b$ | $r(A) = r(\bar{A})$ 时有解 | $r(A) = r(\bar{A}) = n$ 时唯一解 |
| 非齐次 $Ax = b$ | $r(A) \neq r(\bar{A})$ 时无解 | $r(A) = r(\bar{A}) < n$ 时无穷多解 |

### 1.3 齐次方程组的基础解系

**定义**：若 $\xi_1, \xi_2, \ldots, \xi_s$ 满足：
1. 线性无关
2. 都是 $Ax = 0$ 的解
3. $Ax = 0$ 的任一解都可由它们线性表示

则称 $\xi_1, \xi_2, \ldots, \xi_s$ 是 $Ax = 0$ 的一个基础解系。

**基础解系含解向量的个数**：$n - r(A)$

**通解**：$x = c_1\xi_1 + c_2\xi_2 + \cdots + c_{n-r}\xi_{n-r}$

### 1.4 非齐次方程组的解的结构

**通解 = 特解 + 齐次通解**

$$x = \eta^* + c_1\xi_1 + c_2\xi_2 + \cdots + c_{n-r}\xi_{n-r}$$

其中 $\eta^*$ 是一个特解，$\xi_1, \ldots, \xi_{n-r}$ 是对应齐次方程组的基础解系。

### 1.5 求解步骤

**齐次方程组 $Ax = 0$**：
1. 对 $A$ 进行初等行变换化为行最简形
2. 确定自由变量
3. 令自由变量轮流为 1，其余为 0，求出基础解系
4. 写出通解

**非齐次方程组 $Ax = b$**：
1. 对增广矩阵 $\bar{A} = (A|b)$ 进行初等行变换
2. 判断是否有解（$r(A) = r(\bar{A})$？）
3. 求一个特解（令自由变量全为 0）
4. 求对应齐次方程组的基础解系
5. 写出通解

## 三、解题技巧总结

### 3.1 基础解系求解步骤

1. 将系数矩阵化为行最简形
2. 找出主元列和自由列
3. 对每个自由变量，令其为 1，其余自由变量为 0
4. 求出主变量的值
5. 得到基础解系的各个向量

### 3.2 常见陷阱

| 陷阱 | 正确做法 |
|------|---------|
| 基础解系向量个数错误 | 应为 $n - r(A)$ 个 |
| 非齐次通解忘记加特解 | 通解 = 特解 + 齐次通解 |
| 解的判定条件记错 | $r(A) = r(\bar{A})$ 有解，$<$ 无穷多解 |
| 行变换错误 | 只能用初等行变换 |

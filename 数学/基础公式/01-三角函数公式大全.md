## 一、基本关系

### 1.1 倒数关系

| 公式 | 记忆 |
|------|------|
| $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$ | 正切 = 正 ÷ 余 |
| $\cot\alpha = \frac{\cos\alpha}{\sin\alpha}$ | 余切 = 余 ÷ 正 |
| $\sin\alpha \cdot \csc\alpha = 1$ | 正弦 × 余割 = 1 |
| $\cos\alpha \cdot \sec\alpha = 1$ | 余弦 × 正割 = 1 |
| $\tan\alpha \cdot \cot\alpha = 1$ | 正切 × 余切 = 1 |

### 1.2 商数关系

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}, \quad \cot\alpha = \frac{\cos\alpha}{\sin\alpha}$$

### 1.3 平方关系

| 公式 | 变形 |
|------|------|
| $\sin^2\alpha + \cos^2\alpha = 1$ | $1 - \sin^2\alpha = \cos^2\alpha$ |
| $1 + \tan^2\alpha = \sec^2\alpha$ | $\sec^2\alpha - 1 = \tan^2\alpha$ |
| $1 + \cot^2\alpha = \csc^2\alpha$ | $\csc^2\alpha - 1 = \cot^2\alpha$ |

## 二、诱导公式（奇变偶不变，符号看象限）

### 2.1 口诀

> **奇变偶不变**：$k \cdot \frac{\pi}{2}$ 中 $k$ 为奇数则函数名变（sin↔cos，tan↔cot），偶数则不变
>
> **符号看象限**：把 $\alpha$ 看作锐角，看原函数的符号

### 2.2 常用诱导公式表

| 角度 | $\sin$ | $\cos$ | $\tan$ |
|------|--------|--------|--------|
| $-\alpha$ | $-\sin\alpha$ | $\cos\alpha$ | $-\tan\alpha$ |
| $\pi - \alpha$ | $\sin\alpha$ | $-\cos\alpha$ | $-\tan\alpha$ |
| $\pi + \alpha$ | $-\sin\alpha$ | $-\cos\alpha$ | $\tan\alpha$ |
| $2\pi - \alpha$ | $-\sin\alpha$ | $\cos\alpha$ | $-\tan\alpha$ |
| $\frac{\pi}{2} - \alpha$ | $\cos\alpha$ | $\sin\alpha$ | $\cot\alpha$ |
| $\frac{\pi}{2} + \alpha$ | $\cos\alpha$ | $-\sin\alpha$ | $-\cot\alpha$ |
| $\frac{3\pi}{2} - \alpha$ | $-\cos\alpha$ | $-\sin\alpha$ | $\cot\alpha$ |
| $\frac{3\pi}{2} + \alpha$ | $-\cos\alpha$ | $\sin\alpha$ | $-\cot\alpha$ |

## 三、和差公式

| 公式 | 记忆 |
|------|------|
| $\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$ | 正余余正，符号同原 |
| $\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$ | 余余正正，符号相反 |
| $\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$ | 上同下异 |

---

## 四、倍角公式

| 公式 | 变形 |
|------|------|
| $\sin 2\alpha = 2\sin\alpha\cos\alpha$ | — |
| $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$ | $= 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$ |
| $\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$ | — |

### 4.1 降幂公式（考研高频）

| 公式 |
|------|
| $\sin^2\alpha = \frac{1 - \cos 2\alpha}{2}$ |
| $\cos^2\alpha = \frac{1 + \cos 2\alpha}{2}$ |
| $\sin\alpha\cos\alpha = \frac{1}{2}\sin 2\alpha$ |

---

## 五、半角公式

| 公式 |
|------|
| $\sin\frac{\alpha}{2} = \pm\sqrt{\frac{1 - \cos\alpha}{2}}$ |
| $\cos\frac{\alpha}{2} = \pm\sqrt{\frac{1 + \cos\alpha}{2}}$ |
| $\tan\frac{\alpha}{2} = \pm\sqrt{\frac{1 - \cos\alpha}{1 + \cos\alpha}} = \frac{\sin\alpha}{1 + \cos\alpha} = \frac{1 - \cos\alpha}{\sin\alpha}$ |

---

## 六、积化和差公式

| 公式 |
|------|
| $\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta) + \sin(\alpha-\beta)]$ |
| $\cos\alpha\sin\beta = \frac{1}{2}[\sin(\alpha+\beta) - \sin(\alpha-\beta)]$ |
| $\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha+\beta) + \cos(\alpha-\beta)]$ |
| $\sin\alpha\sin\beta = -\frac{1}{2}[\cos(\alpha+\beta) - \cos(\alpha-\beta)]$ |

---

## 七、和差化积公式

| 公式 |
|------|
| $\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$ |
| $\sin\alpha - \sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$ |
| $\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$ |
| $\cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$ |

---

## 八、最常用特殊值

| 角度 | $0$ | $\frac{\pi}{6}$ | $\frac{\pi}{4}$ | $\frac{\pi}{3}$ | $\frac{\pi}{2}$ |
|------|-----|-----------------|-----------------|-----------------|-----------------|
| $\sin$ | $0$ | $\frac{1}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{3}}{2}$ | $1$ |
| $\cos$ | $1$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{2}}{2}$ | $\frac{1}{2}$ | $0$ |
| $\tan$ | $0$ | $\frac{\sqrt{3}}{3}$ | $1$ | $\sqrt{3}$ | $\infty$ |

## 九、考研高频三角恒等变换

| 变换 | 用途 |
|------|------|
| $1 = \sin^2 x + \cos^2 x$ | 常数代换 |
| $\sin^2 x = \frac{1 - \cos 2x}{2}$ | 降幂积分 |
| $\cos^2 x = \frac{1 + \cos 2x}{2}$ | 降幂积分 |
| $\sin x \cos x = \frac{1}{2}\sin 2x$ | 化简乘积 |
| $a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$ | 辅助角公式 |
| $\tan^2 x + 1 = \sec^2 x$ | 积分换元 |

### 9.1 辅助角公式

$$a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \varphi)$$

其中 $\tan\varphi = \frac{b}{a}$，$\varphi$ 所在象限与 $(a, b)$ 相同。

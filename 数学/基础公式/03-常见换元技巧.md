## 一、第一类换元法（凑微分法）

### 1.1 核心思想

$$\int f(\varphi(x)) \varphi'(x) dx = \int f(u) du \quad (u = \varphi(x))$$

### 1.2 常见凑微分形式 ⭐

| 形式 | 凑微分 | 结果 |
|------|--------|------|
| $\int f(ax+b) dx$ | $d(ax+b) = a\,dx$ | $\frac{1}{a}\int f(ax+b) d(ax+b)$ |
| $\int f(x^n) x^{n-1} dx$ | $d(x^n) = nx^{n-1}dx$ | $\frac{1}{n}\int f(x^n) d(x^n)$ |
| $\int f(e^x) e^x dx$ | $d(e^x) = e^x dx$ | $\int f(e^x) d(e^x)$ |
| $\int f(\ln x) \frac{1}{x} dx$ | $d(\ln x) = \frac{1}{x}dx$ | $\int f(\ln x) d(\ln x)$ |
| $\int f(\sin x) \cos x dx$ | $d(\sin x) = \cos x dx$ | $\int f(\sin x) d(\sin x)$ |
| $\int f(\cos x) \sin x dx$ | $d(\cos x) = -\sin x dx$ | $-\int f(\cos x) d(\cos x)$ |
| $\int f(\tan x) \sec^2 x dx$ | $d(\tan x) = \sec^2 x dx$ | $\int f(\tan x) d(\tan x)$ |
| $\int f(\arctan x) \frac{1}{1+x^2} dx$ | $d(\arctan x) = \frac{1}{1+x^2}dx$ | $\int f(\arctan x) d(\arctan x)$ |
| $\int f(\arcsin x) \frac{1}{\sqrt{1-x^2}} dx$ | $d(\arcsin x) = \frac{1}{\sqrt{1-x^2}}dx$ | $\int f(\arcsin x) d(\arcsin x)$ |

## 二、第二类换元法

### 2.1 核心思想

$$\int f(x) dx = \int f(\varphi(t)) \varphi'(t) dt \quad (x = \varphi(t))$$

### 2.2 三角代换（根式代换）⭐⭐⭐

| 被积函数含 | 代换 | 根式化简 |
|-----------|------|---------|
| $\sqrt{a^2 - x^2}$ | $x = a\sin t$ | $\sqrt{a^2-x^2} = a\cos t$ |
| $\sqrt{a^2 + x^2}$ | $x = a\tan t$ | $\sqrt{a^2+x^2} = a\sec t$ |
| $\sqrt{x^2 - a^2}$ | $x = a\sec t$ | $\sqrt{x^2-a^2} = a\tan t$ |

### 2.3 三角代换的几何意义

利用直角三角形理解：
- $\sqrt{a^2 - x^2}$：邻边，令 $x = a\sin t$
- $\sqrt{a^2 + x^2}$：斜边，令 $x = a\tan t$
- $\sqrt{x^2 - a^2}$：对边，令 $x = a\sec t$

### 2.4 倒代换

**适用**：分母次数比分子高 2 次以上

$$\text{令 } x = \frac{1}{t}, \quad dx = -\frac{1}{t^2}dt$$

**典型**：$\int \frac{dx}{x^4\sqrt{1+x^2}}$

### 2.5 根式代换

**适用**：含 $\sqrt[n]{ax+b}$ 或 $\sqrt{\frac{ax+b}{cx+d}}$

| 形式 | 代换 |
|------|------|
| $\sqrt[n]{ax+b}$ | $t = \sqrt[n]{ax+b}$ |
| $\sqrt[n]{\frac{ax+b}{cx+d}}$ | $t = \sqrt[n]{\frac{ax+b}{cx+d}}$ |
| $\sqrt{ax^2+bx+c}$ | 先配方，再三角代换 |

### 2.6 指数代换

**适用**：含 $e^x$ 或 $a^x$

$$\text{令 } e^x = t, \quad x = \ln t, \quad dx = \frac{dt}{t}$$

## 三、定积分换元的特殊注意事项

### 3.1 三换原则

> **换元必换限**：换元后积分上下限必须相应改变
>
> **换元必求导**：需要计算 $\varphi'(t)$
>
> **换元必回代**：计算完成后的结果要化为原变量（或直接用新变量的上下限计算）

### 3.2 定积分换元示例

$$\int_0^4 \frac{dx}{1+\sqrt{x}}$$

令 $\sqrt{x} = t$，则 $x = t^2$，$dx = 2t\,dt$

当 $x = 0$ 时 $t = 0$；当 $x = 4$ 时 $t = 2$

$$\int_0^4 \frac{dx}{1+\sqrt{x}} = \int_0^2 \frac{2t}{1+t} dt$$

## 四、对称区间上的积分技巧

### 4.1 奇偶性

$$\int_{-a}^a f(x) dx = \begin{cases} 2\int_0^a f(x) dx, & f(x) \text{ 为偶函数} \\ 0, & f(x) \text{ 为奇函数} \end{cases}$$

### 4.2 偶倍奇零的推广

$$\int_{-a}^a f(x) dx = \int_0^a [f(x) + f(-x)] dx$$

### 4.3 区间再现公式 ⭐

若 $f(x)$ 在 $[0, a]$ 上连续，则：

$$\int_0^a f(x) dx = \int_0^a f(a-x) dx$$

**推论**：

$$\int_0^{\pi/2} \frac{f(\sin x)}{f(\sin x) + f(\cos x)} dx = \frac{\pi}{4}$$

$$\int_0^{\pi/2} \frac{\sin^n x}{\sin^n x + \cos^n x} dx = \frac{\pi}{4}$$

## 五、二重积分的换元

### 5.1 极坐标变换 ⭐⭐⭐

$$\iint_D f(x,y) dxdy = \iint_D f(r\cos\theta, r\sin\theta) \cdot r \, drd\theta$$

**关键**：$dxdy = r\,drd\theta$（雅可比行列式 $J = r$）

### 5.2 适用情形

| 区域特征 | 被积函数特征 |
|---------|-------------|
| 圆形 $x^2+y^2 \leq a^2$ | 含 $x^2+y^2$ |
| 扇形 | 含 $x^2+y^2$ |
| 环形 | 含 $\sqrt{x^2+y^2}$ |
| 椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2} \leq 1$ | — |

### 5.3 广义极坐标（椭圆变换）

$$\begin{cases} x = ar\cos\theta \\ y = br\sin\theta \end{cases}, \quad J = abr$$

$$\iint_D f(x,y) dxdy = \iint_D f(ar\cos\theta, br\sin\theta) \cdot abr \, drd\theta$$

### 5.4 一般换元（雅可比行列式）

$$\begin{cases} x = x(u,v) \\ y = y(u,v) \end{cases}, \quad J = \frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix} \frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ \frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} \end{vmatrix}$$

$$\iint_D f(x,y) dxdy = \iint_{D'} f(x(u,v), y(u,v)) |J| \, dudv$$

## 六、常见换元组合技巧

### 6.1 分子分母同乘/同除

$$\int \frac{dx}{1+\sin x} = \int \frac{1-\sin x}{\cos^2 x} dx = \int (\sec^2 x - \sec x \tan x) dx$$

### 6.2 拆项法

$$\int \frac{x^2}{1+x^2} dx = \int \frac{x^2+1-1}{1+x^2} dx = \int (1 - \frac{1}{1+x^2}) dx$$

### 6.3 配方法

$$\int \frac{dx}{x^2+2x+5} = \int \frac{d(x+1)}{(x+1)^2+4} = \frac{1}{2}\arctan\frac{x+1}{2} + C$$

### 6.4 万能代换（半角代换）

**适用**：被积函数是 $\sin x, \cos x$ 的有理式

令 $t = \tan\frac{x}{2}$，则：

$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad dx = \frac{2dt}{1+t^2}$$

> ⚠️ 万能代换计算量大，仅在无其他方法时使用

## 七、换元法选择流程图

```
被积函数
│
├─ 含根式？
│   ├─ √(a²-x²) → x = a sin t
│   ├─ √(a²+x²) → x = a tan t
│   ├─ √(x²-a²) → x = a sec t
│   └─ ⁿ√(ax+b) → t = ⁿ√(ax+b)
│
├─ 含 eˣ 或 aˣ？
│   └─ 令 eˣ = t 或 aˣ = t
│
├─ 含三角函数？
│   ├─ 凑微分（sin/cos/tan）
│   ├─ 万能代换 t = tan(x/2)
│   └─ 降幂公式
│
├─ 分母次数高？
│   └─ 倒代换 x = 1/t
│
└─ 一般形式
    ├─ 凑微分（第一类换元）
    └─ 分部积分
```

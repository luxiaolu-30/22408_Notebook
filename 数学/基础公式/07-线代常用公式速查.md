## 一、行列式

### 1.1 行列式的性质

| 性质 | 内容 |
|------|------|
| 转置不变 | $\|A\| = \|A^T\|$ |
| 交换两行（列） | 行列式变号 |
| 某行（列）乘 $k$ | 行列式乘 $k$ |
| 两行（列）成比例 | 行列式为 0 |
| 拆分性 | 某行可拆为两行之和，行列式可拆分 |
| 倍加不变 | 某行的 $k$ 倍加到另一行，行列式不变 |

### 1.2 行列式展开定理

**按行展开**：$\|A\| = a_{i1}A_{i1} + a_{i2}A_{i2} + \cdots + a_{in}A_{in}$

**按列展开**：$\|A\| = a_{1j}A_{1j} + a_{2j}A_{2j} + \cdots + a_{nj}A_{nj}$

**异乘法则**：$\sum_{k=1}^{n} a_{ik}A_{jk} = 0 \quad (i \neq j)$

### 1.3 重要行列式

| 类型 | 结果 |
|------|------|
| 上三角行列式 | $\|A\| = a_{11}a_{22}\cdots a_{nn}$ |
| 下三角行列式 | $\|A\| = a_{11}a_{22}\cdots a_{nn}$ |
| 对角行列式 | $\|A\| = a_{11}a_{22}\cdots a_{nn}$ |
| 副对角线 | $(-1)^{\frac{n(n-1)}{2}} a_{1n}a_{2,n-1}\cdots a_{n1}$ |

### 1.4 克拉默法则

方程组 $Ax = b$，当 $\|A\| \neq 0$ 时：

$$x_i = \frac{\|A_i\|}{\|A\|}$$

其中 $A_i$ 是将 $A$ 的第 $i$ 列换为 $b$ 所得的矩阵。

## 二、矩阵运算

### 2.1 矩阵的基本运算

| 运算 | 公式 |
|------|------|
| 加法 | $(A+B)_{ij} = a_{ij} + b_{ij}$ |
| 数乘 | $(kA)_{ij} = k \cdot a_{ij}$ |
| 乘法 | $(AB)_{ij} = \sum_{k=1}^{n} a_{ik}b_{kj}$ |
| 转置 | $(A^T)_{ij} = a_{ji}$ |

### 2.2 转置的性质

| 性质 | 公式 |
|------|------|
| 双重转置 | $(A^T)^T = A$ |
| 加法 | $(A+B)^T = A^T + B^T$ |
| 数乘 | $(kA)^T = kA^T$ |
| 乘法 | $(AB)^T = B^T A^T$ |

### 2.3 逆矩阵

**定义**：若 $AB = BA = E$，则 $B = A^{-1}$

**充要条件**：$A$ 可逆 $\Leftrightarrow \|A\| \neq 0$

**求逆公式**（伴随矩阵法）：

$$\boxed{A^{-1} = \frac{A^*}{\|A\|}}$$

其中 $A^*$ 是 $A$ 的伴随矩阵。

### 2.4 逆矩阵的性质

| 性质 | 公式 |
|------|------|
| 双重逆 | $(A^{-1})^{-1} = A$ |
| 数乘 | $(kA)^{-1} = \frac{1}{k}A^{-1}$ |
| 乘法 | $(AB)^{-1} = B^{-1}A^{-1}$ |
| 转置 | $(A^T)^{-1} = (A^{-1})^T$ |
| 行列式 | $\|A^{-1}\| = \frac{1}{\|A\|}$ |

### 2.5 伴随矩阵

**定义**：$A^* = (A_{ij})^T$，其中 $A_{ij}$ 是代数余子式

**重要公式**：

| 公式 | 说明 |
|------|------|
| $AA^* = A^*A = \|A\|E$ | 基本关系 |
| $\|A^*\| = \|A\|^{n-1}$ | 行列式关系 |
| $(A^*)^{-1} = (A^{-1})^* = \frac{A}{\|A\|}$ | 逆的关系 |
| $(A^*)^T = (A^T)^*$ | 转置关系 |
| $(AB)^* = B^*A^*$ | 乘法关系 |

### 2.6 矩阵的秩

**定义**：矩阵中非零子式的最高阶数

**性质**：

| 性质 | 公式 |
|------|------|
| 范围 | $0 \leq r(A) \leq \min(m, n)$ |
| 转置 | $r(A) = r(A^T)$ |
| 加法 | $r(A+B) \leq r(A) + r(B)$ |
| 乘法 | $r(AB) \leq \min(r(A), r(B))$ |
| 可逆矩阵 | $A$ 可逆 $\Rightarrow r(AB) = r(B), r(CA) = r(A)$ |
| 等价矩阵 | $A \cong B \Leftrightarrow r(A) = r(B)$ |

**求秩方法**：初等行变换化为行阶梯形，非零行数即为秩。

## 三、特征值与特征向量

### 3.1 基本公式

| 公式 | 说明 |
|------|------|
| 特征方程 | $\|A - \lambda E\| = 0$ |
| 特征多项式 | $f(\lambda) = \|A - \lambda E\|$ |
| 特征值之和 | $\sum \lambda_i = \sum a_{ii} = tr(A)$（迹） |
| 特征值之积 | $\prod \lambda_i = \|A\|$ |

### 3.2 特征值的性质

| 性质 | 内容 |
|------|------|
| $A$ 可逆 | 特征值全不为 0 |
| $A^2$ 的特征值 | $\lambda^2$ |
| $A^k$ 的特征值 | $\lambda^k$ |
| $A^{-1}$ 的特征值 | $\frac{1}{\lambda}$ |
| $A^*$ 的特征值 | $\frac{\|A\|}{\lambda}$ |
| $f(A)$ 的特征值 | $f(\lambda)$ |
| $A^T$ | 特征值与 $A$ 相同 |

### 3.3 特征向量的性质

| 性质 | 内容 |
|------|------|
| 不同特征值对应的特征向量 | 线性无关 |
| 不同特征值的特征向量之和 | 不再是特征向量 |
| 实对称矩阵不同特征值的特征向量 | 正交 |

## 四、矩阵相似对角化

### 4.1 相似矩阵

**定义**：若存在可逆矩阵 $P$ 使得 $P^{-1}AP = B$，则 $A \sim B$

**性质**：

| 不变量 | 内容 |
|--------|------|
| 秩 | $r(A) = r(B)$ |
| 行列式 | $\|A\| = \|B\|$ |
| 特征值 | 相同 |
| 迹 | $tr(A) = tr(B)$ |

### 4.2 可对角化条件

| 条件 | 等价 |
|------|------|
| $A$ 可对角化 | 有 $n$ 个线性无关的特征向量 |
| $A$ 可对角化 | $k$ 重特征值有 $k$ 个线性无关特征向量 |
| $A$ 有 $n$ 个不同特征值 | 必可对角化（充分条件） |
| 实对称矩阵 | 必可对角化 |

### 4.3 对角化步骤

1. 求特征值：$\|A - \lambda E\| = 0$
2. 求特征向量：解 $(A - \lambda_i E)x = 0$
3. 判断：是否有 $n$ 个线性无关特征向量
4. 构造 $P = (\xi_1, \xi_2, \ldots, \xi_n)$
5. $P^{-1}AP = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$

## 五、实对称矩阵与二次型

### 5.1 实对称矩阵的性质

| 性质 | 内容 |
|------|------|
| 特征值 | 全为实数 |
| 特征向量 | 不同特征值的特征向量正交 |
| 对角化 | 必可正交对角化 |
| 正定性 | 特征值全正 ⇔ 正定 |

### 5.2 正定矩阵的判定

| 方法 | 条件 |
|------|------|
| 特征值法 | 所有特征值 $> 0$ |
| 顺序主子式法 | 所有顺序主子式 $> 0$ |
| 定义法 | $x^T Ax > 0$（$\forall x \neq 0$） |
| 标准形法 | 正惯性指数 $= n$ |

### 5.3 惯性定理

二次型化为标准形后：
- 正惯性指数 $p$：正平方项个数
- 负惯性指数 $q$：负平方项个数
- 秩：$r = p + q$
- 符号差：$p - q$

## 六、施密特正交化

### 6.1 正交化公式

给定向量组 $\alpha_1, \alpha_2, \ldots, \alpha_m$，构造正交向量组：

$$\begin{aligned}
\beta_1 &= \alpha_1 \\
\beta_2 &= \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1 \\
\beta_3 &= \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2 \\
&\vdots \\
\beta_m &= \alpha_m - \sum_{i=1}^{m-1}\frac{(\alpha_m, \beta_i)}{(\beta_i, \beta_i)}\beta_i
\end{aligned}$$

### 6.2 单位化

$$\gamma_i = \frac{\beta_i}{\|\beta_i\|}$$

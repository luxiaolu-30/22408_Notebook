## 一、基本求导公式

### 1.1 基本函数导数表

| $f(x)$ | $f'(x)$ | 备注 |
|--------|---------|------|
| $C$（常数） | $0$ | — |
| $x^n$ | $nx^{n-1}$ | $n \in \mathbb{R}$ |
| $a^x$ | $a^x \ln a$ | $a > 0, a \neq 1$ |
| $e^x$ | $e^x$ | 特殊 |
| $\log_a x$ | $\frac{1}{x \ln a}$ | $a > 0, a \neq 1$ |
| $\ln x$ | $\frac{1}{x}$ | 特殊 |
| $\sin x$ | $\cos x$ | — |
| $\cos x$ | $-\sin x$ | 注意负号 |
| $\tan x$ | $\sec^2 x = \frac{1}{\cos^2 x}$ | — |
| $\cot x$ | $-\csc^2 x$ | — |
| $\sec x$ | $\sec x \tan x$ | — |
| $\csc x$ | $-\csc x \cot x$ | — |
| $\arcsin x$ | $\frac{1}{\sqrt{1-x^2}}$ | $|x| < 1$ |
| $\arccos x$ | $-\frac{1}{\sqrt{1-x^2}}$ | 注意负号 |
| $\arctan x$ | $\frac{1}{1+x^2}$ | — |
| $\text{arccot } x$ | $-\frac{1}{1+x^2}$ | — |

### 1.2 求导法则

| 法则 | 公式 |
|------|------|
| 四则（加减） | $(f \pm g)' = f' \pm g'$ |
| 四则（乘法） | $(fg)' = f'g + fg'$ |
| 四则（除法） | $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$ |
| 链式法则 | $[f(g(x))]' = f'(g) \cdot g'(x)$ |
| 反函数 | $(f^{-1})'(y) = \frac{1}{f'(x)}$ |

### 1.3 莱布尼茨公式（高阶导数）

$$(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}$$

### 1.4 常见函数的高阶导数

| $f(x)$ | $f^{(n)}(x)$ |
|--------|--------------|
| $e^{ax}$ | $a^n e^{ax}$ |
| $\sin(ax+b)$ | $a^n \sin(ax+b + \frac{n\pi}{2})$ |
| $\cos(ax+b)$ | $a^n \cos(ax+b + \frac{n\pi}{2})$ |
| $(ax+b)^{-1}$ | $(-1)^n n! a^n (ax+b)^{-(n+1)}$ |
| $(ax+b)^\alpha$ | $\alpha(\alpha-1)\cdots(\alpha-n+1)a^n(ax+b)^{\alpha-n}$ |
| $\ln(ax+b)$ | $(-1)^{n-1}(n-1)! a^n (ax+b)^{-n}$ |

## 二、基本积分公式

### 2.1 基本积分表

| $f(x)$ | $\int f(x) dx$ | 备注 |
|--------|----------------|------|
| $x^n$ ($n \neq -1$) | $\frac{x^{n+1}}{n+1} + C$ | 幂函数 |
| $\frac{1}{x}$ | $\ln\|x\| + C$ | 注意绝对值 |
| $e^x$ | $e^x + C$ | — |
| $a^x$ | $\frac{a^x}{\ln a} + C$ | — |
| $\sin x$ | $-\cos x + C$ | — |
| $\cos x$ | $\sin x + C$ | — |
| $\sec^2 x$ | $\tan x + C$ | — |
| $\csc^2 x$ | $-\cot x + C$ | — |
| $\sec x \tan x$ | $\sec x + C$ | — |
| $\frac{1}{1+x^2}$ | $\arctan x + C$ | — |
| $\frac{1}{\sqrt{1-x^2}}$ | $\arcsin x + C$ | — |
| $\frac{1}{x^2-a^2}$ | $\frac{1}{2a}\ln\left\|\frac{x-a}{x+a}\right\| + C$ | — |
| $\frac{1}{x^2+a^2}$ | $\frac{1}{a}\arctan\frac{x}{a} + C$ | — |
| $\frac{1}{\sqrt{a^2-x^2}}$ | $\arcsin\frac{x}{a} + C$ | — |
| $\frac{1}{\sqrt{x^2+a^2}}$ | $\ln(x+\sqrt{x^2+a^2}) + C$ | — |
| $\frac{1}{\sqrt{x^2-a^2}}$ | $\ln\|x+\sqrt{x^2-a^2}\| + C$ | — |

### 2.2 含有 $ax+b$ 的积分

$$\int f(ax+b) dx = \frac{1}{a} \int f(ax+b) d(ax+b)$$

### 2.3 含有 $\sqrt{a^2-x^2}$ 的积分

令 $x = a\sin t$，则 $\sqrt{a^2-x^2} = a\cos t$

### 2.4 含有 $\sqrt{x^2+a^2}$ 的积分

令 $x = a\tan t$，则 $\sqrt{x^2+a^2} = a\sec t$

### 2.5 含有 $\sqrt{x^2-a^2}$ 的积分

令 $x = a\sec t$，则 $\sqrt{x^2-a^2} = a\tan t$

## 三、点火公式（Wallis 公式）⭐ 考研高频

### 3.1 基本形式

$$I_n = \int_0^{\pi/2} \sin^n x \, dx = \int_0^{\pi/2} \cos^n x \, dx$$

$$I_n = \begin{cases} \frac{n-1}{n} \cdot \frac{n-3}{n-2} \cdots \frac{1}{2} \cdot \frac{\pi}{2}, & n \text{ 为正偶数} \\ \frac{n-1}{n} \cdot \frac{n-3}{n-2} \cdots \frac{2}{3} \cdot 1, & n \text{ 为正奇数} \end{cases}$$

### 3.2 常用值

| $n$ | $\int_0^{\pi/2} \sin^n x \, dx$ |
|-----|--------------------------------|
| 0 | $\frac{\pi}{2}$ |
| 1 | $1$ |
| 2 | $\frac{\pi}{4}$ |
| 3 | $\frac{2}{3}$ |
| 4 | $\frac{3\pi}{16}$ |
| 5 | $\frac{8}{15}$ |
| 6 | $\frac{5\pi}{32}$ |

### 3.3 扩展形式

$$\int_0^{\pi} \sin^n x \, dx = 2\int_0^{\pi/2} \sin^n x \, dx$$

$$\int_0^{\pi} \cos^n x \, dx = \begin{cases} 2\int_0^{\pi/2} \cos^n x \, dx, & n \text{ 为偶数} \\ 0, & n \text{ 为奇数} \end{cases}$$

## 五、变限积分求导公式

### 5.1 基本公式

$$\frac{d}{dx} \int_a^x f(t) dt = f(x)$$

### 5.2 一般形式

$$\frac{d}{dx} \int_{a(x)}^{b(x)} f(t) dt = f(b(x)) \cdot b'(x) - f(a(x)) \cdot a'(x)$$

### 5.3 含参变量的变限积分

$$\frac{d}{dx} \int_{a(x)}^{b(x)} f(x, t) dt = f(x, b(x)) \cdot b'(x) - f(x, a(x)) \cdot a'(x) + \int_{a(x)}^{b(x)} \frac{\partial f}{\partial x} dt$$

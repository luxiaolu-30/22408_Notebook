## 一、基本不等式

### 1.1 均值不等式

对正数 $a_1, a_2, \ldots, a_n$：

$$\frac{n}{\frac{1}{a_1} + \frac{1}{a_2} + \cdots + \frac{1}{a_n}} \leq \sqrt[n]{a_1 a_2 \cdots a_n} \leq \frac{a_1 + a_2 + \cdots + a_n}{n} \leq \sqrt{\frac{a_1^2 + a_2^2 + \cdots + a_n^2}{n}}$$

即：**调和 ≤ 几何 ≤ 算术 ≤ 平方**

**最常用**（两元形式）：

$$\frac{2}{\frac{1}{a} + \frac{1}{b}} \leq \sqrt{ab} \leq \frac{a+b}{2} \leq \sqrt{\frac{a^2+b^2}{2}}$$

### 1.2 基本不等式链

对 $a > 0, b > 0$：

$$\boxed{2\sqrt{ab} \leq a + b} \quad \text{（当且仅当 } a = b \text{ 时取等）}$$

$$\frac{a+b}{2} \geq \sqrt{ab}$$

### 1.3 绝对值不等式

$$||a| - |b|| \leq |a \pm b| \leq |a| + |b|$$

### 1.4 柯西不等式

$$(a_1^2 + a_2^2 + \cdots + a_n^2)(b_1^2 + b_2^2 + \cdots + b_n^2) \geq (a_1b_1 + a_2b_2 + \cdots + a_nb_n)^2$$

**两元形式**：$(a^2 + b^2)(c^2 + d^2) \geq (ac + bd)^2$

## 二、与 $e$ 相关的重要不等式

### 2.1 基本不等式

| 不等式 | 条件 |
|--------|------|
| $e^x \geq x + 1$ | $x \in \mathbb{R}$，等号仅当 $x = 0$ |
| $e^x \geq e \cdot x$ | $x \in \mathbb{R}$，等号仅当 $x = 1$ |
| $e^x \geq \frac{x^2}{2} + x + 1$ | $x \geq 0$ |
| $x - 1 \geq \ln x$ | $x > 0$，等号仅当 $x = 1$ |
| $\frac{x}{1+x} \leq \ln(1+x) \leq x$ | $x > -1$，等号仅当 $x = 0$ |
| $\frac{1}{x+1} < \ln(1+\frac{1}{x}) < \frac{1}{x}$ | $x > 0$ |

### 2.2 记忆图像

```
e^x ≥ x + 1          → 指数函数在 x=0 处的切线
x - 1 ≥ ln x         → 对数函数在 x=1 处的切线
```

## 三、与三角函数相关的不等式

### 3.1 基本不等式

| 不等式 | 条件 |
|--------|------|
| $\|\sin x\| \leq \|x\|$ | $x \in \mathbb{R}$ |
| $\|\sin x\| \leq 1$ | $x \in \mathbb{R}$ |
| $x < \tan x$ | $0 < x < \frac{\pi}{2}$ |
| $\sin x < x < \tan x$ | $0 < x < \frac{\pi}{2}$ |
| $\frac{2}{\pi}x < \sin x < x$ | $0 < x < \frac{\pi}{2}$ |
| $1 - \frac{x^2}{2} < \cos x < 1 - \frac{x^2}{2} + \frac{x^4}{24}$ | $x > 0$ |

### 3.2 重要推论

当 $0 < x < \frac{\pi}{2}$ 时：

$$\sin x > x - \frac{x^3}{6}$$

$$\cos x > 1 - \frac{x^2}{2}$$

## 四、与数列相关的不等式

### 4.1 重要极限相关

$$\lim_{n \to \infty} \sqrt[n]{n} = 1$$

$$\lim_{n \to \infty} \frac{n!}{n^n} = 0$$

$$\lim_{n \to \infty} \frac{a^n}{n!} = 0 \quad (a > 0)$$

$$\lim_{n \to \infty} \frac{n!}{a^n} = +\infty \quad (a > 0)$$

### 4.2 阶的比较（$n \to \infty$）

$$(\ln n)^\alpha \ll n^\beta \ll a^n \ll n! \ll n^n \quad (\alpha \in \mathbb{R}, \beta > 0, a > 1)$$

即：**对数 ≪ 幂函数 ≪ 指数 ≪ 阶乘 ≪ nⁿ**

### 4.3 常见数列不等式

| 不等式 | 条件 |
|--------|------|
| $(1 + \frac{1}{n})^n < e < (1 + \frac{1}{n})^{n+1}$ | $n \in \mathbb{N}^+$ |
| $(1 + \frac{1}{n})^n$ 单调递增趋于 $e$ | — |
| $(1 + \frac{1}{n})^{n+1}$ 单调递减趋于 $e$ | — |
| $\frac{1}{n+1} < \ln(1+\frac{1}{n}) < \frac{1}{n}$ | $n \in \mathbb{N}^+$ |

## 五、积分不等式

### 5.1 积分估值不等式

若 $m \leq f(x) \leq M$ 在 $[a, b]$ 上成立，则：

$$m(b-a) \leq \int_a^b f(x) dx \leq M(b-a)$$

### 5.2 积分绝对值不等式

$$\left|\int_a^b f(x) dx\right| \leq \int_a^b |f(x)| dx$$

### 5.3 施瓦茨不等式（积分形式）

$$\left(\int_a^b f(x)g(x) dx\right)^2 \leq \left(\int_a^b f^2(x) dx\right)\left(\int_a^b g^2(x) dx\right)$$

### 5.4 常用积分不等式

| 不等式 | 条件 |
|--------|------|
| $\int_0^{\pi/2} \frac{\sin x}{x} dx < \frac{\pi}{2}$ | — |
| $\int_0^1 \frac{x}{1+x} dx < \int_0^1 x dx = \frac{1}{2}$ | — |
| $\int_0^1 e^{-x^2} dx < 1$ | — |

## 六、中值定理相关的重要结论

### 6.1 零点定理

若 $f(x)$ 在 $[a, b]$ 上连续，且 $f(a) \cdot f(b) < 0$，则存在 $\xi \in (a, b)$ 使得 $f(\xi) = 0$。

### 6.2 介值定理

若 $f(x)$ 在 $[a, b]$ 上连续，且 $f(a) \neq f(b)$，则对任意 $\mu$ 介于 $f(a)$ 与 $f(b)$ 之间，存在 $\xi \in (a, b)$ 使得 $f(\xi) = \mu$。

### 6.3 有界性定理

若 $f(x)$ 在 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上有界。

### 6.4 最值定理

若 $f(x)$ 在 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上必有最大值和最小值。

## 七、函数性质的重要结论

### 7.1 可导与连续的关系

$$可导 \Rightarrow 连续 \Rightarrow 可积 \Rightarrow 有界$$

反之均不成立。

### 7.2 可微的判定

| 条件 | 结论 |
|------|------|
| 偏导数连续 | $\Rightarrow$ 可微 |
| 可微 | $\Rightarrow$ 偏导数存在 |
| 可微 | $\Rightarrow$ 连续 |
| 偏导数存在 | $\nRightarrow$ 可微 |

### 7.3 极值的判定

**必要条件**：若 $f(x)$ 在 $x_0$ 处可导且取极值，则 $f'(x_0) = 0$

**充分条件**：
- $f'(x_0) = 0, f''(x_0) > 0$ → 极小值
- $f'(x_0) = 0, f''(x_0) < 0$ → 极大值
- $f'(x_0) = 0, f''(x_0) = 0$ → 需进一步判断

## 八、常见等价关系与阶的比较

### 8.1 $x \to 0$ 时的阶

| 阶数 | 函数 |
|------|------|
| 1阶 | $x, \sin x, \tan x, \arcsin x, \arctan x, e^x-1, \ln(1+x)$ |
| 2阶 | $1-\cos x, x-\ln(1+x), x-\arctan x$ |
| 3阶 | $x-\sin x, \tan x-x, \tan x-\sin x$ |

### 8.2 $x \to +\infty$ 时的阶

| 阶数 | 函数 |
|------|------|
| 低阶 | $\ln x$ |
| 中阶 | $x^\alpha (\alpha > 0)$ |
| 高阶 | $e^x, a^x (a > 1)$ |
| 最高阶 | $x^x$ |

### 8.3 常见等价关系

当 $x \to 0$：

$$\sqrt{1+x} - 1 \sim \frac{x}{2}$$

$$\sqrt[n]{1+x} - 1 \sim \frac{x}{n}$$

$$a^x - 1 \sim x\ln a$$

$$x - \sin x \sim \frac{x^3}{6}$$

$$\tan x - x \sim \frac{x^3}{3}$$

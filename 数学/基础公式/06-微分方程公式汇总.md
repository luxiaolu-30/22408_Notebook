## 一、一阶微分方程

### 1.1 可分离变量方程

**形式**：$\frac{dy}{dx} = f(x)g(y)$

**解法**：分离变量后两边积分

$$\int \frac{dy}{g(y)} = \int f(x) dx + C$$

### 1.2 齐次方程

**形式**：$\frac{dy}{dx} = \varphi(\frac{y}{x})$

**解法**：令 $u = \frac{y}{x}$，则 $y = xu$，$\frac{dy}{dx} = u + x\frac{du}{dx}$

代入得：$u + x\frac{du}{dx} = \varphi(u)$

分离变量：$\frac{du}{\varphi(u) - u} = \frac{dx}{x}$

### 1.3 一阶线性微分方程 ⭐⭐⭐

**形式**：$y' + P(x)y = Q(x)$

**通解公式**：

$$\boxed{y = e^{-\int P(x) dx} \left(\int Q(x) e^{\int P(x) dx} dx + C\right)}$$

**记忆技巧**：
1. 求积分因子 $\mu(x) = e^{\int P(x) dx}$
2. 通解 $y = \frac{1}{\mu(x)}\left(\int Q(x)\mu(x) dx + C\right)$

### 1.4 伯努利方程（数学二不考，数学一考）

**形式**：$y' + P(x)y = Q(x)y^n$（$n \neq 0, 1$）

**解法**：令 $z = y^{1-n}$，化为一阶线性方程

## 二、二阶常系数线性微分方程

### 2.1 二阶常系数齐次方程 ⭐⭐⭐

**形式**：$y'' + py' + qy = 0$

**特征方程**：$r^2 + pr + q = 0$

**通解形式**：

| 特征根情况 | 判别式 | 通解形式 |
|-----------|--------|---------|
| 两不等实根 $r_1 \neq r_2$ | $\Delta > 0$ | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| 两相等实根 $r_1 = r_2$ | $\Delta = 0$ | $y = (C_1 + C_2 x) e^{r_1 x}$ |
| 共轭复根 $\alpha \pm i\beta$ | $\Delta < 0$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

### 2.2 二阶常系数非齐次方程 ⭐⭐⭐

**形式**：$y'' + py' + qy = f(x)$

**通解结构**：

$$\boxed{y = \bar{y} + y^*}$$

其中 $\bar{y}$ 是对应齐次方程的通解，$y^*$ 是非齐次方程的一个特解。

### 2.3 非齐次方程的特解形式

| $f(x)$ 类型 | 特解形式 | $k$ 的取值 |
|------------|---------|-----------|
| $P_n(x)$（n次多项式） | $y^* = x^k Q_n(x)$ | $k = 0, 1, 2$（0 不是特征根→0；单根→1；二重根→2） |
| $e^{\alpha x} P_n(x)$ | $y^* = x^k Q_n(x) e^{\alpha x}$ | $k = 0, 1, 2$（$\alpha$ 不是特征根→0；单根→1；二重根→2） |
| $e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ | $y^* = x^k e^{\alpha x}(A\cos\beta x + B\sin\beta x)$ | $k = 0, 1$（$\alpha \pm i\beta$ 不是特征根→0；是特征根→1） |

### 2.4 特解设法记忆

> **$k$ 等于特征根的重数**：
> - 不是特征根 → $k = 0$
> - 是单特征根 → $k = 1$
> - 是二重特征根 → $k = 2$

## 三、可降阶的高阶微分方程

### 3.1 类型与解法

| 类型 | 形式 | 解法 |
|------|------|------|
| **类型1** | $y^{(n)} = f(x)$ | 逐次积分 $n$ 次 |
| **类型2** | $y'' = f(x, y')$（缺 $y$） | 令 $p = y'$，则 $y'' = p'$，降为一阶 |
| **类型3** | $y'' = f(y, y')$（缺 $x$） | 令 $p = y'$，则 $y'' = p\frac{dp}{dy}$，降为一阶 |

### 3.2 类型2 示例

**方程**：$y'' = f(x, y')$

令 $p = y'$，则 $p' = y'' = f(x, p)$

解此一阶方程得 $p = \varphi(x, C_1)$

再积分：$y = \int \varphi(x, C_1) dx + C_2$

### 3.3 类型3 示例

**方程**：$y'' = f(y, y')$

令 $p = y'$，则 $y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p\frac{dp}{dy}$

代入得：$p\frac{dp}{dy} = f(y, p)$

解此一阶方程得 $p = \varphi(y, C_1)$

分离变量：$\frac{dy}{\varphi(y, C_1)} = dx$，积分得通解

## 四、微分方程的初值问题

### 4.1 初始条件

| 方程阶数 | 初始条件 |
|---------|---------|
| 一阶 | $y(x_0) = y_0$ |
| 二阶 | $y(x_0) = y_0, y'(x_0) = y_1$ |
| $n$ 阶 | $y(x_0) = y_0, y'(x_0) = y_1, \ldots, y^{(n-1)}(x_0) = y_{n-1}$ |

### 4.2 解题步骤

1. 判断方程类型
2. 选择对应解法求通解
3. 代入初始条件确定常数
4. 写出特解

## 五、常见微分方程模型

### 5.1 指数增长/衰减模型

$$\frac{dy}{dt} = ky \Rightarrow y = Ce^{kt}$$

- $k > 0$：指数增长
- $k < 0$：指数衰减

### 5.2 逻辑斯蒂模型

$$\frac{dy}{dt} = ky(1 - \frac{y}{M})$$

解：$y = \frac{M}{1 + Ce^{-kt}}$

### 5.3 牛顿冷却定律

$$\frac{dT}{dt} = -k(T - T_{env})$$

解：$T = T_{env} + (T_0 - T_{env})e^{-kt}$

## 六、线性微分方程的性质

### 6.1 齐次方程解的叠加性

若 $y_1, y_2$ 是齐次方程的解，则 $C_1y_1 + C_2y_2$ 也是解。

### 6.2 非齐次方程解的性质

| 性质 | 内容 |
|------|------|
| 性质1 | 非齐次两解之差 = 齐次方程的解 |
| 性质2 | 非齐次解 + 齐次解 = 非齐次解 |
| 性质3 | 若 $y_1^*, y_2^*$ 分别是 $f_1(x), f_2(x)$ 的特解，则 $y_1^* + y_2^*$ 是 $f_1(x) + f_2(x)$ 的特解 |

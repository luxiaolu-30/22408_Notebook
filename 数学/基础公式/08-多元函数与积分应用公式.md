## 一、偏导数与全微分

### 1.1 偏导数的链式法则

| 情形 | 求导公式 |
|------|---------|
| $z=f(u,v), u=\varphi(x,y), v=\psi(x,y)$ | $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$ |
| $z=f(u), u=\varphi(x)$ | $\frac{dz}{dx} = f'(u) \cdot \varphi'(x)$ |
| $z=f(x, y)$，$y=\varphi(x)$ | $\frac{dz}{dx} = \frac{\partial f}{\partial x} + \frac{\partial f}{\partial y}\frac{dy}{dx}$ |

### 1.2 全微分

$$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$$

### 1.3 可微的条件

| 条件 | 结论 |
|------|------|
| 偏导数连续 | $\Rightarrow$ 可微（充分条件） |
| 可微 | $\Rightarrow$ 偏导数存在（必要条件） |
| 可微 | $\Rightarrow$ 连续 |

## 二、隐函数求导

### 2.1 一个方程的情形

**隐函数 $y = f(x)$**（由 $F(x, y) = 0$ 确定）：

$$\frac{dy}{dx} = -\frac{F_x}{F_y}$$

**隐函数 $z = f(x, y)$**（由 $F(x, y, z) = 0$ 确定）：

$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

### 2.2 方程组的情形

**方程组确定函数组**：对方程组两边关于自变量求导，解方程组得到偏导数。

## 三、多元函数的极值

### 3.1 无条件极值

**必要条件**：若 $(x_0, y_0)$ 是极值点且偏导存在，则 $f_x = 0, f_y = 0$

**充分条件**：设 $A = f_{xx}(x_0, y_0)$，$B = f_{xy}(x_0, y_0)$，$C = f_{yy}(x_0, y_0)$

$$\Delta = B^2 - AC$$

| $\Delta$ | $A$ | 结论 |
|---------|-----|------|
| $< 0$ | $> 0$ | 极小值 |
| $< 0$ | $< 0$ | 极大值 |
| $> 0$ | — | 不是极值 |
| $= 0$ | — | 需进一步判断 |

### 3.2 条件极值（拉格朗日乘数法）

**问题**：在约束条件 $\varphi(x, y) = 0$ 下，求 $f(x, y)$ 的极值

**拉格朗日函数**：$L(x, y, \lambda) = f(x, y) + \lambda \varphi(x, y)$

**方程组**：
$$\begin{cases} \frac{\partial L}{\partial x} = f_x + \lambda \varphi_x = 0 \\ \frac{\partial L}{\partial y} = f_y + \lambda \varphi_y = 0 \\ \frac{\partial L}{\partial \lambda} = \varphi(x, y) = 0 \end{cases}$$

### 3.3 拉格朗日乘数法推广

**两个约束条件**：$\varphi(x, y, z) = 0, \psi(x, y, z) = 0$

$$L(x, y, z, \lambda, \mu) = f(x, y, z) + \lambda \varphi(x, y, z) + \mu \psi(x, y, z)$$

## 四、定积分的应用

### 4.1 平面图形的面积

| 情形 | 公式 |
|------|------|
| 由 $y=f(x)$ 和 $x$ 轴围成 | $A = \int_a^b \|f(x)\| dx$ |
| 由 $y=f(x)$ 和 $y=g(x)$ 围成 | $A = \int_a^b \|f(x) - g(x)\| dx$ |
| 参数方程 $x=\varphi(t), y=\psi(t)$ | $A = \int_\alpha^\beta \|\psi(t) \varphi'(t)\| dt$ |
| 极坐标 $r=r(\theta)$ | $A = \frac{1}{2} \int_\alpha^\beta r^2(\theta) d\theta$ |

### 4.2 旋转体的体积

| 情形 | 公式 |
|------|------|
| 绕 $x$ 轴旋转（圆盘法） | $V = \pi \int_a^b [f(x)]^2 dx$ |
| 绕 $y$ 轴旋转（柱壳法） | $V = 2\pi \int_a^b x\|f(x)\| dx$ |
| 绕 $y$ 轴旋转（反函数形式） | $V = \pi \int_c^d [\varphi(y)]^2 dy$ |

### 4.3 曲线的弧长

| 情形 | 公式 |
|------|------|
| 直角坐标 $y=f(x)$ | $s = \int_a^b \sqrt{1 + [f'(x)]^2} dx$ |
| 参数方程 $x=\varphi(t), y=\psi(t)$ | $s = \int_\alpha^\beta \sqrt{[\varphi'(t)]^2 + [\psi'(t)]^2} dt$ |
| 极坐标 $r=r(\theta)$ | $s = \int_\alpha^\beta \sqrt{r^2(\theta) + [r'(\theta)]^2} d\theta$ |

## 五、二重积分

### 5.1 直角坐标系下的计算

**X 型区域**（先 $y$ 后 $x$）：

$$D = \{(x,y) \mid a \leq x \leq b, \varphi_1(x) \leq y \leq \varphi_2(x)\}$$

$$\iint_D f(x,y) dxdy = \int_a^b dx \int_{\varphi_1(x)}^{\varphi_2(x)} f(x,y) dy$$

**Y 型区域**（先 $x$ 后 $y$）：

$$D = \{(x,y) \mid c \leq y \leq d, \psi_1(y) \leq x \leq \psi_2(y)\}$$

$$\iint_D f(x,y) dxdy = \int_c^d dy \int_{\psi_1(y)}^{\psi_2(y)} f(x,y) dx$$

### 5.2 极坐标系下的计算

$$\iint_D f(x,y) dxdy = \iint_D f(r\cos\theta, r\sin\theta) \cdot r \, drd\theta$$

**关键**：$dxdy = r\,drd\theta$（不要忘记 $r$）

### 5.3 极坐标下的区域描述

| 区域类型 | 描述 |
|---------|------|
| 圆心在原点，半径 $a$ | $0 \leq r \leq a, 0 \leq \theta \leq 2\pi$ |
| 圆心在 $(a, 0)$，半径 $a$ | $r = 2a\cos\theta$ |
| 圆心在 $(0, a)$，半径 $a$ | $r = 2a\sin\theta$ |
| 扇形 | $r_1 \leq r \leq r_2, \theta_1 \leq \theta \leq \theta_2$ |

### 5.4 对称性的利用

| 对称类型 | 条件 | 结论 |
|---------|------|------|
| 关于 $x$ 轴对称 | $D$ 关于 $x$ 轴对称 | $f(x,-y) = -f(x,y) \Rightarrow \iint = 0$ |
| 关于 $y$ 轴对称 | $D$ 关于 $y$ 轴对称 | $f(-x,y) = -f(x,y) \Rightarrow \iint = 0$ |
| 关于原点对称 | $D$ 关于原点对称 | $f(-x,-y) = -f(x,y) \Rightarrow \iint = 0$ |
| 关于 $y=x$ 对称 | $D$ 关于 $y=x$ 对称 | $\iint_D f(x,y) dxdy = \iint_D f(y,x) dxdy$ |

### 5.5 交换积分次序

**步骤**：
1. 根据原积分限画出积分区域 $D$
2. 重新描述区域 $D$（换一种类型）
3. 确定新的积分限
4. 写出新积分

## 六、多元函数微分的重要关系

### 6.1 梯度

$$\nabla f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right)$$

### 6.2 方向导数

$$\frac{\partial f}{\partial l} = \nabla f \cdot \vec{l}^0 = f_x \cos\alpha + f_y \cos\beta + f_z \cos\gamma$$

其中 $\vec{l}^0 = (\cos\alpha, \cos\beta, \cos\gamma)$ 是方向 $l$ 的单位向量。

### 6.3 梯度与方向导数的关系

- 沿梯度方向，方向导数最大，最大值为 $\|\nabla f\|$
- 沿负梯度方向，方向导数最小
- 沿等值线切线方向，方向导数为 0

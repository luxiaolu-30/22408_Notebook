## 一、高数核心公式

### 1.1 极限

**等价无穷小（x→0，必背 8 组）**：

| 等价关系 | 等价关系 |
|---------|---------|
| sin x ~ x | tan x ~ x |
| 1-cos x ~ x²/2 | eˣ-1 ~ x |
| ln(1+x) ~ x | (1+x)^α - 1 ~ αx |
| arcsin x ~ x | arctan x ~ x |

**洛必达法则**：0/0 或 ∞/∞ 型，lim f/g = lim f'/g'（分子分母同时求导）。前提：右端极限存在或为 ∞。

**常用方法**：等价无穷小替换 → 洛必达 → 泰勒展开（处理加减型、高阶项）。

### 1.2 导数

- **复合函数**：dy/dx = dy/du · du/dx（链式法则）
- **隐函数**：F(x,y)=0，dy/dx = -F'_x / F'_y
- **参数方程**：dy/dx = (dy/dt)/(dx/dt)
- **高阶导数**：常用 (uv)⁽ⁿ⁾ = Σ C(n,k) u⁽ᵏ⁾ v⁽ⁿ⁻ᵏ⁾（莱布尼茨）
- **基本求导**：见 [[数学/基础公式/02-求导与积分公式速查]]

### 1.3 积分

**基本积分表核心**：∫xⁿdx = xⁿ⁺¹/(n+1)+C、∫dx/x = ln|x|+C、∫eˣdx = eˣ+C、∫sin x dx = -cos x+C、∫cos x dx = sin x+C、∫sec²x dx = tan x+C

**三大方法**：
- **换元法**：第一类（凑微分）、第二类（三角代换 x=a sinθ / 去根号）
- **分部积分**：∫u dv = uv - ∫v du（"反对幂指三"靠前者取作 u）
- **定积分性质**：奇偶性（对称区间奇函数=0）、几何意义、比较性质

### 1.4 微分方程

| 类型 | 通解 |
|------|------|
| 一阶线性 y' + p(x)y = q(x) | y = e^(−∫pdx) [∫q·e^(∫pdx)dx + C] |
| 二阶常系数齐次 y'' + py' + qy = 0 | 特征方程 r² + pr + q = 0：Δ>0 两实根 y=C₁e^(r₁x)+C₂e^(r₂x)；Δ=0 y=(C₁+C₂x)e^(rx)；Δ<0 y=e^(αx)(C₁cos βx + C₂sin βx) |

> 完整微分方程公式（可分离变量、齐次、可降阶等）见 [[数学/基础公式/06-微分方程公式汇总]]。

## 二、线代核心结论

### 2.1 行列式性质

- 某行（列）有公因子可提出；两行相同值为 0
- |AB| = |A||B|；|Aᵀ| = |A|；|kA| = kⁿ|A|
- |A*| = |A|ⁿ⁻¹；|A⁻¹| = 1/|A|

### 2.2 矩阵秩的结论

- r(A) ≤ min(m, n)；r(AB) ≤ min(r(A), r(B))
- r(A + B) ≤ r(A) + r(B)
- A 可逆 ⟺ r(A) = n ⟺ |A| ≠ 0
- r(A*)：r(A)=n 时为 n；r(A)=n-1 时为 1；r(A)<n-1 时为 0

### 2.3 线性相关性判定

- 向量组线性相关 ⟺ 至少有一个向量可由其余线性表示 ⟺ 以其为列的矩阵秩 < 向量个数
- n+1 个 n 维向量必线性相关
- 部分相关 ⟹ 整体相关；整体无关 ⟹ 部分无关

### 2.4 方程组解的结构

- **Ax = 0**：r(A) = r < n 时有非零解，基础解系含 n - r 个解向量
- **Ax = b**：r(A) = r(A|b) = r 时有解；r < n 时有无穷多解，通解 = 特解 + Ax=0 的通解
- 有解判定：r(A) = r(A,b) 有解；r(A) + 1 = r(A,b) 无解

### 2.5 特征值性质

- **Σλᵢ = tr(A)**（迹）；**Πλᵢ = |A|**（行列式）
- A 的特征值为 λ ⟹ A² 特征值为 λ²、A⁻¹ 为 1/λ、A* 为 |A|/λ、A+kE 为 λ+k
- 不同特征值对应的特征向量线性无关
- 实对称矩阵：特征值全实数，不同特征值的特征向量正交，必可正交对角化

### 2.6 二次型正定判定

以下条件等价（A 为 n 阶实对称矩阵）：
- A 正定（x≠0 时 xᵀAx > 0）
- 顺序主子式全大于 0
- 特征值全大于 0
- 正惯性指数 = n
- 存在可逆矩阵 C，A = CᵀC

## 三、易错警示（10 条）

1. **变限积分求导**：∫ₐˣ f(t)dt 求导直接代上限，但**上限是函数时先乘复合因子**；被积函数含 x 必须先拆出（提取或换元），如 ∫₀ˣ (x-t)f(t)dt = x∫₀ˣf(t)dt - ∫₀ˣtf(t)dt 再求导。
2. **二重积分换序**：交换积分次序必须**重新画区域**，按新次序重新定限，不能直接交换上下限。
3. **抽象矩阵不可随意交换**：AB ≠ BA！提取公因子 (AB)² = ABAB ≠ A²B²；(A+B)² = A² + AB + BA + B²。
4. **洛必达失效情形**：使用后极限不存在（震荡型如 x sin(1/x)）≠ 原极限不存在，需换方法。
5. **等价无穷小替换限制**：乘除可整体替换，**加减不能随意替换**（除非写成整体等价形式，用泰勒展开确定阶数）。
6. **分段函数在分界点的导数**：必须用**定义**（左导数 = 右导数）判断，不能两边分别求导后代入。
7. **反常积分敛散性**：p 积分 ∫₁^∞ dx/xᵖ 当 p>1 收敛、p≤1 发散；∫₀¹ dx/xᵖ 当 p<1 收敛、p≥1 发散——两个临界方向相反。
8. **对称区间定积分**：先看奇偶性再计算；偶函数 = 2 倍半区间积分，奇函数直接为 0。
9. **特征值与特征向量**：求 A 的特征向量时，k 重特征值最多有 k 个线性无关特征向量；A 可对角化 ⟺ 每个 λᵢ 的线性无关特征向量个数 = 重数。
10. **正交变换 vs 可逆变换**：化二次型为标准形，**只有正交变换**能保持长度/得到的标准形是特征值（配方法得到的标准形系数不一定是特征值）。

## 四、考场策略

| 策略 | 说明 |
|------|------|
| **选填 60 分钟内完成** | 选择 40min + 填空 20-30min，共 80 分是基本盘；单题超 6 分钟果断跳过、做标记 |
| **先易后难** | 按 1→22 顺序但不恋战；解答题先做二重积分/微分方程等常规题，中值定理证明留后面 |
| **步骤分意识** | 解答题按步给分：写出公式、代入、变形过程都有分；即使算不出最终结果，把思路写上（如"由泰勒中值定理展开…"） |
| **草稿规范** | 按题号分区打草稿，方便检查时快速回溯 |
| **检查重点** | 选填的符号、正负号、定义域；解答应代入验证（如微分方程解代回原方程） |
| **涂卡** | 留 10-15 分钟涂卡 + 检查，切勿做完一道涂一道浪费时间 |

> 时间分配详表见 [[数学/数学考情分析]] 第三节。

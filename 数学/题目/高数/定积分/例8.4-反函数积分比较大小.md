# 例8.4：反函数积分与 $ab$ 的大小比较

> **题目类型**：定积分 — 几何意义 + 反函数积分比较大小
>
> **核心考点**：定积分的几何意义、反函数与原函数共线、利用图形面积比较大小

---

## 题目

设可导函数 $y=f(x)$ 在 $[0,+\infty)$ 上的值域是 $[0,+\infty)$，$f(0)=0$，$f'(x)>0$，$x=\varphi(y)$ 是 $y=f(x)$ 的反函数。记

$$I = \int_0^a f(x)\,dx + \int_0^b \varphi(y)\,dy$$

其中常数 $a, b > 0$，当 $a < \varphi(b)$ 时，则（　）

| 选项 | 结论 |
|------|------|
| (A) | $I > ab$ |
| (B) | $I < ab$ |
| (C) | $I = ab$ |
| (D) | $I$ 与 $ab$ 的大小关系不确定 |

---

## 解答

### 答案：**A**

### 解题关键：几何意义

由题设，$f(x)$ 过原点且在 $[0,+\infty)$ 上单调递增。$x=\varphi(y)$ 是 $y=f(x)$ 的反函数，二者在同一坐标系下**共线**（是同一条曲线）。

> **关键理解**：$y=f(x)$ 与 $x=\varphi(y)$ 是同一条曲线，而 $y=f^{-1}(x)$ 是它关于 $y=x$ 的对称曲线。

由 $a < \varphi(b)$ 及 $f$ 单调递增，可得 $f(a) < b$，即曲线在 $x=a$ 处的高度低于 $y=b$。

### 图形分解

如图所示，将区域分解为三部分：

| 区域 | 含义 | 面积来源 |
|------|------|---------|
| $S_1$ | 曲线下方、$x=a$ 左侧的区域 | $\int_0^a f(x)\,dx$ 的主体部分 |
| $S_2$ | 曲线左侧、$y=b$ 下方的矩形区域 | $\int_0^b \varphi(y)\,dy$ 的主体部分 |
| $S_3$ | 曲线与矩形 $(0,0)$-$(a,b)$ 之间的**多余区域** | 因 $a < \varphi(b)$ 产生的额外面积 |

### 核心推导

$$I = \int_0^a f(x)\,dx + \int_0^b \varphi(y)\,dy = S_1 + S_2 + S_3$$

由于 $a < \varphi(b)$ 使得 $S_3 > 0$，故：

$$I = S_1 + S_2 + S_3 > S_1 + S_2 = ab$$

因此 $I > ab$，选 **(A)**。

---

## 推广：三种情况总结

| 条件 | 几何含义 | 结论 |
|------|---------|------|
| $a < \varphi(b)$（即 $f(a) < b$） | 曲线在矩形角点 $(a,b)$ 下方经过，$S_3 > 0$ | $I > ab$ |
| $a = \varphi(b)$（即 $f(a) = b$） | 曲线恰好过角点 $(a,b)$，$S_3 = 0$ | $I = ab$ |
| $a > \varphi(b)$（即 $f(a) > b$） | 曲线在矩形角点 $(a,b)$ 上方经过 | $I < ab$ |

> **经典恒等式**：当 $a = \varphi(b)$（即 $b = f(a)$）时，$\displaystyle\int_0^a f(x)\,dx + \int_0^{f(a)} \varphi(y)\,dy = a \cdot f(a)$，这是反函数积分的基本恒等式。

---

## 易错点

| 陷阱 | 说明 |
|------|------|
| **混淆 $x=\varphi(y)$ 与 $y=f^{-1}(x)$** | $x=\varphi(y)$ 与 $y=f(x)$ 是同一条曲线；$y=f^{-1}(x)$ 是关于 $y=x$ 的对称曲线 |
| **忽略条件 $a < \varphi(b)$** | 不同条件下 $I$ 与 $ab$ 的大小关系不同，必须根据条件判断 |
| **仅用代数方法** | 此题用几何意义最直观，纯代数推导容易迷失方向 |

# 例8.1：由积分方程求 f(x)

> **题目类型**：不定积分 — 由积分方程求函数（两边求导法）
>
> **核心考点**：不定积分与求导的互逆关系、复合函数求导

---

## 题目

设 $0 < x < 1$，且

$$\int (1-x^2) f(x^2) \, dx = \arcsin x + C$$

则 $f(x) = \quad(\quad)$

| 选项 | 表达式 |
|------|--------|
| (A) | $(1-x)^{\frac{3}{2}}$ |
| (B) | $(1-x)^{-\frac{3}{2}}$ |
| (C) | $(1-x^2)^{\frac{3}{2}}$ |
| (D) | $(1-x^2)^{-\frac{3}{2}}$ |

---

## 解答

### 方法：对积分等式两边求导

**关键思路**：若 $\int g(x)\,dx = F(x) + C$，则 $g(x) = F'(x)$。

**第一步：两边对 $x$ 求导**

$$\frac{d}{dx}\left[\int (1-x^2) f(x^2)\, dx\right] = \frac{d}{dx}\left[\arcsin x + C\right]$$

左边：积分与求导互逆，直接还原被积函数：

$$(1-x^2) f(x^2)$$

右边：

$$\frac{1}{\sqrt{1-x^2}} = (1-x^2)^{-\frac{1}{2}}$$

**第二步：解出 $f(x^2)$**

$$(1-x^2) f(x^2) = (1-x^2)^{-\frac{1}{2}}$$

$$f(x^2) = (1-x^2)^{-\frac{1}{2}} \cdot (1-x^2)^{-1} = (1-x^2)^{-\frac{3}{2}}$$

**第三步：求 $f(x)$**

令 $x^2 = t$，则 $f(t) = (1-t)^{-\frac{3}{2}}$，即：

$$\boxed{f(x) = (1-x)^{-\frac{3}{2}}}$$

### 答案：**B**

---

## 验证

若 $f(x) = (1-x)^{-\frac{3}{2}}$，则 $f(x^2) = (1-x^2)^{-\frac{3}{2}}$。

$$(1-x^2) \cdot (1-x^2)^{-\frac{3}{2}} = (1-x^2)^{-\frac{1}{2}} = \frac{1}{\sqrt{1-x^2}}$$

而 $\displaystyle\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + C$ ✓

---

## 易错点

| 陷阱 | 说明 |
|------|------|
| **指数符号错误** | 化简 $(1-x^2)^{-\frac{1}{2}} \div (1-x^2)$ 时，指数应为 $-\frac{1}{2} - 1 = -\frac{3}{2}$，而非 $+\frac{3}{2}$ |
| **变量替换遗漏** | 求出 $f(x^2)$ 后忘记将 $x^2$ 替换为 $x$，误选 (D) |
| **混淆 $f(x)$ 与 $f(x^2)$** | 选项 (C)(D) 是 $f(x^2)$ 的形式，题目要求的是 $f(x)$ |

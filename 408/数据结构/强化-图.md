# 数据结构 强化-图

> **本板块串联**：图是 DS 的集大成者——它把前面所有结构当作工具（邻接表 = 数组 + 链表，遍历 = 栈 + 队列），又是 42 题大题的绝对主力；学图等于对整个知识体系做一次总演练。

## 🧭 知识主线

本板块的主线是：**图的遍历衍生出一切应用**。整个图算法体系只有两颗种子——DFS（栈/递归，一条路走到黑）和 BFS（队列，逐层扩散），其余算法全部是遍历思想的变体，复习时按"从遍历长出了什么"来串：① 给遍历加上"贪心选最小"→ 最小生成树（Prim = 顶点扩展、O(V²) 适合稠密图；Kruskal = 边排序 + 并查集判环、O(E logE) 适合稀疏图）；② BFS 天然求无权单源最短路，边一有权就升级为 Dijkstra（逐轮选 dist 最小的未确定顶点 + 松弛邻边，O(V²)，不能处理负权）；③ 给边加上"方向约束"→ 拓扑排序（AOV 网：入度法，删零入度顶点，输出数 < V 则有环）；④ 给边加上"持续时间"→ 关键路径（AOE 网：正序拓扑推 ve 取 max，逆序拓扑推 vl 取 min，活动 e==l 即关键活动，关键路径长度 = ve(汇点)）。两大易混网对照记：**AOV 网（顶点=活动、边=先后约束、无权）→ 拓扑排序；AOE 网（边=活动带权、顶点=事件）→ 关键路径**。再注意三个算法框架高度同构——Dijkstra、Prim、拓扑排序都是"每轮选一个 + 更新辅助数组"（dist / lowcost / indegree），手动模拟时统一按"画图 → 初始状态表 → 每轮选谁、更新什么、为什么 → 最终结果"的格式作答，这正是 42 题的采分点。

## 图的存储

### 邻接矩阵

```c
#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];                // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum]; // 邻接矩阵
    int vexnum, arcnum;                   // 顶点数、边数
} MGraph;
```

| 特性 | 邻接矩阵 | 邻接表 |
|------|----------|--------|
| 空间复杂度 | O(V²) | O(V+E)（无向图） |
| 适合 | 稠密图 | 稀疏图 |
| 查边是否存在 | O(1) | O(度) |
| 求度 | O(V) | 直接读边表 |
| 判断连通 | 遍行矩阵 O(V²) | BFS/DFS O(V+E) |

### 邻接表

```c
typedef struct ArcNode {       // 边节点
    int adjvex;               // 邻接顶点编号
    struct ArcNode *next;     // 下一条边
} ArcNode;

typedef struct VNode {         // 顶点节点
    char data;
    ArcNode *firstarc;        // 第一条边
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```

> 无向图邻接表中每条边存两份，有向图存一份。考试中邻接表更常见。

## 图的遍历

### BFS（广度优先——队列实现）

```c
bool visited[MaxVertexNum];
int d[MaxVertexNum];  // 记录到源点距离

void BFS(MGraph G, int v) {
    int queue[MaxVertexNum]; int front = 0, rear = 0;
    visited[v] = true; d[v] = 0;
    queue[rear++] = v;
    while (front != rear) {
        int u = queue[front++];
        for (int w = 0; w < G.vexnum; w++) {
            if (G.Edge[u][w] == 1 && !visited[w]) {  // 邻接且未访问
                visited[w] = true;
                d[w] = d[u] + 1;
                queue[rear++] = w;
            }
        }
    }
}

void BFSTraverse(MGraph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) BFS(G, i);  // 处理非连通图
}
```

- BFS 可求无权图单源最短路径
- 同一图的 BFS 序列不唯一（取决于邻接点访问顺序）
- BFS 生成树的高度 <= DFS 生成树的高度

### DFS（深度优先——递归实现）

```c
bool visited[MaxVertexNum];

void DFS(MGraph G, int v) {
    visited[v] = true;
    Visit(v);
    for (int w = 0; w < G.vexnum; w++) {
        if (G.Edge[v][w] == 1 && !visited[w])
            DFS(G, w);
    }
}

void DFSTraverse(MGraph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) DFS(G, i);
}
```

- 邻接矩阵的 DFS 时间复杂度 O(V²)
- 邻接表的 DFS 时间复杂度 O(V+E)

## 最小生成树（MST）

### Prim 算法（从顶点扩展）

思想：从一个顶点开始，每次选「已选顶点集 → 未选顶点集」中权值最小的边，加入对应顶点。

```c
#define INF 0x3fffffff
void Prim(MGraph G, int v0) {
    int lowcost[MaxVertexNum];  // 各顶点到已选集合的最小边权
    int closest[MaxVertexNum];  // 记录该最小边对应的已选顶点
    for (int i = 0; i < G.vexnum; i++) {
        lowcost[i] = G.Edge[v0][i];
        closest[i] = v0;
    }
    lowcost[v0] = 0;  // v0 加入集合

    for (int i = 1; i < G.vexnum; i++) {  // 找 n-1 条边
        int min = INF, k = -1;
        for (int j = 0; j < G.vexnum; j++) {
            if (lowcost[j] != 0 && lowcost[j] < min) {
                min = lowcost[j]; k = j;
            }
        }
        // 选中顶点 k，边 (closest[k], k) 入 MST
        printf("(%d, %d)\n", closest[k], k);
        lowcost[k] = 0;  // k 加入已选集合
        for (int j = 0; j < G.vexnum; j++) {  // 更新 lowcost
            if (G.Edge[k][j] < lowcost[j]) {
                lowcost[j] = G.Edge[k][j];
                closest[j] = k;
            }
        }
    }
}
```

- 时间复杂度 O(V²)，适合稠密图

### Kruskal 算法（按边排序 + 并查集）

思想：所有边按权值排序，从小到大选边，用并查集判断是否成环，不成环则加入。

```c
// 并查集
int parent[MaxVertexNum];
int Find(int x) {
    while (parent[x] != x) x = parent[x];
    return x;  // 路径压缩可优化
}
void Union(int a, int b) {
    int ra = Find(a), rb = Find(b);
    if (ra != rb) parent[ra] = rb;
}

typedef struct { int u, v, w; } Edge;
Edge edges[MaxSize];

void Kruskal(MGraph G) {
    // 1. 提取所有边并排序（略）
    // 2. 初始化并查集
    for (int i = 0; i < G.vexnum; i++) parent[i] = i;
    int cnt = 0;  // 已选边数
    for (int i = 0; i < G.arcnum && cnt < G.vexnum - 1; i++) {
        int ru = Find(edges[i].u), rv = Find(edges[i].v);
        if (ru != rv) {           // 不成环
            printf("(%d, %d)\n", edges[i].u, edges[i].v);
            Union(ru, rv);
            cnt++;
        }
    }
}
```

- 时间复杂度 O(E logE)（排序为主），适合稀疏图

| 算法 | 思想 | 时间复杂度 | 适合 |
|------|------|-----------|------|
| Prim | 从顶点扩展 | O(V²) | 稠密图 |
| Kruskal | 从边扩展 | O(E logE) | 稀疏图 |

## 最短路径

### Dijkstra 算法（单源最短路径，逐轮松弛）

> 不适用于负权边。

```c
void Dijkstra(MGraph G, int v0) {
    int dist[MaxVertexNum];       // v0 到各顶点最短距离
    bool final[MaxVertexNum];     // 是否已确定最短路径
    int path[MaxVertexNum];       // 前驱顶点

    for (int i = 0; i < G.vexnum; i++) {
        dist[i] = G.Edge[v0][i];
        final[i] = false;
        path[i] = (G.Edge[v0][i] < INF) ? v0 : -1;
    }
    dist[v0] = 0; final[v0] = true;

    for (int i = 1; i < G.vexnum; i++) {  // 选 n-1 个顶点
        int min = INF, u = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (!final[j] && dist[j] < min) { min = dist[j]; u = j; }
        final[u] = true;  // u 的最短路径确定
        for (int j = 0; j < G.vexnum; j++)
            if (!final[j] && dist[u] + G.Edge[u][j] < dist[j]) {
                dist[j] = dist[u] + G.Edge[u][j];  // 松弛
                path[j] = u;
            }
    }
}
```

- 时间复杂度 O(V²)

## 拓扑排序

### AOV 网拓扑排序（入度法 + 栈/队列）

```c
bool TopologicalSort(ALGraph G) {
    int indegree[MaxVertexNum] = {0};
    // 1. 计算各顶点入度
    for (int i = 0; i < G.vexnum; i++) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p) { indegree[p->adjvex]++; p = p->next; }
    }
    // 2. 入度为 0 的入栈
    int stack[MaxVertexNum], top = -1;
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) stack[++top] = i;
    // 3. 拓扑排序
    int count = 0;  // 已输出顶点数
    while (top >= 0) {
        int u = stack[top--];  // 出栈（用队列也可）
        printf("%d ", u);
        count++;
        ArcNode *p = G.vertices[u].firstarc;
        while (p) {
            indegree[p->adjvex]--;        // 邻接点入度减1
            if (indegree[p->adjvex] == 0)
                stack[++top] = p->adjvex;
            p = p->next;
        }
    }
    return count == G.vexnum;  // true 表示无环
}
```

- 时间复杂度 O(V+E)
- 栈和队列都能用，但产生的拓扑序列不同
- 用栈时是 DFS 逆后序的近似（深度优先），用队列时偏 BFS

## 关键路径（AOE 网）

### AOV vs AOE

| | AOV 网 | AOE 网 |
|---|--------|--------|
| 顶点 | 活动 | 事件 |
| 边 | 前驱关系（无权） | 活动（带权值=持续时间） |
| 目的 | 拓扑排序 | 关键路径 |

### 四个关键量计算

#### 1. ve（事件最早发生时间）——正序拓扑排序取 max

- ve(源点) = 0
- ve(j) = max{ ve(i) + w(i→j) }，对所有以 j 为终点的边
- 按拓扑排序顺序计算

#### 2. vl（事件最迟发生时间）——逆序拓扑排序取 min

- vl(汇点) = ve(汇点)
- vl(i) = min{ vl(j) - w(i→j) }，对所有以 i 为起点的边
- 按逆拓扑排序顺序计算

#### 3. e（活动最早开始时间）

- e(i→j) = ve(i)  // 活动最早开始 = 起点事件最早发生

#### 4. l（活动最迟开始时间）

- l(i→j) = vl(j) - w(i→j)  // 活动最迟开始 = 终点事件最迟发生 - 活动时间

#### 关键活动

- **关键活动 = e == l 的活动**
- 关键活动组成的路径就是关键路径
- 关键路径长度 = ve(汇点) = vl(汇点)

void DFS_NonRec(MGraph G, int v) {

## 易错点清单

1. **BFS/DFS 序列不唯一**：取决于邻接点的访问顺序（编号大小或邻接表顺序）。考试需明确遍历规则。
2. **DFS 时间复杂度区分存储**：邻接矩阵 O(V²)、邻接表 O(V+E)。答案要看题目用的存储结构。
3. **Dijkstra 不能处理负权边**：负权边可能导致已确定最短路径的顶点被后续松弛更新，破坏贪心正确性。若问适用条件务必答这点。
4. **Dijkstra 松弛条件**：是 `dist[u] + w < dist[j]` 而非 `dist[u] + w <= dist[j]`，等号不影响正确性但可能影响序列。
5. **拓扑排序判断有无环**：最终输出顶点数 < 顶点总数则有环。不能只靠是否所有顶点入度归零判断。
6. **关键路径不唯一**：一个 AOE 网可能有不止一条关键路径，缩短工期需同时缩短所有关键路径上的活动。
7. **ve 取 max、vl 取 min**：ve 是取所有前驱最大值（等所有前置完成），vl 是取所有后继最小值（不能耽误后续）。方向别搞反。
8. **关键活动 e == l**：是活动的最早/最迟**开始**时间相等，不是事件的 ve == vl（虽然关键事件也满足 ve == vl）。
9. **AOV 网无权值、AOE 网有权值**：拓扑排序用于 AOV，关键路径用于 AOE。别混淆。
10. **并查集 Find 的路径压缩**：Kruskal 中 Union 前需判断 `Find(u) != Find(v)` 才 Union，否则会合并已连通分量导致成环。

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. 先给题目定性，按关键词对号：无权最短路 → BFS；带权单源最短路 → Dijkstra；联网成本最小 → MST；先后依赖/课程安排 → 拓扑排序（AOV 网）；工期/并行活动/关键活动 → 关键路径（AOE 网）
2. 再确认存储结构：邻接矩阵 O(V²) vs 邻接表 O(V+E)——复杂度答案随存储变，题目没说明时按邻接矩阵答并注明
3. 手动模拟题按统一格式作答：画图 → 列初始状态表（dist/indegree/lowcost/ve/vl）→ 逐轮记录"选了谁、更新了什么、理由"→ 给最终结果（问路径还要给 path 数组或路径序列）
4. 判环三法备用：拓扑排序输出数 < V；DFS 三色标记（灰遇灰即有环）；无向图用并查集（Find 相同已在同分量）
5. 关键路径题先写拓扑序：正序推 ve（取 max）、逆序推 vl（取 min），逐边算 e 和 l，e==l 的是关键活动；注意关键路径可能不唯一

**知识串联提示：**
- 与其他板块的关联：DFS/BFS 的引擎是栈队列板块的栈（显式栈/递归系统栈）和队列；Kruskal 的判环依赖并查集，邻接表本质是"数组 + 单链表"（线性表板块的直接应用）；Dijkstra 与 Prim 的"逐轮选最小 + 更新数组"框架同构，这种贪心选择思想与排序板块堆优化的选择也相通；AOE 网的 ve/vl 必须按拓扑序计算——拓扑排序是关键路径的前置
- 容易混淆的概念对比：AOV（顶点=活动、无权）vs AOE（边=活动带权）；BFS 求的是无权最短路，不能直接用于带权图；Dijkstra 不能处理负权边（贪心确定的顶点不可撤销）；DFS 生成树高度 ≥ BFS 生成树高度；拓扑排序用栈或队列结果不同但都合法；缩短工期必须缩短所有关键路径上的活动，只缩一条无效

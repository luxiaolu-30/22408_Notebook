# 数据结构 强化-排序

- **选择题必考，大题偶尔出现（4/10 年）**

## 插入排序

### 直接插入排序

```c
void InsertSort(int A[], int n) {
    int i, j, temp;
    for (i = 1; i < n; i++) {      // 第1个元素视为已排序
        if (A[i] < A[i - 1]) {     // 需要插入
            temp = A[i];
            for (j = i - 1; j >= 0 && A[j] > temp; j--)
                A[j + 1] = A[j];   // 后移
            A[j + 1] = temp;        // 插入
        }
    }
}
```

- 最好 O(n)（已有序），最坏 O(n²)（逆序），平均 O(n²)
- 稳定排序
- 空间 O(1)

### 折半插入排序

```c
void BinInsertSort(int A[], int n) {
    int i, j, low, high, mid, temp;
    for (i = 1; i < n; i++) {
        temp = A[i];
        low = 0; high = i - 1;
        while (low <= high) {      // 折半查找插入位置
            mid = (low + high) / 2;
            if (A[mid] > temp) high = mid - 1;
            else low = mid + 1;
        }
        for (j = i - 1; j >= low; j--)
            A[j + 1] = A[j];       // 后移
        A[low] = temp;
    }
}
```

- 查找部分 O(n logn)，移动部分仍 O(n)，整体仍 O(n²)
- 稳定排序

### 希尔排序（增量序列模拟）

```c
void ShellSort(int A[], int n) {
    int dk, i, j, temp;
    for (dk = n / 2; dk >= 1; dk /= 2) {  // 增量序列 n/2, n/4, ..., 1
        for (i = dk; i < n; i++) {
            if (A[i] < A[i - dk]) {
                temp = A[i];
                for (j = i - dk; j >= 0 && A[j] > temp; j -= dk)
                    A[j + dk] = A[j];
                A[j + dk] = temp;
            }
        }
    }
}
```

- 时间复杂度取决于增量序列，约 O(n^1.3) ~ O(n²)
- **不稳定**排序
- 空间 O(1)

#### 希尔排序手动模拟示例

```
初始：{49, 38, 65, 97, 76, 13, 27, 49*, 55, 04}
（49* 标注第二个49）

第1趟 dk=5：
分为5组：{49,13} {38,27} {65,49*} {97,55} {76,04}
组内排序后：{13,49} {27,38} {49*,65} {55,97} {04,76}
结果：{13, 27, 49*, 55, 04, 49, 38, 65, 97, 76}

第2趟 dk=2：
分为2组：{13,49*,04,38,97} {27,55,49,65,76}
组内排序后：{04,13,38,49*,97} {27,49,55,65,76}
结果：{04, 27, 13, 49, 38, 55, 49*, 65, 97, 76}

第3趟 dk=1：直接插入排序
结果：{04, 13, 27, 38, 49, 49*, 55, 65, 76, 97}
```

## 交换排序

### 冒泡排序

```c
void BubbleSort(int A[], int n) {
    int i, j, temp;
    bool flag;
    for (i = 0; i < n - 1; i++) {
        flag = false;
        for (j = n - 1; j > i; j--) {  // 从后往前冒泡
            if (A[j - 1] > A[j]) {     // 相邻比较
                temp = A[j]; A[j] = A[j-1]; A[j-1] = temp;
                flag = true;
            }
        }
        if (!flag) break;  // 一趟无交换则有序
    }
}
```

- 最好 O(n)（已有序），最坏 O(n²)，平均 O(n²)
- 稳定排序
- 空间 O(1)
- 每趟将一个最小元素冒到前面

### 快速排序（partition 过程手动模拟）

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];  // 选第一个为基准
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];  // 小于基准的移到左侧
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];  // 大于基准的移到右侧
    }
    A[low] = pivot;        // 基准归位
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pos = Partition(A, low, high);
        QuickSort(A, low, pos - 1);
        QuickSort(A, pos + 1, high);
    }
}
```

- 最好 O(n logn)，最坏 O(n²)（已有序/逆序），平均 O(n logn)
- **不稳定**排序
- 空间 O(logn)（递归栈），最坏 O(n)
- 是所有内部排序中平均性能最好的

## 选择排序

### 简单选择排序

```c
void SelectSort(int A[], int n) {
    int i, j, min, temp;
    for (i = 0; i < n - 1; i++) {
        min = i;
        for (j = i + 1; j < n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) {
            temp = A[i]; A[i] = A[min]; A[min] = temp;
        }
    }
}
```

- 最好/最坏/平均都 O(n²)
- **不稳定**排序
- 空间 O(1)
- 比较次数固定 O(n²)，与初始序列无关

### 堆排序

#### 堆的定义

- 大根堆：每个节点值 >= 其子节点值（根最大）
- 小根堆：每个节点值 <= 其子节点值（根最小）
- 堆是完全二叉树，用数组存储

#### 堆的建立（自下而上调整）

```c
// 向下调整（以大根堆为例）
void AdjustDown(int A[], int k, int len) {
    int temp = A[k];
    for (int i = 2 * k + 1; i < len; i = 2 * i + 1) {  // 左孩子下标
        if (i + 1 < len && A[i] < A[i + 1]) i++;  // 选较大的孩子
        if (temp >= A[i]) break;   // 已满足堆性质
        A[k] = A[i];               // 孩子上移
        k = i;                     // 继续向下
    }
    A[k] = temp;  // 原值归位
}

// 建堆：从最后一个非叶节点开始，自下而上调整
void BuildMaxHeap(int A[], int len) {
    for (int i = len / 2 - 1; i >= 0; i--)  // 最后一个非叶节点
        AdjustDown(A, i, len);
}
```

> 注：数组下标从 0 开始时，节点 i 的左孩子为 2i+1，右孩子为 2i+2，父节点为 (i-1)/2。

#### 堆排序过程

```c
void HeapSort(int A[], int n) {
    BuildMaxHeap(A, n);          // 1. 建大根堆
    for (int i = n - 1; i > 0; i--) {
        int temp = A[0]; A[0] = A[i]; A[i] = temp;  // 2. 交换堆顶到末尾
        AdjustDown(A, 0, i);    // 3. 调整剩余部分为大根堆
    }
}
```

## 归并排序

### 2路归并排序

```c
int *B = (int *)malloc(sizeof(int) * n);  // 辅助数组

void Merge(int A[], int low, int mid, int high) {
    int i, j, k;
    for (k = low; k <= high; k++) B[k] = A[k];  // 复制到辅助数组
    for (i = low, j = mid + 1, k = low; i <= mid && j <= high;) {
        if (B[i] <= B[j]) A[k++] = B[i++];
        else A[k++] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];  // 剩余部分
    while (j <= high) A[k++] = B[j++];
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);     // 左半排序
        MergeSort(A, mid + 1, high); // 右半排序
        Merge(A, low, mid, high);   // 合并
    }
}
```

- 最好/最坏/平均都 O(n logn)
- 稳定排序
- 空间 O(n)（辅助数组）
- 归并趟数 = ⌈log₂n⌉

#### 归并排序分治过程示例

```
初始：{49, 38, 65, 97, 76, 13, 27}

第1趟（len=1→2）：两两归并
  [49] [38] → [38, 49]
  [65] [97] → [65, 97]
  [76] [13] → [13, 76]
  [27]      → [27]
  结果：{38, 49, 65, 97, 13, 76, 27}

第2趟（len=2→4）：四四归并
  [38, 49] [65, 97] → [38, 49, 65, 97]
  [13, 76] [27]      → [13, 27, 76]
  结果：{38, 49, 65, 97, 13, 27, 76}

第3趟（len=4→7）：整体归并
  [38, 49, 65, 97] [13, 27, 76] → [13, 27, 38, 49, 65, 76, 97]
  最终：{13, 27, 38, 49, 65, 76, 97}
```

## 基数排序

### 分配 + 收集

```
示例：{278, 109, 063, 930, 589, 184, 505, 269, 008, 083}
基数为10，关键字位数为3

第1趟（按个位分配）：
分配到桶：0→930,008 | 3→063,083 | 4→184 | 5→505 | 8→278,589 | 9→109,269
收集：{930, 008, 063, 083, 184, 505, 278, 589, 109, 269}

第2趟（按十位分配）：
分配到桶：0→930,008,109 | 3→063 | 6→269 | 7→278 | 8→083,184,589 | 5→505
收集：{930, 008, 109, 063, 269, 278, 083, 184, 589, 505}

第3趟（按百位分配）：
分配到桶：0→008,063,083 | 1→109,184 | 2→278,269 | 5→589,505 | 9→930
收集：{008, 063, 083, 109, 184, 269, 278, 505, 589, 930}
```

- 时间复杂度 O(d(n+r))，d 为关键字位数，r 为基数，n 为元素数
- **稳定**排序
- 空间 O(r)（桶）
- 不需要比较关键字，适合多关键字排序

## 外部排序

### 败者树

- 用于 k 路归并的优化，减少比较次数
- 从 k 个归并段中选最小值，每次只需 O(log₂k) 次比较
- 比简单选优（O(k) 次比较）更高效

### 置换-选择排序（生成初始归并段）

- 用工作区（内存 w 个记录）扫描一遍文件
- 当工作区满时选最小值输出，形成递增的归并段
- 当工作区中最小值大于当前归并段最后一个值时，该记录冻结
- 所有记录都冻结后，开新归并段，解冻所有记录继续
- 得到的初始归并段平均长度为 2w（w 为工作区大小）

### 最佳归并树

- 对长度不等的初始归并段进行 k 路归并
- 类似哈夫曼树：短的归并段多参加归并（靠近叶子），长的少参加
- 补充虚段使 (n-1) % (k-1) == 0，再建 k 叉哈夫曼树
- 目标：最小化总 I/O 次数

## 各排序算法特性对比表

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定性 | 备注 |
|------|------|------|------|------|--------|------|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 | 顺序表+链表均可 |
| 折半插入 | O(n²) | O(n²) | O(n²) | O(1) | 稳定 | 查找更快，移动不变 |
| 希尔排序 | — | O(n^1.3) | O(n²) | O(1) | 不稳定 | 增量分组 |
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 | 可提前终止 |
| 快速排序 | O(n logn) | O(n logn) | O(n²) | O(logn) | 不稳定 | 平均最快 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 | 比较次数固定 |
| 堆排序 | O(n logn) | O(n logn) | O(n logn) | O(1) | 不稳定 | 适合大数据 |
| 归并排序 | O(n logn) | O(n logn) | O(n logn) | O(n) | 稳定 | 需额外空间 |
| 基数排序 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | 稳定 | 非比较排序 |

> **稳定性口诀**：插冒归基稳定，希快选堆不稳定（直接插入、冒泡、归并、基数是稳定的；希尔、快速、选择、堆排是不稳定的）

> **时间下界**：比较排序最好只能 O(n logn)，基数排序等非比较排序可突破此下界。

## 快排和堆排的手动模拟答题格式

### 快排 partition 答题格式

```
1. 标注基准值 pivot
2. 画双指针 low / high 的移动过程
3. 每一步标注：
   - 指针移动方向（high左移找小值 / low右移找大值）
   - 交换前后的数组状态（before → after）
   - 空出的位置（被覆盖的槽位）
4. 最终 pivot 归位，标注基准位置 pos
5. 写出左右子序列，标注递归继续
```

### 堆排序答题格式

```
1. 画出初始完全二叉树（标注下标）
2. 建堆过程：从最后一个非叶节点 (n/2-1) 开始
   - 逐节点标注调整过程
   - 每次调整标明：比较的对象、是否交换、交换后位置
3. 输出大根堆后的数组状态
4. 排序过程：
   - 每趟：交换堆顶到末尾 → 调整堆 → 标注有序段边界（用 | 分隔）
   - 画出每趟后的数组状态
5. 最终有序结果
```

## 易错点清单

1. **稳定性判断**：直接插入、冒泡、归并、基数排序稳定；希尔、快速、选择、堆排不稳定。选择题高频考点。
2. **快排最坏情况**：已有序/逆序时退化为 O(n²)，且递归深度达 n 层，空间 O(n)。不要误以为快排所有情况都是 O(n logn)。
3. **快排基准选取影响性能**：选第一个元素为基准时，有序序列导致最坏情况。随机选或取中位数可优化但 408 不要求。
4. **快排不稳定原因**：`A[high] >= pivot` 用 `>=` 可能跳过等值元素，导致相对顺序改变。
5. **堆排序建堆起点**：从**最后一个非叶节点**（下标 n/2-1，数组从0开始）开始向上调整，不是从根开始。
6. **大根堆 vs 小根堆**：升序排序用大根堆（堆顶最大换到末尾）；降序排序用小根堆。别搞反。
7. **堆排序空间 O(1)**：虽然堆是树形结构，但用数组存储不需要额外指针空间，只有递归调整可能用 O(1)（迭代实现）。
8. **归并排序空间 O(n)**：需要辅助数组 B[n]，这是与快排堆排（O(1) 空间）的关键区别。
9. **选择排序比较次数固定**：简单选择排序比较次数始终为 n(n-1)/2，与初始序列无关。这是与插入排序的不同点。
10. **归并趟数**：n 个元素 k 路归并，趟数为 ⌈log_k(n)⌉，每趟 O(n) 时间。
11. **基数排序不比较关键字**：基数排序是分配+收集，不是基于比较的排序，所以没有 O(n logn) 下界限制。
12. **希尔排序不稳定**：虽然基于插入排序，但跨步长比较可能改变相同元素的相对顺序。

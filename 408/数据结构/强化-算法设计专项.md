# 数据结构 强化-算法设计专项

## 41 题算法设计题专项训练

> 数据口径：2016-2025 近 10 年大题统计。DS 大题为 41-42 题（22-24分）。
> 41 题通常为算法设计题，42 题为综合应用题。

## 答题规范

### 标准答题结构

```
1. 数据结构定义
   - 定义题目涉及的链表/树/图等结构
   - 若题目已给定义则不需重复

2. 函数签名
   - 明确返回类型、函数名、参数列表
   - C 语言用指针传参（int*），C++ 可用引用（int&）
   - 408 允许用 C/C++ 混合写法

3. 边界处理（评分要点！）
   - 空表 / 空树 / 空数组 / 单元素
   - k = 0 / k 超出范围
   - 特殊输入（已有序 / 全相同等）

4. 核心逻辑
   - 变量命名语义化
   - 每步加注释说明操作目的
   - 指针操作前后注意保存后继

5. 复杂度分析（必写！）
   - 时间复杂度：O(?) + 一句话理由
   - 空间复杂度：O(?) + 递归考虑栈空间

标准模板：
/*
   功能：[描述函数做什么]
   时间复杂度：O(n)，遍历一次链表
   空间复杂度：O(1)，仅用常数辅助空间
*/
```

## 按题型分类的模板代码

### 一、链表操作类

#### 1. 链表反转（头插法）

```c
typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;

LinkList Reverse(LinkList L) {
    LNode *p = L->next, *q;
    L->next = NULL;          // 断开，变成空表
    while (p) {
        q = p->next;         // 保存后继
        p->next = L->next;   // 头插到 L 之后
        L->next = p;
        p = q;
    }
    return L;
}
// 时间 O(n)，空间 O(1)
```

#### 2. 有序链表合并（双指针）

```c
LinkList Merge(LinkList La, LinkList Lb) {
    LNode *pa = La->next, *pb = Lb->next;
    La->next = NULL;  // 用 La 的头节点做结果头
    LNode *tail = La;
    while (pa && pb) {
        if (pa->data <= pb->data) {
            tail->next = pa; pa = pa->next;
        } else {
            tail->next = pb; pb = pb->next;
        }
        tail = tail->next;
    }
    tail->next = pa ? pa : pb;  // 接上剩余段
    free(Lb);                    // 释放 Lb 头节点
    return La;
}
// 时间 O(m+n)，空间 O(1)
```

#### 3. 找中点（快慢指针）

```c
LNode* FindMiddle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast->next && fast->next->next) {
        slow = slow->next;       // 走1步
        fast = fast->next->next; // 走2步
    }
    return slow;  // 奇数个节点时是中间，偶数个时是前半段最后一个
}
// 时间 O(n)，空间 O(1)
```

#### 4. 判环 + 找环入口（Floyd）

```c
// 判环
bool HasCycle(LinkList L) {
    LNode *fast = L->next, *slow = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

// 找环入口
LNode* CycleEntry(LinkList L) {
    LNode *fast = L->next, *slow = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;
    }
    if (!fast || !fast->next) return NULL;  // 无环
    LNode *p = L->next;
    while (p != slow) { p = p->next; slow = slow->next; }
    return p;
}
// 时间 O(n)，空间 O(1)
```

### 二、树操作类

#### 1. 求树高度

```c
typedef struct BiTNode { int data; struct BiTNode *lchild, *rchild; } BiTNode, *BiTree;

int Height(BiTree T) {
    if (!T) return 0;
    int lh = Height(T->lchild);
    int rh = Height(T->rchild);
    return (lh > rh ? lh : rh) + 1;
}
// 时间 O(n)，空间 O(h)（h 为树高，递归栈）
```

#### 2. 最近公共祖先（LCA）

```c
// 通用二叉树 LCA
BiTNode* LCA(BiTree T, BiTNode *p, BiTNode *q) {
    if (!T || T == p || T == q) return T;
    BiTNode *L = LCA(T->lchild, p, q);
    BiTNode *R = LCA(T->rchild, p, q);
    if (L && R) return T;   // p, q 分布两侧 → 当前节点是 LCA
    return L ? L : R;       // 都在同一侧
}
// 时间 O(n)，空间 O(h)
```

#### 3. 遍历变体：求叶子节点数

```c
int LeafCount(BiTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;  // 叶子
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}
```

#### 4. 判断 BST

```c
// 中序遍历递增 → 是 BST
// 用 pre 记录前驱值（需全局或引用传递）
bool isBST(BiTree T, int *pre) {
    if (!T) return true;
    if (!isBST(T->lchild, pre)) return false;
    if (T->data <= *pre) return false;  // ⚠️ <= 而非 <
    *pre = T->data;
    return isBST(T->rchild, pre);
}
// 调用：int pre = -1e9; isBST(T, &pre);
```

#### 5. 判断完全二叉树

```c
bool isComplete(BiTree T) {
    if (!T) return true;
    BiTNode *queue[MaxSize]; int front = 0, rear = 0;
    queue[rear++] = T;
    bool metNull = false;
    while (front != rear) {
        BiTNode *p = queue[front++];
        if (!p) { metNull = true; continue; }
        if (metNull) return false;
        queue[rear++] = p->lchild;
        queue[rear++] = p->rchild;
    }
    return true;
}
// 时间 O(n)，空间 O(n)（队列最大宽度）
```

### 三、图算法类

#### 1. BFS 遍历

```c
void BFS(MGraph G, int v) {
    bool visited[MaxVertexNum] = {false};
    int queue[MaxVertexNum], front = 0, rear = 0;
    visited[v] = true;
    queue[rear++] = v;
    while (front != rear) {
        int u = queue[front++];
        Visit(u);
        for (int w = 0; w < G.vexnum; w++)
            if (G.Edge[u][w] && !visited[w]) {
                visited[w] = true;
                queue[rear++] = w;
            }
    }
}
```

#### 2. Dijkstra 最短路径

```c
void Dijkstra(MGraph G, int v0, int dist[], int path[]) {
    bool final[MaxVertexNum] = {false};
    for (int i = 0; i < G.vexnum; i++) {
        dist[i] = G.Edge[v0][i];
        path[i] = (dist[i] < INF) ? v0 : -1;
    }
    final[v0] = true; dist[v0] = 0;
    for (int i = 1; i < G.vexnum; i++) {
        int min = INF, u = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (!final[j] && dist[j] < min) { min = dist[j]; u = j; }
        final[u] = true;
        for (int j = 0; j < G.vexnum; j++)
            if (!final[j] && dist[u] + G.Edge[u][j] < dist[j]) {
                dist[j] = dist[u] + G.Edge[u][j];
                path[j] = u;
            }
    }
}
// 时间 O(V²)，空间 O(V)
```

#### 3. Prim 最小生成树

```c
void Prim(MGraph G, int v0) {
    int lowcost[MaxVertexNum], closest[MaxVertexNum];
    for (int i = 0; i < G.vexnum; i++) {
        lowcost[i] = G.Edge[v0][i];
        closest[i] = v0;
    }
    lowcost[v0] = 0;
    for (int i = 1; i < G.vexnum; i++) {
        int min = INF, k = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (lowcost[j] && lowcost[j] < min) { min = lowcost[j]; k = j; }
        printf("(%d,%d)\n", closest[k], k);
        lowcost[k] = 0;
        for (int j = 0; j < G.vexnum; j++)
            if (G.Edge[k][j] < lowcost[j]) { lowcost[j] = G.Edge[k][j]; closest[j] = k; }
    }
}
```

#### 4. 拓扑排序

```c
bool TopoSort(ALGraph G) {
    int indegree[MaxVertexNum] = {0};
    for (int i = 0; i < G.vexnum; i++) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p) { indegree[p->adjvex]++; p = p->next; }
    }
    int stack[MaxVertexNum], top = -1, count = 0;
    for (int i = 0; i < G.vexnum; i++)
        if (!indegree[i]) stack[++top] = i;
    while (top >= 0) {
        int u = stack[top--]; count++;
        ArcNode *p = G.vertices[u].firstarc;
        while (p) {
            if (--indegree[p->adjvex] == 0) stack[++top] = p->adjvex;
            p = p->next;
        }
    }
    return count == G.vexnum;  // true = 无环
}
```

### 四、数组操作类

#### 1. 双指针：有序数组交集

```c
int intersect(int a[], int na, int b[], int nb, int c[]) {
    int i = 0, j = 0, k = 0;
    while (i < na && j < nb) {
        if (a[i] == b[j]) { c[k++] = a[i]; i++; j++; }
        else if (a[i] < b[j]) i++;
        else j++;
    }
    return k;
}
```

#### 2. 滑动窗口：求最长不重复子串长度

```c
int lengthOfLongestSubstring(int a[], int n) {
    int freq[256] = {0};  // 假设元素范围为0-255
    int left = 0, maxLen = 0;
    for (int right = 0; right < n; right++) {
        freq[a[right]]++;
        while (freq[a[right]] > 1) {  // 有重复
            freq[a[left]]--;
            left++;
        }
        maxLen = (right - left + 1) > maxLen ? (right - left + 1) : maxLen;
    }
    return maxLen;
}
// 时间 O(n)，空间 O(1)（固定256）
```

#### 3. 摩尔投票法：主元素

```c
int majorityElement(int nums[], int n) {
    int cand = nums[0], cnt = 1;
    for (int i = 1; i < n; i++) {
        if (cnt == 0) { cand = nums[i]; cnt = 1; }
        else if (nums[i] == cand) cnt++;
        else cnt--;
    }
    // 验证（如不保证存在）
    cnt = 0;
    for (int i = 0; i < n; i++) if (nums[i] == cand) cnt++;
    return cnt > n / 2 ? cand : -1;
}
// 时间 O(n)，空间 O(1)
```

#### 4. 循环移位（三次反转）

```c
void reverse(int a[], int l, int r) {
    while (l < r) { int t = a[l]; a[l] = a[r]; a[r] = t; l++; r--; }
}
void rotate(int a[], int n, int k) {
    k %= n;
    reverse(a, 0, n - 1);
    reverse(a, 0, k - 1);
    reverse(a, k, n - 1);
}
// 时间 O(n)，空间 O(1)
```

### 五、递归设计类

#### 1. 分治：归并排序

```c
void mergeSort(int a[], int low, int high, int tmp[]) {
    if (low >= high) return;
    int mid = (low + high) / 2;
    mergeSort(a, low, mid, tmp);
    mergeSort(a, mid + 1, high, tmp);
    // merge
    int i = low, j = mid + 1, k = low;
    for (int x = low; x <= high; x++) tmp[x] = a[x];
    while (i <= mid && j <= high) {
        if (tmp[i] <= tmp[j]) a[k++] = tmp[i++];
        else a[k++] = tmp[j++];
    }
    while (i <= mid) a[k++] = tmp[i++];
    while (j <= high) a[k++] = tmp[j++];
}
// 时间 O(n logn)，空间 O(n)
```

#### 2. 回溯：全排列

```c
void permute(int a[], int start, int n) {
    if (start == n) {
        for (int i = 0; i < n; i++) printf("%d ", a[i]);
        printf("\n");
        return;
    }
    for (int i = start; i < n; i++) {
        int t = a[start]; a[start] = a[i]; a[i] = t;  // 交换
        permute(a, start + 1, n);
        t = a[start]; a[start] = a[i]; a[i] = t;       // 回溯
    }
}
```

## 模拟训练题（5 道，附思路提示）

### 训练 1：链表分区

> 以给定值 x 为基准，将链表中小于 x 的节点放到前面，大于等于 x 的放到后面，保持各段原相对顺序。

**思路提示**：
- 拆成两个子链表（小于段 + 大于等于段），用两个头节点和尾指针
- 遍历原链表，按值分别接尾
- 最后将两段连接，小于段尾接大于等于段头
- 时间 O(n)，空间 O(1)

```c
LinkList Partition(LinkList L, int x) {
    LNode smallHead, bigHead, *s = &smallHead, *b = &bigHead;
    LNode *p = L->next;
    while (p) {
        if (p->data < x) { s->next = p; s = p; }
        else { b->next = p; b = p; }
        p = p->next;
    }
    b->next = NULL;    // ⚠️ 大段尾置空
    s->next = bigHead.next;
    L->next = smallHead.next;
    return L;
}
```

### 训练 2：二叉树的最大路径和

> 求二叉树中任意节点到任意节点的路径上的最大权和（路径至少含一个节点）。

**思路提示**：
- 后序遍历，每个节点计算「从该节点向下延伸的最大单侧路径和」
- 更新全局最大 = max(全局, 左侧贡献 + 右侧贡献 + 节点值)
- 负贡献直接截断为 0（不取那条分支）
- 时间 O(n)，空间 O(h)

```c
int maxSum = -1e9;
int maxGain(BiTree T) {
    if (!T) return 0;
    int L = max(0, maxGain(T->lchild));  // 负贡献截断
    int R = max(0, maxGain(T->rchild));
    maxSum = max(maxSum, L + R + T->data);
    return max(L, R) + T->data;  // 返回单侧最大
}
```

### 训练 3：数组中第 K 大元素

> 在无序数组中找第 K 大的元素。

**思路提示**：
- 快排 partition 思路：选基准，小于基准的放左，大于放右
- 基准归位后若位置 = k-1 则找到
- 若基准位置 < k-1，递归右半；否则递归左半
- 平均时间 O(n)，最坏 O(n²)

```c
int findKth(int a[], int low, int high, int k) {
    int pivot = a[low], i = low, j = high;
    while (i < j) {
        while (i < j && a[j] <= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] >= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;
    if (i == k - 1) return a[i];
    else if (i < k - 1) return findKth(a, i + 1, high, k);
    else return findKth(a, low, i - 1, k);
}
```

### 训练 4：二叉树的层序锯齿遍历

> 层序遍历二叉树，但奇数层从左到右、偶数层从右到左输出。

**思路提示**：
- 用队列做层序遍历，记录每层节点数
- 偶数层逆序输出（可用栈或从尾部读入）
- 时间 O(n)，空间 O(n)

### 训练 5：判断图中是否有环

> 给定有向图，判断是否含环。

**思路提示**：
- 拓扑排序：若能输出全部顶点则无环，否则有环
- 或用 DFS + 三色标记法（白/灰/黑）
- 灰色节点遇到灰色后继 → 有环
- 时间 O(V+E)

```c
// 三色标记 DFS 判环
// 0=白(未访问) 1=灰(在栈中) 2=黑(已完成)
bool hasCycle_DFS(ALGraph G, int v, int color[]) {
    color[v] = 1;  // 灰
    ArcNode *p = G.vertices[v].firstarc;
    while (p) {
        int w = p->adjvex;
        if (color[w] == 1) return true;  // 遇到灰 → 环
        if (color[w] == 0 && hasCycle_DFS(G, w, color)) return true;
        p = p->next;
    }
    color[v] = 2;  // 黑
    return false;
}
```

## 易丢分点清单

1. **边界遗漏（最致命）**：空表、空树、单节点、k=0、k 超界等边界未处理，直接扣 2-3 分。代码开头必写 `if (!L) return;` 之类。
2. **复杂度分析未写**：题目明确要求分析时间/空间复杂度，不写或不完整直接扣分。必写 O(?) + 一句话理由。
3. **指针后继丢失**：删除/反转链表节点时，未先保存 `next` 就修改 `next`，导致后续节点丢失。务必 `q = p->next` 先保存。
4. **尾节点未置空**：链表反转/合并/拆分后，新尾节点的 `next` 未设为 NULL，导致遍历越界。每次修改链表尾务必 `tail->next = NULL`。
5. **函数签名不明确**：返回类型不匹配（void vs 非 void）、参数类型不匹配（值传递 vs 引用传递）。注意 C 语言无 `&` 引用，用指针。
6. **变量未初始化**：C 语言局部变量不初始化为随机值，链表 next / 数组计数器等未初始化可能出 bug。
7. **递归终止条件错误**：递归必须有正确终止条件，否则无限递归栈溢出。如二叉树递归 `if (!T) return 0;`。
8. **时间复杂度分析不区分最好最坏**：链表插入删除平均 O(n)，不能只写 O(1)。快排需说明最好 O(n logn) 最坏 O(n²)。
9. **注释不足**：核心逻辑不加注释，阅卷老师难以理解意图。关键步骤至少加一句注释。
10. **内存泄漏（不严重扣分但减印象）**：删除节点后未 `free`。408 一般不严格要求 free，但写了更好。
11. **数组越界**：循环条件 `i < n` 写成 `i <= n`，或 `j = i` 写成 `j = i + 1`，差一错误是高频 bug。
12. **数据结构定义与操作不匹配**：题给结构体是带头节点的链表，代码却按无头节点写。务必看清题目结构体定义。

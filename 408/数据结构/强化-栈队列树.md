# 数据结构 强化-栈队列树

> **本板块串联**：栈和队列是线性表的"受限版"，却因受限而成为最强工具——它们是遍历树和图的引擎；二叉树上承线性结构（遍历序列是线性的），下启查找与排序（BST/AVL/堆都是二叉树的变种）。

## 🧭 知识主线

本板块的主线是：**受限的线性结构服务于树**。栈限制"只在一端进出"，恰好匹配递归和 DFS 的"走到底再回头"——表达式求值、中缀转后缀、非递归遍历、递归的栈模拟，全是同一个原理；队列限制"一端进一端出"，恰好匹配 BFS/层序遍历的"先来先服务、按层扩散"。抓住这一点，零散知识点就串起来了：中缀转后缀（运算符栈）→ 后缀求值（操作数栈）→ 非递归遍历（节点栈，三种遍历的区别只在"访问时机"）→ 层序遍历（节点队列）。树的方面，核心骨架只有一个——**遍历**：先/中/后序是 DFS 的三个变体（访问根的时机不同），层序是 BFS；其余内容全是遍历的应用或变体：前序+中序还原树（先序定根、中序分左右，前序+后序不唯一）；BST（中序序列有序，插入查找走大小分支，删除分三种情况）；AVL（BST + 平衡因子，LL/RR/LR/RL 四种旋转对应失衡路径）；线索二叉树（把空指针改造成中序前驱后继）；判断完全二叉树（层序遇空后不得再非空）；LCA（BST 上用大小关系找分叉，普通树递归左右分治）；堆（完全二叉树 + 数组存储，归排序板块）。复习任何树的算法，先自问：它是 DFS 型还是 BFS 型？访问时机在何时？答案自然浮现。

## 栈

### 栈的基本操作

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;  // 栈顶指针，-1 表示空栈
} SqStack;

void InitStack(SqStack &S) { S.top = -1; }
bool StackEmpty(SqStack S) { return S.top == -1; }
bool Push(SqStack &S, int e) {
    if (S.top >= MaxSize - 1) return false;  // 栈满
    S.data[++S.top] = e;  // 先移后存
    return true;
}
bool Pop(SqStack &S, int &e) {
    if (S.top == -1) return false;
    e = S.data[S.top--];  // 先存后移
    return true;
}
```

> 注意：另一种实现 `top = 0` 初始化（先存后移），考试看题目约定。

### 表达式求值

#### 中缀转后缀（栈存运算符）

规则：
1. 操作数直接输出
2. 左括号入栈
3. 右括号：弹栈输出直到左括号（左括号丢弃不输出）
4. 运算符：弹栈输出所有优先级 >= 当前运算符的栈顶运算符，再入栈当前运算符
5. 栈非空则全部弹出输出

```
示例：A+B*(C-D)-E/F
后缀：ABCD-*+EF/-

过程：
A → 输出 A
+ → 栈空入栈，栈：+
B → 输出 B
* → + 优先级 < *，入栈，栈：+ *
( → 入栈，栈：+ * (
C → 输出 C
- → ( 在栈顶不比较优先级，入栈，栈：+ * ( -
D → 输出 D
) → 弹栈输出直到 (，输出 -，弹出 (，栈：+ *
- → 弹出 >= - 的：* 和 + 都弹出输出，入栈 -，栈：-
E → 输出 E
/ → - 优先级 < /，入栈，栈：- /
F → 输出 F
结束 → 弹栈：输出 / 和 -

结果：A B C D - * + E F / -
```

#### 后缀求值（栈存操作数）

规则：
1. 操作数入栈
2. 运算符：弹两个操作数计算后入栈（先弹的是右操作数！）

```
示例：ABCD-*+EF/-

栈状态变化：
A   → [A]
B   → [A, B]
C   → [A, B, C]
D   → [A, B, C, D]
-   → 弹 D, 弹 C → C-D=C' → [A, B, C']
*   → 弹 C', 弹 B → B*C'=B' → [A, B']
+   → 弹 B', 弹 A → A+B'=R → [R]
E   → [R, E]
F   → [R, E, F]
/   → 弹 F, 弹 E → E/F=E' → [R, E']
结束 → 栈中剩 R+E' 为最终结果
```

### 递归的栈模拟

递归调用本质是系统用栈保存：返回地址 + 局部变量。手动模拟递归即用显式栈替代系统栈。

```c
// 递归阶乘
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

// 栈模拟递归（以斐波那契为例）
int fib(int n) {
    int stack[100], top = -1;
    int result[100] = {0};
    stack[++top] = n;
    while (top >= 0) {
        int cur = stack[top--];
        if (cur <= 1) result[cur] = cur;
        else if (result[cur] == 0) {
            stack[++top] = cur;      // 重新入栈等结果
            stack[++top] = cur - 1;  // 先算左
            stack[++top] = cur - 2;  // 再算右
        }
    }
    return result[n];
}
```

## 队列

### 循环队列

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;  // front 指向队首元素，rear 指向队尾下一位置
} SqQueue;

void InitQueue(SqQueue &Q) { Q.front = Q.rear = 0; }
bool QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }

// ⚠️ 判满需要牺牲一个单元（否则满和空都是 front==rear）
bool QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MaxSize == Q.front;
}
bool EnQueue(SqQueue &Q, int e) {
    if (QueueFull(Q)) return false;
    Q.data[Q.rear] = e;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
bool DeQueue(SqQueue &Q, int &e) {
    if (QueueEmpty(Q)) return false;
    e = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
// 队列长度
int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MaxSize) % MaxSize;
}
```

> 另一种判满方案：设 `size` 变量计数，`size == MaxSize` 则满。无需牺牲单元。

### 队列在层序遍历中的应用

队列是二叉树层序遍历、图的 BFS 的核心数据结构。详见后文。

## 二叉树性质

1. **n0 = n2 + 1**：叶子节点数 = 度为2的节点数 + 1
   - 推导：n = n0 + n1 + n2，边数 = n - 1 = n1 + 2*n2 → 联立解得 n0 = n2 + 1
2. **完全二叉树高度**：n 个节点的完全二叉树高度为 ⌊log₂n⌋ + 1
3. 第 i 层最多 2^(i-1) 个节点（从第1层算起）
4. 深度为 h 的二叉树最多 2^h - 1 个节点
5. 完全二叉树节点编号 i：左孩子 2i，右孩子 2i+1（若存在且从1编号）

## 二叉树遍历

### 二叉树定义

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

### 先序/中序/后序递归遍历

```c
void Visit(BiTNode *p) { /* 访问节点 */ }

void PreOrder(BiTree T) {
    if (T) {
        Visit(T);
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}
void InOrder(BiTree T) {
    if (T) {
        InOrder(T->lchild);
        Visit(T);
        InOrder(T->rchild);
    }
}
void PostOrder(BiTree T) {
    if (T) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        Visit(T);
    }
}
```

### 非递归遍历（栈实现）

```c
// 中序非递归：左链入栈到底 → 弹出访问 → 转右子树
void InOrderNR(BiTree T) {
    BiTNode *stack[MaxSize]; int top = -1;
    BiTNode *p = T;
    while (p || top >= 0) {
        while (p) {            // 一路向左入栈
            stack[++top] = p;
            p = p->lchild;
        }
        p = stack[top--];      // 弹出
        Visit(p);              // 访问
        p = p->rchild;         // 转右子树
    }
}

// 先序非递归：与中序类似，只是访问时机在入栈时
void PreOrderNR(BiTree T) {
    BiTNode *stack[MaxSize]; int top = -1;
    BiTNode *p = T;
    while (p || top >= 0) {
        while (p) {
            Visit(p);          // 先序：入栈时即访问
            stack[++top] = p;
            p = p->lchild;
        }
        p = stack[top--];
        p = p->rchild;
    }
}

// 后序非递归：需要标记节点是否已访问右子树
void PostOrderNR(BiTree T) {
    BiTNode *stack[MaxSize]; int top = -1;
    BiTNode *p = T, *r = NULL; // r 记录最近访问过的节点
    while (p || top >= 0) {
        while (p) {
            stack[++top] = p;
            p = p->lchild;
        }
        p = stack[top];
        if (p->rchild && p->rchild != r) {
            p = p->rchild;     // 右子树未访问，转向右
        } else {
            top--;             // 弹出
            Visit(p);
            r = p;             // 记录最近访问
            p = NULL;          // p 置空防止重复左走
        }
    }
}
```

### 层序遍历（队列实现）

```c
void LevelOrder(BiTree T) {
    if (!T) return;
    BiTNode *queue[MaxSize]; int front = 0, rear = 0;
    queue[rear++] = T;
    while (front != rear) {
        BiTNode *p = queue[front++];  // 出队
        Visit(p);
        if (p->lchild) queue[rear++] = p->lchild;  // 左孩子入队
        if (p->rchild) queue[rear++] = p->rchild;  // 右孩子入队
    }
}
```

### 由前序+中序还原二叉树

步骤：
1. 前序第一个元素是根
2. 在中序中找到根，左边是左子树，右边是右子树
3. 递归处理左子树和右子树

```
示例：
前序：A B D E C F
中序：D B E A C F

1. 根 = A（前序首）
2. 中序中 A 左边 {D, B, E} = 左子树，右边 {C, F} = 右子树
3. 左子树前序 = B D E（前序中 A 之后取3个），中序 = D B E
   - 根 = B，左 = D，右 = E
4. 右子树前序 = C F，中序 = C F
   - 根 = C，左 = 空，右 = F

结果：
        A
       / \
      B   C
     / \   \
    D   E   F
```

> 同理可用「中序+后序」还原（后序最后一个是根）。但不能用「前序+后序」还原（不唯一）。

## BST（二叉排序树）操作

### BST 定义

左子树所有节点值 < 根 < 右子树所有节点值（中序遍历为有序序列）。

### 查找

```c
BiTNode* BST_Search(BiTree T, int key) {
    while (T && T->data != key) {
        T = (key < T->data) ? T->lchild : T->rchild;
    }
    return T;
}
```

### 插入

```c
bool BST_Insert(BiTree &T, int key) {
    if (!T) {
        T = (BiTNode*)malloc(sizeof(BiTNode));
        T->data = key;
        T->lchild = T->rchild = NULL;
        return true;
    }
    if (key == T->data) return false;  // 已存在不插入
    else if (key < T->data) return BST_Insert(T->lchild, key);
    else return BST_Insert(T->rchild, key);
}
```

### 删除（三种情况）

```c
// 删除节点有三种情况：
// 1. 叶子节点：直接删除
// 2. 只有一棵子树：用子树替代被删节点
// 3. 有两棵子树：用左子树最大值或右子树最小值替代，再删除替代节点
bool BST_Delete(BiTree &T, int key) {
    if (!T) return false;
    if (key < T->data) return BST_Delete(T->lchild, key);
    else if (key > T->data) return BST_Delete(T->rchild, key);
    else {  // 找到
        if (!T->lchild && !T->rchild) {       // 情况1：叶子
            free(T); T = NULL;
        } else if (!T->lchild) {               // 情况2a：只有右子树
            BiTNode *tmp = T; T = T->rchild; free(tmp);
        } else if (!T->rchild) {               // 情况2b：只有左子树
            BiTNode *tmp = T; T = T->lchild; free(tmp);
        } else {                               // 情况3：有两棵子树
            // 找右子树最小值替代
            BiTNode *min = T->rchild;
            while (min->lchild) min = min->lchild;
            T->data = min->data;
            BST_Delete(T->rchild, min->data);  // 递归删除替代节点
        }
        return true;
    }
}
```

## 平衡二叉树（AVL）

### 平衡因子 BF = 左子树高度 - 右子树高度，平衡时 |BF| <= 1

### 四种旋转

#### LL 旋转（右单旋）

```
    A                  B
   / \               /   \
  B   T3    →      C     A
 / \              / \   / \
C   T2           T0 T1 T2 T3
/ \
T0 T1
```
- 在 A 的左子树 B 的左子树上插入导致失衡
- 以 B 为支点右旋

#### RR 旋转（左单旋）

```
  A                    B
 / \                 /   \
T0  B       →      A     C
   / \           / \   / \
  T1  C         T0 T1 T2 T3
     / \
    T2 T3
```
- 在 A 的右子树 B 的右子树上插入导致失衡
- 以 B 为支点左旋

#### LR 旋转（先左后右双旋）

```
    A                  A                  C
   / \                / \               /   \
  B   T4    →       C   T4    →       B     A
 / \                / \               / \   / \
T0  C              B   T3            T0 T1 T2 T3
   / \            / \
  T1 T2          T0 T1
```
- 在 A 的左子树 B 的右子树上插入导致失衡
- 先对 B 左旋（变成 LL 型），再对 A 右旋

#### RL 旋转（先右后左双旋）

```
  A                  A                    C
 / \                / \                 /   \
T0  B     →       T0   C       →      A     B
   / \                / \             / \   / \
  C   T3            T1   B          T0 T1 T2 T3
 / \                     / \
T1 T2                   T2 T3
```
- 在 A 的右子树 B 的左子树上插入导致失衡
- 先对 B 右旋（变成 RR 型），再对 A 左旋

> 口诀：LL 右旋、RR 左旋、LR 先左后右、RL 先右后左。字母表示插入路径（失衡节点 → 子节点 → 新插入子树方向）。

## 常见算法设计题型

### 1. 求二叉树高度

```c
int Height(BiTree T) {
    if (!T) return 0;
    int lh = Height(T->lchild);
    int rh = Height(T->rchild);
    return (lh > rh ? lh : rh) + 1;
}
```

### 2. 判断 BST

```c
// 方法1：利用中序遍历递增特性
int pre = -1e9;  // 记录前驱值
bool isBST(BiTree T) {
    if (!T) return true;
    if (!isBST(T->lchild)) return false;
    if (T->data <= pre) return false;  // ⚠️ 必须 <=，等值也违法
    pre = T->data;
    if (!isBST(T->rchild)) return false;
    return true;
}
```

### 3. 最近公共祖先 LCA（BST 上）

```c
// BST 上的 LCA：利用大小关系
BiTNode* LCA_BST(BiTree T, int p, int q) {
    while (T) {
        if (T->data > p && T->data > q) T = T->lchild;      // 都在左子树
        else if (T->data < p && T->data < q) T = T->rchild; // 都在右子树
        else return T;  // 分叉点就是 LCA
    }
    return NULL;
}

// 普通二叉树上的 LCA：递归
BiTNode* LCA(BiTree T, BiTNode *p, BiTNode *q) {
    if (!T || T == p || T == q) return T;
    BiTNode *left = LCA(T->lchild, p, q);
    BiTNode *right = LCA(T->rchild, p, q);
    if (left && right) return T;  // p, q 分别在两侧
    return left ? left : right;   // 都在一侧
}
```

### 4. 判断完全二叉树

```c
// 层序遍历，遇到空节点后不应再出现非空节点
bool isComplete(BiTree T) {
    if (!T) return true;
    BiTNode *queue[MaxSize]; int front = 0, rear = 0;
    queue[rear++] = T;
    bool flag = false;  // 标记是否遇到空节点
    while (front != rear) {
        BiTNode *p = queue[front++];
        if (!p) { flag = true; continue; }  // 遇到空，标记
        if (flag) return false;  // 空之后又有非空 → 非完全
        queue[rear++] = p->lchild;
        queue[rear++] = p->rchild;
    }
    return true;
}
```

### 5. 线索化二叉树

```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;  // 0: 指向孩子，1: 指向前驱/后继
} ThreadNode, *ThreadTree;

ThreadNode *pre = NULL;  // 全局前驱

void InThread(ThreadTree T) {
    if (T) {
        InThread(T->lchild);
        // 当前节点左空则指向前驱
        if (!T->lchild) { T->lchild = pre; T->ltag = 1; }
        // 前驱右空则指向当前
        if (pre && !pre->rchild) { pre->rchild = T; pre->rtag = 1; }
        pre = T;
        InThread(T->rchild);
    }
}
```

## 易错点清单

1. **循环队列判空判满**：牺牲一个单元时 `(rear+1)%MaxSize == front` 判满、`front == rear` 判空；二者同时满足不可能，需区分方案。考试需明确说明用了哪种方案。
2. **中缀转后缀运算符优先级**：左结合运算符（如减法），遇到同优先级时也要弹出栈顶再入栈。不要误以为同优先级不弹出。
3. **后缀求值弹栈顺序**：先弹的是右操作数，后弹的是左操作数。减法/除法顺序不可搞反。
4. **二叉树性质 n0 = n2 + 1**：注意前提是二叉树（每个节点度 0/1/2），不是所有树的通用性质。
5. **后序非递归遍历**：需要额外标记 `r` 记录最近访问节点，否则右子树会被重复访问。这是最易出错的遍历。
6. **BST 删除情况3**：用右子树最小值（或左子树最大值）替代后，要递归删除原位置的替代节点，不要忘了。
7. **AVL 旋转方向**：LL 是右旋不是左旋。LL/RR 描述的是插入路径，旋转方向与之相反。LR/RL 是双旋。
8. **判断 BST 时比较用 <=**：BST 不允许等值节点，所以遇到 `==` 也应返回 false。
9. **线索化 pre 的全局性**：`pre` 是全局或引用传递，不能当作局部变量，否则中序前驱关系丢失。
10. **完全二叉树判断**：层序遍历遇空后不能再有非空。空节点也要入队列参与判断，不能跳过。

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. 栈/队列题先确认实现约定：栈 top=-1 还是 top=0 初始化；循环队列判空判满用哪种方案（牺牲单元 / size 计数）——没说清楚就先声明约定再答题
2. 表达式题对号入座：中缀转后缀用运算符栈（左括号入栈、右括号弹到左括号、同优先级先弹再入）；后缀求值用操作数栈（先弹的是右操作数！）
3. 树的算法题先归位到骨架：能一次遍历解决吗？DFS 型（递归/栈）还是 BFS 型（队列）？访问时机决定先/中/后序；需要"自底向上汇总"（高度/路径和）用后序递归，需要"按层"（层序/锯齿/判完全）用队列
4. 性质计算题用两条铁律：n0 = n2 + 1（用"数边"推导）；完全二叉树编号 i 的孩子是 2i/2i+1
5. 失衡旋转、BST 删除类题，先画出最小示意图再动手改指针，不凭空想象

**知识串联提示：**
- 与其他板块的关联：栈（显式/隐式系统栈）和队列是图板块 DFS/BFS 的直接引擎；BST/AVL 衔接查找板块（ASL 度量、B树的平衡思想一脉相承）；堆是排序板块堆排序的基础；循环队列的取模运算与散列表线性探测 (H(key)+i) mod m 同构；中序有序性是"判断 BST"与"折半查找判定树"的共同语言；非递归遍历的栈操作是理解递归栈空间的钥匙
- 容易混淆的概念对比：LL 旋转是右单旋（LL 描述的是插入路径，旋转方向相反）；top=-1（先移后存）vs top=0（先存后移）两套栈实现；牺牲单元方案里 front==rear 只可能是空栈；线索树中 ltag/rtag=1 时才指向遍历前驱/后继而非孩子；前序+中序可还原树但前序+后序不唯一

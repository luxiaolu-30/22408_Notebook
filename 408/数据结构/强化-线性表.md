# 数据结构 强化-线性表

> **本板块串联**：线性表是整个 DS 体系的起点——顺序表和链表是后续所有结构（栈/队列/树/图/散列表）的存储基础；而链表操作又是 41 题算法设计的绝对主力，本板块的双指针思维会贯穿全书。

## 🧭 知识主线

线性表所有考点围绕一条主线展开：**逻辑结构相同（一对一的线性关系），存储结构决定算法策略**。同一组基本操作——查找、插入、删除、反转、合并——放到顺序表和链表上是两套完全不同的实现：顺序表靠"下标 + 整体搬移"（随机存取 O(1)，插入删除 O(n)），链表靠"指针逐个定位 + 局部改接"（定位后改指针 O(1)，但定位本身 O(n)）。复习时不要逐个题型背代码，而是拿一个操作自问：顺序表怎么做？链表怎么做？复杂度差在哪？——这样所有题型自动归位：反转（三指针/头插）、合并（双指针尾插）、去重（相邻比较）、找中点/倒数第 k（快慢/前后双指针）、判环（Floyd 龟兔）、循环移位（三次反转）、主元素（摩尔投票）、原地去重/交集（读写双指针）。你会发现**双指针思想贯穿始终**：快慢指针处理"速度差"（中点/判环），前后指针处理"距离差"（倒数第 k），左右指针处理"区间划分"（交集/移位）——这正是 41 题最常考的思维能力。

## 顺序表操作

### 插入与删除时间复杂度分析

| 操作 | 最好情况 | 最坏情况 | 平均情况 | 说明 |
|------|----------|----------|----------|------|
| 插入 | O(1)（尾部插入） | O(n)（头部插入） | O(n) | 需后移 n-i+1 个元素 |
| 删除 | O(1)（尾部删除） | O(n)（头部删除） | O(n) | 需前移 n-i 个元素 |
| 按值查找 | O(1) | O(n) | O(n) | 顺序查找 |

### 顺序表基本操作代码

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

// 插入：在第 i（1-based）个位置插入元素 e
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1) return false;  // 边界
    if (L.length >= MaxSize) return false;          // 满
    for (int j = L.length; j >= i; j--)
        L.data[j] = L.data[j - 1];  // 后移
    L.data[i - 1] = e;
    L.length++;
    return true;
}

// 删除：删除第 i 个位置元素，用 e 返回
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++)
        L.data[j - 1] = L.data[j];  // 前移
    L.length--;
    return true;
}
```

## 链表算法高频题型

### 链表定义

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

### 1. 链表反转（三指针法 / 头插法）

```c
// 迭代法：三指针 prev, curr, next
LinkList ReverseList(LinkList L) {
    LNode *prev = NULL, *curr = L->next, *next;
    while (curr) {
        next = curr->next;   // 保存后继
        curr->next = prev;   // 反转指针
        prev = curr;         // 前移
        curr = next;
    }
    L->next = prev;  // 头指针指向新首节点
    return L;
}
```

- 时间复杂度 O(n)，空间复杂度 O(1)
- 递归法也可，但空间 O(n)

### 2. 有序链表合并（双指针法）

```c
// 将两个升序链表合并为升序链表（原地合并，不新建节点）
LinkList Merge(LinkList L1, LinkList L2) {
    LNode dummy;            // 哨兵节点，简化头插逻辑
    LNode *tail = &dummy;
    LNode *p = L1->next, *q = L2->next;
    while (p && q) {
        if (p->data <= q->data) {
            tail->next = p; p = p->next;
        } else {
            tail->next = q; q = q->next;
        }
        tail = tail->next;
    }
    tail->next = p ? p : q;  // 接上剩余
    L1->next = dummy.next;
    return L1;
}
```

- 时间复杂度 O(m+n)，空间复杂度 O(1)

### 3. 链表去重（快慢指针跳过重复值）

```c
// 升序链表去重，保留每个值的一次出现
void RemoveDup(LinkList L) {
    LNode *p = L->next;
    if (!p) return;
    while (p->next) {
        if (p->data == p->next->data) {
            LNode *tmp = p->next;
            p->next = tmp->next;
            free(tmp);
        } else {
            p = p->next;
        }
    }
}
```

- 时间复杂度 O(n)，空间复杂度 O(1)

### 4. 找中点（快慢指针法）

```c
// 返回链表中间节点（偶数个时返回前半段最后一个）
LNode* FindMiddle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;       // 慢指针走1步
        fast = fast->next->next; // 快指针走2步
    }
    return slow;
}
```

- 快指针到尾时，慢指针恰在中点
- 常用于归并排序分链表

### 5. 判环 / 找环入口（Floyd 龟兔赛跑算法）

```c
// 判环：快慢指针相遇则有环
bool HasCycle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

// 找环入口：相遇后，一指针回到头，两指针同速再走，再次相遇点即入口
LNode* FindCycleEntry(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;
    }
    if (!fast || !fast->next) return NULL;  // 无环
    LNode *p = L->next;
    while (p != slow) {
        p = p->next;
        slow = slow->next;
    }
    return p;
}
```

- 数学证明：设环外长度 a、环长 b，快指针走 2(a+b)、慢指针走 a+b，相遇时 slow 在环中走 b。重置后同步走 a 步即到入口。

### 6. 找倒数第 k 个节点（前指针先走 k 步）

```c
LNode* FindKthFromEnd(LinkList L, int k) {
    LNode *fast = L->next, *slow = L->next;
    for (int i = 0; i < k; i++) {  // 快指针先走k步
        if (!fast) return NULL;    // 链表不足k个
        fast = fast->next;
    }
    while (fast) {  // 同步前进
        slow = slow->next;
        fast = fast->next;
    }
    return slow;  // 快指针到尾时，慢指针在倒数第k
}
```

- 时间复杂度 O(n)，只需一次遍历

## 顺序表算法高频题型

### 1. 数组主元素（摩尔投票法）

> 主元素：出现次数超过 n/2 的元素（保证存在时）

```c
int MajorityElement(int nums[], int n) {
    int candidate = nums[0], count = 1;
    for (int i = 1; i < n; i++) {
        if (count == 0) { candidate = nums[i]; count = 1; }
        else if (nums[i] == candidate) count++;
        else count--;
    }
    // 如果不保证主元素存在，需二次遍历验证
    return candidate;
}
```

- 时间复杂度 O(n)，空间复杂度 O(1)
- 核心思想：不同元素两两抵消，剩余的一定是主元素

### 2. 原地移除重复（有序数组，双指针覆盖法）

```c
// 有序数组原地移除重复元素，返回新长度
int RemoveDuplicates(int nums[], int n) {
    if (n == 0) return 0;
    int j = 0;  // 慢指针：不重复段的末尾
    for (int i = 1; i < n; i++) {
        if (nums[i] != nums[j]) {
            j++;
            nums[j] = nums[i];
        }
    }
    return j + 1;
}
```

### 3. 循环移位（三次反转法）

```c
// 将数组右移 k 位（原地）
void Reverse(int nums[], int left, int right) {
    while (left < right) {
        int tmp = nums[left];
        nums[left] = nums[right];
        nums[right] = tmp;
        left++; right--;
    }
}

void Rotate(int nums[], int n, int k) {
    k %= n;  // 处理 k > n
    Reverse(nums, 0, n - 1);       // 全部反转
    Reverse(nums, 0, k - 1);      // 反转前k个
    Reverse(nums, k, n - 1);      // 反转剩余
}
```

- 时间复杂度 O(n)，空间复杂度 O(1)
- 三步反转原理：右移 k 位 = 全反转 + 前k反转 + 后段反转

### 4. 有序数组交集（双指针同步推进）

```c
// 返回有序数组 a 和 b 的交集（元素不重复）
int Intersect(int a[], int na, int b[], int nb, int result[]) {
    int i = 0, j = 0, k = 0;
    while (i < na && j < nb) {
        if (a[i] == b[j]) {
            result[k++] = a[i];
            i++; j++;
        } else if (a[i] < b[j]) i++;
        else j++;
    }
    return k;
}
```

## 易错点清单

1. **头指针 vs 头节点**：带头节点的链表，第一个数据节点是 `L->next`，遍历从 `L->next` 开始；不带头节点的链表，第一个节点就是 `L`。题目不明确时按带头节点处理（408 默认）。
2. **边界遗漏**：空链表、单节点链表、k=0、k 大于链表长度——务必在代码开头处理。
3. **free 丢失后继**：删除节点时先保存 `next` 指针再 `free`，否则访问已释放内存。
4. **尾节点 next 未置空**：反转/拆分链表后，新尾节点的 `next` 必须设为 `NULL`，否则遍历越界。
5. **摩尔投票适用条件**：仅当保证主元素存在时结果正确；否则需二次验证。
6. **三次反转移位方向**：右移 k = 反转全部 → 反转前 k → 反转剩余；左移 k = 反转全部 → 反转后 k → 反转前 n-k。注意方向别搞反。
7. **数组下标 0-based vs 1-based**：题目用 1-based 描述位置时，代码中对应 `index - 1`。
8. **链表合并结果**：注意合并后不能丢原链表节点（不要 free），只需调整 `next` 指针。
9. **C 语言引用传参**：C 语言没有引用 `&`（C++ 才有），408 答题可用 `&` 或用指针传参，看题目要求。
10. **复杂度分析的 "平均"**：链表插入删除平均时间 O(n)，不要误写 O(1)——O(1) 是头插/头删的最好情况。

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. 先问存储结构：顺序表还是链表（带头节点吗？408 默认带头）——同一操作在两种结构上的实现和复杂度完全不同
2. 再问操作本质：定位类（中点/倒数第 k/判环）→ 双指针；变形类（反转/合并/移位/分区）→ 指针改接或原地搬移；统计类（主元素/去重/交集）→ 一次遍历 + 常数辅助变量
3. 写代码前先列边界清单：空表、单节点、k=0 或 k 越界、1-based/0-based
4. 收尾必做两件事：新尾节点 `next` 置空；写明时间/空间复杂度及一句话理由

**知识串联提示：**
- 与其他板块的关联：链表是栈/队列链式实现的基础（链栈 = 头插头删的单链表）；二叉链表就是"每节点带两个 next 的链表"，双指针思维直接迁移到树和图；散列表的链地址法把同义词挂成单链表；排序板块的归并 = 有序链表合并的数组版；摩尔投票/三指针反转是算法设计专项的高频模板
- 容易混淆的概念对比：头指针 vs 头节点（`L->next` 才是首元节点）；链表插入删除 O(1) 指"已定位后"的操作，平均意义仍是 O(n)；顺序表"随机存取" vs 链表"顺序存取"——不要说成"链式存储可随机存取"

## POSIX 多线程编程

### 基本概念

- **异步**：相互之间没有数据依赖性
- **并发** vs **并行**

### 线程

#### 线程拥有
1. 当前指令位置指针 PC
2. 栈顶指针 SP
3. 通用寄存器
4. 浮点或地址寄存器

#### 线程共享
- 地址空间、代码段、数据段、堆

#### 线程优点
- 多处理器系统中开发并行性
- 等待慢速外设 I/O 同时可执行其他计算
- 模块化编程模型，清晰表达独立事件间关系

#### 线程缺点
- 计算负荷
- 编程规则复杂
- 难以调试

### 进程
- 独立的虚拟内存空间

### 线程系统三要素
1. 执行环境
2. 调度
3. 同步

### 同步机制
- 管道
- 信号量
- 消息队列

### 关键类型

| 类型 | 说明 |
|------|------|
| pthread_mutex_t | 互斥量 |
| pthread_t | 线程标识符 |
| pthread_cond_t | 条件变量 |
| pthread_attr_t | 线程属性对象 |

### 线程基本操作

```c
// 线程ID
pthread_t pid;

// 线程函数
void* fn(void *) { }

// 获取自身ID
pthread_self();

// 比较两个线程（相同返回!0，否则0）
pthread_equal(tid1, tid2);
```

### 主线程与分离线程
- 主线程：初始线程，main 函数
- 分离线程：通知系统线程终止时资源可回收，推荐使用
- 分离线程保证线程资源可直接复用于建立新线程

### 线程状态
时间片机制：线程运行足够时间后被抢占 → 直接入就绪态 → 事件后若处理器可用则入运行态

### 临界区
影响共享数据的代码段

## 互斥量（Mutex）

- Mutual + Exclusion 的组合
- 保护共享谓词状态的代码段

#### 操作
- 创建和销毁互斥量
- 加锁和解锁
- 非阻塞式互斥量锁
- **死锁**：加锁顺序不一致导致
- **解决方案**：固定加锁层次（a→b）；尝试加锁和回退

## 条件变量（Condition Variable）

用于线程间通信

#### 操作
- 创建和释放
- 等待条件变量
- 唤醒等待线程

#### 三种特殊情况
1. **被拦截的唤醒**：线程等待条件变量时包括加锁互斥量，但该量可能被其他线程提前加锁
2. **松散的谓词**：在等待前后检测严谨谓词，使用松散谓词时程序同样可用
3. **假唤醒**

## 线程间内存可见性规则

1. 线程调用 pthread_create 时，子线程能看到创建线程此时的内存值；create 之后的写入数据子线程**可能看不到**
2. 解锁互斥量时看到的内存数据，能被后来锁住相同互斥量的线程看到；解锁后的写入不必被其他线程看到
3. 线程终止时看到的内存数据能被 join 它的线程看到，但终止后的写入不会被连接线程看到
4. 发信号或广播条件变量时看到的内存数据，可被唤醒的线程看到，但发送后的写入不必被唤醒线程看到

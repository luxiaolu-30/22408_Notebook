### 23. （2 分 · 计算机系统概述）

下列选项中，操作系统提供给应用程序的接口是（ ）。

- **A.** 系统调用
- **B.** 中断
- **C.** 库函数
- **D.** 原语

**答案**：A

**解析**：答案 A。操作系统向应用程序提供的接口是系统调用（另一类是命令接口）。库函数是用户程序中封装系统调用的函数，不属于操作系统接口。

### 24. （2 分 · 进程与线程）

下列选项中，导致创建新进程的操作是（ ）。 

I. 用户登录成功

II. 设备分配

III. 启动程序执行

- **A.** 仅 I 和 II
- **B.** 仅 II 和 III
- **C.** 仅 I 和 III
- **D.** I、II 和 III

**答案**：C

**解析**：答案 C。用户登录成功、启动程序执行都会创建新进程；设备分配只是修改设备分配的数据结构，不创建进程。故选 I 和 III。

### 25. （2 分 · 进程与线程）

设与某资源关联的信号量初值为 3，当前值为 1。若 M 表示该资源的可用个数，N 表示等待该资源的进程数，则 M、N 分别是（ ）。

- **A.** 0、1
- **B.** 1、0
- **C.** 1、2
- **D.** 2、0

**答案**：B

**解析**：答案 B。信号量大于 0 时表示还有 S 个资源可用，当前值为 1，故可用资源数 M = 1；资源未用尽，没有进程等待，N = 0。

### 26. （2 分 · 进程与线程）

下列选项中，降低进程优先级的合理时机是（ ）。

- **A.** 进程时间片用完
- **B.** 进程刚完成 I/O 操作，进入就绪队列
- **C.** 进程长期处于就绪队列
- **D.** 进程从就绪状态转为运行状态

**答案**：A

**解析**：答案 A。时间片用完说明进程持续占用 CPU，应降低其优先级让其他进程获得调度；刚完成 I/O 的进程应提高优先级以尽快处理结果，长期就绪的进程应提高优先级防止饥饿。

### 27. （2 分 · 进程与线程）

进程 $P_0$ 和 $P_1$ 的共享变量定义及其初值为：

```c
boolean flag[2];
int turn = 0;
flag[0] = FALSE;
flag[1] = FALSE;
```

若进程 $P_0$ 和 $P_1$ 访问临界资源的类 C 伪代码实现如下：

```c
void P0() {
    while (TRUE) {
        flag[0] = TRUE;
        turn = 1;
        while (flag[1] && (turn == 1));
        临界区;
        flag[0] = FALSE;
    }
}

void P1() {
    while (TRUE) {
        flag[1] = TRUE;
        turn = 0;
        while (flag[0] && (turn == 0));
        临界区;
        flag[1] = FALSE;
    }
}
```

则并发执行进程 $P_0$ 和 $P_1$ 时产生的情形是（ ）。

- **A.** 不能保证进程互斥进入临界区，会出现“饥饿”现象
- **B.** 不能保证进程互斥进入临界区，不会出现“饥饿”现象
- **C.** 能保证进程互斥进入临界区，会出现"饥饿"现象
- **D.** 能保证进程互斥进入临界区，不会出现"饥饿"现象

**答案**：D

**解析**：答案 D。这是 Peterson 算法：先置自己的 flag 为真，再把 turn 指向对方，然后检查对方 flag 与 turn。turn 只能取一个值，两进程不可能同时通过 while 条件，故能互斥；后设 turn 者让位，不会饥饿。

### 28. （2 分 · 内存管理）

某基于动态分区存储管理的计算机，其主存容量为 55MB（初始为空闲），采用最佳适配 (Best Fit) 算法，分配和释放的顺序为：分配 15MB、分配 30MB、释放 15MB、分配 8MB、分配 6MB，此时主存中最大空闲分区的大小是（ ）。

- **A.** 7MB
- **B.** 9MB
- **C.** 10MB
- **D.** 15MB

**答案**：B

**解析**：答案 B。最佳适配每次选最小够用分区。55MB：分 15MB 剩 40MB；分 30MB 剩 10MB；释放 15MB 后空闲为 15MB、10MB；分 8MB 切 10MB 剩 2MB；分 6MB 切 15MB 剩 9MB。最大 9MB。

### 29. （2 分 · 内存管理）

某计算机采用二级页表的分页存储管理方式，按字节编址，页大小为 $2^{10}\,\text{B}$，页表项大小为 $2\,\text{B}$，逻辑地址空间大小为 $2^{16}$ 页，则页目录表中包含表项的个数至少是（ ）。

- **A.** 64
- **B.** 128
- **C.** 256
- **D.** 512

**答案**：B

**解析**：答案 B。一页可存放 2¹⁰/2 = 2⁹ = 512 个页表项，逻辑地址空间 2¹⁶ 页共需 2¹⁶ 个页表项，需 2¹⁶/2⁹ = 2⁷ = 128 个页面存放，故页目录表至少含 128 项。

### 30. （2 分 · 文件管理）

设文件索引结点中有 7 个地址项，其中 4 个地址项是直接地址索引，2 个地址项是一级间接地址索引，1 个地址项是二级间接地址索引，每个地址项大小为 4B，若磁盘索引块和磁盘数据块大小均为 256B，则可表示的单个文件最大长度是（）。

- **A.** 33KB
- **B.** 519KB
- **C.** 1057KB
- **D.** 1651KB

**答案**：C

**解析**：答案 C。索引块含 256/4 = 64 个地址项。4 个直接、2 个一级、1 个二级间接分别覆盖 4、128、4096 个数据块，文件最大长度 = 4×256+128×256+4096×256 = 1082368B = 1057KB。

> 难度 ⭐⭐⭐⭐ ｜ 章节 文件管理 ｜ 标签 操作系统 / 文件系统 / 文件 / 目录 / 磁盘

### 31. （2 分 · 文件管理）

设置当前工作目录的的主要目的是（ ）。

- **A.** 节省外存空间
- **B.** 节省内存空间
- **C.** 加快文件的检索速度
- **D.** 加快文件的读/写速度

**答案**：C

**解析**：答案 C。设置当前工作目录后，进程可用相对路径访问文件，不必从根目录逐层检索，从而加快文件的检索速度，与内存、外存空间及读写速度无关。

### 32. （2 分 · 输入输出管理）

本地用户通过键盘登录系统时，首先获得键盘输入信息的程序是（ ）。

- **A.** 命令解释程序
- **B.** 中断处理程序
- **C.** 系统调用服务程序
- **D.** 用户登录程序

**答案**：B

**解析**：答案 B。键盘是典型的中断方式外设，按键触发硬件中断后，首先由中断处理程序获得输入信息，再交给等待的进程（如登录程序）。

### 45. （7 分 · 输入输出管理）

假设计算机系统采用 C-SCAN（循环扫描）磁盘调度策略，使用 2 KB 的内存空间记录 16 384 个磁盘块的空闲状态。


（1）请说明在上述条件下如何进行磁盘块空闲状态的管理。


（2）设某单面磁盘旋转速度为 6000 rpm，每个磁道有 100 个扇区，相邻磁道间的平均移动时间为 1 ms。若在某时刻，磁头位于 100 号磁道处，并沿着磁道号增大的方向移动（见下图），磁道号请求队列为 50、90、30、120，对请求队列中的每个磁道需读取 1 个随机分布的扇区，则读完这 4 个扇区共需要多少时间？要求给出计算过程。

![C-SCAN 磁头移动方向示意图](images/q45-disk.webp)


（3）如果将磁盘替换为随机访问的 Flash 半导体存储器（如 U 盘、SSD 等），是否有比 C-SCAN 更高效的磁盘调度策略？若有，给出磁盘调度策略的名称并说明理由；若无，说明理由。

**答案 / 解析**：

答案：1、用位图（位示图）管理：16384 个磁盘块每位表示一个块的空闲状态，共 16384 位 = 2KB，正好放入题给内存，分配、回收时置位即可。2、C-SCAN 沿磁道号增大方向扫描：访问顺序 120、30、50、90，移动磁道数 20+90+20+40 = 170，寻道时间 170×1ms = 170ms；转速 6000rpm 即每转 10ms，平均旋转延迟 5ms，4 次共 20ms；每磁道 100 个扇区，读 1 个扇区需 0.1ms，4 次共 0.4ms。总时间 = 170+20+0.4 = 190.4ms。3、有，FCFS 更高效。Flash 半导体存储器无机械寻道和旋转延迟，访问时间与位置无关，直接按 I/O 请求的先后顺序服务即可，省去 C-SCAN 的排序开销。

### 46. （8 分 · 内存管理）

设某计算机的逻辑地址空间和物理地址空间均为 64 KB，按字节编址。若某进程最多需要 6 页（Page）数据存储空间，页的大小为 1 KB，操作系统采用固定分配局部置换策略为此进程分配 4 个页框（Page Frame）。在时刻 260 前的该进程访问情况如下（访问位即使用位）：

| 页号 | 页框号 | 装入时刻 | 访问位 |
| --- | --- | --- | --- |
| 0 | 7 | 130 | 1 |
| 1 | 4 | 230 | 1 |
| 2 | 2 | 200 | 1 |
| 3 | 9 | 260 | 1 |

当该进程执行到时刻 260 时，要访问逻辑地址为 17CAH 的数据。


（1）该逻辑地址对应的页号是多少？


（2）若采用先进先出（FIFO）置换算法，该逻辑地址对应的物理地址是多少？要求给出计算过程。


（3）若采用时钟（CLOCK）置换算法，该逻辑地址对应的物理地址是多少？要求给出计算过程（设搜索下一页的指针沿顺时针方向移动，且当前指向 2 号页框，示意图如下）。

![CLOCK 页面置换指针示意图](images/q46-clock.webp)

**答案 / 解析**：

答案：1、页大小 1KB，页内偏移占低 10 位、页号占高 6 位。17CAH = 0001 0111 1100 1010B，页号 = 000101B = 5。2、FIFO 淘汰装入最早的 0 号页，其页框 7 分配给 5 号页，物理地址 = 0001 1111 1100 1010B = 1FCAH。3、CLOCK 指针从 2 号页框开始：依次检查 2、4、7、9 号页框，使用位均为 1，逐个清零；第 5 次回到 2 号页框时使用位为 0，淘汰其中的 2 号页，装入 5 号页，物理地址 = 0000 1011 1100 1010B = 0BCAH。

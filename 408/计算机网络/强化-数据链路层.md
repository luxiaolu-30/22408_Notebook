# 计算机网络 强化-数据链路层

> **本板块串联**：封装成帧 → 差错控制 → 流量控制 → 介质访问控制 → 局域网与交换机。数据链路层在物理层提供的"比特管道"之上把比特组织成帧，向上为网络层提供"相邻结点间的可靠传输"——网络层的 IP 数据报要靠本层封装成帧、逐跳搬运，每一跳的传输质量都由本层机制保证。

## 🧭 知识主线

数据链路层的主线是"**相邻两台机器如何可靠通信**"：先把比特流**封装成帧**（解决定界与透明传输），帧在信道中可能出错 → **差错控制**（CRC 检错），发送太快接收方处理不过来 → **流量控制**（SW/GBN/SR 滑动窗口），多站点共享链路会争用 → **介质访问控制**（CSMA/CD）。解决完"一条链路"的问题后，视角再扩展到**局域网**：以太网帧格式 + 交换机自学习把单链路能力放大成多站点网络。所有零散知识点都是这条主线上的一环。

## 一、封装成帧

### 1.1 成帧方法

| 方法 | 原理 | 特点 |
|------|------|------|
| 字符计数法 | 帧首部用一个字段标明帧长 | 计数字段出错则全帧丢失 |
| 字符填充法 | 使用特殊字符作为定界符（如 SOH/EOT） | 需对数据中的特殊字符转义 |
| 零比特填充法 | 用 01111110 作为定界符，数据中每5个连续1后插入0 | 最常用，透明传输好 |

### 1.2 零比特填充详解

- **帧定界符**：01111110（即 0x7E）
- **发送端**：扫描数据，每出现 5 个连续的"1"后插入一个"0"
- **接收端**：每出现 5 个连续的"1"后删除后面的"0"

> **易错**：零比特填充是数据链路层（PPP协议）的内容，不要与物理层的编码混淆。

## 二、差错控制：CRC循环冗余码

### 2.1 CRC 计算步骤（必考计算题）

> **核心考点**：给出数据 + 生成多项式，求 CRC 码。

**三步法**：

```
步骤1：在数据后面加 k 个 0（k = 生成多项式最高次幂 = 生成多项式位数 - 1）
步骤2：用加0后的数据模2除以生成多项式
步骤3：余数就是 CRC 码（FCS），替换掉添加的0
```

### 2.2 模2除法规则

- 与普通除法类似，但不借位（异或运算）
- 上商规则：首位是1商1，首位是0商0
- 余数位数比除数少一位

### 2.3 计算示例

**例**：数据为 101101，生成多项式为 10011（即 x⁴+x+1），求 CRC 码。

```
步骤1：k = 4（生成多项式5位，最高次幂4），数据后加4个0 → 1011010000

步骤2：模2除法
  1011010000 ÷ 10011

  商：101001
        10101
  1011010000
  10011....        → 00101...
  ----- 
  00101.0...       → 首位0，商0，下移一位
   00000.....
   -----
   10100.0.....    → 商1
   10011......
   -----
   00110.0.....    → 商0
    00000.....
    -----
    1100.0......   → 商1
    10011......
    -----
    1100.0......   → 商0（余数1110？需重新计算）

  最终余数 = 1111（4位）

步骤3：CRC码 = 1111，发送数据 = 101101 1111
```

> **注意**：实际考试中需仔细逐位模2除法，余数位数 = 生成多项式位数 - 1。

### 2.4 CRC性质

- CRC 能检测所有奇数个错误
- 能检测所有双比特错误
- 能检测所有长度 ≤ 多项式最高次幂的突发错误
- CRC 是**检错码**，不能纠错

## 三、流量控制

### 3.1 停止-等待协议（SW）

- 发送方每发一帧后等待确认（ACK）
- 满足：窗口大小 = 1
- 信道利用率：$U = \frac{t_f}{t_f + RTT + t_a}$

其中：
- t_f = 发送时延（数据长度/带宽）
- RTT = 往返时延
- t_a = 确认帧发送时延（通常忽略）

### 3.2 后退N帧协议（GBN）

- 发送窗口 W ≤ 2^n - 1（n 为序号位数）
- 接收窗口 = 1（只按序接收）
- **出错时回退N帧重传**

**窗口大小限制推导**：
- 序号范围 0 ~ 2^n - 1
- 若 W = 2^n，旧帧和新帧序号重叠，无法区分
- 故 W ≤ 2^n - 1

### 3.3 选择重传协议（SR）

- 发送窗口 W_s 和接收窗口 W_r
- W_s + W_r ≤ 2^n
- 通常 W_s = W_r，故 **W_s = W_r ≤ 2^(n-1)**
- 只重传出错帧，不回退

### 3.4 信道利用率公式

$$U = \frac{W \times t_f}{t_f + RTT + t_a}$$

其中 W = 发送窗口大小，t_f = 单帧发送时延

**最大化发送利用率**：

$$W \geq \frac{t_f + RTT + t_a}{t_f} = 1 + \frac{RTT}{t_f}$$

### 3.5 三种协议对比

| 特性 | 停止-等待 | GBN | SR |
|------|----------|-----|-----|
| 发送窗口 | 1 | ≤ 2^n-1 | ≤ 2^(n-1) |
| 接收窗口 | 1 | 1 | > 1 |
| 出错处理 | 重传当前帧 | 回退N帧重传 | 只重传出错帧 |
| 信道利用率 | 低 | 中 | 高 |
| 缓冲区需求 | 小 | 中 | 大 |

## 四、介质访问控制：CSMA/CD

### 4.1 基本原理

- 载波监听多路访问/碰撞检测
- **先听后发，边发边听，冲突停发，随机重发**

### 4.2 争用期

$$\text{争用期} = 2 \times \text{单程传播时延} = 2\tau$$

- 最多经过 2τ 时间即可检测到冲突
- 若 2τ 内未检测到冲突，则该帧不会发生冲突

### 4.3 最小帧长

$$\text{最小帧长} = 2 \times \text{传播时延} \times \text{数据传输率}$$

$$L_{\min} = 2\tau \times R$$

其中 τ = 单程传播时延，R = 数据传输率

> **推导**：要保证在发送完一帧之前能检测到冲突，帧发送时间 ≥ 2τ，即 L/R ≥ 2τ，故 L ≥ 2τR。

**以太网规定**：最小帧长 64 字节（10 Mbps, 争用期 51.2 μs → 64 B）

### 4.4 二进制指数退避算法

```
第1次冲突：从 {0,1} 中随机选 k，等待 k × 2τ
第2次冲突：从 {0,1,2,3} 中随机选 k，等待 k × 2τ
第3次冲突：从 {0,1,2,3,4,5,6,7} 中随机选 k
...
第i次冲突：从 {0, 1, ..., 2^i - 1} 中随机选 k
第10次冲突以后：k 从 {0,...,1023} 中选
第16次冲突：放弃发送，向上层报错
```

**等待时间** = k × 争用期（2τ）

### 4.5 CSMA/CD 与 CSMA/CA 对比

| 特性 | CSMA/CD | CSMA/CA |
|------|---------|---------|
| 适用 | 有线局域网 | 无线局域网 |
| 冲突检测 | 边发边听 | 无法检测，冲突避免 |
| 机制 | 碰撞检测 | 碰撞避免（RTS/CTS） |

## 五、局域网：以太网帧格式

### 5.1 以太网帧结构

```
| 前导码(7B) | 帧定界(1B) | 目的地址(6B) | 源地址(6B) | 类型(2B) | 数据(46-1500B) | FCS(4B) |
```

| 字段 | 长度 | 说明 |
|------|------|------|
| 前导码 | 7B | 时钟同步，0xAA交替 |
| 帧定界符 | 1B | 0xAB，标志帧开始 |
| 目的地址 | 6B | MAC地址 |
| 源地址 | 6B | MAC地址 |
| 类型 | 2B | 上层协议类型（0x0800=IP, 0x0806=ARP） |
| 数据 | 46-1500B | MTU=1500B，最小46B |
| FCS | 4B | CRC-32校验 |

### 5.2 帧长限制

- **最小帧长**：64 B（含FCS），不含前导码和定界符
- **最大帧长**：1518 B（6+6+2+1500+4）
- 数据字段最短 46 B：若上层报文不足 46 B，需填充

## 六、数据链路层设备

### 6.1 网桥

- 工作在数据链路层
- **分割冲突域**：每个端口是一个独立冲突域
- 基于MAC地址表转发帧
- 不能隔离广播域

### 6.2 交换机

- 多端口网桥，工作在数据链路层
- **全双工**通信，消除碰撞
- **自学习**：构建MAC地址表
  - 收到帧时，记录源MAC→端口的映射
  - 转发时查表，已知则定向转发，未知（或广播帧）则泛洪
- 隔离冲突域，不隔离广播域

### 6.3 自学习转发表示例

| MAC地址 | 端口 | 有效时间 |
|---------|------|---------|
| AA:BB:CC:DD:EE:01 | 1 | 300s |
| AA:BB:CC:DD:EE:02 | 3 | 300s |

## 七、典型计算题及答题模板

### 7.1 CRC 计算题模板

```
题目：数据 M = xxxxx，生成多项式 G = xxxx，求发送的完整数据。

步骤1：确定 k = G 的位数 - 1
步骤2：M 后添加 k 个 0 → M'
步骤3：M' 模2除以 G，得余数 R（k位）
步骤4：发送数据 = M + R

注意：余数不足 k 位时前面补0
```

### 7.2 GBN 信道利用率计算模板

```
题目：带宽 R bps，帧长 L bit，往返时延 RTT，窗口 W，求信道利用率。

步骤1：计算单帧发送时延 t_f = L / R
步骤2：计算信道利用率 U = (W × t_f) / (t_f + RTT)
       （忽略ACK帧发送时延）
步骤3：若 U > 1，取 U = 1（不能超过100%）
```

### 7.3 CSMA/CD 最小帧长计算模板

```
题目：数据传输率 R bps，两站距离 d m，传播速度 v m/s，求最小帧长。

步骤1：单程传播时延 τ = d / v
步骤2：争用期 = 2τ
步骤3：最小帧长 L_min = 2τ × R
```

### 7.4 综合例题

**例**：CSMA/CD网络，数据传输率 1 Gbps，两站距离 1 km，传播速度 2×10⁸ m/s。求最小帧长。

```
τ = 1000 / (2×10⁸) = 5×10⁻⁶ s = 5 μs
L_min = 2 × 5×10⁻⁶ × 10⁹ = 10000 bit = 1250 B
```

> 若标准以太网规定最小帧长 64 B，而计算出需要 1250 B，则需要调整（如千兆以太网使用载波延伸）。

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. **大题先识别题型**：给"数据 + 生成多项式" → CRC 三步法；给"窗口 W + RTT + 帧长/带宽" → 信道利用率；给"距离 + 速率" → CSMA/CD 最小帧长；给"交换机 + 帧序列" → 自学习转发分析。题型定位后直接套对应模板。
2. **CRC 三步法**：k = 生成多项式位数 − 1 → 数据后补 k 个 0 → 模 2 除法（异或、不借位）→ 余数即 FCS；余数不足 k 位前面补 0。
3. **最小帧长两步**：先算单程时延 τ = d/v，再 L_min = 2τR；"×2"来自争用期——最坏情况下信号往返一趟才能确认冲突。
4. **交换机自学习题**：按帧到达顺序逐帧分析——每帧先"学习"（源 MAC → 端口写入 MAC 表），再"转发"（查目的 MAC：表中有且端口不同 → 定向转发；无记录或为广播帧 → 泛洪；端口相同 → 丢弃）。

**知识串联提示：**
- 本层知识点与网络层的关联：以太网帧的"类型"字段（0x0800=IP、0x0806=ARP）是链路层为上层协议预留的接口；网络层 IP 包必须装进帧里逐跳传输，MTU=1500B 这一链路层限制正是网络层分片的根源；跨网段通信时 ARP 解析的是网关 MAC——因为帧只能在本链路内传递。
- 本层知识点与传输层的关联：GBN/SR 滑动窗口是 TCP 滑动窗口的雏形，但链路层窗口以"帧"为单位、只管单链路可靠性，TCP 窗口以"字节"为单位且发送窗口 = min(rwnd, cwnd) 受双重约束。
- 容易混淆的概念对比：CSMA/CD（有线、边发边听、检测冲突）vs CSMA/CA（无线、冲突避免）；GBN（W ≤ 2ⁿ−1，出错回退 N 帧）vs SR（W ≤ 2ⁿ⁻¹，只重传出错帧）；集线器（物理层、广播转发）vs 交换机（链路层、查表定向转发）。

## 八、易错点清单

1. **GBN 窗口大小 ≤ 2^n - 1**，不是 2^n；序号 n 位时最大 2^n-1。
2. **SR 窗口大小 ≤ 2^(n-1)**，且 W_s + W_r ≤ 2^n。
3. **CRC 余数位数 = 生成多项式位数 - 1**，不足前面补0。
4. **CRC 是检错码不是纠错码**。
5. **CSMA/CD 最小帧长 = 2τ × R**，不要忘记乘以2（争用期 = 2倍单程时延）。
6. **以太网最小帧长 64 B 是数据链路层限制**，与MTU（1500B）不同。
7. **信道利用率不能超过 100%**，计算结果超过1时取1。
8. **交换机隔离冲突域但不隔离广播域**。
9. **零比特填充每5个"1"后插"0"**，不是每5个"1"加"1"。
10. **GBN 接收窗口 = 1**，只按序接收，不能乱序接收。
11. **CSMA/CD 用于有线（以太网）**，CSMA/CA 用于无线（WLAN），不要混淆。
12. **二进制指数退避第10次后窗口不再增大**，保持 {0,...,1023}；第16次放弃。

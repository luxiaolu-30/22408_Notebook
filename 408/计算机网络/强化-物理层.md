# 计算机网络 强化-物理层

> **本板块串联**：比特 → 信号 → 信道 → 传输。物理层是整个网络体系的最底层，为数据链路层提供"透明传输的比特流"——链路层只管交付比特，不关心比特如何编码成信号、占用多大带宽、经历多少延迟，而这些正是物理层要解决的问题。

## 🧭 知识主线

物理层的主线是"**数据如何变成信号并通过信道**"：比特流先经**编码**变成信号（NRZ/曼彻斯特，决定波特率与比特率的关系），信号进入**信道**后受容量限制（奈奎斯特/香农定理），最后沿信道**传输**产生延迟（发送时延 + 传播时延）。所有零散知识点都能挂到"编码 → 信道容量 → 传输延迟"这条流水线上；末尾的物理层设备（中继器/集线器）则是这条流水线的延伸——解决信号衰减后如何再生放大、如何用多端口把一条信道分给多台主机的问题。

## 一、奈奎斯特定理与香农定理

### 1.1 奈奎斯特定理（无噪声信道）

> **定理**：在无噪声、带宽为 W Hz 的理想低通信道中，最高码元传输速率（波特率）为 2W Baud。

**公式**：

$$B = 2 \times W$$

**比特率**：

$$\text{最大数据传输率} = 2W \log_2 V \quad \text{(bps)}$$

其中：
- W = 信道带宽（Hz）
- V = 每个码元能表示的离散状态数（进制数）

**注意**：奈奎斯特定理给出了理想情况下的上限，未考虑噪声。

### 1.2 香农定理（有噪声信道）

> **定理**：在有噪声的带宽为 W Hz 的信道中，最大数据传输速率为：

$$C = W \log_2(1 + S/N) \quad \text{(bps)}$$

其中：
- C = 信道容量（最大数据传输率）
- W = 信道带宽（Hz）
- S = 信号平均功率
- N = 噪声平均功率
- S/N = 信噪比

**信噪比与分贝的换算**：

$$\text{dB} = 10 \log_{10}(S/N)$$

**常用换算值**：
| 分贝 (dB) | S/N 比值 |
|-----------|----------|
| 10 dB | 10 |
| 20 dB | 100 |
| 30 dB | 1000 |
| 3 dB | ≈2 |

### 1.3 两个定理的关系

- 奈奎斯特定理：理想无噪声，给出码元速率上限
- 香农定理：实际有噪声，给出比特率上限
- **实际系统的极限取两者最小值**

> **易错**：考试可能同时给出两个条件，需要分别计算取小值。

## 二、编码方式

### 2.1 三种基本编码方式

| 编码方式 | 规则 | 时钟同步 | 自同步 |
|---------|------|----------|--------|
| NRZ（非归零编码） | 1为高电平，0为低电平 | ❌ 无 | ❌ |
| 曼彻斯特编码 | 每位中间跳变：高→低为1，低→高为0 | ✅ 有 | ✅ |
| 差分曼彻斯特编码 | 每位中间必跳变；位开始处有跳变=0，无跳变=1 | ✅ 有 | ✅ |

### 2.2 曼彻斯特编码核心特性

> **重点**：曼彻斯特编码的时钟同步特性是其最大优点。

- 每个比特周期中间都有一次电平跳变，既传数据又传时钟信号
- **不需要额外的时钟线**即可实现自同步
- 缺点：带宽利用率低（每个比特需要两个信号周期），实际传输效率只有 50%

### 2.3 编码效率对比

| 编码方式 | 比特率/波特率 | 带宽效率 |
|---------|--------------|---------|
| NRZ | 1:1 | 高 |
| 曼彻斯特 | 1:2 | 低（50%） |
| 差分曼彻斯特 | 1:2 | 低（50%） |

> **注意**：曼彻斯特编码中，波特率 = 2 × 比特率，即每个比特对应2个码元。

## 三、波特率与比特率关系

### 3.1 基本公式

$$\text{比特率} = \text{波特率} \times \log_2(\text{进制数})$$

- **波特率**：每秒传输的码元（信号）个数，单位 Baud
- **比特率**：每秒传输的比特数，单位 bps
- **进制数**：每个码元可表示的状态数

### 3.2 计算示例

**例**：一个信道波特率为 1200 Baud，采用 16 进制调制，求比特率。

$$\text{比特率} = 1200 \times \log_2 16 = 1200 \times 4 = 4800 \text{ bps}$$

## 四、信道延迟计算

### 4.1 发送延迟（传输延迟）

$$\text{发送延迟} = \frac{\text{数据长度（bit）}}{\text{带宽（bps）}}$$

### 4.2 传播延迟

$$\text{传播延迟} = \frac{\text{距离（m）}}{\text{传播速度（m/s）}}$$

**常见传播速度**：
- 电磁波在光纤/铜线中：≈ 2×10⁸ m/s（约光速的 2/3）
- 电磁波在真空中：3×10⁸ m/s

### 4.3 总延迟

$$\text{总延迟} = \text{发送延迟} + \text{传播延迟} + \text{处理延迟} + \text{排队延迟}$$

### 4.4 计算示例

**例**：数据长度 1000 B（8000 bit），带宽 1 Mbps，距离 1000 km，传播速度 2×10⁸ m/s。

- 发送延迟 = 8000 / 10⁶ = 0.008 s = 8 ms
- 传播延迟 = 1000×10³ / (2×10⁸) = 5×10⁻³ s = 5 ms
- 总延迟（不考虑处理排队）= 8 + 5 = 13 ms

## 五、物理层设备

### 5.1 中继器（Repeater）

- 工作在物理层
- 作用：放大和再生信号，延长网络传输距离
- 不能隔离冲突域
- 两端网段使用相同协议

### 5.2 集线器（Hub）

- 多端口中继器，工作在物理层
- **广播式转发**：从一个端口收到的信号向所有其他端口转发
- **不隔离冲突域**：所有端口共享带宽
- **不隔离广播域**

### 5.3 冲突域与广播域

| 设备 | 隔离冲突域 | 隔离广播域 |
|------|-----------|-----------|
| 中继器 | ❌ | ❌ |
| 集线器 | ❌ | ❌ |
| 网桥 | ✅ | ❌ |
| 交换机 | ✅ | ❌ |
| 路由器 | ✅ | ✅ |

## 六、典型计算题及答题模板

### 6.1 答题模板：信道容量计算

```
步骤1：判断是否有噪声
  - 有噪声 → 用香农定理
  - 无噪声 → 用奈奎斯特定理

步骤2：代入公式计算
  - 香农：C = W × log2(1 + S/N)
  - 奈奎斯特：C = 2W × log2(V)

步骤3：若同时有两个条件，取两者最小值
```

### 6.2 典型例题

**例1**：信道带宽 4 kHz，信噪比 30 dB，求最大数据传输率。

```
S/N: 30 dB → 10^(30/10) = 1000
香农：C = 4000 × log2(1+1000) = 4000 × log2(1001)
     ≈ 4000 × 9.97 ≈ 39860 bps ≈ 40 kbps
```

**例2**：无噪声信道，带宽 3 kHz，每个码元 4 个离散状态，求最大数据传输率。

```
奈奎斯特：B = 2 × 3000 = 6000 Baud
最大数据传输率 = 6000 × log2(4) = 6000 × 2 = 12000 bps
```

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. **容量计算题**：先问"有无噪声"——无噪声用奈奎斯特（2W·log₂V），有噪声用香农（W·log₂(1+S/N)）；给了 dB 先换算成比值；两个条件都给时分别计算取最小值。
2. **速率换算题**：先分清题目问的是波特率还是比特率，再用"比特率 = 波特率 × log₂(进制数)"换算；涉及曼彻斯特编码时记住波特率 = 2×比特率。
3. **延迟计算题**：拆成发送时延（数据长度/带宽，取决于"多长、多快"）和传播时延（距离/传播速度，取决于"多远、什么介质"），别把 2×10⁸ 和 3×10⁸ 混用。
4. **设备选择题**：先定位设备所在层次，再用"隔离冲突域？隔离广播域？"两个问题快速判断（物理层设备两个都不隔离）。

**知识串联提示：**
- 本层知识点与数据链路层的关联：物理层只传输"比特流"，不认识"帧"——帧的定界（如零比特填充）是链路层的事；曼彻斯特编码虽是物理层内容，却是传统以太网（链路层标准）选用的编码方式；本层的发送时延/传播时延是上层一切计算（GBN 信道利用率、CSMA/CD 最小帧长）的基础原料。
- 容易混淆的概念对比：波特率（码元速率）vs 比特率（数据速率）；奈奎斯特（无噪声、码元速率上限）vs 香农（有噪声、比特率上限）；中继器/集线器（物理层、啥都不隔离）vs 网桥/交换机（链路层、隔离冲突域）。

## 七、易错点清单

1. **波特率 ≠ 比特率**：波特率是码元速率，比特率还要乘 log2(进制数)。
2. **香农定理中 S/N 是比值而非分贝值**：题目给分贝需先用 10·log10(S/N) 换算。
3. **奈奎斯特定理的 2W 是波特率上限，不是比特率**：比特率 = 2W·log2(V)。
4. **曼彻斯特编码波特率 = 2 × 比特率**：每个比特占两个码元周期。
5. **传播速度在光纤/电缆中约为 2×10⁸ m/s**，不是 3×10⁸ m/s。
6. **集线器不隔离冲突域**：所有端口在同一冲突域中。
7. **中继器和集线器都是物理层设备**，不涉及MAC地址。
8. **曼彻斯特编码的高→低和低→高方向**：不同教材约定不同，以题目说明为准，一般高→低为1。
9. **同时有奈奎斯特和香农约束时取最小值**。
10. **信道带宽单位是 Hz**，数据传输率单位是 bps，注意区分。

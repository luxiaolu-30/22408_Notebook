# 计算机网络 强化-网络层

> **本板块串联**：IP 编址 → 路由与转发 → 分片 → NAT → 路由协议。网络层在链路层"相邻结点传输"的基础上，解决"跨越多个网络的端到端传输"——把链路层一跳一跳的传输拼接成从源主机到目的主机的完整路径，是整个互联网体系的核心枢纽。

## 🧭 知识主线

网络层的主线是"**一个 IP 包的一生**"：源主机先通过 **DHCP** 拿到地址，发包时根据**路由表**（子网划分/最长前缀匹配决定它的组织方式）选择下一跳，包超过链路 MTU 就要**分片**，穿过私有网络边界时经 **NAT** 转换地址，跨自治系统时靠 **RIP/OSPF/BGP** 学出来的路径转发。辅助机制也都挂在这条旅程上：ARP 回答"下一跳的 MAC 是谁"，ICMP 报告旅途中的差错（ping/traceroute），IPv6 是整套体系的升级版。

## 二、子网划分与子网掩码

### 2.1 借位计算

**从主机号借 n 位做子网号**：

- 子网数 = 2^n
- 每个子网主机数 = 2^m - 2（m = 剩余主机位数）
  - 减2：去除网络地址（主机号全0）和广播地址（主机号全1）

> **注意**：早期标准子网划分中，全0和全1子网不可用，子网数 = 2^n - 2。现代CIDR中全0和全1子网可用，子网数 = 2^n。考试通常默认可用。

### 2.2 子网掩码

- 子网掩码与IP地址按位与运算 = 网络地址
- 例如：IP = 192.168.1.130，掩码 = 255.255.255.192（/26）
  - 192.168.1.130 & 255.255.255.192 = 192.168.1.128（网络地址）

### 2.3 计算示例

**例**：将 192.168.1.0/24 划分为 4 个子网。

```
需要借 2 位（2^2 = 4）
新掩码：/24 + 2 = /26 → 255.255.255.192

子网1：192.168.1.0/26    范围 0~63   可用主机 1~62
子网2：192.168.1.64/26   范围 64~127 可用主机 65~126
子网3：192.168.1.128/26  范围 128~191 可用主机 129~190
子网4：192.168.1.192/26  范围 192~255 可用主机 193~254
每个子网可用主机 = 2^6 - 2 = 62
```

## 三、CIDR与路由聚合

### 3.1 CIDR（无分类域间路由）

- 消除A/B/C类限制
- 使用"网络前缀"代替网络号
- 表示法：IP地址/前缀长度，如 192.168.1.0/22

### 3.2 路由聚合（超网）

**方法**：取多个子网的公共前缀

**例**：合并以下 4 个子网
```
192.168.0.0/24  → 11000000 10101000 00000000 00000000
192.168.1.0/24  → 11000000 10101000 00000001 00000000
192.168.2.0/24  → 11000000 10101000 00000010 00000000
192.168.3.0/24  → 11000000 10101000 00000011 00000000
```
公共前缀 22 位 → 聚合为 **192.168.0.0/22**

### 3.3 最长前缀匹配

- 路由表中有多个匹配项时，选择前缀最长的（最具体的）
- 这是路由器转发的基本原则

## 四、IP分片计算

### 4.1 分片规则

- MTU = 1500 B（以太网），IP首部 20 B，数据部分最大 1480 B
- 分片大小必须是 **8的倍数**（因为片偏移以8字节为单位）
- 除最后一片外，每片数据尽量取最大值

### 4.2 各字段变化

| 字段 | 分片后变化 |
|------|-----------|
| 总长度 | 每片的总长度（首部+该片数据） |
| MF标志 | 非最后一片 MF=1，最后一片 MF=0 |
| DF标志 | 若 DF=1 且数据>MTU，丢弃并报错 |
| 片偏移 | 原数据偏移量 / 8 |
| 标识 | 所有分片相同（同一数据报） |

### 4.3 计算示例

**例**：一个 4000 B 的IP数据报（含20B首部，数据3980B），经MTU=1500B链路，求分片。

```
数据部分 = 3980 B
每片最大数据 = 1480 B（1500 - 20，且1480是8的倍数）

片1：数据1480B，总长1500B，MF=1，片偏移=0
片2：数据1480B，总长1500B，MF=1，片偏移=1480/8=185
片3：数据3980-1480-1480=1020B，总长1040B，MF=0，片偏移=2960/8=370
```

> **易错**：片偏移 = 该片数据在原数据报中的起始位置 / 8，不是该片的序号。

## 五、ARP协议

### 5.1 功能

- **IP地址 → MAC地址** 映射
- 工作在网络层（也有认为是数据链路层之上的层间协议）

### 5.2 工作流程

```
1. 主机A要发数据给同一子网的主机B
2. A查ARP缓存表，若无B的MAC地址
3. A广播ARP请求（目标IP=B的IP）
4. 子网内所有主机收到请求
5. B匹配后单播回复ARP响应（包含B的MAC）
6. A更新ARP缓存表
```

### 5.3 要点

- ARP请求：**广播**（目标MAC = FF:FF:FF:FF:FF:FF）
- ARP响应：**单播**
- ARP缓存表有生存时间（通常 20 分钟）
- **跨网段通信**：ARP请求的目标是**默认网关**的MAC地址，而非目标主机

## 六、DHCP协议

### 6.1 四步获取地址

```
1. DISCOVER：客户端广播发现DHCP服务器（源0.0.0.0 → 目的255.255.255.255）
2. OFFER：服务器单播/广播回应，提供IP地址
3. REQUEST：客户端广播请求确认使用（可能收到多个OFFER，选一个）
4. ACK：服务器确认分配
```

### 6.2 端口与传输层

- 使用 **UDP**
- 服务器端口：**67**
- 客户端端口：**68**

### 6.3 要点

- DHCP使用UDP，不可靠
- DISCOVER是广播，因为客户端还没有IP地址
- REQUEST也是广播，为了让未被选中的服务器收回地址

## 七、网络地址转换NAT

### 7.1 原理

- 内部网络使用私有IP地址
- 通过NAT路由器将私有IP转换为全球IP
- **利用端口号区分不同内部主机**

### 7.2 NAT转换表

| 内部本地IP:端口 | 内部全局IP:端口 | 外部本地IP:端口 | 外部全局IP:端口 |
|----------------|----------------|----------------|----------------|
| 192.168.1.10:3344 | 202.1.1.1:5001 | — | 61.0.0.1:80 |
| 192.168.1.20:3345 | 202.1.1.1:5002 | — | 61.0.0.2:80 |

### 7.3 工作流程

```
出方向：源IP(私有) → 源IP(全局)，源端口 → 新端口，记录映射
入方向：目的IP(全局) → 目的IP(私有)，目的端口 → 原端口，查表
```

### 7.4 NAT类型

| 类型 | 特点 |
|------|------|
| 静态NAT | 一对一固定映射 |
| 动态NAT | 一对一动态分配，地址池 |
| NAPT/PAT | 多对一，利用端口号区分 |

> **考点**：NAPT（端口NAT）允许多个内部主机共享一个全局IP，靠端口号区分。

## 八、路由协议

### 8.1 静态路由 vs 动态路由

| 特性 | 静态路由 | 动态路由 |
|------|---------|---------|
| 配置 | 手动 | 自动学习 |
| 开销 | 小 | 大 |
| 收敛速度 | — | 取决于协议 |
| 适用 | 小型网络 | 大型网络 |

### 8.2 RIP协议

| 特性 | 说明 |
|------|------|
| 类型 | 距离向量路由协议 |
| 度量 | 跳数（每经过一个路由器+1） |
| 最大跳数 | 15（16=不可达） |
| 更新周期 | 每30秒 |
| 传输层 | UDP，端口520 |
| 收敛 | 慢，可能计数到无穷 |

> **易错**：RIP最大跳数15，16跳视为不可达。

### 8.3 OSPF协议

| 特性 | 说明 |
|------|------|
| 类型 | 链路状态路由协议 |
| 算法 | Dijkstra最短路径 |
| 度量 | 带宽/延迟/代价 |
| 更新 | 触发更新 + 每30分钟 |
| 传输层 | IP直接承载（协议号89） |
| 收敛 | 快 |

> OSPF使用洪泛法交换链路状态信息，每个路由器构建完整拓扑图。

### 8.4 BGP协议

| 特性 | 说明 |
|------|------|
| 类型 | 路径向量路由协议 |
| 度量 | 路径属性（AS路径等） |
| 传输层 | TCP，端口179 |
| 适用 | 自治系统间（AS间） |

### 8.5 三种协议对比

| 特性 | RIP | OSPF | BGP |
|------|-----|------|-----|
| 类型 | 距离向量 | 链路状态 | 路径向量 |
| 算法 | 距离向量 | Dijkstra | 路径属性 |
| 传输 | UDP 520 | IP协议89 | TCP 179 |
| 适用范围 | IGP（AS内） | IGP（AS内） | EGP（AS间） |
| 收敛速度 | 慢 | 快 | 中 |

## 九、ICMP协议

### 9.1 功能

- 报告差错和异常
- 用于网络诊断

### 9.2 报文类型

| 类别 | 类型 | 说明 |
|------|------|------|
| 差错报告 | 目的不可达（Type 3） | 网络/主机/端口不可达 |
| 差错报告 | 超时（Type 11） | TTL=0 |
| 差错报告 | 重定向（Type 5） | 更优路由 |
| 询问 | 回送请求/应答（Type 8/0） | ping |
| 询问 | 时间戳请求/应答（Type 13/14） | 时间同步 |

### 9.3 应用

- **ping**：回送请求（Type 8）→ 回送应答（Type 0），测试连通性
- **traceroute**：利用TTL递增和超时报文（Type 11），逐跳追踪路径

## 十、IPv6

### 10.1 基本特征

| 特性 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32位 | 128位 |
| 首部长度 | 20-60B（可变） | 40B（固定） |
| 分片 | 路由器可分片 | 仅源端分片 |
| 校验和 | 有 | 无（取消CRC） |
| 地址表示 | 点分十进制 | 冒号十六进制 |

### 10.2 IPv6首部简化

- 基本首部固定40字节
- 扩展首部链式结构
- **取消首部校验和**（由上层协议保证可靠性）
- 取消分片相关字段（移至扩展首部）

### 10.3 地址表示

```
完整：2001:0DB8:0000:0000:0000:0000:0000:0001
压缩：2001:0DB8::0001（连续的0可用::表示，但只能用一次）
进一步：2001:DB8::1
```

## 十一、典型计算题及答题模板

### 11.1 子网划分计算模板

```
题目：IP = a.b.c.d/n，划分 m 个子网（或每个子网 k 台主机）

步骤1：确定需要的子网位数
  - 划分 m 个子网：n' = ⌈log2(m)⌉
  - 或每个子网 k 台主机：m = ⌈log2(k+2)⌉（+2为网络地址和广播地址）

步骤2：新前缀 = n + n'（划分子网）或 n + n'（主机位借子网位）
        或新前缀 = 32 - m（从主机需求反推）

步骤3：计算各子网地址
  - 子网号从0递增
  - 每个子网的地址范围 = 2^(32-新前缀)

步骤4：每个子网
  - 网络地址：主机位全0
  - 广播地址：主机位全1
  - 可用主机范围
```

### 11.2 IP分片计算模板

```
题目：数据报总长 L B（含首部），MTU = M B

步骤1：数据部分 = L - 20
步骤2：每片最大数据 = (M - 20) 向下取8的倍数
       d_max = floor((M-20)/8) × 8
步骤3：分片数 = ceil((L-20) / d_max)
步骤4：各片信息
  - 片i：总长 = 20 + d_i
  - MF：非最后一片 MF=1，最后一片 MF=0
  - 片偏移 = (该片数据起始偏移) / 8
```

### 11.3 NAT转换表填写模板

```
题目：内部主机IP:端口 → NAT路由器全局IP

步骤1：出方向
  - 源IP:源端口 → 全局IP:新端口
  - 记录映射关系到NAT表

步骤2：入方向
  - 查NAT表，将目的IP:端口替换为内部IP:原端口
  - 转发到内部主机
```

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. **大题先识别题型**：给"IP + 掩码 + 划分需求" → 子网划分；给"数据报长度 + MTU" → IP 分片；给"内外部地址" → NAT 转换表；给"拓扑 + 路由信息" → 路由协议分析。定位后套对应模板。
2. **子网划分**：先确定需求方向（划分 m 个子网 → 借位 ⌈log₂m⌉；每子网 k 台主机 → 留 ⌈log₂(k+2)⌉ 位），再逐个子网写"网络地址 / 可用主机范围 / 广播地址"，主机数记得减 2（去掉全 0 和全 1）。
3. **分片计算**：每片最大数据 = (MTU − 20) 向下取 8 的倍数；片偏移 = 该片数据在原始数据部分的起始偏移 ÷ 8（不是片序号）；MF 仅最后一片为 0。
4. **选择题记三组硬数据**：RIP = UDP 520、最大 15 跳；OSPF = 直接封装在 IP（协议号 89）；BGP = TCP 179；特殊地址 0.0.0.0（本网络本主机）/ 255.255.255.255（受限广播）/ 127.x（环回）。

**知识串联提示：**
- 本层知识点与数据链路层的关联：IP 包必须封装进以太网帧（MTU 1500B）才能传输，分片由此而生，且在**目的主机**重组而非中间路由器；IP 地址端到端不变（除 NAT）、MAC 地址逐跳改变，这一分工是综合题高频切入点。
- 本层知识点与传输层的关联：NAPT 靠**端口号**（传输层概念）区分多台内部主机，是"传输层联手应用层"解决"网络层地址不足"的方案；ICMP 的"端口不可达"差错源于传输层无对应端口；IPv6 取消首部校验和，把差错检测责任进一步交给传输层。
- 容易混淆的概念对比：RIP（距离向量、UDP、跳数）vs OSPF（链路状态、IP 直接承载、Dijkstra）vs BGP（路径向量、TCP、AS 间）；子网划分（掩码变长）vs 路由聚合（取公共前缀、掩码变短）；IPv4（路由器可分片、有校验和）vs IPv6（仅源端分片、无首部校验和）。

## 十二、易错点清单

1. **子网主机数 = 2^m - 2**，减去网络地址和广播地址。
2. **全0和全1子网现代默认可用**，但旧标准不可用，注意题目年份和说明。
3. **IP分片大小必须是8的倍数**，向下取整。
4. **片偏移以8字节为单位**，不是字节，计算时要除以8。
5. **ARP请求广播，ARP响应单播**，跨网段时ARP请求发给网关。
6. **DHCP使用UDP**，服务器端口67，客户端端口68。
7. **RIP最大跳数15**，16跳=不可达，不是16。
8. **OSPF直接承载在IP上**，协议号89，不是TCP/UDP。
9. **BGP使用TCP**，端口179。
10. **NAT利用端口号区分不同内部主机**，不仅转换IP。
11. **最长前缀匹配原则**：多条路由匹配时选前缀最长的。
12. **IPv6取消首部校验和**，取消路由器分片（仅源端分片）。
13. **192.168.1.130/26 属于 192.168.1.128 子网**，不是 192.168.1.0。
14. **路由聚合取公共前缀**，前缀长度 = 公共位数。

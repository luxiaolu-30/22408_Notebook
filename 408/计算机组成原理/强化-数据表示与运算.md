# 计算机组成原理 强化 · 数据表示与运算

> **数据口径**：2016-2025 近 10 年大题统计。计组大题为 43-44 题（22 分）。
> 选择题常考，44 题大题偶尔涉及（约 5/10 年），是选择题高频考点。

> **本板块串联**：本章回答"机器如何存数、如何算数"——为指令系统提供操作对象（机器数），为 CPU 板块提供 ALU 运算电路；IEEE 754 与补码是选择题 10/10 的两大必考格式翻译题。

## 🧭 知识主线

本章不是零散的进制、码制、运算规则的堆砌，而是一条从数学到电路的加工链：**从真值到机器数再到运算电路，每一层都是上一层的工程化**。真值（如 −12.75）是人类世界的数；第一层"表示"把它变成机器数——原码直观但有 ±0，补码统一加减法且多表示一个 $-2^{n-1}$，移码保序、专供阶码比较；第二层"格式"解决小数点放哪——定点数隐含固定小数点、浮点数用阶码+尾数显式表达；第三层"标准"把浮点格式工程化——IEEE 754 三段切割（S/E/M）、隐含前导 1、偏移 127、E 全 0/全 1 的特殊值约定；第四层"算法"落地运算——补码加减、Booth 乘法、加减交替除法、浮点五步法（对阶→尾数加减→规格化→舍入→判溢出）；第五层"电路"把算法做成硬件——先行进位加法器（G/P 信号）与 ALU。10/10 的选择题考点集中在前三层（补码与 IEEE 754），44 题大题则常把第四、五层与 CPU 数据通路结合出题。

## 二、进制转换

### 2.1 各进制对照

| 进制 | 基数 | 标识 | 常用 |
|------|------|------|------|
| 二进制 | 2 | B | 机器内部 |
| 八进制 | 8 | Q/O | 权限表示 |
| 十进制 | 10 | D | 人类阅读 |
| 十六进制 | 16 | H | 地址/数据表示 |

### 2.2 转换方法

**十进制 → 二进制**：
- 整数部分：除 2 取余，逆序排列
- 小数部分：乘 2 取整，顺序排列

**二进制 → 八进制**：每 3 位一组，不足补零（整数左补，小数右补）

**二进制 → 十六进制**：每 4 位一组，不足补零

**八进制 ↔ 十六进制**：先转二进制，再分组

> 易错：小数部分可能无法精确转换（如 0.1 在二进制下是无限循环小数）。

## 三、原码 / 反码 / 补码 / 移码

### 3.1 定义对比（n 位机器数）

| 码制 | 正数 | 负数 | 零的表示 |
|------|------|------|---------|
| 原码 | 符号位 0 + 绝对值 | 符号位 1 + 绝对值 | +0 = 00...0，-0 = 10...0（两种） |
| 反码 | 符号位 0 + 绝对值 | 符号位 1 + 逐位取反 | +0 = 00...0，-0 = 11...1（两种） |
| 补码 | 符号位 0 + 绝对值 | 符号位 1 + 逐位取反 + 1 | 0 = 00...0（唯一） |
| 移码 | 补码符号位取反 | 补码符号位取反 | 0 = 10...0（唯一） |

### 3.2 补码关键公式

$$\boxed{[x]_{\text{补}} = \begin{cases} x & x \geq 0 \\ 2^n + x = 2^n - |x| & x < 0 \end{cases}}$$

**负数补码求法**：取反 + 1（注意：符号位不参与取反）

**补码 → 真值**：
- 若符号位为 0：直接读数（正数）
- 若符号位为 1：取反 + 1 得绝对值，加负号

### 3.3 移码

$$[x]_{\text{移}} = [x]_{\text{补}} \text{ 的符号位取反}$$

- 移码主要用于表示**浮点数的阶码**
- 偏移量 = $2^{n-1}$（或 $2^{n-1}-1$，取决于定义）
- 移码大小关系与真值大小关系一致（便于比较）

### 3.4 表示范围（n 位，含 1 位符号位）

| 码制 | 最小值 | 最大值 | 范围 |
|------|--------|--------|------|
| 原码 | $-(2^{n-1}-1)$ | $2^{n-1}-1$ | $[-(2^{n-1}-1),\ 2^{n-1}-1]$ |
| 反码 | $-(2^{n-1}-1)$ | $2^{n-1}-1$ | $[-(2^{n-1}-1),\ 2^{n-1}-1]$ |
| 补码 | $-2^{n-1}$ | $2^{n-1}-1$ | $[-2^{n-1},\ 2^{n-1}-1]$ |

> **核心差异**：补码比原码/反码**多表示一个最小负数** $-2^{n-1}$（如 8 位补码可表示 -128，但原码最小为 -127）。
> 这个最小负数**没有原码**，无法取反加 1 还原。

## 四、IEEE 754 浮点数（核心考点！）

### 4.1 格式

| 类型 | 总位数 | S（符号） | E（阶码） | M（尾数） | 偏移量 |
|------|:------:|:---------:|:---------:|:---------:|:------:|
| 单精度 | 32 | 1 | 8 | 23 | 127 |
| 双精度 | 64 | 1 | 11 | 52 | 1023 |

### 4.2 真值公式

**规格化数**（$1 \leq E \leq 254$ 单精度 / $1 \leq E \leq 2046$ 双精度）：

$$\boxed{X = (-1)^S \times 1.M \times 2^{E-127} \quad \text{（单精度）}}$$

$$\boxed{X = (-1)^S \times 1.M \times 2^{E-1023} \quad \text{（双精度）}}$$

**关键理解**：
- 尾数 M 前隐含一个 **1**，所以实际尾数为 **1.M**
- 阶码用**移码**表示，偏移量 = $2^{n-1}-1$（n=8 时为 127）
- 实际指数 $e = E - 127$（单精度），范围 $[-126, +127]$

### 4.3 特殊值对照表

| 阶码 E | 尾数 M | 含义 | 真值 |
|:------:|:------:|------|------|
| 0 | 0 | ±0 | 0 |
| 0 | ≠ 0 | 非规格化数 | $(-1)^S \times 0.M \times 2^{-126}$ |
| 1~254 | 任意 | 规格化数 | $(-1)^S \times 1.M \times 2^{E-127}$ |
| 255（全1） | 0 | ±∞ | 无穷大 |
| 255（全1） | ≠ 0 | NaN | 非数 |

### 4.4 表数范围（单精度）

| 边界 | 值 |
|------|-----|
| 最大正数 | $(2 - 2^{-23}) \times 2^{127} \approx 3.4 \times 10^{38}$ |
| 最小规格化正数 | $1.0 \times 2^{-126} = 2^{-126} \approx 1.18 \times 10^{-38}$ |
| 最小非规格化正数 | $2^{-23} \times 2^{-126} = 2^{-149} \approx 1.4 \times 10^{-45}$ |

### 4.5 十进制 → IEEE 754 转换步骤

```
例：将 -12.75 转为 IEEE 754 单精度

步骤 1：确定符号位 S
  -12.75 < 0 → S = 1

步骤 2：将绝对值转为二进制
  12.75 = 8 + 4 + 0.5 + 0.25 = 1100.11B

步骤 3：规格化（小数点移到第一个 1 后面）
  1100.11 = 1.10011 × 2^3
  实际指数 e = 3

步骤 4：计算阶码 E
  E = e + 127 = 3 + 127 = 130 = 10000010B

步骤 5：取尾数（去掉隐含的 1，补齐 23 位）
  M = 10011000000000000000000

步骤 6：组合 S + E + M
  1 10000010 10011000000000000000000

步骤 7：转十六进制
  = 1100 0001 0100 1100 0000 0000 0000 0000
  = C14C0000H
```

### 4.6 IEEE 754 → 十进制转换步骤

```
例：将 4730 0000H 转为十进制真值

步骤 1：转 32 位二进制
  0100 0111 0011 0000 0000 0000 0000 0000

步骤 2：拆分 S / E / M
  S = 0
  E = 10001110 = 142
  M = 01100000000000000000000

步骤 3：判断 E
  1 ≤ 142 ≤ 254 → 规格化数

步骤 4：计算实际指数
  e = 142 - 127 = 15

步骤 5：还原尾数（加隐含的 1）
  1.M = 1.011B = 1 + 0.25 + 0.125 = 1.375

步骤 6：计算真值
  X = (-1)^0 × 1.375 × 2^15 = 1.375 × 32768 = 45056
```

### 4.7 浮点数加减运算

**五步法**：

| 步骤 | 操作 | 要点 |
|------|------|------|
| ① 对阶 | 小阶向大阶看齐 | **小阶尾数右移**，每移一位阶码 +1，**不丢失精度**的说法是错的，**会丢精度** |
| ② 尾数加减 | 补码加减运算 | 注意隐藏的 1 要还原 |
| ③ 规格化 | 尾数左规/右规 | 左规：尾数左移，阶码 -1；右规：尾数右移，阶码 +1 |
| ④ 舍入 | 对阶和右规时产生误差 | 常用方法：0 舍 1 入、就近舍入（默认） |
| ⑤ 溢出判断 | 检查阶码是否溢出 | 阶码上溢→±∞；阶码下溢→±0 |

> **对阶原则**：小阶向大阶对齐，尾数右移。**不能大阶向小阶对齐**（尾数左移会导致高位丢失，精度损失更大）。

### 4.8 浮点数乘除运算

- 乘法：阶码相加，尾数相乘，再规格化
- 除法：阶码相减，尾数相除，再规格化

## 五、定点数运算

### 5.1 补码加减法

$$[x + y]_{\text{补}} = [x]_{\text{补}} + [y]_{\text{补}} \pmod{2^n}$$

$$[x - y]_{\text{补}} = [x]_{\text{补}} + [-y]_{\text{补}}$$

其中 $[-y]_{\text{补}}$ = $[y]_{\text{补}}$ 连同符号位一起取反 + 1。

### 5.2 溢出判断

#### 方法一：单符号位法

- 操作数符号相同，结果符号不同 → 溢出
- 正 + 正 = 负 → 上溢
- 负 + 负 = 正 → 下溢

#### 方法二：双符号位法（变形补码）

- 符号位 00 → 正数，无溢出
- 符号位 11 → 负数，无溢出
- 符号位 01 → 正溢出（上溢）
- 符号位 10 → 负溢出（下溢）

> **双符号位判断规则**：两位符号位相同→无溢出；不同→有溢出。

#### 方法三：进位判断法

- 符号位进位 $C_s$ 与最高数值位进位 $C_1$
- $C_s \oplus C_1 = 1$ → 溢出

### 5.3 溢出标志位

| 标志 | 含义 | 判断 |
|------|------|------|
| **OF** | 有符号数溢出 | 双符号位不同 / $C_s \oplus C_1$ |
| **CF** | 无符号数进位/借位 | 最高位进位输出 |
| **SF** | 符号标志 | 结果最高位 |
| **ZF** | 零标志 | 结果全 0 |

> **高频考点**：OF 和 CF 的区别！
> - OF 判断**有符号数**溢出（看符号位变化）
> - CF 判断**无符号数**进位/借位（看最高位是否有进位）
> - 同一个运算结果，OF 和 CF 可能不同

## 六、乘法运算

### 6.1 原码一位乘法

**规则**：
1. 符号位单独处理：$P_s = x_s \oplus y_s$
2. 数值部分用绝对值相乘
3. 每次判断乘数最低位：
   - 为 1 → 部分积 + |被乘数|，然后右移
   - 为 0 → 部分积 + 0，然后右移
4. 重复 n 次（n 为数值位数）

**特点**：用**两步符号位**，运算过程中**绝对值相加**，逻辑移位。

### 6.2 Booth 算法（补码一位乘法）

**规则**：
1. 被乘数 $[x]_{\text{补}}$、部分积 $[P]_{\text{补}}$、乘数 $[y]_{\text{补}}$ 均用**双符号位**
2. 乘数末尾附加一位 $y_{n+1} = 0$
3. 根据相邻两位 $y_i y_{i+1}$ 判断操作：

| $y_i$ | $y_{i+1}$ | 操作 |
|:-----:|:---------:|------|
| 0 | 0 | 部分积右移 1 位 |
| 0 | 1 | 部分积 $+ [x]_{\text{补}}$，右移 1 位 |
| 1 | 0 | 部分积 $+ [-x]_{\text{补}}$，右移 1 位 |
| 1 | 1 | 部分积右移 1 位 |

4. 共进行 $n + 1$ 次判断，$n$ 次移位（最后一次不移位）

> **Booth 关键**：最后一步判断后**不移位**，第 $n+1$ 次只判断不操作。

## 七、除法运算

### 7.1 恢复余数法

**流程**：
1. 符号位单独处理
2. 被除数/余数左移 1 位
3. 余数 - 除数（补码加法）
4. 判断余数符号：
   - 同号（够减）→ 商上 1，保留余数
   - 异号（不够减）→ 商上 0，**恢复余数**（余数 + 除数）
5. 重复 n 次

> 缺点：不够减时需要额外加法恢复余数，速度慢。

### 7.2 加减交替法（不恢复余数法）

**规则**：
- 够减（商 1）：下一步减去除数
- 不够减（商 0）：下一步加上除数（不恢复，直接继续）

| 上一步商 | 本步操作 |
|:--------:|---------|
| 1 | 余数 - 除数 |
| 0 | 余数 + 除数 |

> 优点：每次只需一次加减操作，无需恢复，速度更快。

## 八、ALU 设计

### 8.1 加法器类型

| 类型 | 原理 | 延迟 | 特点 |
|------|------|------|------|
| 串行进位 | 逐位传递进位 | O(n) | 简单但慢 |
| 并行进位（先行进位） | 同时计算所有进位 | O(1)~O(log n) | 快但硬件复杂 |

### 8.2 先行进位（Carry Lookahead）

**进位生成与传播**：
- 进位生成：$G_i = A_i \cdot B_i$（该位产生进位）
- 进位传递：$P_i = A_i \oplus B_i$（该位传递低位进位）
- 进位：$C_{i+1} = G_i + P_i \cdot C_i$

**4 位先行进位**：

$$C_1 = G_0 + P_0 C_0$$
$$C_2 = G_1 + P_1 G_0 + P_1 P_0 C_0$$
$$C_3 = G_2 + P_2 G_1 + P_2 P_1 G_0 + P_2 P_1 P_0 C_0$$
$$C_4 = G_3 + P_3 G_2 + P_3 P_2 G_1 + P_3 P_2 P_1 G_0 + P_3 P_2 P_1 P_0 C_0$$

> 每个进位只依赖 $G$、$P$ 和 $C_0$，可以同时计算。

### 8.3 分组先行进位

- **单级先行**：4 位一组，组内先行进位，组间串行
- **多级先行**：组内先行 + 组间先行（两级结构），如 SN74182 芯片

## 九、易错点清单

| # | 易错点 | 正确理解 |
|---|--------|---------|
| 1 | 补码 = 反码 + 1（包括符号位） | 错！符号位不参与取反，数值位取反后 +1 |
| 2 | 补码最小负数有原码 | 错！$-2^{n-1}$ 只能用补码表示，无原码和反码 |
| 3 | 移码 = 补码全部取反 | 错！移码 = 补码**符号位取反**，数值位不变 |
| 4 | IEEE 754 尾数包含前导 1 | 错！前导 1 是**隐含**的，M 中不存 |
| 5 | 非规格化数偏移量也是 127 | 错！非规格化实际指数固定为 **-126**（单精度），不是 E-127 |
| 6 | 对阶时大阶向小阶对齐 | 错！**小阶向大阶对齐**，小阶尾数右移 |
| 7 | 对阶不会损失精度 | 错！小阶尾数右移会丢失低位，**有精度损失** |
| 8 | OF 用于无符号数溢出 | 错！OF 用于**有符号数**溢出，CF 用于无符号数 |
| 9 | CF = 1 一定有溢出 | 错！CF 只表示无符号数有进位/借位，与溢出无关 |
| 10 | Booth 算法最后一步要移位 | 错！Booth 最后一步（第 n+1 次）**只判断不移位** |
| 11 | 原码乘法用补码运算 | 错！原码一位乘用**绝对值**运算，Booth 用补码 |
| 12 | IEEE 754 全 0 阶码是规格化数 | 错！E=0 是**非规格化数**或 ±0 |
| 13 | 先行进位所有进位完全并行 | n 位时分组处理，组内并行，组间可能串行 |
| 14 | 双符号位法适用于所有运算 | 双符号位主要用于加减法溢出判断，乘除法用双符号位但目的不同 |

## 🧠 思考模式

**遇到这类题，第一反应应该是：**

1. IEEE 754 翻译题：先按位数画三段切割线（单精度 1/8/23、双精度 1/11/52）→ 判断 E 是否全 0 或全 1（特殊值）→ 套 $X = (-1)^S \times 1.M \times 2^{E-127}$，时刻记住尾数隐含前导 1、阶码是偏移 127 的移码
2. 溢出判断题：先分清有符号还是无符号——有符号看 OF（双符号位相异或 $C_s \oplus C_1$），无符号看 CF（最高位进位/借位），同一个运算结果两者可能不同
3. 浮点运算题：五步法走流程（对阶→尾数加减→规格化→舍入→判溢出），对阶永远"小阶向大阶、尾数右移"；溢出只看阶码——上溢为 ±∞，下溢按 ±0 处理

**知识串联提示：**
- 与其他板块的关联：补码加减产生的 OF/CF/SF/ZF 正是 CPU 板块 PSW（标志寄存器）的内容，条件转移指令靠它判断；先行进位加法器（G/P 逻辑）就是 CPU 数据通路中 ALU 的内部结构，44 题可能要求结合数据通路分析；移码思想在本章服务于浮点阶码比较，与指令系统相对寻址中"补码偏移量"同属"编码即运算"的思想
- 容易混淆的概念对比：OF vs CF（有符号溢出 vs 无符号进位）；原码一位乘（绝对值运算、逻辑移位）vs Booth 算法（补码运算、算术移位）；补码 vs 移码（仅符号位相反）；E 全 0 vs E 全 1（非规格化数/±0 vs ±∞/NaN）；对阶是否丢精度（小阶尾数右移必然丢低位，"不丢精度"是错误说法）

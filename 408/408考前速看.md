# 408 考前速看（四科浓缩卡片）

> 考前 1-2 周每天过一遍：核心公式 → 必背结论 → 大题框架 → 易错警示 → 考场策略。
> 计网协议交互流程（DHCP/DNS/ARP/NAT/ICMP/RIP/OSPF）见 [[408/计算机网络/考前速看-核心协议]]。

## 一、考场策略

### 时间分配（180 分钟）

| 部分 | 题量 | 分值 | 用时 |
|------|:----:|:----:|------|
| 单项选择题 1-40 | 40 题 | 80 分 | 60-70 分钟 |
| 综合应用题 41-47 | 7 题 | 70 分 | 95-105 分钟 |
| 涂卡 + 检查 | — | — | 10-15 分钟 |

### 做题顺序

1. 先做选择题，单题卡壳超过 2 分钟立即标记跳过
2. 大题按顺序做；**43（Cache）与 45（PV）是送分题，务必拿满**
3. 算法题（41）无思路时：先写暴力解法 + 文字描述保过程分，最后有余力再优化
4. 交卷前 15 分钟：补跳过的选择题 + 检查涂卡

### 答题规范

- 应用题**写清步骤不跳步**，计算题先列公式再代数
- Cache/虚存题画地址结构图；PV 题注明信号量含义与初值；cwnd 题画波形图并标注各阶段
- 算法题：算法思想 → 数据结构定义 → 代码/伪代码 → 复杂度分析，一步都不省

## 二、数据结构速记（45 分）

### 二叉树性质（选择必考）

- $n_0 = n_2 + 1$（叶子数 = 度 2 结点数 + 1）
- 第 i 层最多 $2^{i-1}$ 个结点；高度 h 的二叉树最多 $2^h - 1$ 个结点
- n 个结点的完全二叉树高度为 $\lceil \log_2(n+1) \rceil$
- 完全二叉树顺序存储（从 1 编号）：左孩子 2i、右孩子 2i+1、双亲 ⌊i/2⌋
- 遍历还原：**中序 +（前序 | 后序 | 层序）可唯一确定**；前序 + 后序不能
- 哈夫曼树：n 个叶子共 **2n−1** 个结点（只有度 0 和度 2）；WPL = Σwᵢlᵢ；哈夫曼编码是前缀码

### 图算法（42 题必考）

| 算法 | 类型 | 复杂度 | 要点 |
|------|------|--------|------|
| Dijkstra | 单源最短路 | O(n²) | **不能处理负权边**；贪心 |
| Floyd | 全源最短路 | O(n³) | 可负权边（无负环）；三重循环 DP |
| Prim | MST 加点法 | O(n²) | 稠密图 |
| Kruskal | MST 加边法 | O(e·log e) | 稀疏图；并查集判环 |
| 拓扑排序 | AOV 网 | O(n+e) | 入度 0 入队；可判有向环 |
| 关键路径 | AOE 网 | — | 源→汇最长路径；**e = vl 的活动是关键活动** |

### 排序特性对比（选择高频）

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|:----:|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | ✔ |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✔ |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ✘ |
| 希尔 | — | ≈O(n^1.3) | O(n²) | O(1) | ✘ |
| 快排 | O(nlogn) | O(nlogn) | **O(n²)** | O(logn)~O(n) | ✘ |
| 堆排 | O(nlogn) | O(nlogn) | O(nlogn) | O(1) | ✘ |
| 归并 | O(nlogn) | O(nlogn) | O(nlogn) | O(n) | ✔ |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✔ |

- 每趟至少一个元素到位：**快排、冒泡、简单选择、堆排**（归并不是）
- 简单选择的**比较次数与初始序列无关**（恒 n(n−1)/2）
- 快排空间 = 递归栈深：平均 O(logn)，最坏 O(n)

### 查找

- 折半查找 ASL ≈ log₂(n+1) − 1；判定树是平衡 BST
- 散列：除留余数 p 取**不大于表长的最大质数**；装填因子 α = n/m，ASL 只与 α 有关
- 线性探测法会产生"堆积"（非同义词也冲突）；平方探测 ±1²、±2²…
- B 树（m 阶）：非叶结点关键字 ⌈m/2⌉−1 ~ m−1 个，子树 ⌈m/2⌉ ~ m 棵（根至少 2 棵）
- B+ 树：n 个关键字 n 棵子树，**叶子含全部关键字且链表相连**

### 41 题算法设计

二叉树遍历框架（递归/非递归）、链表快慢指针/头插逆置、图 DFS/BFS 模板 → 模板代码见 [[408/数据结构/强化-算法设计专项]]

## 三、计算机组成原理速记（45 分）

### IEEE 754（选择 15/15 年）

- 单精度 1+8+23 位，偏置 **127**；双精度 1+11+52 位，偏置 **1023**
- 规格化真值：$X = (-1)^S × 1.M × 2^{E-127}$（**隐含前导 1**）
- 十进制 → 754：化二进制 → 规格化为 1.x × 2ᵉ → E = e + 127 → 拼 S/E/M
- 特殊值：E=255 且 M=0 → ±∞；E=255 且 M≠0 → NaN；**E=0 且 M≠0 → 非规格化（无隐含 1）**

### 补码与浮点运算

- n 位补码范围 −2ⁿ⁻¹ ~ 2ⁿ⁻¹−1；0 表示唯一
- [−x]补 = [x]补 取反加一；移码 = 补码符号位取反
- 浮点加减五步：**对阶（小阶向大阶）→ 尾数加减 → 规格化 → 舍入 → 判溢出（看阶码）**

### Cache（43 题全勤）

| 映射方式 | 主存地址结构 | 特点 |
|----------|-------------|------|
| 直接映射 | 标记 \| 行号 \| 块内地址 | 每块固定一行，冲突率高 |
| 组相联 | 标记 \| 组号 \| 块内地址 | 组间直接、组内全相联 |
| 全相联 | 标记 \| 块内地址 | 任意行，标记比较开销大 |

- 平均访问时间 = h·t_cache + (1−h)·t_main
- 写策略：**写直达**（同时写主存）vs **写回**（脏位，换出时写回）；写缺失分写分配/非写分配
- 与虚存联动：虚地址 → 查 TLB/页表 → 物理地址 → 查 Cache

### 寻址方式（EA）

| 方式 | 有效地址 | 典型用途 |
|------|---------|---------|
| 立即 | 操作数在指令中 | 常数 |
| 直接 | EA = A | — |
| 间接 | EA = (A) | — |
| 寄存器间接 | EA = (Rᵢ) | — |
| 变址 | EA = (IX) + A | **数组、循环** |
| 基址 | EA = (BR) + A | **重定位、多道程序** |
| 相对 | EA = (PC) + A | **转移指令**（PC 已指向下条指令） |

### 指令流水线

- n 条指令 k 段流水：总时间 = (k + n − 1)Δt
- 吞吐率 = n/((k+n−1)Δt)，最大 1/Δt；加速比 = kn/(k+n−1)；效率 = n/(k+n−1)
- 三种冒险：**结构**（资源冲突）、**数据**（RAW，转发/暂停）、**控制**（转移，分支预测）

### I/O 与总线

- 中断：CPU 执行中断服务程序；多重中断靠**屏蔽字**控制优先级
- DMA：传送阶段不需 CPU；适合高速批量数据；周期窃取挪用存取周期
- 总线带宽 = 频率 × 宽度/8（如 32 位 @ 100 MHz = 400 MB/s）

## 四、操作系统速记（35 分）

### PV 操作（45 题必考）

- P：申请资源（减 1，< 0 阻塞）；V：释放资源（加 1，唤醒等待者）
- **同步的 P 必须在互斥的 P 之前**（否则死锁）；V 的顺序可交换
- 互斥信号量初值 1；同步信号量初值 = 资源数量
- 五大模型：生产者-消费者（empty/full/mutex）、多生产者-多消费者（盘子/水果）、读者-写者（readcount + rw，写优先再加 w）、哲学家（**最多 4 人同时拿筷**）、吸烟者（材料组合信号量）
- 做题四步：找制约关系 → 定义信号量（写含义和初值）→ 写进程代码 → 检查 P 顺序防死锁

### 死锁

- 四必要条件：**互斥、占有并等待、不可剥夺、循环等待**——破坏任一即可预防
- 银行家算法：Need = Max − Allocation；找安全序列（可用资源先满足 Need 最小者）
- 死锁 ≠ 饥饿：饥饿不一定死锁（SSTF 磁盘调度可致饥饿）

### 页面置换（46 题必考）

| 算法 | 依据 | 特点 |
|------|------|------|
| OPT | 未来最久不使用 | 理论最优，不可实现 |
| FIFO | 最先进入 | **有 Belady 异常** |
| LRU | 最近最久未使用 | 无 Belady 异常；可用栈实现 |
| CLOCK | 访问位 | 循环扫描；改进型再加修改位 |

- 抖动（颠簸）：缺页率过高导致 CPU 大部分时间在调页 → 工作集模型

### 内存管理

- 分页：物理地址 = 页框号 × 页大小 + 页内偏移；页大小 2ᵏ 时偏移占低 k 位
- 快表命中率 α：EAT = α(t_TLB + t_存) + (1−α)(t_TLB + 2t_存)
- 动态分区：首次适应（按地址递增）、最佳适应（最小空闲、碎片最多）、最坏适应（最大空闲）

### 文件与磁盘

- 多级索引：一级间接块数 = 块大小 ÷ 地址项大小；UNIX：直接 + 一级 + 二级 + 三级
- 磁盘调度：FCFS / **SSTF**（最短寻道，可饥饿）/ **SCAN**（电梯，双向）/ **C-SCAN**（单向循环更均匀）
- 磁盘容量 = 磁头数 × 柱面数 × 每磁道扇区数 × 每扇区字节数

### I/O

- 单缓冲每块耗时 = **max(C, T) + M**；双缓冲每块 = **max(C+M, T)**（T 设备输入、C 处理、M 缓冲→工作区）
- SPOOLing：用磁盘模拟脱机 I/O（共享打印机原理）；组成：输入/输出井 + 缓冲区 + 输入/输出进程

## 五、计算机网络速记（25 分）

### 物理层

- 奈奎斯特（无噪声）：$C = 2W\log_2 V$；香农（有噪声）：$C = W\log_2(1+S/N)$
- 信噪比换算：dB = 10·lg(S/N)，**30 dB = 1000 倍**
- 曼彻斯特编码：**波特率 = 2 × 数据率**（10 Mb/s → 20 MBaud）
- 总时延 = 发送(长度/带宽) + 传播(距离 ÷ 2×10⁵ km/s) + 处理 + 排队

### 数据链路层

- 以太网**最小帧长 64 B**，争用期 2τ = 51.2 μs；最小帧长 = 2τ × 带宽
- CSMA/CD：先听后发、边听边发、冲突停发、随机重发（二进制指数退避）
- 滑动窗口：停等 W=1；**GBN 发送窗 ≤ 2ⁿ−1（接收窗 = 1）**；**SR 收发窗 ≤ 2ⁿ⁻¹**
- 停等信道利用率 ≈ T_D/(T_D + RTT + T_A)
- CRC：生成多项式 r 位 → 数据补 r 个 0 → 模 2 除 → 余数为 FCS

### 网络层

- **子网划分五步**：①算需求 ②借位 s（2ˢ ≥ 子网数）、留 h 位（2ʰ−2 ≥ 主机数）③写掩码 ④网络地址 = IP AND 掩码、广播地址 = 主机位全 1 ⑤可用范围去掉全 0 全 1
- 同网段判断：两 IP 与掩码 AND 结果相同 → 直接交付
- IP 分片：**片偏移单位 8 B**；总长度字段单位 1 B；MF=1 表示后面还有分片
- 路由协议：RIP（距离向量、跳数 ≤ 15、UDP 520、30 s）；OSPF（链路状态、Dijkstra、直接封装 IP）；BGP（路径向量、TCP 179）
- 常用端口：FTP 21/20、SMTP 25、DNS 53、HTTP 80、HTTPS 443、POP3 110、DHCP 67/68（均记传输层协议）

### 传输层（47 题必考）

- 三次握手：SYN → SYN+ACK → ACK；第三次握手**防止失效连接请求浪费资源**
- 四次挥手：FIN → ACK → FIN → ACK；主动方 TIME_WAIT 等 **2MSL**（保 ACK 到达 + 旧报文消逝）
- **拥塞控制四算法**：
  - 慢开始：cwnd 从 1 起，每 RTT **×2（指数）**，到 ssthresh 转拥塞避免
  - 拥塞避免：每 RTT **+1（线性）**；**超时 → ssthresh = cwnd/2，cwnd 重置 1**，重新慢开始
  - 快重传：**3 个重复（冗余）ACK** 立即重传
  - 快恢复：ssthresh = cwnd/2，**cwnd = ssthresh（不回到 1）**
- 发送窗口 = min(rwnd, cwnd)；流量控制靠 rwnd

## 七、易错警示 TOP 15

1. 前序 + 后序**不能**唯一确定二叉树
2. Dijkstra 不能处理负权边；Floyd 可以（但不能有负环）
3. 快排最坏 O(n²)（序列基本有序时）；简单选择比较次数与初始序列无关
4. IEEE 754 非规格化数**没有**隐含 1（值 = 0.M × 2⁻¹²⁶）
5. Cache 写回法靠**脏位**决定是否写回主存
6. 相对寻址 EA=(PC)+A 中 PC 已加"1"指向下条指令
7. PV 中同步 P 放在互斥 P 之后会**死锁**；V 顺序无所谓
8. **Belady 异常只有 FIFO 有**（LRU/OPT/CLOCK 没有）
9. 饥饿不一定死锁；死锁一定有循环等待
10. 页面置换模拟**首次装入也算缺页**
11. 子网可用主机数要 **−2**（网络地址 + 广播地址）
12. IP 分片片偏移单位 **8 B**；以太网数据字段 46~1500 B
13. TCP **超时**（cwnd=1 重来）与**快重传**（减半快恢复）处理完全不同
14. 曼彻斯特编码波特率翻倍；CSMA/CD 最小帧长与争用期绑定
15. GBN 接收窗口 = 1（不能乱序收）；SR 才有接收缓存

## 一、数据结构（45 分）

### 考点 1：绪论与基本概念
- [ ] 数据、数据元素、数据项、数据对象的概念

- [ ] 存储结构：顺序存储、链式存储、索引存储、散列存储
- [ ] 数据类型与抽象数据类型（ADT）
- [ ] 算法的五大特征（有穷性、确定性、可行性、输入、输出）
- [ ] 时间复杂度与空间复杂度分析（大 O 表示法）

### 考点 2：线性表

- [ ] 单链表：头插法/尾插法建立、插入、删除、查找
- [ ] 双链表与循环链表
- [ ] 静态链表
- [ ] 顺序表 vs 链表的比较（存取方式、插入删除效率、空间利用）

- [ ] 顺序栈与链栈

- [ ] 栈与队列的综合应用

### 考点 4：树与二叉树 ⭐⭐⭐
- [ ] 二叉树的定义与五大性质
  - [ ] 第 i 层最多 $2^{i-1}$ 个结点
  - [ ] 高度为 h 的二叉树最多 $2^h-1$ 个结点
  - [ ] $n_0 = n_2 + 1$（叶子数 = 度2数 + 1）
  - [ ] 完全二叉树编号：左孩子=2i，右孩子=2i+1，父结点=⌊i/2⌋
  - [ ] 满二叉树与完全二叉树的关系
- [ ] 二叉树的遍历：前序（NLR）、中序（LNR）、后序（LRN）、层序
- [ ] 由遍历序列还原二叉树（前序+中序 / 后序+中序 / 层序+中序）
- [ ] 线索二叉树（前驱/后继指针）
- [ ] 树的存储结构（双亲表示法、孩子表示法、孩子兄弟表示法）
- [ ] 树与二叉树的转换
- [ ] 森林与二叉树的转换
- [ ] 哈夫曼树与哈夫曼编码 ⭐
  - [ ] 构造算法（贪心合并）
  - [ ] WPL 计算
  - [ ] 前缀编码性质
  - [ ] 判定是否为哈夫曼编码

- [ ] 最短路径 ⭐

### 考点 6：查找

- [ ] 分块查找（索引顺序查找）

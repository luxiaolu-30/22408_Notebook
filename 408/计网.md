## ASN.1（Abstract Syntax Notation One）

抽象语法定义：ISO/ITU-T 标准

描述了一种对数据进行表示、**编码**、传输和解码的数据格式。不同设备节点通信时定义统一数据结构，定义要传输的信息结构。

### 语法说明

1. 基础类型
2. 组合类型
3. 符号

### 基础类型

| 基本类型 | 含义 |
|----------|------|
| NULL | 只包含一个值 NULL，用于传送报告或作为 CHOICE 类型中的某些值 |
| BOOLEAN | TRUE or FALSE |
| INTEGER | 全部整数（正数和负数）|
| REAL | 实数，表示浮点数 |
| ENUMERATED | 标识符和枚举（如状态机状态）|
| BIT STRING | 比特串 |
| OCTET STRING | 字节串 |

### 组合类型

| 组合类型 | 含义 |
|----------|------|
| CHOICE | 在类型中选择，相当于 C 中的联合 |
| SEQUENCE | 由不同类型的值组成有序结构 ≈ C 结构体 |
| SET | 由不同类型的值组成无序结构 |
| SEQUENCE OF | 由相同类型值组成有序结构 ≈ C 数组 |
| SET OF | 由相同类型值组成无序结构 |

### 符号

| 符号 | 含义 |
|------|------|
| -- | 后面是注释行 |
| ::= | 定义为 |
| \| | 或 |
| {} | 清单的开始和结束 |
| [] | 标签的开始和结束 |
| () | 子类型的开始和结束 |
| .. | 范围 |

### ASN.1 编码方式

ASN.1 支持多种编码方式，可结合实际项目选择，编译时按 `-gen-PER` 格式指定。

| 编码方式 | 英文 | 优势 |
|----------|------|------|
| PER 编码 | 压缩编码规则 | 压缩能力强 |
| BER 编码 | 基本编码规则 | 基础方案（类型+长度+内容），额外数据多 |
| CER 编码 | 规范编码规则 | 安全性高 |
| DER 编码 | 识别名编码规则 | 安全性高 |
| OER 编码 | 八位字节编码规则 | 安全性高 |
| XER 编码 | XML 编码规则 | - |

## 三、本年命题特点

2014 年 408 真题整体难度适中偏上，跨学科综合题成为亮点。选择题方面，数据结构考查了时间复杂度分析、中缀转后缀过程中栈的状态、循环队列判断条件、线索二叉树、森林与二叉树转换、前缀编码、拓扑排序、B 树性质和排序算法（希尔排序增量、快速排序阶段性结果），其中第 3 题（循环队列两端均可入队出队的判断条件）和第 11 题（快速排序第 2 趟结果排除）区分度较高；组成原理首次考查 DRAM 地址复用引脚数计算（第 15 题）和编译优化对执行时间的影响（第 12 题），并延续了 IEEE 754 浮点数比较和总线突发传输的考查；操作系统考查了死锁避免的最小设备数（第 24 题）、Belady 异常（第 30 题）和多级页表优点（第 32 题），覆盖面广；计算机网络考查了 GBN 协议最大传输速率（第 36 题）和 CDMA 码片序列（第 37 题），难度较大。

综合应用题方面，2014 年最大的特色是跨学科综合：第 42 题将 OSPF 路由协议的网络拓扑抽象为数据结构中的带权图，要求设计链式存储结构并用 Dijkstra 算法计算最短路径，实现了数据结构与计算机网络的交叉考查；第 43 题延续第 42 题的网络场景，考查路由表构建、路由聚合、TTL 计算和 LSI 更新；第 44-45 题连续考查同一程序段 P，从指令格式、流水线冒险分析到虚拟存储、Cache 命中率和缺页处理，深度递进；第 46 题文件系统比较连续分配与链接分配的插入效率及文件最大长度；第 47 题考查带约束的生产者-消费者模型（消费者需连续取 10 件产品），对 PV 操作的理解要求较高。整体来看，2014 年真题强调综合分析能力和跨章节知识迁移。

## 四、重点题目解析

### 第 41 题（数据结构，13 分）

给定二叉树 T 的二叉链表存储（含 left、weight、right 域），设计算法求 WPL（所有叶结点带权路径长度之和）。核心思想有两种：

（1）基于先序遍历递归：设全局变量 wpl，将结点深度 deep 作为参数传递。若为叶结点，wpl += weight × deep；若为非叶结点，递归左右子树且 deep+1。

（2）基于层次遍历：使用队列，记录当前层深度，逐层遍历。遇到叶结点时累加 weight × 深度。

参考代码（递归法）：
```
typedef struct node {
    int weight;
    struct node *left, *right;
} BiNode, *BiTree;

int wpl = 0;
void calcWPL(BiTree root, int deep) {
    if (root == NULL) return;
    if (root->left == NULL && root->right == NULL)
        wpl += root->weight * deep;
    calcWPL(root->left, deep + 1);
    calcWPL(root->right, deep + 1);
}
```

### 第 42 题（数据结构，10 分）

某网络中路由器运行 OSPF 协议，R1 维护的 LSI 包含 R1-R4 的链路状态信息（Router ID、Link 的 ID/IP/Metric、直连网络 Net1 前缀和 Metric）。要求：

（1）网络可抽象为数据结构中的**带权无向图**（加权图），路由器为顶点，链路为边，Metric 为权值。

（2）设计链式存储结构：使用邻接表，定义头结点 HNode（保存 Router ID）和边结点 ArcNode（保存所连路由器 ID、IP、Metric、Next 指针），以及直连网络信息。

（3）按 Dijkstra 算法，R1 到各子网的最短路径及费用：
- 192.1.1.0/24（Net1）：R1 直连，费用 1
- 192.1.5.0/24（Net3）：R1→R3→Net3，费用 2+1=3
- 192.1.6.0/24（Net2）：R1→R2→Net2，费用 3+1=4
- 192.1.7.0/24（Net4）：R1→R2→R4→Net4，费用 3+4+1=8

### 第 44 题（组成原理，12 分）

程序段 P："for(int i=0; i<N; i++) sum += A[i]"，编译为 6 条指令（sll、add、load、add、add、bne）。

（1）M 的存储器编址单位为**字节**：相邻指令地址差 4（08048100H→08048104H），32 位定长指令占 4 字节。

（2）数组 A 中每个元素占 **32 位（4 字节）**：sll R4, R2, 2 将下标左移 2 位（乘 4），得到字节偏移。

（3）bne 指令机器码 1446FFFAH，OFFSET 字段为 FFFAH（补码，真值 -6）。转移目标地址计算公式：**目标地址 = (PC) + 4 + OFFSET × 4**。验证：08048114H + 4 + (-6)×4 = 08048118H - 18H = 08048100H = loop，正确。

（4）5 级流水线（IF/ID/EXE/MEM/WB），无转发，分支阻塞 3 周期：
- **数据相关阻塞**：指令 2（add R4,R4,R3 依赖指令 1 的 R4）、指令 3（load R5,0(R4) 依赖指令 2 的 R4）、指令 4（add R1,R1,R5 依赖指令 3 的 R5）、指令 6（bne R2,R6,loop 依赖指令 5 的 R2）。
- **控制冒险**：指令 6 为分支指令，引起 3 个时钟周期阻塞。
- **指令 1 不因与指令 5 的数据相关而阻塞**：指令 6 的分支阻塞 3 个周期，使得下一轮指令 1 开始执行时，指令 5 已完成 WB 阶段，R2 已写回，不存在数据相关。

### 第 45 题（组成原理，11 分）

基于第 44 题的计算机 M 和程序 P，M 采用页式虚拟存储管理，P 执行时 (R1)=(R2)=0，(R6)=1000，机器代码已调入主存但不在 Cache 中，数组 A 未调入主存（所有元素在同一页，存储在磁盘同一扇区）。

（1）P 执行结束时，R2 = **1000**。R2 从 0 开始，每次循环加 1，循环 N=1000 次，故 R2=1000。

（2）指令 Cache 有 16 行，块大小 32 字节：
- 数据区容量 = 16 × 32B = **512B**
- 6 条指令占 24 字节（地址 08048100H~08048117H），可放入一个 32 字节的 Cache 行。第一次取指缺失，调入后一直命中。共 1000×6=6000 次取指，1 次缺失，命中率 = 5999/6000 ≈ **99.98%**

（3）指令 4（add R1,R1,R5）累加数组元素，可能产生**溢出异常**；指令 3（load R5,0(R4)）访问数组 A，可能产生**缺页异常**。对于数组 A 的访问，需读磁盘至少 **1 次**（全部元素在同一页，一次缺页调入），TLB 至少 **1 次**（首次访问缺页后 TLB 加载页表项，后续均命中）。

### 第 46 题（操作系统，7 分）

文件 F 有 200 条记录，欲将新记录插入为第 30 条记录。

（1）连续分配方式，每个磁盘块存放一条记录，文件前后均有空闲空间：
- 将记录 1~29 向前移动一个磁盘块（利用文件前方空闲空间），共 29 次读 + 29 次写 = 58 次磁盘访问，再将新记录写入原记录 29 的位置（第 30 块前），共 **59 次**磁盘块访问。
- F 的文件控制块内容改变：**起始地址**（前移一个磁盘块）和**文件长度**（200→201）。

（2）链接分配方式，每个磁盘块存放一条记录和一个链接指针：
- 需沿链查找第 29 条记录：29 次读磁盘；将新记录写入新块并设置链接指针：1 次写；修改第 29 块的链接指针指向新块：1 次写。共 **31 次**磁盘块访问。
- 每块 1KB = 1024B，链接指针 4B（32 位，可寻址 2^32 个磁盘块），每块可用数据空间 1020B。文件最大长度 = 2^32 × 1020B ≈ **4.08TB**。

### 第 47 题（操作系统，8 分）

多个生产者和多个消费者共享 1000 件容量的环形缓冲区，要求一个消费者连续取 10 件后其他消费者才能取。信号量定义：

- `empty = 1000`：缓冲区空位数，初始 1000
- `full = 0`：缓冲区产品数，初始 0
- `mutex = 1`：缓冲区互斥访问
- `consumer_mutex = 1`：消费者间互斥（保证连续取 10 件）

```
// 生产者
Producer() {
    P(empty);      // 等待空位
    P(mutex);      // 互斥访问缓冲区
    // 放入产品
    V(mutex);
    V(full);       // 增加产品数
}

// 消费者
Consumer() {
    P(consumer_mutex);    // 保证独占连续取 10 件
    for (int i = 0; i < 10; i++) {
        P(full);          // 等待产品
        P(mutex);         // 互斥访问缓冲区
        // 取走产品
        V(mutex);
        V(empty);         // 增加空位
    }
    V(consumer_mutex);    // 释放消费者互斥
}
```

关键点：consumer_mutex 确保一个消费者的 10 次 P(full)/V(empty) 操作整体完成后才允许下一个消费者进入。P 操作顺序为先同步后互斥，避免死锁。

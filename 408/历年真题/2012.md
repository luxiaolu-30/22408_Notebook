## 三、本年命题特点

2012 年 408 真题在延续 2011 年风格的基础上，难度略有提升，尤其体现在综合应用题的区分度上。选择题方面，数据结构部分对图的考查明显加重（第 5-8 题连续考查 BFS 时间复杂度、拓扑排序、Dijkstra 算法和最小生成树性质），同时首次出现 B 树删除操作（第 9 题），对考生提出了更高要求；组成原理考查了 IEEE 754 浮点数最大值、Cache 组相联映射和微指令编码等细节考点；操作系统的进程调度时机（第 30 题）和用户态/内核态辨析（第 23 题）易错度高；计算机网络覆盖了从物理层到应用层的各层核心考点，布局均衡。

综合应用题方面，第 41 题以 6 个不等长有序表合并为背景，考查哈夫曼树思想在归并排序中的应用，需要理解最优合并策略与最坏比较次数计算；第 42 题链表共同后缀算法设计是经典的链表操作题，考查时间效率优化（先求长度再对齐）；第 43 题 MIPS/Cache/DMA 综合计算跨章节考查存储器层次结构；第 44 题指令流水线分析考查数据相关导致的流水线阻塞，要求画流水线时空图；第 45 题请求分页页面置换策略较为新颖，需模拟扫描回收过程；第 47 题以实际抓包数据为背景，分析 TCP 连接建立过程和以太网帧填充。整体来看，2012 年真题计算量大、综合度高，对考生的综合分析能力和计算能力要求较高。

## 四、重点题目解析

### 第 41 题（数据结构，10 分）
设有 6 个不等长有序表（元素数分别为 10、35、40、50、60、200），要求通过 5 次两两合并合成一个升序表，使最坏情况下比较总次数最小。核心思想是利用哈夫曼树思想：每次选择当前最短的两个表合并。合并过程为 A+B→AB(45)，D+E→DE(110)，AB+C→ABC(85)，ABC+DE→ABCDE(195)，ABCDE+F→最终表(395)。最坏比较总次数 = 45-1 + 85-1 + 110-1 + 195-1 + 395-1 = 825 次。推广到 N 个不等长表：采用哈夫曼树策略，每次合并最短的两表，可保证最坏情况下比较次数最小。

### 第 42 题（数据结构，13 分）
设计时间高效的算法，找出两个单链表共同后缀的起始位置。核心思想：（1）分别遍历两个链表求长度 m 和 n；（2）让较长链表的指针先走 |m-n| 步，使两指针到末尾距离相同；（3）两指针同步后移，直到指向同一结点（即共同后缀起点）或到达末尾。时间复杂度 O(m+n)，空间复杂度 O(1)。也可使用快慢指针或逆置链表等方法，但上述方法最为直观高效。

### 第 43 题（组成原理，10 分）
已知 CPU 主频 80MHz、CPI=4、Cache 命中率 99% 等条件，考查：（1）MIPS = 80MHz/4 = 20，每秒 Cache 缺失次数 = 20M×1.5×1% = 300000 次，主存带宽 = 300000×16B = 4.8MB/s；（2）缺页异常次数 = 300000×0.0005% = 1.5 次/s，DMA 请求次数 = 1.5×4KB/4B = 1536 次；（3）DMA 优先级更高，因为 DMA 请求若不及时响应可能导致数据丢失；（4）四体交叉存储最大带宽 = 32bit/(50ns/4) = 320MB/s。

### 第 44 题（组成原理，12 分）
在 16 位计算机的 5 段流水线（IF/ID/EX/M/WB）中分析数据相关阻塞：（1）-513 的补码为 FEFFH，SHR R1 算术右移后为 FF7FH（符号位扩展）；（2）无阻塞时 4 条指令需 8 个时钟周期（5+3）；（3）I3 的 ID 段被阻塞是因为 I2 的 WB 段写 R1 而不采用转发，同一寄存器读写不能同周期；I4 的 IF 段被阻塞是因为 I3 的 ID 段延迟导致；（4）x=x*2+a 对应 LOAD R1,[x]、SHL R1、LOAD R2,[a]、ADD R2,R1、STORE R2,[x]，需计算最少时钟周期并画流水线图。

### 第 45 题（操作系统，7 分）
某请求分页系统采用周期扫描回收策略（每 5 个时间单位扫描一轮），本轮未访问的页框被回收到空闲链尾。给定空闲页框链（32、15、21、41）和访问序列，需模拟页面分配与回收过程。关键在于理解"内容不清空"机制：被回收的页框内容保留，若再次缺页且该页仍在空闲链中，则直接放回驻留集（不产生真正的缺页中断）。需逐时刻模拟驻留集变化和空闲链变化。

### 第 47 题（计算机网络，10 分）
主机 H（192.168.0.8）通过快速以太网连接服务器 S（211.68.71.80），在 H 上捕获 5 个 IP 分组。考查：（1）识别哪些分组由 H 发送（源 IP 为 192.168.0.8 的分组），1、2、3 号分组完成 TCP 连接建立（SYN/SYN+ACK/ACK 三次握手），3、5 号分组因总长度 40 字节小于以太网最小帧长 46 字节而进行了填充；（2）由 3 号分组的 TCP 段确定发送方初始序号，由 5 号分组确定确认号，计算已发送数据字节数；（3）通过 NAT 分析路由器需修改的字段（源 IP 地址、首部校验和，可能修改 TTL）。

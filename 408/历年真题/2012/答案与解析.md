### 1. （2 分 · 绪论）

求整数 n(n≥0)  阶乘的算法如下，其时间复杂度是（ ）。

```C
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

- **A.** O(log₂n))
- **B.** O(n)
- **C.** O(nlog₂n))
- **D.** O(n²)

**答案**：B

**解析**：答案 B。递归调用链 fact(n)→fact(n−1)→…→fact(1) 共 n 次，每次调用只做常数次比较和乘法，工作量 O(1)。总时间 = n×O(1)，即 O(n)。

### 41. （10 分 · 树与二叉树）

设有 6 个有序表 A、B、C、D、E、F，分别含有 10、35、40、50、60 和 200 个数据元素，各表中元素按升序排列。要求通过 5 次两两合并，将 6 个表最终合并成 1 个升序表，并在最坏情况下比较的总次数达到最小。请回答下列问题：

(1) 给出完整的合并过程，并求出最坏情况下比较的总次数。

(2) 根据你的合并过程，描述 N（N ≥ 2）个不等长升序表的合并策略，并说明理由。

**答案 / 解析**：

答案：1、合并过程（类似哈夫曼树，每次合并最短的两个表）：A(10)+B(35)→AB(45)；AB(45)+C(40)→ABC(85)；D(50)+E(60)→DE(110)；ABC(85)+DE(110)→ABCDE(195)；ABCDE(195)+F(200)→395。各次最坏比较次数分别为 10+35−1=44、45+40−1=84、50+60−1=109、85+110−1=194、195+200−1=394，总次数 44+84+109+194+394 = 825。2、策略：借鉴哈夫曼树（最优归并树）思想，每次选择长度最短的两个表合并。理由：两表合并最坏需比较 m+n−1 次，先合并短表可减少长表参与比较的次数，使总比较次数最小。

### 42. （12 分 · 线性表）

假定采用带头结点的单链表保存单词，当两个单词有相同的后缀时，则可共享相同的后缀存储空间。例如，“loading”和“being”的存储映像如下图所示。

![loading 与 being 共享后缀 ing 的链式存储映像](q42-shared-suffix.webp)

设 str1 和 str2 分别指向两个单词所在单链表的头结点，链表结点结构为 `data | next`。请设计一个时间上尽可能高效的算法，找出由 str1 和 str2 所指向两个链表共同后缀的起始位置（如图中字符 i 所在结点的位置 p）。

（1）给出算法的基本设计思想。

（2）根据设计思想，采用 C、C++ 或 Java 语言描述算法，关键之处给出注释。

（3）说明你所设计算法的时间复杂度。

**答案 / 解析**：

答案：1、基本思想：分别求出两链表长度 m、n，将较长链表的指针先走 |m−n| 步，使两指针距表尾等长；再同步后移并比较，第一个相同的结点即共同后缀的起始位置。2、核心代码（C 语言）：

```c
int getLength(Node *h) {            // h 为带头结点链表的头指针
    int len = 0;
    for (Node *p = h->next; p != NULL; p = p->next) len++;
    return len;
}
Node* findCommonSuffix(Node *str1, Node *str2) {
    int m = getLength(str1), n = getLength(str2);
    Node *p = str1->next, *q = str2->next;
    while (m > n) { p = p->next; m--; }   // 长表指针先走差值步
    while (n > m) { q = q->next; n--; }
    while (p != NULL && p != q) {         // 同步后移，找共同后缀起点
        p = p->next;
        q = q->next;
    }
    return p;                             // 共同后缀起始结点，无则返回 NULL
}
```

3、时间复杂度 O(m+n)（或 O(max(m,n))），空间复杂度 O(1)。

某计算机存储器按字节编址，采用小端方式存放数据。假定编译器规定 int 型和 short 型长度分别为 32 位和 16 位，并且数据按边界对齐存储。某 C 语言程序段如下：

### 43. （13 分 · 存储器层次结构）

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 的命中率为 99%，存储器总线宽度为 32 位。请回答下列问题。

(1) 该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？

(2) 假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？

(3) CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？

(4) 为了提高性能，主存采用四体低位交叉存储模式，工作时每 1/4 个存储周期启动一个体。若每个体的存储周期为 50ns，则该主存能提供的最大带宽是多少？

**答案 / 解析**：

### 45. （7 分 · 内存管理）

- 当发生缺页时，如果该页曾被使用过且还在空闲页框链表中，则重新放回进程的驻留集中；否则，从空闲页框链表头部取出一个页框

进程 P 依次访问的 ⟨虚拟页号, 访问时刻⟩ 是：

⟨1, 1⟩、⟨3, 2⟩、⟨0, 4⟩、⟨0, 6⟩、⟨1, 11⟩、⟨0, 13⟩、⟨2, 14⟩

请回答下列问题：

(1) 访问 ⟨0, 4⟩ 时，对应的页框号是什么？

(2) 访问 ⟨1, 11⟩ 时，对应的页框号是什么？说明理由。

(3) 访问 ⟨2, 14⟩ 时，对应的页框号是什么？说明理由。

(4) 该策略是否适合于时间局部性好的程序？说明理由。

**答案 / 解析**：

### 46. （8 分 · 文件管理）

某文件系统空间的最大容量为 4 TB（$1\text{ TB} = 2^{40}\text{ B}$），以磁盘块为基本分配单位。磁盘块大小为 1 KB。文件控制块（FCB）包含一个 512 B 的索引表区。请回答下列问题：

(1) 假设索引表区仅采用直接索引结构，索引表区存放文件占用的磁盘块号。索引表项中块号最少占多少字节？可支持的单个文件最大长度是多少字节？

(2) 假设索引表区采用如下结构：第 0～7 字节采用 `<起始块号, 块数>` 格式表示文件创建时预分配的连续存储空间（其中起始块号占 6 B、块数占 2 B）；剩余 504 字节采用直接索引结构，一个索引项占 6 B。那么：

- 可支持的单个文件最大长度是多少字节？
- 为了使单个文件长度达到最大，请指出起始块号和块数分别所占字节数的合理值并说明理由。

**答案 / 解析**：

答案：1、磁盘块总数 = 4TB/1KB = 2³² 个，块号至少 32/8 = 4B；512B 索引区可放 512/4 = 128 个索引项，单文件最大 128×1KB = 128KB。2、连续区块数字段 2B 可表示 2¹⁶ 个磁盘块，即 2²⁶B；直接索引区 504B/6B = 84 项，即 84KB；故单文件最大长度为 2²⁶+84KB 字节。为使文件最大，起始块号和块数应各占 4B：起始块号 4B 可寻址 2³² 个磁盘块即整个 4TB 空间，块数 4B 也可表示最多 2³² 块（4TB），两者都达到系统容量上限。

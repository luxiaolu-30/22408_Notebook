## 三、本年命题特点

2015 年 408 真题整体难度较 2014 年略有提升，选择题覆盖面广、综合性强。数据结构考查了递归调用栈、卡特兰数计算不同二叉树个数、哈夫曼树构造特点、AVL 树性质、DFS 遍历序列计数、Kruskal 与 Prim 算法选边差异、折半查找比较序列、KMP 失配处理、基数排序特点、小根堆删除重建和希尔排序原理，其中第 3 题（哈夫曼树根到叶子的权值序列）和第 8 题（KMP 算法失配后 i、j 值）区分度较高；组成原理首次系统考查直接映射 Cache 总容量计算含脏位（第 15 题）和 4 体交叉存储器访存冲突判断（第 18 题），第 16 题将 Cache 写策略与 TLB 结合考查访问主存次数；操作系统考查了死锁避免与检测的对比（第 26 题）、LRU 页面置换（第 27 题）、固定分配与全局置换不能组合（第 30 题）和 SCAN 磁盘调度（第 32 题）；计算机网络考查了滑动窗口帧序号比特数（第 35 题）、CSMA/CD 不适用无线网络（第 36 题）和 TCP 拥塞窗口与接收缓存动态变化（第 39 题），其中第 39 题需要同时考虑拥塞窗口和接收窗口的动态变化，难度较大。

综合应用题方面，第 41 题分值高达 15 分，考查单链表按绝对值去重算法设计，要求用辅助数组实现 O(m+n) 时间复杂度；第 42 题考查邻接矩阵 A²和 B^m 中元素含义（路径条数），综合性强；第 43-44 题连续考查同一 16 位计算机的 CPU 数据通路和指令系统，从寄存器可见性、ALU 控制信号位数、数据通路连线到指令格式、机器代码、控制信号和时钟周期，深度递进，是 2015 年最大的特色；第 45 题考查信箱同步问题，需设置 6 个信号量（互斥+同步），对 PV 操作的理解要求较高；第 46 题考查二级页表分页存储管理的页大小、页表占页数和地址转换；第 47 题考查 DHCP 动态分配、ARP 解析 MAC 地址和子网掩码/网关配置对网络访问的影响。整体来看，2015 年真题强调对底层硬件机制的深入理解和跨章节知识综合运用。

## 四、重点题目解析

### 第 41 题（数据结构，15 分）

用单链表保存 m 个整数（|data|≤n），删除所有绝对值相等的重复结点（仅保留第一次出现的结点）。核心思想：使用大小为 n+1 的辅助数组 flag（初值均为 0），遍历链表时检查 flag[|data|]：
- 若 flag[|data|]=0，保留该结点，置 flag[|data|]=1
- 若 flag[|data|]=1，删除该结点

```
typedef struct node {
    int data;
    struct node *link;
} Node;

void filter(Node *head, int n) {
    int *flag = (int *)calloc(n + 1, sizeof(int));
    Node *p = head, *q;
    while (p->link != NULL) {
        q = p->link;
        if (flag[abs(q->data)] == 0) {
            flag[abs(q->data)] = 1;
            p = q;
        } else {
            p->link = q->link;
            free(q);
        }
    }
    free(flag);
}
```

时间复杂度 O(m+n)，空间复杂度 O(n)。

### 第 42 题（数据结构，8 分）

已知 5 顶点图 G 的邻接矩阵 A：
（1）写出邻接矩阵 A（行、列下标从 0 开始）。

（2）求 A²，A²[0][3] 的含义：表示从顶点 0 到顶点 3 的**长度为 2 的路径条数**。若 A²[0][3]=3，则从顶点 0 到顶点 3 共有 3 条长度为 2 的路径。

（3）B^m（2≤m≤n）中非零元素 B^m[i][j] 的含义：表示从顶点 i 到顶点 j 的**长度为 m 的路径条数**。这是邻接矩阵幂的经典性质，可用于求解图中任意两点间指定长度的路径数。

### 第 43 题（组成原理，13 分）

某 16 位计算机（主存按字节编址，存取单位 16 位，16 位定长指令字），CPU 采用单总线结构，含 R0~R3 通用寄存器、暂存器 T、移位寄存器 SR（直送/左移/右移）、ALU（7 种操作）等。

（1）**程序员可见的寄存器**：R0~R3、PC。设置暂存器 T 的原因：单总线结构在同一时刻只能传输一个数据到 ALU 输入端，需要先用 T 暂存第一个操作数（数 A），再从总线送入第二个操作数（数 B），然后执行运算。

（2）ALUop 位数：ALU 有 7 种操作，⌈log₂7⌉=**3 位**。SRop 位数：SR 有 3 种操作，⌈log₂3⌉=**2 位**。

（3）SRout：控制移位寄存器 SR 的输出是否送到内总线上（输出使能信号）。

（4）端点连接到控制部件输出端的信号：各寄存器的输入/输出控制信号（如 R0in/R0out）、ALUop、SRop、SRout、MEMop 等。

（5）需添加的连线：如 ALU 输出→SR 输入、SR 输出→总线、各寄存器与总线之间的双向连接等，以完善数据通路。

（6）MUX 的一个输入端为 2 的原因：主存按字节编址，指令为 16 位（2 字节），PC 每次自增 2。MUX 用于在 PC+2（取下一条指令）和 ALU 输出（转移地址）之间选择，常量 2 用于 PC 递增。

### 第 44 题（组成原理，10 分）

基于第 43 题计算机，指令格式为 OP(7 位)|Md(1)|Rd(2)|Ms1(1)|Rs1(2)|Ms2(1)|Rs2(2)，支持寄存器直接（0）和寄存器间接（1）寻址。

（1）该机指令系统最多可定义 **2^7=128** 条三地址指令。

（2）机器代码：
- inc R1：OP=01H，单地址格式（末 6 位为 0），Md=0, Rd=01 → 0000 0010 0100 0000 = 0240H
- shl R2, R1：OP=02H，二地址格式（末 3 位为 0），Md=0, Rd=10, Ms1=0, Rs1=01 → 0000 0100 1000 1000 = 0488H
- sub R3, (R1), R2：OP=03H，三地址格式，Md=0, Rd=11, Ms1=1(间接), Rs1=01, Ms2=0(直接), Rs2=10 → 0000 0110 1110 1010 = 06EAH

（3）根据指令执行流程图，标号①~⑧处应填入相应的控制信号（如 PCout、MARin、MEMread、MDRout、IRin 等）。

（4）"sub R1, R3, (R2)"含间接寻址，需取数、访存取操作数、运算、写回，至少需要更多时钟周期；"inc R1"为单地址指令，只需取数、运算、写回，时钟周期较少。

### 第 45 题（操作系统，9 分）

A、B 两人通过信箱辩论。A 信箱最多 M 个邮件，初始 x 个；B 信箱最多 N 个邮件，初始 y 个。每次从自己信箱取一个邮件，回答并放新邮件到对方信箱。

信号量定义：
- `full_A = x`：A 信箱中的邮件数，初始 x
- `empty_A = M - x`：A 信箱可用空位数，初始 M-x
- `full_B = y`：B 信箱中的邮件数，初始 y
- `empty_B = N - y`：B 信箱可用空位数，初始 N-y
- `mutex_A = 1`：A 信箱互斥访问
- `mutex_B = 1`：B 信箱互斥访问

```
// 进程 A
while(TRUE) {
    P(full_A);       // 等 A 信箱有邮件
    P(mutex_A);      // 互斥访问 A 信箱
    // 从 A 信箱取出邮件
    V(mutex_A);
    V(empty_A);      // A 信箱空位增加
    
    // 回答问题并提出新问题
    
    P(empty_B);      // 等 B 信箱有空位
    P(mutex_B);      // 互斥访问 B 信箱
    // 将新邮件放入 B 信箱
    V(mutex_B);
    V(full_B);       // B 信箱邮件数增加
}

// 进程 B：对称结构（A↔B 互换）
```

关键点：每个进程对自身信箱执行 P(full)/P(mutex)/取/V(mutex)/V(empty)，对对方信箱执行 P(empty)/P(mutex)/放/V(mutex)/V(full)。P 操作顺序为先同步后互斥，避免死锁。

### 第 46 题（操作系统，6 分）

某系统按字节编址，二级页表分页存储，虚拟地址格式：页目录号(10 位)|页表索引(10 位)|页内偏移量(12 位)。

（1）页大小 = 2^12 = **4KB**，页框大小 = **4KB**。进程虚拟地址空间 = 2^32 / 2^12 = 2^20 = **1M 页**（即 1048576 页）。

（2）页目录项和页表项各占 4B：
- 页目录：2^10 项 × 4B = 4KB = **1 页**
- 所有页表：2^20 项 × 4B = 4MB = **1024 页**
- 页目录和页表共占 **1025 页**

（3）虚拟地址 0100 0000H 和 0111 2048H：
- 0x01000000：页目录号 = (0x01000000 >> 22) = 4，页表索引 = 0
- 0x01112048：页目录号 = (0x01112048 >> 22) = 4，页表索引 = 274
- 两者页目录号相同（均为 4），访问的是**同一个二级页表**，共访问 **1 个**二级页表。

### 第 47 题（计算机网络，9 分）

网络拓扑中，路由器内网接口、DHCP 服务器、WWW 服务器和主机 1 均为静态 IP，主机 2~N 通过 DHCP 动态获取 IP。

（1）DHCP 服务器可为主机 2~N 动态分配 IP 地址的最大范围：根据网络拓扑中的子网划分确定。主机 2 发送 DHCP Discover 报文时，源 IP = **0.0.0.0**（尚未获取 IP），目的 IP = **255.255.255.255**（广播）。

（2）主机 2 ARP 表为空时：
- 第一个以太网帧（DHCP/ARP 请求）的目的 MAC = **FF-FF-FF-FF-FF-FF**（广播地址）
- 封装主机 2 发往 Internet 的 IP 分组的以太网帧的目的 MAC = **路由器内网接口的 MAC 地址**（通过 ARP 解析默认网关的 MAC）

（3）主机 1 子网掩码 255.255.255.0、默认网关 111.123.15.2：
- 主机 1 的 IP 若为 111.123.0.x，则其所在子网为 111.123.0.0/24
- 默认网关 111.123.15.2 不在子网 111.123.0.0/24 中（111.123.15.2 属于 111.123.15.0/24）
- 因此主机 1**无法访问默认网关**，从而**不能访问 Internet**
- 若 WWW 服务器与主机 1 在同一子网（111.123.0.0/24），则主机 1**可以访问** WWW 服务器（直接通信，无需网关）；否则不能访问

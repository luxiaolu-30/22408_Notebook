## 三、本年命题特点

1. **数据结构算法设计经典而新颖**：第 41 题为 15 分算法设计大题，要求在含 n 个整数的数组中找出未出现的最小正整数，采用空间换时间策略（辅助标记数组），时间复杂度 O(n)，空间复杂度 O(n)。该题是 LeetCode 经典问题的变体，考查候选人的算法设计思维。第 42 题将最小生成树与 TTL（IP 生存时间）结合，实现了图论与网络知识的交叉。

2. **组成原理聚焦 I/O 与存储体系**：选择题覆盖了补码运算（第 13 题）、IEEE 754 浮点数（第 14 题）、移位操作（第 16 题）、流水线（第 20 题）等核心计算题。应用题第 43 题系统比较了程序查询、中断和 DMA 三种 I/O 方式的时间开销，第 44 题考查虚拟地址到物理地址的完整变换链路（页表→TLB→Cache），综合性很强。

3. **操作系统注重文件系统与调度**：选择题中文件系统相关题目占 2 道（第 30、31 题），进程管理占 5 道。应用题第 45 题考查二级页式虚拟存储管理（与第 44 题组成原理的存储体系形成呼应），第 46 题考查 UNIX 三级索引结构（直接地址+一级/二级/三级间接地址），是文件系统物理结构的经典考点。

4. **计算机网络覆盖面广**：选择题从物理层接口特性到应用层协议均有涉及，其中第 36 题（停等协议信道利用率）和第 37 题（转发中 MAC/IP 地址变化）需要具体计算。应用题第 47 题考查 IP 子网划分与 IP 数据报分片（涉及不同子网 MTU 差异），是网络层的综合应用题。

## 四、重点题目解析

### 第 41 题（数据结构，15 分）

给定一个长度为 n 的整数数组 A，设计一个时间上尽可能高效的算法，找出 A 中未出现的最小正整数。
- 基本思想：分配辅助数组 B[n]（初始全 0），遍历 A，若 0 < A[i] <= n 则标记 B[A[i]-1]=1。再遍历 B，第一个 B[i]==0 的位置 i+1 即为答案；若 B 全为 1 则返回 n+1。
- 时间复杂度：O(n)，空间复杂度：O(n)。
解题关键：理解"空间换时间"策略，以及正整数范围 1~n+1 的分析。

### 第 42 题（数据结构，8 分）

将光通信网络铺设费用问题抽象为无向带权图的最小生成树问题。
- 第（1）问：用 Prim 或 Kruskal 算法求最小生成树，总费用为 16（有两种构造方案）。
- 第（2）问：采用邻接矩阵或邻接表存储图。
- 第（3）问：TTL=5 时，分析 IP 分组能否从 H1 传送到 H2（取决于方案中两城市间跳数是否超过 5）。
解题关键：将实际问题抽象为最小生成树模型，理解 TTL 的含义。

### 第 43 题（组成原理，13 分）

三种 I/O 方式的综合比较。设备 A（2MB/s）和设备 B（40MB/s），CPU 主频 500MHz。
- 第（1）问：程序查询方式下设备 A 的 CPU 时间占比（至少 4%）。
- 第（2）问：中断方式是否适合设备 B（中断处理时间 0.8μs，B 准备 32 位数据仅 0.1μs，数据会丢失，不适合）。
- 第（3）问：DMA 方式下设备 B 的 CPU 时间占比（最多 4%）。
解题关键：掌握三种 I/O 方式的工作原理和时间开销计算方法。

### 第 44 题（组成原理，10 分）

虚拟地址到物理地址的变换。给定二级页表结构（页目录号+页表号+页内偏移），结合 TLB 和 Cache 分析地址变换过程。
- 考查点：虚拟地址分解、页表查找、TLB 命中判断、Cache 组映射和块内偏移。
解题关键：理清"虚拟地址 → 查 TLB/页表 → 物理地址 → 查 Cache"的完整流程。

### 第 45 题（操作系统，8 分）

二级页式虚拟存储管理。基于第 44 题的虚拟存储方式，分析：
- 第（1）问：给定虚拟地址求页目录号、页号、页内偏移量及十六进制表示。
- 第（2）问：PDBR 寄存器的作用（保存当前进程页目录起始地址），进程切换时是否需要更新。
解题关键：理解二级页表的地址变换过程和 PDBR 在进程切换中的作用。

### 第 46 题（操作系统，7 分）

UNIX 文件系统索引结构。给定 inode 包含直接地址项、一级/二级/三级间接地址项，簇大小为 4KB。
- 第（1）问：计算最大文件长度（直接+一级+二级+三级间接地址可寻址的范围）。
- 第（2）问：给定图像文件大小，计算需要的磁盘簇数和索引块数。
解题关键：掌握 UNIX 多级索引结构的寻址计算方法。

### 第 47 题（计算机网络，9 分）

IP 子网划分与数据报分片。192.168.1.0/24 均分给销售部和技术部，销售部 MTU=1500B，技术部 MTU=800B。
- 第（1）问：子网划分（各 126 个可分配地址）。
- 第（2）问：分析 IP 数据报从销售部到技术部时是否需要分片及分片细节（因 MTU 从 1500 降为 800，需要分片）。
解题关键：理解 CIDR 子网划分方法和 IP 分片机制（MF 标志、片偏移量计算）。

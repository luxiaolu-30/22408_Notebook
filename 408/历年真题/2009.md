## 三、本年命题特点

1. **数据结构以"概念辨析 + 算法设计"为主线**。选择题第 3 题考查 RNL 这种非标准遍历方式（中序遍历的镜像），第 6 题森林转二叉树后结点关系的判断均要求对遍历与转换规则的深入理解；第 9 题小根堆插入调整、第 10 题由第二趟结果识别插入排序，注重对排序算法过程特征的识别。应用题第 41 题（10 分）以"贪心法求最短路径"为背景考查反例构造与证明能力，第 42 题（15 分）考查单链表倒数第 k 个结点的双指针算法设计，要求 O(n) 时间 O(1) 空间，是经典的高效算法设计题。

2. **组成原理首次系统考查 CPU 数据通路与指令执行**。第 44 题（13 分）以加法指令 `ADD (R1),R0` 为背景，要求列出指令执行阶段每个节拍的功能和有效控制信号，是 408 历年首次系统考查 CPU 数据通路设计。选择题中第 11 题指令周期阶段区分指令/数据、第 16 题相对寻址目标地址计算（PC+2 易错点）、第 17 题 RISC 不普遍采用微程序、第 18 题流水线时钟周期取最慢段、第 19 题硬布线与微程序控制器对比，均体现对 CPU 核心概念的深入考查。第 14 题 Cache 组相联映射、第 15 题 ROM/RAM 芯片扩展、第 21 题 Cache 命中率、第 13 题浮点数加法溢出判断也延续了对存储器与数据表示的考查传统。

3. **操作系统应用题考查"进程同步 + 虚拟内存"组合**。第 45 题（7 分）以三个进程共享 N 个单元的缓冲区为背景，P1 生产、P2 取奇数、P3 取偶数，要求用信号量机制实现同步与互斥，需要设置 mutex、empty、odd、even 四个信号量。第 46 题（8 分）考查请求分页系统，给定页表、TLB 访问时间、缺页处理时间，要求计算三个虚地址访问时间并确定缺页后的物理地址。选择题中第 25 题死锁最小 K 值（鸽巢原理）、第 27 题分段最大段长 2²⁴ B、第 29 题 SCAN 调度磁道序列、第 31 题符号链接与硬链接引用计数，均体现对操作系统核心概念的精准考查。

4. **计算机网络应用题综合考查子网划分与路由聚合**。第 47 题（9 分）以路由器 R1、R2 连接两个局域网、DNS 服务器和互联网为背景，要求（1）将 202.118.1.0/24 划分为两个 /25 子网；（2）给出 R1 路由表（含局域网 1、局域网 2、DNS 主机路由、默认路由）；（3）用路由聚合技术给出到两个局域网的路由。该题将子网划分、特定主机路由、默认路由和 CIDR 路由聚合有机结合。选择题中第 34 题奈奎斯特定理 + QAM 调制、第 35 题 GBN 累计确认、第 37 题 CSMA/CD 最短帧长与距离、第 39 题 TCP 拥塞窗口慢开始/拥塞避免动态变化，均是网络协议细节的重点考查点。

## 四、重点题目解析

### 第 41 题（数据结构，10 分）

本题给出一种"每次选择离当前顶点 u 最近的未访问顶点 v"的最短路径求解方法，要求判断是否可行并举例说明。**答案**：不一定能求得最短路径。该方法每次选「离 u 最近的邻接点」是局部贪心，不能保证全局最短。反例：设顶点 1 到 4 的直连边权为 3，另有路径 1→2→3→4 总权为 2；按该方法会走权 3 的直边得到长度 3，而非最短的 2。该题考查对 Dijkstra 算法"按距源点距离单调递增"性质的理解，以及对贪心算法局限性的反思。

### 第 42 题（数据结构，15 分）

本题要求在带表头结点的单链表中查找倒数第 k 个位置上的结点。**算法思想**：使用快慢双指针，先让指针 p 前进 k 步，再让 q 与 p 同步前进；当 p 到达表尾时，q 即指向倒数第 k 个结点。一趟扫描完成。时间复杂度 O(n)，空间复杂度 O(1)。

```c
int FindKthFromEnd(Node *head, int k) {
    Node *p = head, *q = head;
    for (int i = 0; i < k; i++) {
        if (p->link == NULL) return 0;
        p = p->link;
    }
    while (p != NULL) { p = p->link; q = q->link; }
    return q->data;
}
```

该题是双指针技巧的经典应用，考查对链表一趟扫描完成多重任务的算法设计能力。

### 第 44 题（组成原理，13 分）

本题以 16 位计算机为背景，加法指令 `ADD (R1),R0` 的功能为 `(R0) + ((R1)) → (R1)`，要求列出指令执行阶段每个节拍的功能和有效控制信号。题中已给出取指/译码阶段（C1–C4）的节拍与控制信号。**执行阶段（C5–C10）**：

| 时钟 | 功能 | 有效控制信号 |
|------|------|------------|
| C5 | (R1)→MAR | R1out, MARin |
| C6 | M(MAR)→MDR | MemR, MDRinE |
| C7 | (MDR)→A | MDRout, Ain |
| C8 | (A)+(R0)→AC | R0out, Add, ACin |
| C9 | (AC)→MDR | ACout, MDRin |
| C10 | (MDR)→M(MAR) | MDRoutE, MemW |

数据流动：先把 R1 内容作地址送 MAR，读出内存到 MDR，MDR 送入 ALU 输入端 A，与 R0 相加得 AC，再经 MDR 写回原地址（MAR 不变）。该题考查对 CPU 数据通路、节拍划分与控制信号设计的完整理解。

### 第 45 题（操作系统，7 分）

本题以三个进程 P1、P2、P3 互斥使用 N 个单元的缓冲区为背景：P1 生成正整数并 put 入缓冲区，P2 取奇数并 countodd，P3 取偶数并 counteven。要求用信号量机制实现同步与互斥。**信号量设置**：mutex=1（互斥访问缓冲区）、empty=N（空位数）、odd=0（奇数同步）、even=0（偶数同步）。

```c
semaphore mutex=1, empty=N, odd=0, even=0;
P1() { while(1) { x=produce(); P(empty); P(mutex); put(x); V(mutex);
    if(x%2==0) V(even); else V(odd); } }
P2() { while(1) { P(odd); P(mutex); getodd(); V(mutex); V(empty); countodd(); } }
P3() { while(1) { P(even); P(mutex); geteven(); V(mutex); V(empty); counteven(); } }
```

该题考查对生产者-消费者问题的变体（按数据特征分流）的信号量设计能力。

### 第 46 题（操作系统，8 分）

本题考查请求分页管理系统。页大小 4KB，TLB 访问 10ns，访存 100ns，缺页处理 10⁸ns，驻留集大小 2，LRU 局部淘汰。访问序列 2362H、1565H、25A5H。**答案**：
1. 访问 2362H（页号 2，页内 362H）：TLB 未命中→访页表 100ns→访存 100ns，加 10ns 快表共 210ns；
2. 访问 1565H（页号 1，缺页）：TLB、页表均未命中→缺页 10⁸ns→再访快表 10ns→访存 100ns，共 100000220ns；
3. 访问 25A5H（页号 2，已在 TLB）：10+100=110ns；
4. 1565H 缺页时淘汰 0 号页（LRU），其页框 101H 分配给 1 号页，物理地址 101565H。

该题考查对 TLB、页表、缺页中断协同工作流程的理解。

### 第 47 题（计算机网络，9 分）

本题以路由器 R1、R2 连接局域网 1、局域网 2、域名服务器和互联网为背景。**答案**：
1. 将 202.118.1.0/24 划分为两个 /25 子网：202.118.1.0/25（局域网 1）、202.118.1.128/25（局域网 2），每个子网可含 126 台主机，满足不少于 120。
2. R1 路由表：局域网 1 (202.118.1.0/25) 经 E1 直连；局域网 2 (202.118.1.128/25) 经 E2 直连；DNS 主机路由 (202.118.3.2/32) 下一跳 202.118.2.2 经 L0；默认路由 (0.0.0.0/0) 下一跳 202.118.2.2 经 L0。
3. 两个局域网可聚合为 202.118.1.0/24，R2 到它们的路由为 202.118.1.0/24 下一跳 202.118.2.1 经 L0。

该题将子网划分、特定主机路由、默认路由和 CIDR 路由聚合有机结合，是计算机网络部分的综合应用题。

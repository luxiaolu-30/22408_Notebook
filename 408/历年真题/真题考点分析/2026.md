## 三、本年命题特点

1. **数据结构以"结构性质 + 算法设计"双线考查**。选择题第 1 题出入栈序列反推栈容量最小值（D 选项 3），第 2 题二叉树排序对应遍历方式（中序），第 3 题完全二叉树性质辨析，第 4 题二叉排序树插入/删除性质，第 5 题由遍历序列构造二叉树结点数，第 6 题哈夫曼树性质，第 7 题邻接矩阵性质，第 8 题最小生成树性质，第 9–11 题堆/冒泡/快排的过程特征识别，覆盖树、图、排序、栈与队列、查找五大模块。应用题第 41 题（13 分）以二叉链表为背景，要求先构造二叉树再进行中序线索化，是树结构算法设计的综合考查；第 42 题（10 分）以双栈共享空间模拟队列为背景，考查队列判满条件的判别与算法实现，体现对共享存储结构的灵活运用。

2. **组成原理首次将多周期 CPU 状态机作为重点**。第 44 题（14 分）以多周期 CPU 为背景，要求给出指令执行状态机、列出每个状态的微操作与控制信号，是 408 历年首次系统考查多周期控制器设计，分值 14 分为历年之最。第 43 题（11 分）继续考查指令格式设计、寻址方式与执行结果计算，延续 2010 年以来的命题传统。选择题中第 13 题 IEEE 754 浮点数表示范围、第 14 题 C 语言 int/unsigned/float 类型转换、第 15 题 Cache 写策略、第 18 题指令流水线数据冒险处理（转发/阻塞）、第 19 题单周期/多周期 CPU 数据通路比较、第 21 题 RAID 0/1/5/10 容错与性能、第 22 题多周期 CPU 控制信号生成方式，均体现对核心概念的精准考查，且第 19、22 题与第 44 题在多周期 CPU 主题上形成呼应。

3. **操作系统应用题考查"进程同步 + 虚拟内存"组合**。第 45 题（7 分）以多进程共享缓冲区为背景，考查进程间通信与同步的信号量机制实现，要求设置同步、互斥信号量并写出 PV 操作伪代码。第 46 题（8 分）以虚拟内存页面置换为背景，考查 LRU/CLOCK 置换算法的执行过程、地址转换与缺页中断处理的协同。选择题中第 24 题用户级线程与内核级线程对比、第 25 题线程相关系统调用（pthread_create/join/exit）、第 27 题银行家算法安全序列个数、第 28 题页式存储多级页表与地址转换、第 29 题 TLB 命中率与平均访问时间、第 32 题 SPOOLing 技术与虚拟设备，均是对操作系统核心概念的经典考查。

4. **计算机网络应用题考查子网划分与路由聚合**。第 47 题（9 分）以某公司网络拓扑为背景，要求（1）将一个 /24 网络划分为多个子网满足主机数需求；（2）给出路由器 R1 的路由表（含直连网络、特定主机路由、默认路由）；（3）用 CIDR 路由聚合技术给出 R2 到该公司网络的路由。该题延续 2009 年第 47 题的命题风格，将子网划分、特定主机路由、默认路由和 CIDR 路由聚合有机结合。选择题中第 34 题奈奎斯特/香农定理与数据传输速率、第 35 题 CSMA/CD 最短帧长计算、第 36 题以太网交换机自学习与转发过滤、第 37 题 IP 数据报分片与重组、第 38 题 OSPF/RIP/BGP 路由协议对比、第 39 题 TCP 三次握手与连接状态转换、第 40 题 DNS 查询方式（递归/迭代），均是对网络协议与子网划分的经典考查。

## 四、重点题目解析

### 第 41 题（数据结构，13 分）

本题以二叉链表为背景，先要求根据给定的遍历序列构造二叉树，再进行中序线索化。**算法思想**：
1. **构造二叉树**：由先序和中序遍历序列递归构造，先序首字符为根，在中序中定位根后分左右子树，递归处理。
2. **中序线索化**：递归中序遍历二叉树，使用前驱指针 `pre` 记录上一个访问的结点；当前结点无左子树时左指针指向 `pre` 并置 `ltag=1`；`pre` 无右子树时右指针指向当前结点并置 `pre->rtag=1`；最后处理最右结点的右指针。

```c
void InThread(ThreadTree p, ThreadTree *pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);
        if (p->lchild == NULL) { p->lchild = *pre; p->ltag = 1; }
        if (*pre != NULL && (*pre)->rchild == NULL) {
            (*pre)->rchild = p; (*pre)->rtag = 1;
        }
        *pre = p;
        InThread(p->rchild, pre);
    }
}
```

该题考查二叉树遍历、递归构造与线索化算法设计的综合能力。

### 第 42 题（数据结构，10 分）

本题以两个栈 S1、S2 共享一个数组空间 V[m] 模拟一个队列 Q 为背景，要求给出队列判满条件并实现入队、出队操作。**判满条件**：当 S1 栈顶（队头）和 S2 栈顶（队尾）相邻时队列满，即 `(top2 + 1) mod m == top1`（top1 指向 S1 栈顶位置，top2 指向 S2 栈顶位置）。

```c
bool QueueFull() { return (top2 + 1) % m == top1; }
void EnQueue(int x) {
    if (QueueFull()) return;
    V[top2] = x;
    top2 = (top2 - 1 + m) % m;
}
int DeQueue() {
    int x = V[top1];
    top1 = (top1 + 1) % m;
    return x;
}
```

该题考查栈与队列相互模拟、共享存储空间判满条件的灵活运用。

### 第 43 题（组成原理，11 分）

本题以 16 位计算机单字长指令格式为背景，操作码字段、寻址方式字段、寄存器号字段、形式地址字段各占若干位，要求：
1. 计算最多指令数、通用寄存器数、MAR/MDR 位数；
2. 给定某汇编指令（如 `add (R4), (R5)+`）计算其机器码；
3. 计算指令执行后寄存器与内存单元的值。

该题延续 2010 年第 43 题的命题风格，考查指令格式设计、寻址方式编码与执行结果计算的综合能力，是组成原理部分的传统重点综合题。

### 第 44 题（组成原理，14 分）

本题以多周期 CPU 为背景，要求：
1. 给出某指令（如 `add`、`load`、`store`、`beq`）执行的状态机，列出取指、译码、执行、访存、写回等状态；
2. 列出每个状态的有效控制信号（RegRead、ALUOp、MemRead、MemWrite、RegWrite、PCWrite 等）；
3. 计算指令执行所需的时钟周期数。

该题是 408 历年首次系统考查多周期 CPU 控制器设计，分值 14 分为历年之最，体现对 CPU 数据通路与控制器设计原理的深入理解。

### 第 45 题（操作系统，7 分）

本题以多进程共享缓冲区为背景，考查进程间通信与同步的信号量机制实现。要求设置同步、互斥信号量并写出 PV 操作伪代码，确保各进程按约束协同执行。该题延续 2009 年第 45 题的命题风格，考查信号量机制在生产者-消费者变体问题中的应用能力。

### 第 46 题（操作系统，8 分）

本题以虚拟内存页面置换为背景，给定页表、TLB、访存时间、缺页处理时间，要求：
1. 计算给定访问序列的命中率与平均访问时间；
2. 使用 LRU 或 CLOCK 算法计算某次访问的物理地址；
3. 分析缺页中断处理流程与地址转换的协同关系。

该题延续 2009 年第 46 题的命题风格，考查虚拟内存页面置换算法与地址转换的综合能力。

### 第 47 题（计算机网络，9 分）

本题以某公司网络拓扑为背景，路由器 R1、R2 连接多个子网。**答案**：
1. 将一个 /24 网络划分为多个子网满足各子网主机数需求（如 /25、/26、/27 等）；
2. R1 路由表：直连网络（直连接口）、特定主机路由（如 DNS 服务器 32 位掩码）、默认路由（0.0.0.0/0 下一跳 R2）；
3. R2 到该公司网络的路由用 CIDR 路由聚合，将多个子网聚合为一个 /24 网络下一跳 R1。

该题延续 2009 年第 47 题的命题风格，将子网划分、特定主机路由、默认路由和 CIDR 路由聚合有机结合，是计算机网络部分的重点综合题。

## 三、本年命题特点

1. **数据结构突出"操作合法性与算法识别"考查**。选择题第 1、2 题以"不允许连续三次退栈""输出受限双端队列"等约束条件考查栈/队列操作序列的合法性判断，第 3 题后序线索二叉树的线索指向辨析、第 4 题 AVL 插入 48 后的 RL 型双旋转调整、第 6 题哈夫曼树性质辨析（不一定完全二叉树），均要求对树结构与平衡操作的精准理解。第 7 题"7 顶点无向图保证连通最少 16 边"和第 8 题拓扑排序不同序列个数共 3 种，是图论基础概念的综合应用。应用题第 41 题（10 分）考查散列表 H(key)=(key×3) mod 7 + 线性探测的构造与查找成功/不成功 ASL 计算；第 42 题（13 分）以"将 R 中序列循环左移 p 位"为背景考查三次逆置算法设计，时间 O(n) 空间 O(1)，是经典的高效算法设计题。

2. **组成原理首次考查指令格式设计与 Cache 命中率对比**。第 43 题（11 分）以 16 位计算机单字长指令格式为背景，要求计算最多指令数、通用寄存器数、MAR/MDR 位数，以及汇编指令 `add (R4),(R5)+` 的机器码 2315H 与执行结果（R5=5679H、地址 5678H=68ACH），是 408 历年首次系统考查指令格式设计与寻址方式编码。第 44 题（12 分）以程序 A（按行）和程序 B（按列）遍历二维数组为背景，考查直接映射 Cache 的总容量、行号计算与命中率对比（A 93.75%、B 0%），体现对 Cache 行为与程序局部性的深入理解。选择题中第 13 题 8 位补码乘法溢出、第 14 题 int/float/double 类型转换、第 17 题 TLB/Cache/Page 命中组合不可能情况（D 选项违反 TLB 命中→Page 必命中）、第 19 题数据旁路不引起流水线阻塞，均体现对核心概念的精准考查。

3. **操作系统应用题考查"磁盘调度 + 页面置换"组合**。第 45 题（7 分）以 C-SCAN 磁盘调度为背景，结合位图法磁盘空闲管理，要求计算磁道访问顺序（120→30→50→90）和总时间 190.4ms，并讨论 Flash 半导体存储器改用 FCFS 的合理性。第 46 题（8 分）以固定分配局部置换、4 个页框、访问逻辑地址 17CAH（页号 5）为背景，分别用 FIFO（淘汰 0 号页，物理地址 1FCAH）和 CLOCK（指针从 2 号页框扫描两轮后淘汰 2 号页，物理地址 0BCAH）算法计算物理地址。选择题中第 27 题 Peterson 算法互斥与不饥饿特性、第 28 题最佳适配分配后最大空闲分区 9MB、第 29 题二级页表页目录项 128 个、第 30 题混合索引最大文件长度 1057KB，均是对操作系统核心概念的经典考查。

4. **计算机网络应用题考查 CSMA/CD 协议细节与有效数据率**。第 47 题（9 分）以 10Mbps CSMA/CD 局域网、两站点距离 2km 为背景，要求（1）计算冲突检测最短 10µs、最长 20µs（2 倍单程传播时延）；（2）在 1518B 数据帧 + 64B ACK + 双程传播时延下，每周期 T=1.2856ms，有效数据率 ≈ 9.33Mb/s。该题将冲突检测窗口、发送时延、传播时延与有效数据率有机结合。选择题中第 34 题分组交换网络文件传输总时间 80.16ms（含末分组经两个交换机各 80µs）、第 35 题 RIP 距离 16 不可达、第 36 题 ICMP 源点抑制、第 37 题 /29 子网划分 32 子网每子网 6 地址、第 39 题 TCP 拥塞窗口与接收窗口下还可发送 1000B、第 40 题 DNS 递归查询消息数（用户/本地各一条），均是对网络协议与子网划分的精准考查。

## 四、重点题目解析

### 第 41 题（数据结构，10 分）

本题要求将关键字序列 ⟨7,8,30,11,18,9,14⟩ 散列存储到表中，散列函数 H(key)=(key×3) mod 7，处理冲突采用线性探测再散列，装填因子 0.7。**答案**：表长 m=7/0.7=10，各关键字散列地址 7→0、8→3、30→6、11→5、18→5、9→6、14→0；填入后地址 0–9 依次为 7、14、空、8、空、11、30、18、9、空。查找成功 ASL=(1+1+1+1+3+3+2)/7=12/7；查找不成功 ASL=(3+2+1+2+1+5+4)/7=18/7。该题考查散列表构造、装填因子与 ASL 计算的综合能力。

### 第 42 题（数据结构，13 分）

本题要求设计算法将数组 R 中序列循环左移 p 位，即 (x₀,...,xₚ₋₁,xₚ,...,xₙ₋₁) → (xₚ,...,xₙ₋₁,x₀,...,xₚ₋₁)。**算法思想**：三次逆置——先逆置前 p 个元素 A，再逆置后 n−p 个元素 B，最后整体逆置，即得 BA。时间 O(n)，空间 O(1)。

```c
void reverse(int a[], int from, int to) {
    int i = from, j = to, tmp;
    while (i < j) { tmp=a[i]; a[i]=a[j]; a[j]=tmp; i++; j--; }
}
void loopMove(int a[], int n, int p) {
    if (p <= 0 || p >= n) return;
    reverse(a, 0, p - 1);
    reverse(a, p, n - 1);
    reverse(a, 0, n - 1);
}
```

该题是"AB→BA"经典变换的高效算法设计题，三次逆置思想在字符串/数组循环移位中应用广泛。

### 第 43 题（组成原理，11 分）

本题以 16 位计算机单字长指令格式为背景，操作码 4 位、操作数 6 位（两个 3 位寄存器号），主存 128KB 按字编址。**答案**：
1. 最多 2⁴=16 条指令；最多 2³=8 个通用寄存器；MAR 至少 16 位（128KB/2B=2¹⁶ 单元）、MDR 至少 16 位。
2. 转移目标地址 = (PC)+(Rn)，PC 与 Rn 均为 16 位，范围 0000H–FFFFH。
3. `add (R4),(R5)+` 机器码 0010 0011 0001 0101B = 2315H；源操作数 = (1234H) = 5678H；目的操作数 = (5678H) = 1234H；结果 5678H+1234H=68ACH 写回 (R5) 所指单元 5678H；R5 自增为 5679H。

该题考查指令格式设计、寻址方式编码与执行结果计算的综合能力。

### 第 44 题（组成原理，12 分）

本题以 256MB 主存、按字节编址、直接映射数据 Cache（8 行 × 64B）为背景，对比程序 A（按行遍历）与程序 B（按列遍历）。**答案**：
1. 主存地址 28 位，块内偏移 6 位、Cache 行号 3 位，Tag=19 位；每行 1 位有效位+19 位标记+512 位数据=532 位，共 8 行，总容量 8×532=4256 位=532B。
2. a[0][31] 地址=320+31×4=444，块号 ⌊444/64⌋=6，行号 6 mod 8=6；a[1][1] 地址=320+(256+1)×4=1348，块号 ⌊1348/64⌋=21，行号 21 mod 8=5。
3. 程序 A 按行访问，每个 64B 块含 16 个 int，命中率 15/16=93.75%；程序 B 按列访问，同一列的 256 行映射到同一 Cache 行，每次都被换出，命中率 0。程序 A 执行时间更短。

该题将 Cache 行号计算、命中率分析与程序局部性原理有机结合，是组成原理部分的重点综合题。

### 第 45 题（操作系统，7 分）

本题以 C-SCAN 磁盘调度为背景，结合位图法磁盘空闲管理。**答案**：
1. 用位图管理：16384 个磁盘块每位表示一个块的空闲状态，共 16384 位=2KB，分配、回收时置位即可。
2. C-SCAN 沿磁道号增大方向扫描：访问顺序 120→30→50→90，移动磁道数 20+90+20+40=170，寻道时间 170×1ms=170ms；转速 6000rpm 即每转 10ms，平均旋转延迟 5ms，4 次共 20ms；每磁道 100 个扇区，读 1 个扇区 0.1ms，4 次共 0.4ms。总时间=170+20+0.4=190.4ms。
3. Flash 半导体存储器无机械寻道和旋转延迟，访问时间与位置无关，应改用 FCFS 按请求顺序服务，省去排序开销。

该题考查磁盘调度算法、位图法管理以及对新型存储介质调度策略的反思。

### 第 46 题（操作系统，8 分）

本题以固定分配局部置换、4 个页框、访问逻辑地址 17CAH 为背景。**答案**：
1. 页大小 1KB，页内偏移占低 10 位、页号占高 6 位。17CAH = 0001 0111 1100 1010B，页号 = 000101B = 5。
2. FIFO 淘汰装入最早的 0 号页，其页框 7 分配给 5 号页，物理地址 = 0001 1111 1100 1010B = 1FCAH。
3. CLOCK 指针从 2 号页框开始：依次检查 2、4、7、9 号页框，使用位均为 1，逐个清零；第 5 次回到 2 号页框时使用位为 0，淘汰 2 号页，装入 5 号页，物理地址 = 0000 1011 1100 1010B = 0BCAH。

该题考查对 FIFO 与 CLOCK 置换算法执行流程的精准理解。

### 第 47 题（计算机网络，9 分）

本题以 10Mbps CSMA/CD 局域网、两站点距离 2km、信号传播速度 200000km/s 为背景。**答案**：
1. 单程传播时延 t₀ = 2km/200000km/s = 10µs。最短情况（甲、乙同时发送）信号在中点相遇，两端同时检测到冲突，需 t₀=10µs；最长情况（甲的信号即将到达乙时乙才发送）乙立即检测到冲突，甲需等冲突信号传回，共 2t₀=20µs。
2. 数据帧发送时延 = 1518×8/10Mbps = 1.2144ms；确认帧发送时延 = 64×8/10Mbps = 0.0512ms；加上双程传播时延 0.02ms，一个发送周期 T = 1.2856ms。每周期传送 1500B 数据，有效数据传输率 = 1500×8/1.2856ms ≈ 9.33Mb/s。

该题将 CSMA/CD 冲突检测窗口、发送/传播时延与有效数据率有机结合。

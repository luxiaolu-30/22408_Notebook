### 12. （2 分 · 计算机系统概述）

假定基准程序 A 在某计算机上的运行时间为 100 秒，其中 90 秒为 CPU 时间，其余为 I/O 时间。若 CPU 速度提高 50%，I/O 速度不变，则运行基准程序 A 所耗费的时间是（ ）。

- **A.** 55s
- **B.** 60s
- **C.** 65s
- **D.** 70s

**答案**：D

**解析**：答案 D。总时间 100s = CPU 90s + I/O 10s。CPU 提速 50% 后 CPU 时间变为 90/1.5 = 60s，I/O 不变，总时间 = 60 + 10 = 70s。

### 13. （2 分 · 数据表示与运算）

假定编译器规定 int 和 short 型长度分别为 32 位和 16 位，执行下列 C 语言语句：

```c
unsigned short x=65530;
unsigned int y=x;
```

得到 y 的机器数为（ ）。

- **A.** 0000 7FFAH
- **B.** 0000 FFFAH
- **C.** FFFF 7FFAH
- **D.** FFFF FFFAH

**答案**：B

**解析**：答案 B。x = 65530 = FFFAH（16 位）。无符号 short 转 32 位 unsigned int 时高位补 0，故 y 的机器数为 0000 FFFAH。

### 14. （2 分 · 数据表示与运算）

float 类型（即 IEEE754 单精度浮点数格式）能表示的最大正整数是（ ）。

- **A.** $2^{126} - 2^{103}$
- **B.** $2^{127} - 2^{104}$
- **C.** $2^{127} - 2^{103}$
- **D.** $2^{128} - 2^{104}$

**答案**：D

**解析**：答案 D。单精度浮点尾数含隐藏位共 24 位，最大阶码 254，能表示的最大正整数为 (2−2⁻²³)×2¹²⁷ = 2¹²⁸−2¹⁰⁴。

### 15. （2 分 · 数据表示与运算）

某计算机存储器按字节编址，采用小端方式存放数据。假定编译器规定 int 型和 short 型长度分别为 32 位和 16 位，并且数据按边界对齐存储。某 C 语言程序段如下：

```c
struct {
    int a;
    char b;
    short c;
} record;

record.a = 273;
```

若 record 变量的首地址为 0xC008，则地址 0xC008 中的内容及 `record.c` 的地址分别为（ ）。

- **A.** 0x00、0xC00D
- **B.** 0x00、0xC00E
- **C.** 0x11、0xC00D
- **D.** 0x11、0xC00E

**答案**：D

**解析**：答案 D。record 对齐后占 8 字节：a 占 0xC008～0xC00B，小端存 273=0x00000111，故 0xC008 中为低字节 0x11；b 在 0xC00C，其后空 1 字节，c 在 0xC00E。

### 16. （2 分 · 存储器层次结构）

下列关于闪存（Flash Memory）的叙述中，错误的是（ ）。

- **A.** 信息可读可写，并且读、写速度一样快
- **B.** 存储元由 MOS 管组成，是一种半导体存储器
- **C.** 掉电后信息不丢失，是一种非易失性存储器
- **D.** 采用随机访问方式，可替代计算机外部存储器

**答案**：A

**解析**：答案 A。闪存可读可写、非易失，但写前必须先擦除原内容，写速度明显慢于读，A 说读写一样快是错的；B、C、D 均正确。

### 17. （2 分 · 存储器层次结构）

> 编者注：本题为**争议题**。组相联映射的组号划分在不同教材中不一致——唐朔飞教材按“主存块号 mod 组数”，蒋本珊教材另有划分规则，两次命题采用的教材不同。

假设某计算机按字节编址，Cache 有 4 个行，Cache 和主存之间交换的块大小为 1 个字（即 2 个字节）。若 Cache 的内容初始为空，采用 2 路组相联映射方式和 LRU 替换策略。访问的主存地址依次为 0, 4, 8, 2, 0, 6, 8, 6, 4, 8 时，命中 Cache 的次数是（ ）。

- **A.** 1
- **B.** 2
- **C.** 3
- **D.** 4

**答案**：C

**解析**：答案 C。2 路组相联、块大小 2B：地址 0、4、8 映射到第 0 组，2、6 映射到第 1 组。按访问序列 0,4,8,2,0,6,8,6,4,8 模拟 LRU 替换，共命中 3 次。

编者注：本题为争议题。组相联映射的组号划分在不同教材中不一致——唐朔飞教材按“主存块号 mod 组数”，蒋本珊教材另有划分规则，两次命题采用的教材不同。本题按蒋本珊教材的方式解答（块 0、2、4 映射到第 0 组，块 1、3 映射到第 1 组），命中 3 次。

### 18. （2 分 · 中央处理器）

某计算机的控制器采用微程序控制方式，微指令中的操作控制字段采用字段直接编码法，共有 33 个微命令，构成 5 个互斥类，分别包含 7、3、12、5 和 6 个微命令，则操作控制字段至少有（ ）。

- **A.** 5位
- **B.** 6位
- **C.** 15位
- **D.** 33位

**答案**：C

**解析**：答案 C。字段直接编码：每个互斥字段的位数取能表示其微命令数并留一个空状态的最小位数。7、3、12、5、6 个微命令分别需 3、2、4、3、3 位，共 3+2+4+3+3 = 15 位。

### 19. （2 分 · 总线）

某同步总线的时钟频率为 100MHz，宽度为 32 位，地址/数据线复用，每传输一个地址或数据占用一个时钟周期。若该总线支持突发（猝发）传输方式，则一次"主存写"总线事务传输 128 位数据所需要的时间至少是（ ）。

- **A.** 20ns
- **B.** 40ns
- **C.** 50ns
- **D.** 80ns

**答案**：C

**解析**：答案 C。总线时钟 100MHz，即 10ns 一个周期。猝发传输先传地址 10ns，再连续传 128 位数据（32 位宽，4 个周期）40ns，共 50ns。

### 20. （2 分 · 总线）

> 编者注（大纲变动）：具体总线/接口标准（USB / PCI / SATA 等）的特性辨析已不在现行 408 大纲中——大纲「总线」现仅含 总线的基本概念、组成及性能指标、总线事务和定时，不再单列总线标准/分类。本题为 2012 年真题，按"真题原貌"保留收录；其考查的"串行 vs 并行总线"概念仍属基本概念范畴，可作方法参考。

关于 USB 总线特性的描述，错误的是（ ）。

- **A.** 即插即用和热插拔
- **B.** 可级联方式连接多台外设
- **C.** 是通信总线可连接不同外设
- **D.** 同时传输 2 位数据

**答案**：D

**解析**：答案 D。USB 是串行总线，同一时刻只能传输 1 位数据，不能同时传输 2 位，D 错误；即插即用、热插拔、菊花链级联多台外设、连接不同外设均正确。

### 21. （2 分 · 输入输出系统）

下列选项中，在 I/O 总线的数据线上传输的信息包括（ ）。

Ⅰ. I/O 接口中的命令字

Ⅱ. I/O 接口中的状态字

Ⅲ. 中断类型号

- **A.** 仅Ⅰ、Ⅱ
- **B.** 仅Ⅰ、Ⅲ
- **C.** 仅Ⅱ、Ⅲ
- **D.** Ⅰ、Ⅱ、Ⅲ

**答案**：D

**解析**：答案 D。I/O 总线的地址线、控制线由 CPU 单向发出；命令字、状态字、中断类型号都由接口发往 CPU，只能经数据线传输，故Ⅰ、Ⅱ、Ⅲ全部正确。

### 22. （2 分 · 中央处理器）

响应外部中断的过程中，中断隐指令完成的操作，除保护断点外，还包括（ ）。

I. 关中断

II. 保存通用寄存器的内容

III. 形成中断服务程序入口地址并送 PC

- **A.** 仅 I、II
- **B.** 仅 I、III
- **C.** 仅 II、III
- **D.** I、II、III

**答案**：B

**解析**：答案 B。中断隐指令完成关中断（Ⅰ）、保护断点、形成中断服务程序入口地址并送 PC（Ⅲ）。保存通用寄存器内容是在进入中断服务程序后执行的，不属于中断隐指令，Ⅱ 错误。

## 二、综合应用题

### 43. （13 分 · 存储器层次结构）

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 的命中率为 99%，存储器总线宽度为 32 位。请回答下列问题。

(1) 该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？

(2) 假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？

(3) CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？

(4) 为了提高性能，主存采用四体低位交叉存储模式，工作时每 1/4 个存储周期启动一个体。若每个体的存储周期为 50ns，则该主存能提供的最大带宽是多少？

**答案 / 解析**：

答案：1、MIPS = 80M/4 = 20。平均每秒 Cache 缺失次数 = 20M×1.5×(1−99%) = 300k；缺失时按 16B 块访存，主存带宽至少 16B×300k/s = 4.8MB/s。2、每秒缺页次数 = 300000×0.0005% = 1.5；总线宽 32 位（4B），DMA 请求次数至少 1.5×4KB/4B = 1536 次/s。3、DMA 优先级更高；因为 DMA 请求得不到及时响应会导致 I/O 数据丢失。4、四体交叉最大带宽 = 4×4B/50ns = 320MB/s。

### 44. （13 分 · 中央处理器）

某 16 位计算机中，带符号整数用补码表示，数据 Cache 和指令 Cache 分离。下表给出了指令系统中部分指令格式，其中 Rs 和 Rd 表示寄存器，mem 表示存储单元地址，`(x)` 表示寄存器 x 或存储单元 x 的内容。

| 名称 | 指令的汇编格式 | 指令功能 |
| --- | --- | --- |
| 加法指令 | `ADD Rs, Rd` | (Rs) + (Rd) → Rd |
| 算术/逻辑左移 | `SHL Rd` | 2 × (Rd) → Rd |
| 算术右移 | `SHR Rd` | (Rd) / 2 → Rd |
| 取数指令 | `LOAD Rd, mem` | (mem) → Rd |
| 存数指令 | `STORE Rs, mem` | (Rs) → mem |

该计算机采用 5 段流水方式执行指令，各流水段分别是取指（IF）、译码/读寄存器（ID）、执行/计算有效地址（EX）、访问存储器（M）和结果写回寄存器（WB）。流水线采用“按序发射，按序完成”方式，没有采用转发技术处理数据相关，并且同一个寄存器的读和写操作不能在同一个时钟周期内进行。


（1）若 int 型变量 x 的值为 −513，存放在寄存器 R1 中，则执行指令 `SHR R1` 后，R1 的内容是多少（用十六进制表示）？


（2）若某个时间段中，有连续的 4 条指令进入流水线，在其执行过程中没有发生任何阻塞，则执行这 4 条指令所需的时钟周期数为多少？


（3）若高级语言程序中某赋值语句为 `x=a+b`，x、a 和 b 均为 int 型变量，它们的存储单元地址分别表示为 `[x]`、`[a]` 和 `[b]`。该语句对应的指令序列及其在指令流水线中的执行过程如下图所示。

![x=a+b 对应的指令流水线时序](q44-pipeline.webp)

则这 4 条指令执行过程中，I3 的 ID 段和 I4 的 IF 段被阻塞的原因各是什么？


（4）若高级语言程序中某赋值语句为 `x=x*2+a`，x 和 a 均为 unsigned int 类型变量，它们的存储单元地址分别表示为 `[x]`、`[a]`，则执行这条语句至少需要多少个时钟周期？要求模仿题图画出这条语句对应的指令序列及其在流水线中的执行过程示意图。

**答案 / 解析**：

答案：1、(R1) = FEFFH。−513 的 16 位补码为 FDFFH，SHR 算术右移一位得 FEFFH。2、5 段流水无阻塞执行 4 条指令需 4+(5−1) = 8 个时钟周期。3、I3 的 ID 段与 I1、I2 存在数据冒险，需等它们把结果写回寄存器后才能读操作数，故被阻塞；I4 的 IF 段因前一条指令 I3 在 ID 段被阻塞、按序发射而随之阻塞。4、指令序列：LOAD R1,[x]；LOAD R2,[a]；SHL R1；ADD R1,R2；STORE R1,[x]。无转发且同周期不能读写同一寄存器，I3 的 ID 需等 I1 写回 R1，I4 的 ID 需等 I3（及 I2）写回，I5 的 ID 需等 I4 写回，阻塞逐条向后传递，共需 17 个时钟周期。

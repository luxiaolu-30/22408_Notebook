### 1. （2 分 · 线性表）

对于采用顺序存储结构的线性表，当存储空间有足够的空闲空间时，在保持表内元素顺序相对不变的情况下，下列哪些操作会必然导致产生移动次数（）。

I. 表头插入一个元素

II. 表头删除一个元素

III. 表尾插入一个元素

IV. 表尾删除一个元素

- **A.** I、II
- **B.** I、III
- **C.** II、IV
- **D.** III、IV

**答案**：A

**解析**：答案 A。顺序表中元素连续存放，表头插入需把全部元素后移一位，表头删除需把其余元素前移一位，都必然产生移动；表尾插入、删除只在末尾操作，无需移动元素。故必然移动的是 I、II。

### 2. （2 分 · 线性表）

设有一个双向链表 L，结构为 [p2, p1]，头结点为 head。初始时 head = cu。现要将每个结点的 p2 指向 p1 指向结点的直接后继，应该进行的操作是（）。

- **A.** `while(cu!=NULL) {cu->p2=cu->p1->p1; cu=cu->p1;}`
- **B.** `while(cu!=NULL && cu->p2!=NULL) {cu->p2 = cu->p1->p1; cu = cu->p1;}`
- **C.** `while(cu!=NULL) {if(cu->p1!=NULL) {cu->p2=cu->p1->p1; cu=cu->p1;}}`
- **D.** `while(cu!=NULL) {if(cu->p1!=NULL) {cu->p2=cu->p1->p1;} else {cu->p2=NULL;} cu=cu->p1;}`

**答案**：D

**解析**：答案 D。目标：令每个结点 cu 的 p2 指向 cu->p1->p1，尾结点（p1 为空）令 p2 为空。A 在尾结点访问空指针越界；B 用待修改的 p2 作循环条件且不处理尾结点；C 在尾结点不推进 cu 而死循环。D 分情况处理且每轮推进 cu，正确。

### 3. （2 分 · 树与二叉树）

已知二叉树 T 的中序遍历为 b, e, d, f, c, a, g，层序遍历为 a, b, g, c, d, e, f，则其后序遍历序列为（）。

- **A.** c, e, d, f, b, g, a
- **B.** c, e, f, d, b, g, a
- **C.** e, f, d, c, b, g, a
- **D.** e, g, f, d, b, c, a

**答案**：C

**解析**：答案 C。层序首元素 a 为根，中序分左子树 {b,e,d,f,c} 和右子树 {g}。由层序知 b 为左子树根，b 无左子树、右子树根为 c；c 的左子树根为 d，d 的左右孩子为 e、f。后序为 e,f,d,c,b、g、a，即 e,f,d,c,b,g,a。

### 4. （2 分 · 树与二叉树）

森林 F 中有 5 颗树，其节点个数分别为 2、3、4、5、7，森林中树的次序可以任意，问 F 对应的二叉树最小高度为多少？

- **A.** 5
- **B.** 6
- **C.** 8
- **D.** 10

**答案**：B

**解析**：答案 B。n 个结点的树转二叉树最小高度为 1+⌈log₂n⌉，故结点数 2、3、4、5、7 分别得 2、3、3、4、4。按高度从大到小排列，第 i 棵树对总高度的贡献为 hᵢ+(i−1)，最大值为 4+2=6，即最小高度为 6。

### 5. （2 分 · 树与二叉树）

假设二叉树中节点权值为 a=1, b=2, c=4, d=5, e=8, f=10, g=12。当带权路径长度 (WPL) 最小时，与节点 e（权值 8）处于相同深度的节点是哪些？

- **A.** d
- **B.** g
- **C.** d, f
- **D.** f, g

**答案**：D

**解析**：答案 D。哈夫曼树：1+2=3，3+4=7，5+7=12，8+10=18，12+12=24，18+24=42。e(8)、f(10) 在根节点 18 下深度为 2，g(12) 在 24 下深度也为 2；d 深 3、c 深 4、a、b 深 5。与 e 同深度的是 f、g。

### 6. （2 分 · 图）

有向图 G=(V, E) 采用邻接表存储，求某点入度的时间复杂度为（）。

- **A.** O(|V|)
- **B.** O(min(|V|, |E|))
- **C.** O(|E|)
- **D.** O(max(|V|, |E|))

**答案**：D

**解析**：答案 D。邻接表只存出边，求某点入度需遍历所有顶点的邻接表统计指向该点的边数，要访问全部 |V| 个顶点和 |E| 条边，时间为 O(|V|+|E|)，等价于 O(max(|V|,|E|))。

### 7. （2 分 · 图）

设有向图 G=(V, E)，顶点集大小 n=|V|，每条边标记一个字符。定义字符串集 S 为所有路径上边标记拼接成的字符串的集合。以下说法错误的是（）。

- **A.** 若 G 无环，则 S 是有限集
- **B.** 若 G 无环，则 S 中存在长度为 n 的字符串
- **C.** 若 G 有环，则 S 中存在长度大于 n 的字符串
- **D.** 若 G 有环，则 S 中存在长度小于 2n 的字符串

**答案**：B

**解析**：答案 B。无环时最长路径边数不超过 n−1，S 中字符串长度最多 n−1，不可能有长度为 n 的串，B 错；无环时路径有限，S 为有限集（A 对）；有环时可沿环走任意圈得任意长字符串（C 对）；S 含空串，长度 0<2n（D 对）。

### 8. （2 分 · 查找）

已知平衡二叉树 (AVL 树) 高度为 4（根节点高度记为 1），则其根节点的左右子树的节点数之差最多为（）。

- **A.** 1
- **B.** 2
- **C.** 3
- **D.** 5

**答案**：D

**解析**：答案 D。高度 4 的平衡树左右子树高度为 (3,3) 或 (3,2)。要使差最大，高的一侧取最多结点、矮的一侧取最少结点：高度 3 最多 7 个（满二叉树），高度 2 最少 2 个，差为 7−2=5。

### 9. （2 分 · 排序）

使用直接插入排序对序列进行升序排序，以下比较次数最少的是（）。

- **A.** 30, 27, 56, 41, 80, 95, 69
- **B.** 31, 43, 26, 55, 63, 99, 77
- **C.** 61, 84, 51, 23, 34, 91, 40
- **D.** 93, 32, 48, 81, 50, 21, 72

**答案**：B

**解析**：答案 B。直接插入排序的比较次数取决于序列初始有序程度，逐项计算：A 为 1+1+2+1+1+3=9，B 为 1+2+1+1+1+2=8，C 为 1+2+3+4+1+5=16，D 为 1+2+2+3+5+3=16。最少的是 B，共 8 次。

### 10. （2 分 · 排序）

现有 $n$ 名学生的成绩记录，每位学生的记录包含两门课程的成绩：课程 1（记为 $C_1$）和课程 2（记为 $C_2$）。

排序规则如下：

1. 首先，依据 $C_1$ 成绩升序排列；
2. 若两名学生的 $C_1$ 成绩相同，则依据其总分（即 $C_1 + C_2$）升序排列。

请从下列排序算法中，选择最适合实现上述需求的算法（）。

- **A.** 基数排序
- **B.** 快速排序
- **C.** 希尔排序
- **D.** 选择排序

**答案**：A

**解析**：答案 A。规则是 C₁ 为主键、总分为次键的多键排序。基数排序稳定，可先按总分稳定排序、再按 C₁ 稳定排序，保证同分时按总分升序；快速、希尔、选择排序都不稳定，不适合。

### 11. （2 分 · 排序）

在外部排序的 $k$ 路归并过程中，归并趟数为 $d$。下列关于 $k$、$d$、初始归并段及内存大小的说法中，正确的是（）。

Ⅰ. $k$ 越大，$d$ 越小

Ⅱ. 初始归并段数不影响 $d$

Ⅲ. 内存大小限制初始归并段的最大长度

- **A.** 仅 I
- **B.** 仅 I、II
- **C.** 仅 I、III
- **D.** 仅 II、III

**答案**：C

**解析**：答案 C。归并趟数 d=⌈logₖm⌉：k 越大 d 越小，Ⅰ 对；d 随初始归并段数 m 变化，Ⅱ 错；初始归并段在内存中生成，长度受内存大小限制，Ⅲ 对。故正确项为 I、III。

### 41. （13 分 · 树与二叉树）

（本题满分 13 分）

假定二叉搜索树使用二叉链表存储，存储结构如下：

```c
typedef struct BSTNode {
    int data;
    struct BSTNode *left, *right;
} BSTNode;
```

给一棵二叉搜索树 T 和整数 K，查找树中关键字与 K 之差的绝对值最小的所有结点，并输出该绝对值与结点中的关键字。

(1) 给出算法的基本设计思想。（4 分）

(2) 使用 C/C++ 描述算法。（9 分）

**答案 / 解析**：

答案：
1、基本思想：二叉搜索树中序遍历得到递增序列，|data−K| 先递减后递增。中序递归遍历并记录当前最小差值 min，每访问一个结点算 diff=|data−K|：diff<min 时更新 min 并重新收集结点；diff=min 时并入；diff>min 说明之后差值只会更大，可停止。与 K 差值最小的结点最多两个（K 两侧各一个），输出最小差值及对应关键字。
2、时间 O(n)，空间 O(h)（h 为树高，递归栈）。核心代码：

```c
int min = INT_MAX, flag = 0, ans[2], cnt = 0;

void search(BSTNode *root, int K) {
    if (root == NULL || flag) return;
    search(root->left, K);              // 中序遍历
    int diff = abs(K - root->data);
    if (diff < min) {                   // 出现更小差值，重新收集
        min = diff; cnt = 1; ans[0] = root->data;
    } else if (diff == min) {           // 并列最小，追加
        ans[cnt++] = root->data;
    } else {                            // 差值开始增大，中序有序可停止
        flag = 1;
    }
    search(root->right, K);
}
```

调用结束后 min 为最小绝对值差值，ans[0..cnt-1] 为对应的关键字。

### 42. （10 分 · 栈、队列与数组）

已知入栈序列是 1, 2, 3, …, $n$，回答下列问题：

(1) 当 $n = 9$ 时，是否能得到出栈序列 {2,3,1,6,4,7,5,9,8}？是否能得到出栈序列 {2,3,1,5,6,7,4,9,8}？（2 分）

(2) 已知 1, 2, 3, …, $n$，对于序列 $P_1, P_2, \dots, P_n$ 中的 $P_i$、$P_j$、$P_k$（$i < j < k$），当 $P_i$、$P_j$、$P_k$ 的大小满足什么关系时，$P_1, P_2, \dots, P_n$ 是不可能得到的出栈序列？（2 分）

(3) 当 $n = 4$ 时，以 2 开头的出栈序列个数是多少？（2 分）

(4) 当 $n = k-1$ 时，能够得到的所有出栈序列个数是 $M$ 个。当 $n = k$ 时，以 1 开头的出栈序列个数是多少？以 2 开头的出栈序列个数是多少？所有能够得到的出栈序列个数是多少？（4 分）

**答案 / 解析**：

答案：
1、{2,3,1,6,4,7,5,9,8} 不能得到：存在 i=4、j=5、k=7，满足 Pⱼ=4 < Pₖ=5 < Pᵢ=6，即出现"312 模式"；{2,3,1,5,6,7,4,9,8} 中不存在任何 i<j<k 使 Pⱼ<Pₖ<Pᵢ，可以得到。
2、当存在下标 i<j<k 使 Pⱼ < Pₖ < Pᵢ（即第二个出栈的数最小、第三个居中、第一个最大）时，该序列不可能由栈得到。
3、n=4 时以 2 开头的出栈序列为 {2,1,3,4}、{2,1,4,3}、{2,3,1,4}、{2,3,4,1}、{2,4,3,1}，共 5 个。
4、n=k 时：以 1 开头，先 push(1)、pop(1)，剩余 k−1 个元素任意出栈，个数为 M；以 2 开头，操作前缀为 push(1)、push(2)、pop(2)，栈底保留 1，对 3…k 的出栈等价于规模 k−1 的情形，个数也为 M。总数为卡特兰数 Cₖ=(2(2k−1)/(k+1))·Cₖ₋₁=(4k−2)/(k+1)·M。

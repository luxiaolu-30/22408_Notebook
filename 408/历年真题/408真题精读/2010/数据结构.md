## 一、单项选择题

### 1. （2 分 · 栈、队列与数组）

若元素 a, b, c, d, e, f 依次进栈，允许进栈、退栈操作交替进行，但不允许连续三次进行退栈操作，则不可能得到的出栈序列是( )。

- **A.** d, c, e, b, f, a
- **B.** c, b, d, a, e, f
- **C.** b, c, a, e, f, d
- **D.** a, f, e, d, c, b

**答案**：D

**解析**：答案 D。进栈序列 a,b,c,d,e,f 固定，连续退栈出的元素必然按逆序排列。D 中 a 先出栈后，需连续退栈 f、e、d 三次，中间没有入栈操作可插入，违反“不允许连续三次退栈”的限制；A、B、C 均可通过适时插入入栈操作实现。

### 2. （2 分 · 栈、队列与数组）

某队列允许在其两端进行入队操作，但仅允许在一端进行出队操作，若元素 a, b, c, d, e 依次入此队列后再进行出队操作，则不可能得到的出队序列是( )。

- **A.** b, a, c, d, e
- **B.** d, b, a, c, e
- **C.** d, b, c, a, e
- **D.** e, c, b, a, d

**答案**：C

**解析**：答案 C。该队列是输出受限的双端队列：队首端入队的元素逆序排在前，队尾端入队的正序排在后。要得到 d,b,c,a,e，c 必须位于 b 与 a 之间，但无论从哪端入队都无法插入，故不可能。

- **A.** 如上图 A
- **B.** 如上图 B

### 4. （2 分 · 查找）

在下图所示的平衡二叉树中，插入关键字 48 后得到一棵新平衡二叉树。在新平衡二叉树中，关键字 37 所在结点的左、右子结点中保存的关键字分别是（ ）。

![插入 48 前的平衡二叉树](q04-avl-tree.webp)

- **A.** 13, 48
- **B.** 24, 48

### 5. （2 分 · 树与二叉树）

在一棵度数为 4 的树 T 中，若有 20 个度为 4 的结点，10 个度为 3 的结点，1 个度为 2 的结点，10 个度为 1 的结点，则树 T 的叶结点个数是( )。

- **A.** 41
- **B.** 82
- **C.** 113
- **D.** 122

**答案**：B

**解析**：答案 B。设叶结点数为 n₀，各结点度之和 = 20×4+10×3+1×2+10×1 = 122，即边数为 122，结点总数 N = 122+1 = 123；又 N = 20+10+1+10+n₀ = 41+n₀，解得 n₀ = 82。

### 6. （2 分 · 树与二叉树）

对 n (n≥ 2) 个权值均不相同的字符构成哈夫曼树。下列关于该哈夫曼树的叙述中，错误的是( )。

- **A.** 该树一定是一棵完全二叉树
- **B.** 树中一定没有度为 1 的结点
- **C.** 树中两个权值最小的结点一定是兄弟结点
- **D.** 树中任一非叶结点的权值一定不小于下一层任一结点的权值

**答案**：A

**解析**：答案 A。哈夫曼树是带权路径长度最小的二叉树，不一定是一棵完全二叉树，故 A 错误。哈夫曼树没有度为 1 的结点（B 对）；构造时最先合并两个权值最小的结点（C 对）；非叶结点权值等于其子树根权值之和，不小于下一层任一结点权值（D 对）。

### 7. （2 分 · 图）

若无向图 G=(V,E) 中含有 7 个顶点，要保证图 G 在任何情况下都是连通的，则需要的边数最少是()。

- **A.** 6
- **B.** 15
- **C.** 16
- **D.** 21

**答案**：C

**解析**：答案 C。要保证任何情况下都连通，先考虑最坏的不连通情形：6 个顶点构成完全图再加 1 个孤立顶点，此时有 6×5/2 = 15 条边仍可能不连通；再添 1 条边把第 7 个顶点连入，共需 16 条边。

### 9. （2 分 · 查找）

已知一个长度为 16 的顺序表 L，其元素按关键字有序排列。若采用折半查找法查找一个 L 中不存在的元素，则关键字的比较次数最多是( )。

- **A.** 4
- **B.** 5

**答案**：B

### 10. （2 分 · 排序）

采用递归方式对顺序表进行快速排序。下列关于递归次数的叙述中，正确的是()。

- **A.** 递归次数与初始数据的排列次序无关。
- **B.** 每次划分后，先处理较长的分区可以减少递归次数。
- **C.** 每次划分后，先处理较短的分区可以减少递归次数。
- **D.** 递归次数与每次划分后得到的分区的处理顺序无关。

**答案**：D

**解析**：答案 D。快排的递归次数由初始数据的排列决定（划分平衡则少、不平衡则多），但每次划分后先处理长分区还是短分区，总递归次数不变，即与分区的处理顺序无关；先短后长只影响递归栈的深度。

### 11. （2 分 · 排序）

对一组数据 (2, 12, 16, 88, 5, 10) 进行排序，若前三趟排序结果如下：第一趟排序结果：2, 12, 16, 5, 10, 88；第二趟排序结果：2, 12, 5, 10, 16, 88；第三趟排序结果：2, 5, 10, 12, 16, 88，则采用的排序方法可能是（）。

- **A.** 冒泡排序
- **B.** 希尔排序
- **C.** 归并排序
- **D.** 基数排序

**答案**：A

**解析**：答案 A。每趟从前往后依次比较，把当前最大值“沉底”：88、16、12 逐趟就位，正是冒泡（起泡）排序的特征。希尔、归并、基数排序的中间状态均与此不符。

### 41. （10 分 · 查找）

将关键字序列 ⟨7, 8, 30, 11, 18, 9, 14⟩ 散列存储到散列表中。散列表的存储空间是一个下标从 0 开始的一维数组，散列函数为 H(key) = (key × 3) mod 7，处理冲突采用线性探测再散列法，要求装填(载)因子为 0.7。

(1) 请画出所构造的散列表。

(2) 分别计算等概率情况下查找成功和查找不成功的平均查找长度。

**答案 / 解析**：

答案：1、散列表：表长 m = 7/0.7 = 10（下标 0～9），H(key) = (key×3) mod 7，线性探测再散列。各关键字散列地址：7→0，8→3，30→6，11→5，18→5，9→6，14→0。填入结果：地址 0～9 依次为 7、14、空、8、空、11、30、18、9、空。2、查找成功 ASL = (1+1+1+1+3+3+2)/7 = 12/7；查找不成功时按 H 输出范围 0～6 等概率、探测到空位为止，ASL = (3+2+1+2+1+5+4)/7 = 18/7。

### 42. （13 分 · 线性表）

设将 n（n > 1）个整数存放到一维数组 R 中。试设计一个在时间和空间两方面都尽可能高效的算法。将 R 中保存的序列循环左移 p（0 < p < n）个位置，即将 R 中的数据由 (x₀, x₁, ..., xₙ₋₁) 变换为 (xₚ, xₚ₊₁, ..., xₙ₋₁, x₀, x₁, ..., xₚ₋₁)。要求：

(1) 给出算法的基本设计思想。

(2) 根据设计思想，采用 C 或 C++ 或 Java 语言描述，关键之处给出注释。

(3) 说明你所设计算法的时间复杂度和空间复杂度。

**答案 / 解析**：

答案：1、基本思想：三次逆置。把数组分为前 p 个元素 A 和后 n−p 个元素 B，目标是把 AB 变成 BA：先逆置 A，再逆置 B，最后整体逆置，即得 BA（循环左移 p 位）。2、核心代码：

```c
void reverse(int a[], int from, int to) {
    int i = from, j = to, tmp;
    while (i < j) {
        tmp = a[i]; a[i] = a[j]; a[j] = tmp;
        i++; j--;
    }
}
void loopMove(int a[], int n, int p) {
    if (p <= 0 || p >= n) return;
    reverse(a, 0, p - 1);
    reverse(a, p, n - 1);
    reverse(a, 0, n - 1);
}
```
3、时间复杂度 O(n)，空间复杂度 O(1)。

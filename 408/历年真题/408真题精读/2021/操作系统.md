### 23. （2 分 · 计算机系统概述）

下列指令中，只能在内核态执行的是（ ）。

- **A.** trap 指令
- **B.** I/O 指令
- **C.** 数据传送指令
- **D.** 设置断点指令

**答案**：B

**解析**：答案 B。I/O 指令直接操作设备控制器，属特权指令，只能在内核态执行；trap 指令、数据传送指令、设置断点指令在用户态均可执行。

### 24. （2 分 · 进程与线程）

下列操作中，操作系统在创建新进程时，必须完成的是（ ）。

Ⅰ. 申请空白的进程控制块
Ⅱ. 初始化进程控制块
Ⅲ. 设置进程状态为执行态

- **A.** 仅 Ⅰ
- **B.** 仅 Ⅰ、Ⅱ
- **C.** 仅 Ⅰ、Ⅲ
- **D.** 仅 Ⅱ、Ⅲ

**答案**：B

**解析**：答案 B。创建进程必须申请空白 PCB 并初始化进程标识、状态、优先级等信息；新进程初始为就绪态而非执行态，故仅 Ⅰ、Ⅱ 正确。

### 25. （2 分 · 进程与线程）

下列内核的数据结构或程序中，分时系统实现时间片轮转调度需要使用的是（ ）。

Ⅰ. 进程控制块
Ⅱ. 时钟中断处理程序
Ⅲ. 进程就绪队列
Ⅳ. 进程阻塞队列

- **A.** 仅 Ⅱ、Ⅲ
- **B.** 仅 Ⅰ、Ⅳ
- **C.** 仅 Ⅰ、Ⅱ、Ⅲ
- **D.** 仅 Ⅰ、Ⅱ、Ⅳ

**答案**：C

**解析**：答案 C。时间片轮转需要 PCB 保存/恢复上下文、时钟中断处理程序检测时间片并触发调度、就绪队列存放等待调度的进程；阻塞队列只用于因等待而阻塞的进程，不参与轮转调度。

### 26. （2 分 · 输入输出管理）

某系统中磁盘的磁道数为 200（0～199），磁头当前在 184 号磁道上。用户进程提出的磁盘访问请求对应的磁道号依次为 184, 187, 176, 182, 199。若采用最短寻道时间优先调度算法（SSTF）完成磁盘访问，则磁头移动的距离（磁道数）是（ ）。

- **A.** 37
- **B.** 38
- **C.** 41
- **D.** 42

**答案**：C

**解析**：答案 C。SSTF 每次选离磁头最近的磁道：184→182→187→176→199，移动距离为 0+2+5+11+23=41。

### 27. （2 分 · 进程与线程）

下列事件中，可能引起进程调度程序执行的是（ ）。

Ⅰ. 中断处理结束
Ⅱ. 进程阻塞
Ⅲ. 进程执行结束
Ⅳ. 进程的时间片用完

- **A.** 仅 Ⅰ、Ⅲ
- **B.** 仅 Ⅱ、Ⅳ
- **C.** 仅 Ⅲ、Ⅳ
- **D.** Ⅰ、Ⅱ、Ⅲ、Ⅳ

**答案**：D

**解析**：答案 D。中断处理结束、进程阻塞、进程执行结束、时间片用完都会使当前进程让出 CPU 或改变进程状态，均可能引起进程调度程序执行，故四项全选。

### 28. （2 分 · 内存管理）

某请求分页存储系统的页大小为 4KB，按字节编址。系统给进程 P 分配 2 个固定的页框并采用改进型 Clock 置换算法，进程 P 页表的部分内容如下表所示：

| 页号 | 页框号 | 存在位（1：存在；0：不存在） | 访问位（1：访问；0：未访问） | 修改位（1：修改；0：未修改） |
| --- | --- | --- | --- | --- |
| ... | ... | ... | ... | ... |
| 2 | 20H | 0 | 0 | 0 |
| 3 | 60H | 1 | 1 | 0 |
| 4 | 80H | 1 | 1 | 1 |
| ... | ... | ... | ... | ... |

若 P 访问虚拟地址为 02A01H 的存储单元，则经地址变换后得到的物理地址是（ ）。

- **A.** 00A01H
- **B.** 20A01H
- **C.** 60A01H
- **D.** 80A01H

**答案**：C

**解析**：答案 C。页大小 4KB，页内偏移 12 位；02A01H 页号为 2，存在位 0，触发缺页。改进型 Clock 第一轮无 (0,0) 页，第二轮清访问位后页 3 变 (0,0) 被换出，页 2 调入页框 60H，物理地址 60A01H。

### 29. （2 分 · 内存管理）

在采用二级页表的分页系统中，CPU 页表基址寄存器中的内容是（ ）。

- **A.** 当前进程的一级页表的起始虚拟地址
- **B.** 当前进程的一级页表的起始物理地址
- **C.** 当前进程的二级页表的起始虚拟地址
- **D.** 当前进程的二级页表的起始物理地址

**答案**：B

**解析**：答案 B。页表基址寄存器存放当前进程一级页表的起始物理地址；页表由 MMU 直接访问，不能再经地址翻译，故必须是物理地址。

### 30. （2 分 · 文件管理）

若目录 dir 下有文件 file1，则为删除该文件内核不必完成的工作是（ ）。

- **A.** 删除 file1 的快捷方式
- **B.** 释放 file1 的文件控制块
- **C.** 释放 file1 占用的磁盘空间
- **D.** 删除目录 dir 中与 file1 对应的目录项

**答案**：A

**解析**：答案 A。删除文件时内核需删除目录项、释放文件控制块和磁盘空间；快捷方式（软链接）是独立文件，内核不会也不必随原文件一起删除，故 A 是内核不必完成的工作。

### 31. （2 分 · 进程与线程）

若系统中有 n（n≥2）个进程，每个进程均需要使用某类临界资源 2 个，则系统不会发生死锁所需的该类资源总数至少是（ ）。

- **A.** 2
- **B.** n
- **C.** n+1
- **D.** 2n

**答案**：C

**解析**：答案 C。每个进程需 2 个同类资源。若资源总数恰为 n，最坏情况下每进程各持 1 个，谁都凑不齐第 2 个，可能死锁；总数为 n+1 时必有进程能凑齐 2 个并释放，不会死锁。

### 32. （2 分 · 计算机系统概述）

下列选项中，通过系统调用完成的操作是（ ）。

- **A.** 页置换
- **B.** 进程调度
- **C.** 创建新进程
- **D.** 生成随机整数

**答案**：C

**解析**：答案 C。系统调用是用户进程请求 OS 服务的入口：创建新进程（如 fork）需内核分配 PCB 等资源，属系统调用；页置换和进程调度由内核内部完成，生成随机整数是普通库函数调用。

## 二、综合应用题

### 45. （7 分 · 进程与线程）

下表给出了整型信号量 S 的 `wait()` 和 `signal()` 操作的功能描述，以及采用开/关中断指令实现信号量操作互斥的两种方法。

功能描述

```c
Semaphore S;

wait(S) {
    while (S <= 0);
    S = S - 1;
}

signal(S) {
    S = S + 1;
}
```

方法 1

```c
wait(S) {
    关中断;
    while (S <= 0);
    S = S - 1;
    开中断;
}

signal(S) {
    关中断;
    S = S + 1;
    开中断;
}
```

方法 2

```c
wait(S) {
    关中断;
    while (S <= 0) {
        开中断;
        关中断;
    }
    S = S - 1;
    开中断;
}

signal(S) {
    关中断;
    S = S + 1;
    开中断;
}
```

请回答下列问题：

(1) 为什么在 `wait()` 和 `signal()` 操作中对信号量 S 的访问必须互斥执行？

(2) 分别说明方法 1 和方法 2 是否正确。若不正确，请说明理由。

(3) 用户程序能否使用开/关中断指令实现临界区互斥？为什么？

**答案 / 解析**：

答案：1、S 是多个进程共享的变量，wait 和 signal 都要对 S 进行读改写，若不互斥，多个进程交错执行会导致 S 的值错误，故对 S 的访问必须互斥。
2、方法 1 错误：S≤0 时关中断后 while 循环空转，其他进程无法运行、无法执行 signal 修改 S，陷入死循环。方法 2 正确：循环体内有开中断操作，使其他进程能修改 S，从而能退出循环。
3、不能。开中断和关中断指令都是特权指令，只能在内核态执行，用户程序无法使用。

### 46. （8 分 · 输入输出管理）

某计算机用硬盘作为启动盘，硬盘第一个扇区存放主引导记录，其中包含磁盘引导程序和分区表。磁盘引导程序用于选择要引导哪个分区的操作系统，分区表记录硬盘上各分区的位置等描述信息。硬盘被划分成若干个分区，每个分区的第一个扇区存放分区引导程序，用于引导该分区中的操作系统。

系统采用多阶段引导方式，除了执行磁盘引导程序和分区引导程序外，还需要执行 ROM 中的引导程序。请回答下列问题：

(1) 系统启动过程中以下 4 个程序的执行顺序是什么？
- 操作系统的初始化程序
- 分区引导程序
- ROM 中的引导程序
- 磁盘引导程序

(2) 把硬盘制作为启动盘时，需要完成以下 4 个操作的正确顺序是什么？
- 操作系统的安装
- 磁盘的物理格式化
- 逻辑格式化
- 对磁盘进行分区

(3) 磁盘扇区的划分和文件系统根目录的建立分别是在第 (2) 问的哪个操作中完成的？

**答案 / 解析**：

答案：1、执行顺序：ROM 中的引导程序 → 磁盘引导程序 → 分区引导程序 → 操作系统的初始化程序。
2、操作顺序：磁盘的物理格式化 → 对磁盘进行分区 → 逻辑格式化 → 操作系统的安装。
3、磁盘扇区的划分在物理格式化中完成；文件系统根目录的建立在逻辑格式化中完成。

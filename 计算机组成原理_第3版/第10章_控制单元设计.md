# 第10章 控制单元的设计

> 408考研权重：⭐⭐⭐（常考章节，约5-10分）

## 考点概述

控制单元的设计有两种主要方法。主要考点包括：
- 组合逻辑设计 vs 微程序设计
- 微指令的编码方式
- 微指令序列地址的形成
- 微指令格式

## 关键知识点

### 10.1 组合逻辑设计

#### 组合逻辑控制框图
```
输入：指令操作码 + 状态标志 + 时序信号
      ↓
组合逻辑网络
      ↓
输出：微操作控制信号
```

#### 微操作节拍安排
1. **安排微操作时序的原则**
   - 微操作先后顺序不能随意变动
   - 被控对象不同的微操作可并行
   - 占用时间不同的微操作安排在较长时间段

2. **节拍分配**
   - 每个时钟周期安排一组可并行的微操作
   - 不同指令的执行周期节拍数不同

#### 组合逻辑设计步骤
1. 列出所有微操作及其时序
2. 确定每个微操作的条件（指令、时序、状态）
3. 写出每个微操作的逻辑表达式
4. 画出组合逻辑电路

**优点**：速度快
**缺点**：设计复杂，不易修改

### 10.2 微程序设计 ⭐⭐⭐⭐⭐

#### 微程序设计思想
- 将每条机器指令编成一段微程序
- 微程序存放在控制存储器中
- 执行时从控制存储器中逐条取出微指令

#### 微程序控制框图
```
指令操作码 → 微地址形成部件 → 微地址
                              ↓
控制存储器（CM）→ 微指令 → 微操作信号
                              ↓
                        微地址序列
```

#### 微指令的编码方式

| 方式 | 特点 | 优点 | 缺点 |
|---|---|---|---|
| **直接编码** | 每位对应一个微操作 | 速度快 | 字长太长 |
| **字段编码** | 将相关微操作分组 | 字长短 | 需译码器 |
| **混合编码** | 结合上述两种 | 折中 | 较复杂 |

#### 微指令序列地址的形成

| 方式 | 说明 |
|---|---|
| **增量方式** | 微程序计数器+1 |
| **断定方式** | 微指令中下地址字段指定 |
| **分支方式** | 根据状态条件跳转 |
| **硬件入口** | 取指周期入口地址固定 |

#### 微指令格式

```
微指令 = 操作控制字段 + 顺序控制字段
```

- **操作控制字段**：指定微操作
- **顺序控制字段**：指定下条微指令地址

#### 微程序设计 vs 组合逻辑设计

| 特性 | 微程序设计 | 组合逻辑设计 |
|---|---|---|
| **速度** | 较慢 | 快 |
| **设计复杂度** | 简单 | 复杂 |
| **可修改性** | 容易修改 | 难修改 |
| **应用场合** | CISC机 | RISC机 |

#### 其他微程序设计技术

| 技术 | 说明 |
|---|---|
| **静态微程序设计** | 微程序不改变 |
| **动态微程序设计** | 可重新加载微程序 |
| **毫微程序设计** | 两级微程序控制 |
| **串行微程序控制** | 串行执行微指令 |
| **并行微程序控制** | 并行执行微指令 |

## 典型例题

### 题型1：组合逻辑 vs 微程序

> **例题**：比较组合逻辑控制和微程序控制的优缺点。

**解答**：
| 特性 | 组合逻辑控制 | 微程序控制 |
|---|---|---|
| 速度 | 快 | 慢 |
| 设计复杂度 | 高 | 低 |
| 可修改性 | 差 | 好 |
| 适用场合 | RISC机 | CISC机 |

### 题型2：微指令格式设计

> **例题**：某机有10个互斥微操作，采用直接编码和字段编码分别需要多少位？

**解答**：
- 直接编码：10位（每位对应一个微操作）
- 字段编码：⌈log₂(10+1)⌉ = 4位（需译码器）

### 题型3：微程序入口地址

> **例题**：微程序控制器中，如何确定取指周期微程序的入口地址？

**解答**：
- 取指周期入口地址通常固定（如0号地址）
- 执行周期入口地址由指令操作码映射得到

## 易错点

1. **组合逻辑vs微程序**：组合逻辑速度快但难修改，微程序可修改但速度慢
2. **微指令格式**：操作控制字段 + 顺序控制字段
3. **直接编码**：每位对应一个微操作，互斥微操作可同字段
4. **微程序入口**：取指周期固定，执行周期由操作码决定

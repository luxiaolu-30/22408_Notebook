# 第4章 存储器

> 408考研权重：⭐⭐⭐⭐⭐（必考章节，约15-20分）

## 考点概述

存储器是408考研的核心章节，每年必考。主要考点包括：
- Cache映射方式与命中率计算（15/15年必考）
- 虚拟存储器（15/15年必考）
- 主存设计与扩展
- 存储系统层次结构

## 关键知识点

### 4.1 存储器分类与层次结构

#### 存储器分类
| 分类方式 | 类型 |
|---|---|
| 存储介质 | 半导体、磁表面、光盘 |
| 存取方式 | RAM、ROM、顺序存取、直接存取 |
| 作用 | 主存、辅存、缓存 |

#### 存储系统层次结构（重要！）
```
CPU → Cache → 主存 → 辅存
      ↑         ↑
   速度最快    容量最大
   容量最小    速度最慢
```

两个层次：
1. **Cache-主存层次**：解决速度不匹配，硬件自动完成
2. **主存-辅存层次**：解决容量问题，硬件+OS完成

### 4.2 主存储器

#### 主存基本结构
- **MAR**（存储器地址寄存器）：存放访问的存储单元地址
- **MDR**（存储器数据寄存器）：存放读/写的数据
- 按地址存取方式

#### 存储单元地址分配
- 存储字长 = 8的倍数（字节整数倍）
- 可按字寻址或按字节寻址
- 大端序 vs 小端序

#### 半导体存储芯片
- **SRAM**（静态RAM）：触发器原理，高速，Cache用
- **DRAM**（动态RAM）：电容充放电，主存用，需刷新

#### 存储器与CPU连接
- 地址线连接：CPU地址线 → 存储器地址译码
- 数据线连接：双向数据总线
- 控制线：读/写命令、片选信号

### 4.3 高速缓冲存储器（Cache）⭐⭐⭐⭐⭐

#### Cache工作原理
- 基于**程序局部性原理**（时间局部性+空间局部性）
- CPU先访问Cache，命中则直接取；未命中再访问主存
- 由**硬件自动完成**，对程序员透明

#### Cache-主存地址映射（必考！）

| 映射方式 | 特点 | 冲突率 | 硬件复杂度 |
|---|---|---|---|
| **直接映射** | 主存块→唯一Cache块 | 高 | 低 |
| **全相联映射** | 主存块→任意Cache块 | 低 | 高 |
| **组相联映射** | 主存块→唯一组，组内任意 | 中 | 中 |

**地址结构**（设Cache共C块，主存共M块）：

直接映射：
```
主存地址 = 标记 + Cache块号 + 块内地址
```

全相联映射：
```
主存地址 = 标记 + 块内地址
```

组相联映射（每组n块）：
```
主存地址 = 标记 + 组号 + 块内地址
```

#### 替换策略
- **LRU**（最近最少使用）：最常用，命中率最高
- **FIFO**（先进先出）：实现简单
- **随机替换**：硬件简单

#### 命中率计算（必考题型）
```
命中率 h = Cache访问次数 / 总访问次数
平均访问时间 ta = h × tc + (1-h) × tm
```
其中：tc = Cache访问时间，tm = 主存访问时间

### 4.4 辅助存储器

#### 磁表面存储器
- 非易失性存储
- 记录方式：归零制、不归零制、调相制、调频制
- 编码方式：改进调频制(MFM)、RLL码

#### 硬磁盘存储器
- 存储结构：盘片、磁道、扇区
- 寻道时间 + 旋转延迟 + 传输时间
- 磁盘调度算法：FCFS、SSTF、SCAN、CSCAN

#### 光盘存储器
- 利用激光读/写
- 类型：CD-ROM、DVD、蓝光光盘

## 典型例题

### 题型1：Cache命中率计算

> **例题**：设CPU执行某程序时，共访问存储器1000次，其中Cache未命中50次。已知Cache存取周期为50ns，主存存取周期为500ns，求：
> (1) Cache命中率
> (2) 平均访问时间
> (3) Cache-主存系统的效率

**解答**：
(1) 命中率 h = (1000-50)/1000 = 0.95

(2) 平均访问时间 ta = 0.95×50 + 0.05×500 = 47.5 + 25 = 72.5ns

(3) 效率 e = tc/ta = 50/72.5 = 68.97%

### 题型2：Cache地址映射

> **例题**：设主存容量为1MB，Cache容量为16KB，每块大小为256B。
> (1) 直接映射时，主存地址各字段位数？
> (2) 全相联映射时，主存地址各字段位数？
> (3) 4路组相联映射时，主存地址各字段位数？

**解答**：
- 块内地址：256B → 8位
- Cache块数：16KB/256B = 64块
- 主存块数：1MB/256B = 4096块

(1) 直接映射：
- Cache块号：64块 → 6位
- 标记：20-8-6 = 6位

(2) 全相联映射：
- 标记：20-8 = 12位
- 块内地址：8位

(3) 4路组相联：
- 组数：64/4 = 16组 → 4位
- 标记：20-8-4 = 8位

## 易错点

1. **Cache容量计算**：注意区分"块"和"页"的概念
2. **地址映射**：直接映射是"主存块→唯一Cache块"，不是"主存地址→唯一Cache地址"
3. **命中率公式**：注意是"Cache访问次数/总访问次数"，不是"主存访问次数/总访问次数"
4. **虚拟存储器**：虚地址→物理地址的变换由硬件+OS完成，不是纯硬件

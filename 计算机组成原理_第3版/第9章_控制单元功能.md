# 第9章 控制单元的功能

> 408考研权重：⭐⭐⭐（常考章节，约5-10分）

## 考点概述

控制单元是CPU的核心部件之一。主要考点包括：
- 微操作命令分析
- 控制单元外特性
- 多级时序系统
- 控制方式

## 关键知识点

### 9.1 微操作命令分析

微操作是控制单元发出的最基本控制信号。

#### 取指周期微操作
1. PC → MAR
2. 读内存
3. MDR → IR
4. PC + 1 → PC
5. OP(IR) → CU（分析操作码）

#### 间址周期微操作（间接寻址时）
1. Ad(IR) → MAR
2. 读内存
3. MDR → Ad(IR)

#### 执行周期微操作
- 不同指令执行周期不同
- 如加法指令：Ad(IR) → MAR → 读内存 → MDR → X → ALU运算 → ACC

#### 中断周期微操作
1. SP - 1 → SP（栈指针减1）
2. SP → MAR
3. PC → MDR（保存断点）
4. 写内存
5. 中断入口地址 → PC

### 9.2 控制单元功能

#### 控制单元外特性
- **输入**：指令操作码、时钟、状态标志、外来信号
- **输出**：CPU内部控制信号、CPU外部控制信号

#### 控制信号举例
- 存储器读/写
- 寄存器输入/输出门
- ALU功能选择
- PC+1
- 时序信号

### 9.3 多级时序系统

#### 时序系统结构
```
指令周期 → 机器周期 → 时钟周期 → 节拍 → 脉冲
```

| 级别 | 说明 |
|---|---|
| **指令周期** | 执行一条指令的时间 |
| **机器周期** | 一个基本操作的时间（取指、执行等） |
| **时钟周期** | 最基本的定时单位（主频的倒数） |
| **节拍** | 一个或多个时钟周期 |
| **脉冲** | 最小的时序单位 |

#### 时序关系
- 一个指令周期包含多个机器周期
- 一个机器周期包含多个时钟周期
- 一个时钟周期包含多个节拍

### 9.4 控制方式

| 方式 | 特点 |
|---|---|
| **同步控制** | 由统一时钟控制，时序固定 |
| **异步控制** | 无统一时钟，握手方式 |
| **联合控制** | 大部分同步，部分异步 |
| **人工控制** | 用于调试（复位、单步） |

### 9.5 多级时序系统实例

#### 假设条件
- 指令周期 = 2个机器周期（取指+执行）
- 每个机器周期 = 4个时钟周期
- 每个时钟周期 = 2个节拍

#### 时序安排
- 取指周期：T1~T4
- 执行周期：T5~T8
- 每周期根据操作码发出不同微操作

## 典型例题

### 题型1：微操作分析

> **例题**：分析加法指令"ADD A"在取指周期和执行周期的微操作。

**解答**：
取指周期：
1. PC → MAR
2. 读内存
3. MDR → IR
4. PC + 1 → PC
5. OP(IR) → CU

执行周期：
1. Ad(IR) → MAR
2. 读内存
3. MDR → X
4. ACC + X → ACC

### 题型2：时序系统理解

> **例题**：说明指令周期、机器周期、时钟周期的关系。

**解答**：
- 一个指令周期包含多个机器周期
- 一个机器周期包含多个时钟周期
- 时钟周期是最基本的定时单位（主频的倒数）

## 易错点

1. **微操作 vs 指令**：微操作是比指令更基本的控制信号
2. **取指周期**：所有指令的取指周期微操作相同
3. **执行周期**：不同指令的执行周期微操作不同
4. **间址周期**：只有间接寻址指令才有间址周期

## 五、备考建议

### 5.1 各科目复习重点优先级

| 优先级 | 科目 | 理由 |

| ⭐⭐⭐⭐⭐ | 毛中特 | 分值最高（30分），分析题必考新思想 |
| ⭐⭐⭐⭐⭐ | 马原 | 24分，分析题34考查辩证法/认识论概率极高 |
| ⭐⭐⭐⭐ | 时政/当代 | 16分，分析题38聚焦三大倡议和外交 |
| ⭐⭐⭐ | 史纲 | 14分，分析题36常考党史和革命精神 |
| ⭐⭐⭐ | 思修法基 | 16分，分析题37结合社会热点 |

### 5.2 选择题备考策略

1. **单选题（16分）**：目标14+分，马原4题尽量全对
2. **多选题（34分）**：拉分关键！目标26+分，需精准把握概念内涵与外延
3. **常见陷阱**：张冠李戴、偷换概念、夸大/缩小范围、时态错误

### 5.3 分析题答题模板

```
第一步：原理阐述（写出相关概念/原理/方法论）
第二步：原理内容展开（分层论述）
第三步：结合材料分析（紧扣材料，原理+材料）
第四步：结论/启示（总结升华）
```

# 习近平新时代中国特色社会主义思想概论（习概）

> 2023 大纲起单列，本部分约 **20+ 分**（含量最大的科目），单选 / 多选 / 分析题全覆盖
> **分析题 35 的绝对高频来源**；与时政结合紧密，新表述年年更新

---

## 一、新时代坚持和发展中国特色社会主义

### 1. 中国特色社会主义进入新时代

**核心要义**：坚持和发展中国特色社会主义。

**主要内容**（框架性记忆）：**「十个明确」「十四个坚持」「十三个方面成就」**
- 十个明确 → 主体内容，构成思想体系的**四梁八柱**，发挥统摄作用
- 十四个坚持 → 基本方略
- 十三个方面成就 → 对新时代伟大实践的科学总结

**世界观和方法论 —— 「六个必须坚持」**
人民至上 / 自信自立 / 守正创新 / 问题导向 / 系统观念 / 胸怀天下

**「两个结合」**：马克思主义基本原理同**中国具体实际**相结合、同**中华优秀传统文化**相结合
- 「第二个结合」是又一次思想解放 → 让马克思主义成为中国的、中华优秀传统文化成为现代的
- 表明 3 个「新高度」：对道路理论制度的认识、历史自信文化自信、推进理论创新的自觉性

**历史地位**：当代中国马克思主义、二十一世纪马克思主义。

### 2. 社会主要矛盾的变化

**新时代主要矛盾**：人民日益增长的**美好生活需要** 与 **不平衡不充分的发展** 之间的矛盾。

> 记：不再是「物质文化需要 vs 落后的社会生产」，重心从「落后」转为「不平衡不充分」。

**根本立场**：以人民为中心。

## 二、中国式现代化 ★★★

> 近年分析题大热门，五特征 + 九本质要求 + 五重大原则必须默写

### 1. 五大特征

1. **人口规模巨大**的现代化（14 亿多人口，超过现有发达国家人口总和）
2. **全体人民共同富裕**的现代化（本质特征，区别于「资本为中心、两极分化」）
3. **物质文明和精神文明相协调**的现代化（物质富足、精神富有）
4. **人与自然和谐共生**的现代化
5. **走和平发展道路**的现代化（不走战争、殖民、掠夺的老路）

### 2. 本质要求与重大原则

**本质要求（九个方面，首要是坚持中国共产党领导）**
1. 坚持中国共产党领导
2. 坚持中国特色社会主义
3. 实现高质量发展
4. 发展全过程人民民主
5. 丰富人民精神世界
6. 实现全体人民共同富裕
7. 促进人与自然和谐共生
8. 推动构建人类命运共同体
9. 创造人类文明新形态

**重大原则（五个）**
1. 坚持和加强党的全面领导
2. 坚持中国特色社会主义道路
3. 坚持以人民为中心的发展思想
4. 坚持深化改革开放
5. 坚持发扬斗争精神

> 五原则记忆：领导力量 / 前进方向 / 发展目的 / 发展动力 / 方式手段

**战略安排（两步走）**
- 2020 → 2035：基本实现社会主义现代化
- 2035 → 本世纪中叶：建成**富强民主文明和谐美丽**的社会主义现代化强国

**「五个必由之路」**
- 坚持党的全面领导 → 坚持和发展中国特色社会主义的必由之路
- 中国特色社会主义 → 实现中华民族伟大复兴的必由之路
- 团结奋斗 → 中国人民创造历史伟业的必由之路
- 贯彻新发展理念 → 新时代我国发展壮大的必由之路
- 全面从严治党 → 党永葆生机活力、走好新的赶考之路的必由之路

> 中国式现代化是**人类文明新形态**，破除「现代化＝西方化」迷思，为发展中国家提供中国方案。

## 三、新发展理念与高质量发展 ★★★

### 1. 创新、协调、绿色、开放、共享

**新发展理念**：创新（**第一动力**）/ 协调（内在要求）/ 绿色（必要条件）/ 开放（必由之路）/ 共享（本质要求）。

**高质量发展**是全面建设社会主义现代化国家的**首要任务**，是「十四五」乃至更长时期我国经济社会发展的主题。

### 2. 新发展格局（双循环）

加快构建**以国内大循环为主体、国内国际双循环相互促进**的新发展格局。

### 3. 新质生产力（2024-2025 高频）

**官方定义**：创新起主导作用，摆脱传统经济增长方式、生产力发展路径，具有**高科技、高效能、高质量**特征，符合新发展理念的**先进生产力质态**。

| 维度 | 内容 |
|------|------|
| 催生 | 技术革命性突破、生产要素创新性配置、产业深度转型升级 |
| 基本内涵 | 劳动者、劳动资料、劳动对象及其优化组合的**跃升** |
| 核心标志 | **全要素生产率大幅提升** |
| 特点 | **创新** |
| 关键 | **质优** |
| 本质 | **先进生产力** |

**实践路径**：科技创新（核心要素）+ 产业创新（重要载体）；因地制宜、先立后破、分类指导。

> 易混：发展新质生产力**不是**忽视、放弃传统产业，要防止一哄而上、泡沫化。

### 4. 共同富裕

**共同富裕是社会主义的本质要求**，是中国式现代化的本质特征。坚持尽力而为、量力而行，分阶段推进。

## 四、「五位一体」总体布局

### 1. 经济建设

高质量发展；构建新发展格局；建设现代化产业体系；坚持「两个毫不动摇」。

### 2. 政治建设（全过程人民民主）

**全过程人民民主**：全链条、全方位、全覆盖；最广泛、最真实、最管用。
- 制度载体：**人民代表大会制度**（根本政治制度）
- 重要形式：人民政协

### 3. 文化建设（文化自信 ★）

**文化自信**是更基础、更广泛、更深厚的自信。
- 「两个结合」；建设中华民族现代文明
- 坚持马克思主义在意识形态领域指导地位的根本制度

### 4. 社会建设

以保障和改善民生为重点；**共建共治共享**的社会治理格局。

### 5. 生态文明建设（两山论）

**绿水青山就是金山银山**；坚持节约优先、保护优先、自然恢复为主。
- **双碳目标**：2030 年前碳达峰、2060 年前碳中和

---

## 五、「四个全面」战略布局

### 1. 全面深化改革

**总目标**：完善和发展中国特色社会主义制度，推进国家治理体系和治理能力现代化。

### 2. 全面依法治国

**总目标**：建设中国特色社会主义法治体系、建设社会主义法治国家。

### 3. 全面从严治党（自我革命）

**自我革命**是我们党跳出治乱兴衰历史周期率的**第二个答案**（第一个答案是人民监督）。

### 4. 全面建成社会主义现代化强国

以中国式现代化全面推进中华民族伟大复兴。

---

## 六、国防军队 / 一国两制 / 大国外交

### 1. 人类命运共同体 ★（与分析题 38 联动）

**推动构建人类命运共同体**是中国式现代化的本质要求之一；建设持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界。

### 2. 三大全球倡议（发展 / 安全 / 文明）

- **全球发展倡议**（2021）
- **全球安全倡议**（2022）
- **全球文明倡议**（2023）

> 中国外交：独立自主的和平外交政策；多边主义；共商共建共享。

### 3. 国防和军队现代化

如期实现**建军一百年奋斗目标**，加快把人民军队建成世界一流军队。

### 4. 一国两制

坚持「一国两制」、推进祖国完全统一；贯彻「爱国者治港」「爱国者治澳」。

# 政治考前速看

> 考前一周到考前一晚的浓缩速记卡片：只放最救命的内容。
> 分析题详细版见 [[政治/答题方法/分析题答题思路与步骤]]，考点统计见 [[政治/政治考情分析]]。

## 一、分析题五科模板速记

> 记住骨架，考场上往里填材料和原理。每题 3-4 点，每点「原理句前置 + 结合材料」。

| 题号 | 科目 | 速记框架 |
|:----:|------|---------|
| 34 | 马原 | **原理 + 方法论 + 材料结合**：①点明原理名 → ②原理论述 2-3 句 → ③方法论 1 句 → ④「材料中"……"体现了……」→ ⑤因此/由此可见 |
| 35 | 毛中特 | **是什么 + 为什么 + 怎么做**：①理论定位（XX 是/体现了 XX）→ ②内涵展开 → ③材料印证 → ④意义/路径（有利于/需要我们） |
| 36 | 史纲 | **背景 + 过程 + 意义**：①历史事实（事件/会议/人物）→ ②历史意义 → ③现实启示（今天我们要……）→ ④材料结合 |
| 37 | 思修 | **概念 + 意义 + 践行**：①理论观点/概念 → ②重要性（对个人/社会）→ ③材料体现 → ④「作为新时代青年，我们应该……」 |
| 38 | 当代 | **背景 + 主张 + 行动 + 意义**：①当今世界形势判断 → ②中国提出/倡导 XX → ③中国通过 XX 践行 → ④这有利于（对世界/对人类） |

### 马原高频原理（34 题必背 8 条）

| 原理 | 一句话原理句 | 方法论 |
|------|------------|--------|
| 对立统一 | 矛盾是事物发展的动力和源泉 | 在对立中把握统一 |
| 矛盾普遍性 | 矛盾存在于一切事物发展过程中 | 承认、分析、解决矛盾 |
| 矛盾特殊性 | 矛盾着的事物各有特点 | 具体问题具体分析 |
| 主次矛盾 | 主要矛盾决定事物发展进程 | 集中力量抓重点 |
| 矛盾主次方面 | 主要方面决定事物性质 | 分清主流与支流 |
| 实践决定认识 | 实践是认识的基础/来源/动力/检验标准 | 坚持实践第一 |
| 认识运动规律 | 认识具有反复性和无限性 | 与时俱进、开拓创新 |
| 真理与价值 | 真理是客观的、具体的、有条件的 | 坚持和发展真理 |

### 通用口诀

```
审题先定位，科目设问明；
列点搭架子，逻辑要分明；
原理打头阵，材料紧跟行；
分点标序号，字迹要端正；
结尾扣主题，金句来点睛。
```

## 二、选择题救命技巧

### 2.1 多选题技巧（17 题 × 2 分，错选漏选全扣）

**「不全选」的信号词（该选项大概率是干扰项）：**

| 信号词 | 原因 |
|--------|------|
| 「就是」「等于」「完全」「根本」等同义反复 | 概念偷换，A 就是 B 的绝对化表述 |
| 「已经」「消除了」「解决了」（说历史矛盾/资本主义矛盾已终结） | 时态错误 |
| 「任何」「所有」「一切……都」 | 绝对化外延扩大 |
| 「唯一」「直接表明」「标志着……完成」 | 夸大或偷换逻辑关系 |

**「必选」的信号词：**

| 信号词 | 原因 |
|--------|------|
| 带「有时/在一定条件下/可能/往往」等限定词 | 表述严谨，通常是正确项 |
| 官方标准提法（XX 是 XX 的 XX，教材原句） | 原文复述基本是答案 |
| 「有利于」「促进」「推动」正向表述 | 没有绝对化的正向判断 |
| 与材料/题干直接对应的同义转述 | 扣材料选项优先保留 |

**多选保命原则：**
- 4 个选项拿不准时：马原多选倾向「17、18、20 题选 2-3 个」；毛中特多选出现「全选（4 个）」概率不低，尤其二十大报告原句类。
- 相信第一直觉，没有把握不要反复改。
- 时政多选（32-33）：领导人讲话要点类题目，通常全选或选 3 个。

### 2.2 单选排除法（16 题 × 1 分）

1. **先排绝对化**：含「唯一」「根本取决于」「任何」「所有」「彻底消除」的选项优先排除。
2. **再排张冠李戴**：把 A 科目的帽子扣到 B 科目头上（如把毛中特的表述说成马原原理）。
3. **再排时态错位**：「已经建成」「已经实现」——现代化强国 2035/本世纪中叶才实现，现在说「已经」就是错。
4. **马原单选（1-4 题）**：哲学概念题选「辩证的、有条件的、具体的」那一项的概率极高。
5. 剩 2 个选项拿不准：选表述更全面、更贴近教材原话的那个。

### 2.3 绝对化表述排除清单

> 出现以下措辞，90% 是错项：

- 「……是唯一正确的」「……是永恒不变的」
- 「彻底解决了」「完全克服了」「消除了基本矛盾」
- 「感性认识高于理性认识」「认识可以脱离实践」
- 「人的意志可以改变客观规律」「意识直接创造物质」

## 三、万能句式

> 背熟后可套用到大部分分析题的结尾或填充。

### 3.1 意义类（问「有何意义/作用」）

1. 是新时代坚持和发展中国特色社会主义的必然要求，为实现中华民族伟大复兴提供了……
2. 体现了社会主义制度的优越性，彰显了以人民为中心的发展思想。
3. 有利于推动高质量发展，满足人民日益增长的美好生活需要。
4. 为解决人类共同问题贡献了中国智慧、中国方案、中国力量。
5. 是对马克思主义的丰富和发展，彰显了真理力量和实践伟力。

### 3.2 措施类（问「如何做/怎么办」）

1. 必须坚持中国共产党的领导，发挥党总揽全局、协调各方的领导核心作用。
2. 坚持以人民为中心的发展思想，做到发展为了人民、发展依靠人民、发展成果由人民共享。
3. 完善制度体系，将制度优势转化为治理效能。
4. 坚持系统观念，统筹兼顾、整体推进，处理好当前与长远的关系。
5. 作为新时代青年，我们要坚定理想信念、练就过硬本领、投身强国实践。

### 3.3 原因类（问「为什么/依据」）

1. 这是由我国社会主义初级阶段的基本国情决定的。
2. 是顺应世界发展潮流、应对时代之变的必然选择。
3. 是马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合的生动体现。
4. 是中国共产党践行初心使命、坚持人民至上的必然要求。
5. 实践证明，……是符合中国国情、得到人民拥护的正确道路。

## 四、时政速览

> 时政 16 分（单选 15-16、多选 32-33、分析 38）按主题归类记忆，不逐条死背。

### 4.1 记忆方法：三大主题归类

| 主题类 | 记忆要点 |
|--------|---------|
| **重大会议类** | 记「会议 + 新提法」：二十大（中国式现代化、三个务必、中心任务）、中央经济工作会议（稳中求进总基调）、两会（政府工作报告关键数字） |
| **重大事件类** | 记「事件 + 一句话定性」：航天（自立自强）、进博会/服贸会（高水平开放）、大国外交活动 |
| **倡议理念类** | 三大倡议（全球发展倡议、全球安全倡议、全球文明倡议）+ 人类命运共同体 + 一带一路——分析 38 题万能素材 |

### 4.2 分析 38 题万能素材（当代）

- **背景句**：当今世界正经历百年未有之大变局，世界之变、时代之变、历史之变正以前所未有的方式展开，和平与发展面临严峻挑战。
- **中国主张句**：中国倡导构建人类命运共同体，提出全球发展倡议、全球安全倡议、全球文明倡议，弘扬和平、发展、公平、正义、民主、自由的全人类共同价值。
- **行动句**：中国通过「一带一路」合作、进博会、联合国等多边平台践行承诺，始终做世界和平的建设者、全球发展的贡献者、国际秩序的维护者。
- **意义句**：这有利于推动国际关系民主化、建设开放型世界经济、推动构建新型国际关系，为人类共同发展贡献中国智慧和中国方案。

### 4.3 时政选择题保命提醒

- 时政考查范围：**上一年 4 月至当年 3 月**的国内外重大时事 + 党和国家重要会议。
- 拿不准的时政多选题：领导人讲话要点类倾向全选；具体数字/排序类要谨慎（数字错一位即错）。

## 五、考场策略

### 5.1 时间分配（180 分钟）

| 部分 | 题量 | 用时 | 要点 |
|------|:----:|:----:|------|
| 单选 + 多选 | 33 题 | **35 分钟内** | 涂卡一起完成；单选 30 秒/题，多选 1.5 分钟/题 |
| 分析题 34-38 | 5 题 | **每题 25 分钟** | 5 分钟审题列点 + 18 分钟作答 + 2 分钟收尾 |
| 检查 | — | 剩余时间 | 优先检查答题卡涂错位、漏题 |

> 写满 105 分钟以上给分析题：宁可多写不要留白，空着必然 0 分。

### 5.2 写字速度与字数

- 目标：每题 600-800 字，写字速度要保证每分钟 30+ 字。
- 字迹不求漂亮，**求清晰可辨**；分点标号 ①②③④，行距留够。
- 写错划一道横线即可，不要涂黑团。

### 5.3 分区作答

- 每道分析题**严格写在对应题号的答题区内**，写错区基本等于丢 10 分。
- 答题卡是分区密封阅卷的：34 区只给马原阅卷人看——答错区域的原理对方不认。
- 每题答到答题区的 80%-90%，不够就加一点「青年践行/现实启示」凑结构，不要越界。

### 5.4 考前一天 checklist

- [ ] 马原 8 条高频原理能默写
- [ ] 五科模板框架各背一遍
- [ ] 三类万能句式各过一遍
- [ ] 三大倡议 + 人类命运共同体素材句过一遍
- [ ] 准考证、身份证、黑色签字笔 ×2、2B 铅笔

# 第20题：利用奇偶性比较定积分大小

> **题目类型**：定积分 — 对称区间上利用奇偶性判断积分值的大小关系
>
> **核心考点**：奇函数/偶函数在对称区间上的积分性质、积分值的正负判断

---

## 题目

设

$$M = \int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \frac{x}{1+x^2}\cos^5 x \, dx$$

$$N = \int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} (x^2 \sin x + \sin^2 x \cos x) \, dx$$

$$P = \int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} (\sin^3 x - \cos^4 x) \, dx$$

则（　）

| 选项 | 大小关系 |
|------|---------|
| (A) | $N < P < M$ |
| (B) | $M < P < N$ |
| (C) | $N < M < P$ |
| (D) | $P < M < N$ |

---

## 解答

### 答案：**D**

### 分析 M

被积函数 $\frac{x}{1+x^2}\cos^5 x$：

| 因子 | 奇偶性 |
|------|--------|
| $\frac{x}{1+x^2}$ | 奇（奇 ÷ 偶 = 奇） |
| $\cos^5 x$ | 偶 |

奇 × 偶 = **奇函数**，对称区间积分 $= 0$：

$$M = 0$$

### 分析 N

拆分被积函数：

$$N = \underbrace{\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} x^2 \sin x \, dx}_{\text{奇函数，=}0} + \underbrace{\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \sin^2 x \cos x \, dx}_{\text{偶函数}}$$

- $x^2 \sin x$：偶 × 奇 = **奇** → 积分 $= 0$
- $\sin^2 x \cos x$：偶 × 偶 = **偶**，且 $\sin^2 x \cos x \geq 0$（不恒为 0）

$$N = 0 + 2\int_0^{\frac{\pi}{2}} \sin^2 x \cos x \, dx > 0$$

### 分析 P

拆分被积函数：

$$P = \underbrace{\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \sin^3 x \, dx}_{\text{奇函数，=}0} - \underbrace{\int_{-\frac{\pi}{2}}^{\frac{\pi}{2}} \cos^4 x \, dx}_{\text{偶函数，}>0}$$

- $\sin^3 x$：**奇函数** → 积分 $= 0$
- $\cos^4 x$：**偶函数**，且 $\cos^4 x > 0$

$$P = 0 - 2\int_0^{\frac{\pi}{2}} \cos^4 x \, dx < 0$$

### 综合比较

$$P < 0 = M < N$$

### 答案：**D**

---

## 方法总结

**对称区间 $[-a, a]$ 上定积分的快速计算**：

| 被积函数奇偶性 | 结论 |
|--------------|------|
| 奇函数 | $\int_{-a}^{a} f(x)\,dx = 0$ |
| 偶函数 | $\int_{-a}^{a} f(x)\,dx = 2\int_0^{a} f(x)\,dx$ |

**奇偶性判断规则**：

| 运算 | 奇偶性 |
|------|--------|
| 奇 × 奇 | 偶 |
| 偶 × 偶 | 偶 |
| 奇 × 偶 | 奇 |
| 奇 ÷ 偶 / 偶 ÷ 奇 | 奇 |
| 奇 + 奇 | 奇 |
| 偶 + 偶 | 偶 |

> **解题策略**：遇到对称区间积分，先判断被积函数奇偶性，奇函数直接归零，偶函数取半区间计算，再判断正负即可比较大小。

---

## 易错点

| 陷阱 | 说明 |
|------|------|
| **不拆分直接判断** | $N$ 和 $P$ 的被积函数本身非奇非偶，需拆成奇+偶两部分分别处理 |
| **正负判断错误** | $P$ 中 $\cos^4 x$ 前面是负号，积分结果为负 |
| **奇偶运算记反** | 奇 × 奇 = 偶（不是奇），奇 × 偶 = 奇 |

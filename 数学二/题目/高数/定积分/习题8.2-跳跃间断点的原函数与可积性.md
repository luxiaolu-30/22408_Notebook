# 习题8.2：跳跃间断点的原函数存在性与可积性

> **题目类型**：定积分 — 分段函数的原函数存在性、可积性、变限积分性质判断
>
> **核心考点**：跳跃间断点对原函数存在性的影响、可积的充分条件、变限积分的连续性与可导性

---

## 题目

设

$$f(x) = \begin{cases} x, & x < 0 \\ \frac{1}{2}, & x = 0 \\ 1, & x > 0 \end{cases}$$

则下列命题：

| # | 命题 |
|---|------|
| ① | $f(x)$ 在 $[-1,1]$ 上有原函数 |
| ② | $f(x)$ 在 $[-1,1]$ 上可积 |
| ③ | $F(x) = \int_{-1}^{x} f(t)\,dt$ 在 $x=0$ 处可导 |
| ④ | $F(x) = \int_{-1}^{x} f(t)\,dt$ 在 $x=0$ 处连续但不可导 |

正确命题的个数为（　）

| 选项 | 个数 |
|------|------|
| (A) | 1 |
| (B) | 2 |
| (C) | 3 |
| (D) | 4 |

---

## 解答

### 函数分析

$x=0$ 处：左极限 $= 0$，右极限 $= 1$，$f(0) = \frac{1}{2}$ → **跳跃间断点**（跳跃度 $= 1$）。

### 逐条判断

**① $f(x)$ 在 $[-1,1]$ 上有原函数 — ✗ 错误**

由 Darboux 定理，导函数具有介值性。$f(x)$ 在 $x=0$ 处有跳跃间断，不满足介值性，因此不可能是一个导函数，即**无原函数**。

**② $f(x)$ 在 $[-1,1]$ 上可积 — ✓ 正确**

$f(x)$ 有界，且在 $[-1,1]$ 上仅有一个间断点（有限个），满足 Riemann 可积的充分条件。

**③ $F(x) = \int_{-1}^{x} f(t)\,dt$ 在 $x=0$ 处可导 — ✗ 错误**

计算 $F(x)$：

$$F(x) = \begin{cases} \int_{-1}^{x} t\,dt = \frac{x^2 - 1}{2}, & x < 0 \\[6pt] \int_{-1}^{0} t\,dt + \int_{0}^{x} 1\,dt = -\frac{1}{2} + x, & x \geq 0 \end{cases}$$

在 $x=0$ 处：
- 左导数：$F'_-(0) = \left.\frac{d}{dx}\frac{x^2-1}{2}\right|_{x=0} = 0$
- 右导数：$F'_+(0) = \left.\frac{d}{dx}\left(-\frac{1}{2}+x\right)\right|_{x=0} = 1$

左导数 $\neq$ 右导数，故 $F(x)$ 在 $x=0$ 处**不可导**。

**④ $F(x)$ 在 $x=0$ 处连续但不可导 — ✓ 正确**

- **连续性**：$F(0^-) = -\frac{1}{2}$，$F(0^+) = -\frac{1}{2}$，$F(0) = -\frac{1}{2}$，连续 ✓
- **不可导**：由 ③ 的分析，左导数 $\neq$ 右导数 ✓

### 正确命题：②④，共 2 个

### 答案：**B**

---

## 知识总结

| 性质 | 条件 | 结论 |
|------|------|------|
| 原函数存在 | $f(x)$ 连续（或满足 Darboux 性质） | 跳跃间断 → **无原函数** |
| 可积 | $f(x)$ 有界 + 有限个间断点 | 跳跃间断 → **仍可积** |
| 变限积分连续 | $f(x)$ 可积 | $F(x)$ 处处**连续** |
| 变限积分可导 | $f(x)$ 在该点连续 | 间断点处 $F(x)$ **不可导**（左右导数不等） |

> **核心结论**：变限积分 $F(x) = \int_a^x f(t)\,dt$ 在 $f$ 的间断点处连续但不可导，左导数 $= f(x_0^-)$，右导数 $= f(x_0^+)$。

---

## 易错点

| 陷阱 | 说明 |
|------|------|
| **误认为可积就有原函数** | 可积 $\not\Rightarrow$ 有原函数，跳跃间断点处可积但无原函数 |
| **误认为变限积分在间断点处不连续** | 变限积分在可积条件下**始终连续**，即使在间断点处 |
| **混淆可导与连续** | 间断点处 $F(x)$ 连续但不可导，需分别验证左右导数 |

# 数学备考规划与资料推荐（数学二）

> 适用对象：22408 考研（数学二：高等数学 + 线性代数，不考概率论）。
> 满分 150 分，高数约 120 分（80%）+ 线代约 30 分（20%）。
> 试卷结构与考点统计详见 [[数学考情分析]]。

---

## 一、三阶段备考规划

### 阶段一：基础阶段（3-6 月）——搭框架、补概念

| 事项 | 说明 |
|------|------|
| **核心任务** | 教材/基础课 + 基础题，高数线代过一轮 |
| **高数** | 按章节过教材（同济版）或基础课，每章配基础习题；重点吃透极限、导数、积分的**概念与定义**（近年选择题对概念辨析考查加深） |
| **线代** | 行列式→矩阵→向量组→方程组→特征值→二次型，按顺序过一轮 |
| **笔记** | 建立概念公式笔记，可对照 [[02-求导与积分公式速查]]、[[07-线代常用公式速查]] 查漏补缺 |
| **达标标志** | 能独立完成教材课后基础题；极限、求导、积分基本计算不出错 |

> 提示：基础阶段不求快求全，**计算能力是数二的命根**，每道题动笔算到底，不眼高手低。

### 阶段二：强化阶段（7-10 月）——刷题型、建方法

| 事项 | 说明 |
|------|------|
| **核心任务** | 强化课 + 1000 题/880 题，按题型方法总结 |
| **高数** | 极限计算方法体系（等价无穷小/洛必达/泰勒）、中值定理证明套路、积分计算技巧（换元/分部）、二重积分、微分方程 |
| **线代** | 重点攻克相似对角化 + 二次型（线代解答题铁打三部曲：特征值→对角化→二次型） |
| **错题本** | 必须建立：记录错因（概念不清/方法没想到/计算失误），每周回看 |
| **达标标志** | 真题常见题型一眼有思路；高频考点（见 [[数学考情分析]] TOP15）全部覆盖 |

### 阶段三：冲刺阶段（11-12 月）——做套卷、查漏补缺

| 事项 | 说明 |
|------|------|
| **核心任务** | 近 15 年数二真题套卷限时模拟 + 模拟卷 |
| **真题** | 严格按 180 分钟限时模拟（上午 8:30-11:30，与考试同步），两天一套：第一天做卷、第二天复盘每道题 |
| **模拟卷** | 保持手感，训练陌生题型应变；错题回归对应考点笔记 |
| **查漏补缺** | 回归错题本和 [[数学考前速看]]，公式最后过一遍 |
| **达标标志** | 真题稳定 120+；选填错误 ≤ 2 个 |

## 二、高数 vs 线代复习要点

| 维度 | 高等数学 | 线性代数 |
|------|---------|---------|
| **复习策略** | **重计算**：极限/导数/积分的计算能力决定分数下限 | **重体系**：概念关联性强，前后章节一体 |
| **特点** | 章节相对独立，可分模块各个击破；题型变化多 | 行列式→矩阵→向量组→方程组→特征值→二次型环环相扣，前面没学透后面寸步难行 |
| **关键能力** | 计算准确率 + 综合题拆解能力（如微分方程+定积分综合） | 概念网络（秩贯穿全科目）+ 解答大题的固定流程 |
| **建议** | 每天保持计算训练量，手不能生 | 一气呵成学完一轮再刷题，切忌碎片化 |

> 高数线代投入时间约 **7:3**。线代虽然只有 30 分，但题型极其稳定（相似对角化/二次型几乎年年考解答题），投入产出比极高。

## 三、资料推荐

| 类别 | 资料 | 说明 |
|------|------|------|
| **教材** | 同济版《高等数学》（第七版） | 基础阶段概念打底，课后题必做 |
| | 同济版《线性代数》（第六版） | 线代入门首选 |
| **基础课** | 汤家凤基础班 | 高数基础扎实，节奏适中，适合零基础 |
| | 张宇基础 30 讲 | 体系完整，概念讲解清晰 |
| **强化** | 武忠祥严选题/强化课 | 高数强化首选，题型方法总结到位 |
| | 李林 880 题 | 贴近真题风格，难度适中 |
| | 张宇 1000 题 | 题量大，适合冲高分的同学 |
| | 李永乐线代讲义 | 线代圣经，跟紧李永乐线代即可 |
| **真题** | 李艳芳真题解析 | 逐题讲解详细，适合精研真题 |
| | 近 15 年数二真题 | 必须限时套卷模拟（2010-2024） |
| **模拟卷** | 李林 6+4 | 考前必做，风格最贴近真题 |
| | 张宇 8+4 | 难度略高于真题，练抗压能力 |

> 使用顺序：教材/基础课 → 严选题/880/1000（强化） → 真题套卷 → 模拟卷 → 回归错题本。

## 四、每日时间安排

**建议每天投入数学 3-4 小时**（考研前期数学是投入大头，占全天学习时间的 40% 左右）。

| 时段 | 内容 | 时长 |
|------|------|------|
| 上午 8:30-11:30（冲刺期） | 套卷限时模拟（与考试时间同步）/ 基础强化期用于新课学习 | 2-3 小时 |
| 下午或晚上 | 当日配套习题 + 订正 | 1-1.5 小时 |
| 睡前 15 分钟 | 过一遍当日错题、公式（配合 [[数学二/基础公式/]] 速查） | 15 分钟 |

**与其他科目配合（参考）**：

- **3-6 月**：数学 3.5h + 英语 2h（单词/语法）+ 408 专业课 3h
- **7-10 月**：数学 3.5h + 英语 2h（真题阅读）+ 408 4h + 政治 1h（9 月起）
- **11-12 月**：数学 3h（套卷）+ 英语 1.5h（作文）+ 408 2.5h + 政治 3h（背诵）

> 原则：数学每天不断线，哪怕冲刺期也要保持 2 小时以上手感；套卷模拟务必安排在上午。

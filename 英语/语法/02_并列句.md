# 第二章 "难点精露尖尖角"——并列句

> **本章目标**：掌握并列连词的分类，学会用并列结构表达复杂逻辑，并能在写作中灵活运用。

---

## 一、并列句概述

### 什么是并列句

**并列句 = 简单句 + 并列连词 + 简单句**

> 两个或更多独立简单句通过并列连词连接，构成并列句。

例：
- 简单句 1：`He is rich.`
- 简单句 2：`He is not happy.`
- 并列句：`He is rich, but he is not happy.`（转折关系）

### 并列句的 4 大关系

| 关系 | 含义 | 常用连词 |
|------|------|---------|
| 并列/顺承 | 平行、递进 | and, not only...but also, neither...nor |
| 转折/对比 | 方向相反 | but, yet, while, whereas |
| 因果 | 原因/结果 | so, for, therefore |
| 选择 | 二选一 | or, either...or, neither...nor |

---

## 二、连词分类及区别

### 1. 表"并列/顺承"

| 连词 | 用法 | 例句 |
|------|------|------|
| and | 最基本，表示并列或顺承 | `I like tea and coffee.` |
| both...and | 强调"两者都" | `Both you and I are wrong.` |
| not only...but also | "不仅...而且..."（also 必带） | `He speaks not only English but also French.` |
| neither...nor | "既不...也不..." | `Neither you nor I can do it.` |

### 2. 表"转折/对比"

| 连词 | 用法 | 例句 |
|------|------|------|
| but | 最常用，前后句子方向相反 | `He is poor but happy.` |
| yet | 较 but 文雅些 | `He worked hard, yet he failed.` |
| while | "然而"（可表对比） | `I like tea while she likes coffee.` |
| whereas | 正式用法 | `Some praise him, whereas others condemn him.` |

### 3. 表"因果"

| 连词 | 用法 | 例句 |
|------|------|------|
| so | 因此（不能与 because 同时使用） | `It was raining, so I stayed home.` |
| for | 因为（并列连词，置于两句之间） | `He must be at home, for his car is in the driveway.` |
| therefore | 因此（较正式） | `He was late; therefore, he missed the meeting.` |

**关键提醒：** `because` 是从属连词（引导原因状语从句），**不能和** `so` **同时使用**！
```
× Because he was late, so he missed the meeting.  ← 错误！because 和 so 不能同时出现
✓ Because he was late, he missed the meeting.
✓ He was late, so he missed the meeting.
```

### 4. 表"选择"

| 连词 | 用法 | 例句 |
|------|------|------|
| or | 否则 | `Study hard, or you'll fail.` |
| either...or | 要么...要么 | `Either you or I am wrong.` |
| neither...nor | 既不...也不（表"都不"） | `Neither rain nor snow can stop us.` |
| whether...or | 是...还是（后接名词/动名词） | `Whether you like it or not, we will go.` |

## 三、写作中容易混淆的连词

### because / so 不可共用

```
错误：Because I was tired, so I went to bed.
正确：Because I was tired, I went to bed.   ← because 表"因"
正确：I was tired, so I went to bed.        ← so 表"果"
```

### although / but 不可共用

```
错误：Although he is rich, but he is not happy.
正确：Although he is rich, he is not happy.
正确：He is rich, but he is not happy.
```

**口诀：**
> "although / because 走一边，but / so 不能同时现。"

### so...that 与 so 的区别

- `so...that`（如此...以至于）：从属连词，引导结果状语从句
- `so`（因此）：并列连词，连接两个独立句子

```
① He is so tired that he can't walk.       ← so...that 引导结果状从
② He is tired, so he can't walk.           ← so 连接并列句
```

## 四、并列句的考点分析

### 考点 1：写作中的应用

#### A. 同义替换练习

> **同一个意思，换不同连词表达**

**主题：学习英语的重要性**

| 连词类型 | 表达方式 |
|---------|---------|
| 顺承 | `English is useful, and it helps in many careers.` |
| 递进 | `English is not only useful but also essential in modern life.` |
| 转折 | `English is difficult, yet it is worth learning.` |
| 因果 | `English is essential, so we must master it.` |
| 选择 | `Either learn English well, or fall behind in the global era.` |

#### B. 汉译英——并列连词选择

**练习示例：**

| 中文 | 分析 | 推荐连词 |
|------|------|---------|
| 天空没有痕迹，但是鸟儿已经飞过。 | 转折关系 | but / yet |
| 平常的人用热闹填补空虚，优秀的人则独处成就自己。 | 对比/转折 | yet / while / whereas |
| 做错事才能长见识，所以人生应当做错一些事情。 | 因果 | so |
| 人们都在人生的苦难中挣扎。有些浴火重生，有些却粉身碎骨。 | 转折 + 对比 | while + by contrast |
| 这幅画引人深思，它描绘了当今社会的一种普遍现象。 | 递进 | and |

#### C. 翻译策略

**两种翻译方法：**

| 方法 | 说明 |
|------|------|
| 方法 1 | 用并列连词（and / but / so）连接，构成并列句 |
| 方法 2 | 分成两个独立的句子，用介词短语（in contrast / by contrast / so / while）或副词表达逻辑 |

### 考点 2：长难句分析中的应用

#### 找并列连词的步骤

```
第一步：找谓语动词（确定有几个分句）
第二步：找并列连词（and / or / but / so / yet...）
第三步：分析并列连词前后结构是否平行（重要考点）
```

#### 并列结构平行性

**核心规则：并列连词前后的语法成分必须对等。**

```
× He likes reading and to swim.           ← reading(动名) + to swim(不定式) 不平行
✓ He likes reading and swimming.          ← 都是动名词
✓ He likes to read and to swim.           ← 都不定式
```

#### 真实例题分析（1995 年阅读第三篇）

```
原文：As families move away from their stable community, their friends of many years, 
and their extended family relationships, the informal flow of information is cut off, 
and with it the confidence that information will be available when needed 
and will be trustworthy and reliable.
```

**两步走分析：**

```
第一步：找谓语
- move（从句谓语，As 引导）
- is cut off（主句谓语）
- will be available（that 从句谓语）
- will be（that 从句谓语，trustworthy 省略）

第二步：找并列连词
共 4 个 and：
1. friends and extended family relationships（并列名词）
2. cut off and (with it the confidence...)
3. will be available and (will be) trustworthy
4. that information...and (that information) will be trustworthy

剥修饰、定主干：
主句主干：the informal flow of information is cut off
              ↑名词+定语↑            ↑谓语↑
```

## 五、并列结构的翻译要点

### "拆与连"原则

| 情况 | 处理 |
|------|------|
| 两个分句逻辑强相关 | 用 and / but / so 等并列连词连接 |
| 两个分句逻辑较弱或句子较长 | 拆成两句，用副词 / 介词短语过渡 |

**示例对比：**

| 原文 | 并列连词版 | 拆句版 |
|------|----------|--------|
| 平常的人用热闹填补空虚，优秀的人则独处成就自己 | Ordinary persons fill the void with excitement, yet these excellent ones accomplish themselves by solitude. | Ordinary persons fill the void with excitement. By contrast, these excellent ones accomplish themselves by solitude. |

## 六、本章核心总结

### 4 大并列关系速记

```
顺承：and / not only...but also
转折：but / yet / while / whereas  → 不能与 although 同现
因果：so / for / therefore         → 不能与 because 同现
选择：or / either...or / whether...or
```

### 写作必背并列连词替换清单

| 关系 | 不要只会说 | 高级替换 |
|------|----------|---------|
| 顺承 | and | furthermore, moreover, in addition |
| 转折 | but | however, nevertheless, on the contrary |
| 因果 | so | therefore, consequently, as a result |
| 强调 | also | in addition, additionally |

### 最关键的"刘晓艳提醒"

> "并列连词前后一定要**结构对等**，这是考研最常考的考点之一。很多同学写错句子就是因为并列结构不平衡。"

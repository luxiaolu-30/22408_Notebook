# 第三章 从句首秀——名词（短语）和名词性从句

> **本章目标**：理解名词（短语）的功能，掌握名词性从句的四种类型（主语、宾语、表语、同位语），能够在长难句分析中准确识别它们。

---

## 一、名词（短语）能作什么成分

### 6 大成分

| 成分 | 能否由名词（短语）充当 | 例句 |
|------|----------------------|------|
| 主语 | ✓ | `The book is interesting.` |
| 宾语 | ✓ | `I love this book.` |
| 表语 | ✓ | `He is a teacher.` |
| 定语 | ✓（用 of 连接） | `The cover of the book is red.` |
| 状语 | ✓（用介词 + 名词） | `I will go on Sunday.` |
| 同位语 | ✓ | `Mr. Smith, our teacher, is kind.` |

**核心口诀：名词是六项全能选手，什么成分都能当！**

### 本节核心收获

> 理解了名词（短语）能作什么成分，就能理解名词性从句为什么也能作这些成分——**名词性从句本质上就是一个"长名词"**。

---

## 二、同位语

### 什么是同位语

**同位语 = 解释、说明名词（短语）的成分**，与被修饰名词的位置、内容对等。

例：
```
My teacher, Mr. Wang, is very kind.
       ↑主语↑  ↑同位语↑
（同位语 Mr. Wang 解释说明 teacher 是谁）
```

### 什么可以作同位语

| 同位语类型 | 例句 |
|-----------|------|
| 名词 | `Beijing, the capital of China, is large.` |
| 代词 | `We both like music.` |
| 形容词 | `The people, young and old, gathered there.` |
| 短语 | `The idea, to travel around the world, excited us.` |
| 从句（**重点**）| `The news that he won the game excited everyone.` |

**抽象名词常接同位语从句：**
- fact, idea, news, belief, hope, suggestion, assumption, conclusion, evidence, thought, etc.

### 同位语在写作中的应用

#### 应用 1：添加同位语增强表达力

**原文：**
```
Beijing is a beautiful city.
```

**升级：**
```
Beijing, the capital of China, is a beautiful city.
```

#### 应用 2：用同位语避免重复

**原文：**
```
My friend is from Japan. My friend speaks Japanese.
```

**升级（用同位语指代）：**
```
My friend, who is from Japan, speaks Japanese.
（who is from Japan 是 my friend 的同位语从句）
```

#### 应用 3：抽象名词 + 同位语从句（高分句型）

例：
```
The fact that English is widely used worldwide makes learning it essential.
↑主语↑          ↑同位语从句（解释 fact）↑
```

## 三、什么是名词性从句

### 名词性从句的本质

> **名词性从句 = 在复合句中起名词作用的主谓结构**。

也就是说，名词能做的成分，名词性从句都能做——主语、宾语、表语、同位语。

### 4 种名词性从句一览

| 类型 | 功能 | 例句 |
|------|------|------|
| 主语从句 | 作主语 | `What he said is true.` |
| 宾语从句 | 作宾语 | `I believe that he is honest.` |
| 表语从句 | 作表语 | `The question is whether we can finish.` |
| 同位语从句 | 解释抽象名词 | `The news that he won the game is exciting.` |

### 名词性从句的引导词

| 引导词 | 含义 |
|--------|------|
| that | 无意义，只起引导作用 |
| whether / if | 是否 |
| what | 什么（what = the thing(s) which） |
| who / whom / whose | 谁 |
| which | 哪个 |
| when / where / why / how | 时间/地点/原因/方式 |

---

## 四、主语从句

### 公式

**主语从句 = 连接词 + 完整句子**

```
What he said is true.    （What he said 整个作主语）
Whether he will come is uncertain.
Who will go is not important.
```

### 写作应用：it 作形式主语

**当主语从句较长时，用 `it` 替代主语，把从句后置，避免头重脚轻。**

#### 五大常见 it 形式主语句型

| 句型 | 例句 |
|------|------|
| It is + adj + that... | `It is obvious that he is lying.` |
| It is + n + that... | `It is a fact that English is global.` |
| It + vi + that... | `It seems that he is right.` |
| It + be + past participle + that... | `It is said that... / It is believed that...` |
| It + be + adj + for/of sb to do | `It is important for us to learn English.` |

**翻译技巧**：
- 中文"我们应该学英语" → 英文 "It is important for us to learn English."

#### 同义替换（同义句型转换）

```
① It is important to learn English.（主语不定式）
② It is important that we (should) learn English.（虚拟语气）
③ Learning English is important.（动名词主语）
④ We should learn English, which is important.（定语从句）
```

## 五、宾语从句

### 公式

**宾语从句 = 主句 + 连接词 + 完整句子**

```
I believe that he is honest.
      ↑  ↑that 从句↑
I wonder whether he will come.
I don't know what he said.
I asked him when he would arrive.
```

### 宾语从句的注意点

#### A. 否定前置

主句谓语为 think / believe / suppose / expect 等，若从句为否定，否定要前置到主句：

```
× I think he is not honest.
✓ I don't think he is honest.    ← 否定前置
```

#### B. 时态呼应

主句谓语为过去时，从句谓语也要相应地"往过去推"：

| 主句时态 | 从句时态对应 |
|---------|-------------|
| 一般现在时 | 任何时态 |
| 一般过去时 | 过去时范畴（过去/过去完成/过去将来） |

```
He says (that) he is happy.        → 现在时可保留
He said (that) he was happy.       → 从句用过去时
He said (that) he had finished.    → "过去的过去"

"穿越原则：主句过去→从句只能'更过去'，不能'穿越到未来'"
```

#### C. whether / if 区别

| 引导词 | 用法 |
|--------|------|
| whether | 通用，可用于所有情况 |
| if | 仅限于"是否"含义，**不能用于句首**、**不能用于介词后** |

```
Whether he will come is unknown.   ← ✓ 句首必须用 whether
I wonder whether/if he will come.  ← ✓ 宾从中都可以
The question of whether...         ← ✓ 介词后必须用 whether
```

## 六、表语从句

### 公式

**表语从句 = 系动词 + 连接词 + 完整句子**

```
The question is whether we can finish on time.
              ↑表语从句↑
The problem is that we don't have enough money.
His suggestion is that we should start early.
```

### 写作应用：用来总结、归纳

> 表语从句非常适合"换一种方式表达同一个意思"，写作中可以用作亮点句型。

| 主题 | 用表语从句总结 |
|------|--------------|
| 学英语 | The reason is that English is a global language. |
| 学语法 | The truth is that grammar is the backbone of English. |
| 学习方法 | The key is that you must keep practicing. |

## 七、同位语从句

### 与定语从句的区别（最易混淆）

| 特征 | 同位语从句 | 定语从句 |
|------|-----------|---------|
| 功能 | 解释名词的具体内容 | 修饰限定名词（确定是"哪个"） |
| 引导词 | that（无意义，不可替换） | 关系词（在从句中作成分） |
| 能否去掉 | 去掉后意思不完整 | 去掉后意思仍成立 |
| 先行词 | 抽象名词 | 各种名词 |

**例子对比：**
```
① The news that he won the game is true.    ← 同位语（解释 news 的内容）
② The news that he told us is true.         ← 定语（修饰 news，that 作 told 的宾语）

判定方法：
- 同位语：从句是完整句子（that 无意义）
- 定语：从句缺成分，that 在从句中作宾语
```

### 同位语从句的引导词

- **that**（最常见，无意义）
- **whether**（较少见）
- **疑问词**（较少见）

### 抽象名词清单（常接同位语从句）

| 类别 | 抽象名词 |
|------|---------|
| 信念类 | belief, fact, idea, hope, suggestion, thought, view |
| 信息类 | news, evidence, proof, conclusion, assumption |
| 状态类 | possibility, likelihood, chance, doubt |

例：
```
① The fact that he failed surprised us.   ← fact
② I have no idea when he will arrive.      ← idea
③ The news that the plane crashed shocked everyone.   ← news
④ There is no doubt that he will succeed.  ← doubt
```

## 八、名词性从句的考点分析

### 考点 1：写作中的应用

#### 句型模板（必须掌握）

| 句型 | 模板 |
|------|------|
| 主语从句 | `What surprises me most is that...` |
| 宾语从句 | `I firmly believe that...` |
| 表语从句 | `The reason is that...` |
| 同位语从句 | `The fact that... shows that...` |

#### 高分句型：it 形式主语

```
① It is universally acknowledged that...
② It is worth noting that...
③ It is high time that we should...
④ It is no exaggeration to say that...
```

### 考点 2：长难句分析中的应用

#### 关键识别步骤

```
第一步：找全句的谓语动词
第二步：找所有连词（that / whether / what / who...）
第三步：判断每个 that/whether/what 引导的是什么从句
       - that 无意义：可能是同位语从句或 that 引导的宾从/主从/表从
       - whether 表"是否"
       - what 表"什么"（what = the thing which）
第四步：确定主句主干
```

#### 真实例题分析（2008 年翻译第 4 题）

```
原文：He asserted, also, that his power to follow a long and purely abstract train 
of thought was very limited, for which reason he felt certain that he never 
could have succeeded with mathematics.
```

**结构分析：**
```
- 主句：He asserted that..., 主谓宾结构
- that 引导的宾语从句：that his power to follow... was very limited
  └ power 后接不定式 to follow... 作后置定语
- for which... 非限制性定语从句，修饰前面整句话
  └ which = for the reason
- that he never could... 嵌套的 that 宾语从句（felt certain 后接）
```

**主干：He asserted that...**

#### 真实例题分析（2021 年英二阅读第一篇）

```
原文：Successive governments have permitted such increases on the grounds 
that the cost of investing in and running the rail network should be 
borne by those who use it, rather than the general taxpayer.
```

**结构分析：**
```
- 主句：Successive governments have permitted such increases
- on the grounds that... 原因状语从句（grounds 是抽象名词，后接同位语从句 that...）
- 介词短语：of investing in and running the rail network 作 cost 的后置定语
- 定语从句：who use it 修饰 those
```

**主干：Successive governments have permitted such increases**

## 九、本章核心总结

### 名词性从句 4 大类口诀

```
主语从句：What he said is...         （What he said = 主语）
宾语从句：I believe that he is...     （that he is... = 宾语）
表语从句：The reason is that...       （that... = 表语）
同位语从句：The fact that... shows... （抽象名词 + that 解释）
```

### 关键判断技巧

| 引导词 | 用途 |
|--------|------|
| that | 无意义，看上下文 |
| whether / if | 是否（if 不能用于句首） |
| what | 什么（本身在从句中作成分） |
| when / where / why / how | 时间/地点/原因/方式 |
| who / whom / whose | 谁 |

### 同位语从句识别"两问"

1. 它前面是抽象名词吗？
2. 它能用 that 替代别的连词吗？不能 → 是同位语；能 → 可能是定语从句

### 最关键的"刘晓艳提醒"

> "区分同位语从句与定语从句，关键看从句是否缺少成分。同位语从句是完整句子，that 无意义；定语从句 that 在从句中作成分，去掉后意思仍然成立。"

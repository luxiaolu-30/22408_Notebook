# 第一章 奋斗的开始——简单句

> **本章目标**：理解句子的最小结构单位——简单句，掌握 5 大基本句型、简单句成分、动词分类、时态与语态。这是整个英语语法体系的基石。

---

## 一、汉英句子比较

### 中文 vs 英文的核心差异

| 中文 | 英文 |
|------|------|
| 意合语言，逻辑藏在文字背后 | 形合语言，逻辑必须显性表达 |
| "我吃饭" → 3 字，没有时态 | 英文必须明示时态（I eat / ate / will eat） |
| 顺序灵活 | 主谓宾的顺序相对固定 |
| 一个句子可以"流水账" | 必须有谓语动词 |

**举例对比：**

| 中文 | 英文 |
|------|------|
| 我爱学习 | I love studying |
| 这本书是我的 | This book is mine |
| 他给了我一支笔 | He gave me a pen（双宾语） |

---

## 二、英文句子的基本结构

### 5 大基本句型（重中之重）

| 句型 | 公式 | 简称 | 例句 |
|------|------|------|------|
| 1 | 主语 + 谓语 | S + V | Birds fly. |
| 2 | 主语 + 谓语 + 宾语 | S + V + O | I love English. |
| 3 | 主语 + 谓语 + 间接宾语 + 直接宾语 | S + V + IO + DO | He teaches us English. |
| 4 | 主语 + 谓语 + 宾语 + 宾语补足语 | S + V + O + OC | We keep the door open. |
| 5 | 主语 + 系动词 + 表语 | S + V + P | She is beautiful. |

### 实义动词 vs 系动词（句型辨别）

**辨别方法：看动词在句中是否有实义（动作）。**

```
① Trees don't grow in the Antarctic.          ← grow 是实义动词（S+V）
② My younger brother is growing tall.         ← grow 是系动词（S+V+P）
③ The house has kept clean for years.         ← keep 是系动词
④ I have kept the dog for 5 years.            ← keep 是实义动词
```

**系动词的 6 大类型：**

| 类型 | 例词 |
|------|------|
| 表状态 | be（最常见） |
| 表感官 | look, sound, taste, smell, feel |
| 表变化 | grow, fall, turn, get, become |
| 表保持 | stand, keep, stay, remain |
| 表表象 | seem, appear |
| 表结果 | prove |

**感官动词陷阱**：感官动词后只能接形容词（不能接副词）。
```
× It feels softly.
✓ It feels soft.
```

### 双宾语动词记忆

**常见双宾语动词（带"人"+"物"两个宾语）：**
- buy, pass, lend, give, tell, teach, show, bring, send
- 也称"双宾动词"

例：
```
① He teaches us English.（us = IO, English = DO）
② He bought me a birthday gift.
```

### 宾语补足语 vs 双宾语（容易混淆）

- **宾语补足语**：补充说明宾语的状态、身份
  - `We should keep the door open.` （宾补 open 补充说明"门"的状态）
- **双宾语**：两个宾语各自完整
  - `He gave me some sugar.` （me = 间接，some sugar = 直接）

## 三、简单句的成分

### 4 大核心成分

| 成分 | 定义 | 充当方式 |
|------|------|----------|
| **谓语** | 描述主语的动作或状态 | 动词（词组） |
| **主语** | 动作的发出者 | 名词、代词、不定式、动名词、主语从句 |
| **宾语** | 动作的承受者 | 名词、代词、不定式、动名词、宾语从句 |
| **表语** | 说明主语的身份、状态、特征 | 形容词、名词、介词短语、不定式、分词 |

### 关键规则：谓语的唯一性

> **一个简单句中只能有一个谓语动词。**

#### 核心规则总结

```
① 一个简单句中可出现多个动词（词组），但只能保留一个动词（词组）作谓语，多余的动词必须转化成其他形式；
② 谓语只能由动词（词组）来充当；
③ 动词（词组）不可以直接用来作句子的主语、宾语或表语。
```

### "非谓语动词"——多余的动词的去处

**非谓语动词的三种形式：**

| 形式 | 含义 | 主动/被动 | 时态 |
|------|------|----------|------|
| doing（现在分词/动名词） | 进行、习惯、主动 | 主动居多数 | 进行/一般 |
| done（过去分词） | 完成、被动 | 被动居多数 | 完成 |
| to do（不定式） | 目的、将来 | 主动、目的、具体动作 | 将来/目的 |

### 非谓语动词的常见用法

#### A. 作主语

| 形式 | 例句（错→对） |
|------|--------------|
| 不定式 | `To finish the work by yourself is very hard.` → `It is very hard to finish the work by yourself.` |
| 动名词 | `Doing nothing is my habit.`（动名词 Doing nothing 作主语） |

#### B. 作表语

```
① Her job is to teach math.                ← 不定式
② Her dream is to be rich.                 ← 不定式
③ The news is disturbing.                  ← 现在分词（说明特征）
```

#### C. 作宾语

```
① I enjoy playing tennis.                 ← 动名词
② My dream is to pass the exam.            ← 事实用动名词，将来用不定式
③ I want to be a successful man.           ← 不定式
```

#### D. 作宾语补足语

```
① His father told him to make friends carefully.  ← 不定式短语
② I had my hair cut yesterday.                    ← 过去分词 cut（被动）
③ I found the book interesting.                   ← 现在分词 interesting
```

#### E. 作定语

```
① the man standing there（现在分词，主动、进行）
② the book written by Lu Xun（过去分词，被动、完成）
③ the way to solve the problem（不定式，将来）
```

#### F. 作状语

| 类型 | 例句 |
|------|------|
| 时间 | `Walking in the street, I met Tom.` |
| 原因 | `Being ill, he stayed at home.` |
| 伴随 | `He sat there, reading a book.` |
| 结果 | `He worked hard, only to fail.` |

## 四、动词的分类、时态和语态

### 1. 动词的分类

| 类别 | 说明 | 例词 |
|------|------|------|
| 实义动词 | 有完整动作含义，分及物/不及物 | eat, run, accept, agree |
| 连系动词 | 本身无实义，连接主语和表语 | be, look, become, get |
| 情态动词 | 表示情感、能力、义务、推测 | can, may, must, will, should |
| 助动词 | 帮助构成时态、语态、疑问句 | do, be, have, will |

**实义动词细分：**
- **及物动词（vt.）**：后面直接加宾语（accept the idea, buy a book）
- **不及物动词（vi.）**：后面不能直接加宾语，必须加介词（agree with you）

### 2. 动词的时态（16 种，最常用 8 种）

> **核心判断维度：时间 + 状态**

| 时态 | 公式 | 用途 |
|------|------|------|
| 一般现在时 | do / does | 习惯性动作、客观真理 |
| 一般过去时 | did | 过去发生的动作 |
| 一般将来时 | will do / be going to do | 将来发生的动作 |
| 现在进行时 | be doing | 现在正在进行的动作 |
| 过去进行时 | was/were doing | 过去某时正在进行的动作 |
| 现在完成时 | have/has done | 过去发生并影响到现在 |
| 过去完成时 | had done | "过去的过去" |
| 过去将来时 | would do | 从过去看将来 |

#### 时态典型考题（现在完成时）

**用法 1：动作发生在过去，结果影响到现在**
```
① I have already finished my homework.   ← 已完成
② Li Ming hasn't handed in his homework yet.
```

**用法 2：从过去某时持续到现在的动作，常用延续性动词**
```
③ I have lived in Beijing for 5 years.
```

**时态标志词**：
- 现在完成时：already, yet, just, ever, never, recently, for+段时间, since+起点
- 过去完成时：by + 过去时间, by the time + 从句

### 3. 动词的语态

**被动语态公式：be + 过去分词（done）**

| 时态 | 主动 | 被动 |
|------|------|------|
| 一般现在时 | do | am/is/are done |
| 一般过去时 | did | was/were done |
| 一般将来时 | will do | will be done |
| 现在完成时 | have done | have been done |
| 情态动词 | can do | can be done |

**被动语态使用场景：**
- 动作承受者不明或不重要：`The window was broken.`
- 强调承受者：`The book was written by Lu Xun.`
- 客观陈述：`It is said that... / It is believed that...`

## 五、简单句的考点分析

### 考点 1：写作中的应用

**核心原则：**
1. **简单句并不简单**——能写出精确的简单句是写作的基本功
2. **不要为了"长"而生造长句**——错误的长句不如准确的简单句
3. **长短结合，有张有弛**

**实操技巧：**

| 问题 | 解决 |
|------|------|
| 写作中遇到不会写的单词 | 用解释或近义词替代 |
| 想写长难句但写不出来 | 用准确的简单句写，写作不是比谁写得更长 |
| 写作中表达同一个意思 | 多种方式切换，展示语言多样性 |

### 考点 2：长难句分析中的应用（核心）

> 长难句的最小单位就是简单句。掌握简单句是分析长难句的前提。

**两步走方法：**

1. **找谓语动词**——确定有几个分句
2. **找主干**——剥掉所有修饰，确定主谓宾 / 主系表

#### 主语位置的"化妆"——主语前的修饰

**主语前面可有**：定语 / 同位语 / 状语

```
[When we are having English class], they, [a group of vigorous university students], [who like various kinds of challenges], are singing songs.
       ↑ 状语              ↑ 同位语               ↑ 定语从句                ↑ 谓语
```

**特点**：主语前从右往左看，每个修饰成分都修饰它右边的名词，直到遇到谓语。

#### 宾语位置的"化妆"——宾语后的修饰

**宾语后面可有**：定语 / 同位语 / 状语

```
I enjoy reading books [which are beneficial to our mental and physical health] [whenever I am free].
            ↑ 宾语       ↑ 定语从句                              ↑ 状语从句
```

## 六、本章核心总结

### 一句话浓缩本章

> **简单句是英语语法的基石，谓语是句子的核心，掌握谓语的唯一性、动词的时态和语态，就能写出准确、通顺的句子。**

### 关键记忆口诀

```
简单句五型：
主谓、主谓宾、主谓宾宾、主谓宾补、主系表。

简单句只能一个谓语，
多余动词三选一：
doing(主动进行)、done(被动完成)、to do(目的将来)。
```

### 最重要的"刘晓艳提醒"

> "写作不需要每句话都加上修饰成分，这样句子太长，老师读起来也很费力。我们要做到有长句也有短句，长短结合，有张有弛。"

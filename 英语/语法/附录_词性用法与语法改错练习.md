# 附录 词性用法与语法改错练习

> **附录定位**：第一部分是词性用法速查（名词、限定词、形容词、副词、动词、代词、介词）；第二部分是语法改错练习（6 篇考生作文实战批改）。是全书的工具书附录。

## 第一部分 词性用法

### 一、名词 (Nouns)

#### 1. 名词的分类

| 类别 | 含义 | 例 |
|------|------|----|
| **专有名词** | 人名、地名、机构名 | China, Beijing, Tom |
| **普通名词** | 泛指 | book, water, idea |

#### 2. 普通名词细分

| 类别 | 含义 | 例 |
|------|------|----|
| **可数名词** | 可用数数 | book, apple, idea |
| **不可数名词** | 不能数数 | water, information, advice |

#### 3. 名词的数

| 单数变复数 | 规则 | 例 |
|-----------|------|----|
| 一般 + s | cat → cats |
| s/x/ch/sh + es | box → boxes |
| 辅音 + y 变 ies | family → families |
| f/fe 变 ves | knife → knives |
| 不规则变化 | man → men, child → children |

#### 4. 名词的所有格

| 形式 | 规则 | 例 |
|------|------|----|
| 's | 单数名词后 | Tom's book |
| s' | 复数名词后（含 s）| the boys' room |
| of + 名词 | 无生命名词 | the cover of the book |

### 二、限定词 (Determiners)

#### 限定词分类

| 类别 | 含义 | 例 |
|------|------|----|
| **冠词** | a/an, the | a book, the book |
| **指示限定词** | this, that, these, those | this book |
| **物主限定词** | my, your, his, her, our, their | my book |
| **数词** | one, two, first, second | one book, the first book |
| **数量限定词** | some, any, no, few, many, much | some books, many books |
| **疑问限定词** | which, what | which book |

#### 限定词使用顺序（多个限定词连用）

**口诀：限定词顺序 = 限定词 + 数词 + 形容词 + 名词**

| 顺序 | 类别 | 例 |
|------|------|----|
| 1 | 前位限定词（all, both, half） | all |
| 2 | 中位限定词（冠词、物主、指示、疑问） | the |
| 3 | 后位限定词（数词 + 形容词） | first |
| 4 | 名词 | chapter |

```
例：all the first three chapters
```

### 三、形容词 (Adjectives)

#### 形容词的用法

| 用法 | 例 |
|------|----|
| **定语**（前置） | `a beautiful flower` |
| **表语**（系动词后） | `The flower is beautiful.` |
| **宾语补足语** | `I find the flower beautiful.` |
| **状语** | `He returned home, hungry and tired.` |

#### 形容词的顺序（多个形容词连用）

**口诀：限定 + 数量 + 性质 + 大小 + 颜色 + 来源 + 物质 + 用途 + 名词**

例：
```
a small red Chinese silk dress
   ↑大小↑颜色↑来源↑物质↑用途↑
```

#### -ing 形容词 vs -ed 形容词

| -ing 形容词 | -ed 形容词 |
|------------|----------|
| 主语通常是动作发出者 | 主语通常是动作承受者 |
| `an interesting book`（书引起兴趣） | `an interested reader`（读者有兴趣） |
| `a boring class`（课令人无聊） | `a bored student`（学生无聊） |

### 四、副词 (Adverbs)

#### 副词的种类

| 类别 | 例 |
|------|----|
| 时间副词 | now, then, today, yesterday |
| 地点副词 | here, there, above, below |
| 方式副词 | quickly, slowly, carefully |
| 程度副词 | very, quite, rather, almost |
| 频率副词 | always, often, sometimes, never |
| 疑问副词 | when, where, why, how |
| 关系副词 | when, where, why |
| 连接副词 | therefore, however, otherwise |

#### 副词位置

| 副词类型 | 位置 |
|---------|------|
| 频率副词（always, often） | 一般动词前，be 动词后 |
| 方式副词 | 动词后（宾语前/后）|
| 时间副词 | 句首或句末 |

#### 易混淆的形容词和副词

| 形容词 | 副词 |
|--------|------|
| hard（努力地、硬的）| hardly（几乎不）|
| late（迟的）| lately（最近）|
| near（近的）| nearly（几乎）|
| high（高的）| highly（高度地）|
| most（大多数的）| mostly（主要地）|

### 五、动词 (Verbs)

#### 动词分类速查

| 类别 | 说明 |
|------|------|
| 实义动词 | 有完整含义，分及物（vt.）/不及物（vi.） |
| 连系动词 | be, look, sound, taste, smell, feel, become, get, turn, grow, keep, stay, remain, seem, appear, prove |
| 情态动词 | can, may, must, should, will, could, might, would |
| 助动词 | do, be, have, will |

#### 短语动词

| 类型 | 例 |
|------|----|
| 动词 + 介词 | look at, look for, look after |
| 动词 + 副词 | put on, take off, look up |
| 动词 + 副词 + 介词 | get along with, look forward to |

#### 常见易混动词

| 动词 | 含义区分 |
|------|---------|
| lie / lay | lie-lay-lain（躺，位于） / lay-laid-laid（放置，产卵） |
| rise / raise | rise-rose-risen（升起） / raise-raised-raised（举起） |
| sit / seat | sit-sat-sat（坐） / seat-seated-seated（使...就座） |
| hang | hang-hanged-hanged（绞死） / hang-hung-hung（悬挂）|

### 六、代词 (Pronouns)

#### 代词分类

| 类别 | 含义 | 例 |
|------|------|----|
| 人称代词 | I/me, you, he/him, she/her, it, we/us, they/them |
| 物主代词 | my/mine, your/yours, his, her/hers, its, our/ours, their/theirs |
| 反身代词 | myself, yourself, himself, herself, itself, ourselves, yourselves, themselves |
| 相互代词 | each other, one another |
| 指示代词 | this, that, these, those |
| 不定代词 | some/any, somebody/anybody, something/anything, one, none |
| 疑问代词 | who, whom, whose, what, which |
| 关系代词 | who, whom, whose, which, that |

#### 不定代词的考点

| 不定代词 | 用法 |
|---------|------|
| some | 肯定句（我希望有）|
| any | 否定/疑问/条件句（我不指望）|
| one | 替代可数名词 |
| that | 替代不可数名词 / 替代特指名词 |

#### it 的特殊用法

| 用法 | 例 |
|------|----|
| 形式主语 | `It is important to...` |
| 形式宾语 | `I find it hard to...` |
| 强调句 | `It is...that...` |
| 替代 | `It is raining.` |

### 七、介词 (Prepositions)

#### 介词分类

| 类型 | 介词 |
|------|------|
| 时间介词 | at, in, on, before, after, during, until, by, since |
| 地点介词 | in, on, at, above, below, under, over, between, among |
| 方向介词 | to, from, into, onto, out of |
| 方式介词 | by, with, in |
| 原因介词 | because of, due to, owing to |
| 目的介词 | for, to |

#### 常见介词短语

| 介词短语 | 例 |
|---------|----|
| in addition to | 除...之外 |
| in spite of | 尽管 |
| in favor of | 支持 |
| with regard to | 关于 |
| in terms of | 在...方面 |
| regardless of | 不顾 |
| on behalf of | 代表 |
| in charge of | 负责 |

#### 重点介词辨析

| 易混点 | 辨析 |
|--------|------|
| in / into | in（在内部） / into（进入）|
| on / onto | on（在上面） / onto（到上面）|
| above / over | above（高于） / over（正上方） |
| below / under | below（低于） / under（正下方） |
| between / among | between（两者之间） / among（三者及以上）|
| by / until | by（截止到） / until（直到） |

## 第二部分 语法改错练习

### 6 篇考生作文实战批改

> 本部分精选 6 篇考生作文，由刘晓艳老师亲自批改，演示常见语法错误。

#### 作文 1："Jobs for Graduates"

**常见错误：**
1. 时态混用（全文现在时+某一段突然过去时）
2. 主谓不一致（单数主语配复数谓语）
3. 介词搭配错误（interested in 而不是 interested to）
4. 词性误用（动词当名词用）

#### 作文 2："Occupying the Seat"

**常见错误：**
1. 动名词作主语的位置错误
2. 句子成分缺失（缺宾语、缺主语）
3. 并列结构不平衡
4. 关系词选择错误

#### 作文 3："Reading Selectively or Extensively"

**常见错误：**
1. 主从时态不一致
2. 状语从句使用错误
3. 形容词/副词混用
4. 单复数错误

#### 作文 4："Reading Classics"

**常见错误：**
1. 限定词多余或缺失
2. 否定词位置错误
3. 被动语态使用错误
4. 不定式与动名词选择错误

#### 作文 5："Travelling Abroad"

**常见错误：**
1. 同位语/定语混淆
2. 强调句识别错误
3. 倒装句使用错误
4. 主语从句结构混乱

#### 作文 6："Reading"

**常见错误：**
1. 名词性从句引导词选择错误
2. 同位语从句与定语从句混淆
3. 状语从句时态错误
4. 虚拟语气使用错误

### 改错练习的总体建议

#### 写作常见错误 10 大类

| 排名 | 错误类型 | 举例 |
|------|---------|------|
| 1 | 主谓不一致 | `He go to school.` → `He goes.` |
| 2 | 时态混用 | 全文用现在时，突然转过去时 |
| 3 | 句子不完整 | 缺主语或谓语 |
| 4 | 主从时态错位 | 主句过去，从句却用现在时 |
| 5 | 介词搭配错 | `interested to` → `interested in` |
| 6 | 形容词/副词混用 | `He runs quick.` → `He runs quickly.` |
| 7 | 并列不平衡 | `He likes reading and to swim.` |
| 8 | 关系词错填 | `the man which...` → `the man who...` |
| 9 | 单复数错 | `a book and a apple` → `a book and an apple` |
| 10 | 动词形式错 | `He have done.` → `He has done.` |

## 本附录核心总结

### 7 大词性速记

```
名词 n. — 名称、抽象、具体
限定词 det. — 限定名词（冠词、物主、指示、数词）
形容词 adj. — 描述名词特征
副词 adv. — 修饰动词/形容词/句子
动词 v. — 动作或状态
代词 pron. — 替代名词
介词 prep. — 表示关系
```

### 语法改错核心思路

```
1. 找谓语 → 看时态是否统一
2. 找主语 → 看主谓是否一致
3. 找连词 → 看主从是否对应、并列是否对等
4. 找修饰 → 看形容词/副词、介词搭配
5. 找名词 → 看单复数、所有格是否正确
```

### 写作中最重要的提醒

> **写作不是写作文，是写句子。**
> **每一个句子都要有完整的"主谓宾/主系表"结构。**
> **不要为了写长句而生造从句——错误的长句不如准确的简单句。**

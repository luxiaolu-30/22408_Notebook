# 第四章 考研英语命穴——定语和定语从句

> **本章地位**：刘晓艳老师把定语和定语从句称为"考研英语命穴"——考试中考查频率最高、难度最大的一章。
> **本章目标**：彻底搞懂定语、定语成分、关系词的区分与选择，能够分析任何复杂的定语从句。

---

## 一、定语概述

### 什么是定语

**定语 = 修饰、限定名词（短语）的成分**

例：
- `a red book`（形容词定语）
- `the book on the desk`（介词短语定语）
- `the book that I bought yesterday`（从句定语）

### 定语的位置

| 位置 | 形式 | 例 |
|------|------|----|
| 前置 | 单词定语（形容词/名词/代词/分词） | `a beautiful girl` |
| 后置 | 短语定语、从句定语 | `the girl in red` / `the girl who is singing` |

### 定语的"嵌入方式"

> 定语一般从名词（短语）后开始，**到主句的谓语动词之前结束**。
> 如果主句的谓语出现在定语前面，定语通常到句末结束。
> 翻译时**从最后一个定语往前翻**。

例：
```
I love Tiechui who comes from Henan province with a large population.
       ↑ 定语从句开始   ↑结束↑
```

## 二、定语的成分

### 4 大定语形式

| 形式 | 举例 | 补充说明 |
|------|------|---------|
| **形容词（短语）** | `a beautiful girl` | 前置，简单 |
| **介词短语** | `the book on the desk` | 后置，表意强 |
| **非谓语动词短语** | `the man standing there / the book written by Lu Xun / the way to solve` | doing（主动进行）/ done（被动完成）/ to do（目的将来） |
| **从句（定语从句）** | `the book (which/that) I bought` | 最复杂，最重要 |

### 非谓语动词作定语（高频考点）

| 形式 | 含义 | 例 |
|------|------|----|
| doing | 主动、进行 | `the man standing there`（站着的男人，主动进行） |
| done | 被动、完成 | `the book written by Lu Xun`（鲁迅写的书，被动完成） |
| to do | 目的、将来 | `the way to solve the problem`（解决问题的方法，目的将来） |

**重要识别技巧：被修饰名词是动作的发出者 → doing；承受者 → done**
```
① the boy playing football           ← the boy 发出的动作
② the game played by the boy         ← the game 是承受者
③ the chance to succeed              ← the chance 后面是将来要发生的事
```

## 三、定语从句

### 1. 定语从句的构成

**定语从句 = 关系词 + 主谓结构（gapped/有缺成分的句子）**

```
关系词（that/which/who...）+ 不完整句子 → 修饰先行词
```

### 2. 定语从句的引导词（关系词）

#### 关系词三大类（按在从句中所作成分）

| 类别 | 关系词 | 在从句中的作用 |
|------|--------|--------------|
| **代词**（可作主/宾/表） | who, whom, that, which | 主语、宾语、表语 |
| **副词**（不作主干成分） | where, when, why | 状语 |
| **形容词**（只作定语） | whose | 定语 |

#### 各关系词详解

**① who / whom（指人）**

| 关系词 | 用法 | 例 |
|--------|------|----|
| who | 主语或宾语 | `The man who is standing there is my father.` |
| whom | 只能作宾语（口语中常省略） | `The man (whom) you met yesterday is my father.` |

**② whose（指人或物，作定语）**

```
① the man whose father is a doctor     ← 指人
② the book whose cover is red         ← 指物（whose = the book's）
```

**③ that（指人或物）**

| 用法 | 例 |
|------|----|
| 指人 | `The man that I met is Tom.` |
| 指物 | `The book that I read is great.` |
| 作主语、宾语、表语都可 | 当先行词为不定代词（all/everything/nothing/anything/much/few 等）或被最高级/序数词修饰时，**只能**用 that |

```
① All that I have is yours.    ← all 后只能用 that
② He is the best man that I've ever met.    ← 最高级后只能用 that
```

**④ which（指物，作主/宾/表）**

```
The book which I bought yesterday is interesting.
```

#### 各关系词的"错填陷阱"（考研最爱考）

```
题① I have a friend _____ is from Beijing.
      答案：who / that
      解析：从句缺主语，先行词是人，从 who/whom/that/which 中选，但 who 和 whom 均只有充当主语时的用法（whom 不作主语），所以填 who 或 that。

题② This is the house _____ I grew up.
      答案：which / that
      解析：从句缺宾语，先行词是物，从 who/whom/whose/that/which 中选，因地点词前已经存在，which/that 皆可。

题③ I might never forget the day _____ we met each other.
      答案：when
      解析：先行词是 the day（时间），从句不缺主干成分（we met 是完整的），所以填关系副词 when。

题④ I might never forget the day _____ we spent.
      答案：which / that
      解析：先行词是 the day，但从句 spent 是及物动词缺宾语，所以填关系代词 which/that。
```

### 3. 关系词选择的"两步法则"

> **第一步：看先行词是人还是物？**
> - 人 → who / whom / whose / that
> - 物 → whose / which / that
>
> **第二步：从句是否缺主干成分？**
> - 缺主语/宾语/表语 → 关系代词（who/whom/that/which）
> - 不缺主干成分 → 关系副词（where/when/why）

### 4. 限定性 vs 非限定性定语从句

| 特征 | 限定性 | 非限定性 |
|------|--------|---------|
| 逗号 | 无 | 有 |
| 是否去掉 | 不能去掉（去掉意思不完整） | 可以去掉（意思仍成立） |
| 关系词 | 全部都可用 | 不可用 that |
| that 是否可用 | ✓ | ✗（必须用 which / who / whom） |
| 翻译 | 前置法 | 拆分后置法 |

#### 真实例题分析

```
① My brother, who lives in Beijing, is a doctor.   ← 非限定，删掉也通顺
② My brother who lives in Beijing is a doctor.     ← 限定，删掉后变成"我有兄弟"，丧失唯一性
```

### 5. 特殊关系词 as

#### as 的用法（最容易失分的考点）

| 句型 | 例句 |
|------|------|
| such...as | `I have never heard such a story as he told.` |
| the same...as | `He is not the same man as he was.` |
| as 引导非限定性从句（位置灵活）| `As we all know, he is a good man.` |

**特殊位置：as 可置于句首、句中、句末**

```
① As is well known, he is a good man.        ← 句首
② He, as we all know, is a good man.          ← 句中
③ He is a good man, as we all know.           ← 句末
```

### 6. 定语从句的特殊用法

#### A. the way 作先行词时

```
Do you remember the way that he solved the problem?
                       ↑ that 可省略（the way 后习惯省略 that）
Do you remember how he solved the problem?
                     ↑ how 与 the way 引导的从句有时可互换
```

#### B. there be 结构中的定语从句

```
He is looking for a house that/which has a garden.
                            ↑ that/which 替代 house 作主语
```

#### C. 介词 + 关系代词（高级用法）

```
① the person with whom I talked    ← with whom = and talked with whom
② the house in which I live        ← in which = in the house where I live
③ the reason for which he quit     ← for which = why
```

#### D. 关系词的省略规则

| 可省略关系词的情况 | 例 |
|------------------|----|
| 关系代词作宾语 | `the book (which) I read` |
| the way 后习惯省略 that | `the way (that) he spoke` |
| 关系词前有介词 | 不可省略（which 在介词后不可省）|

## 四、定语和定语从句的考点分析

### 考点 1：写作中的应用

#### A. 用定语从句丰富表达

**原文：**
```
He is a teacher. He teaches English.
```

**升级（用定语从句合并）：**
```
He is a teacher who teaches English.
```

**再升级（叠加定语）：**
```
He is an excellent teacher who has been teaching English at our school for 10 years.
```

#### B. 用非限定性定语从句添加补充信息

```
Beijing, which is the capital of China, attracts millions of tourists every year.
    ↑同位语（解释 Beijing）
```

#### C. 用介词 + 关系代词提升写作

```
the aspect in which I am interested
= the aspect (that) I am interested in
```

### 考点 2：长难句分析中的应用

#### "两步走"分析定语从句

```
第一步：找谓语动词
第二步：找修饰（先把定语找出来）
```

#### 真实例题分析（1993 年翻译）

```
原文：You have all heard it repeated as mark so that men of science work 
by means of induction and deduction, that by the help of these operations, 
they, in a sort of sense, manage to extract from Nature certain natural laws, 
and that out of these, by some special skills of their own, they build up their theories.
```

**结构分析：**

```
第一步：找谓语
- have heard（主句谓语）
- men work（that 引导宾从的谓语）
- manage to extract（that 引导宾从的谓语）
- build up（and 并列的宾从的谓语）

第二步：找主干
主句：You have heard it repeated as mark so that...
     主  谓  形式宾语  主补
宾语 it 后接 3 个并列的 that 从句
```

#### 定语从句识别 "3 大特征"

| 特征 | 识别信号 |
|------|---------|
| 关系词 | that / which / who / whom / whose / when / where / why / as |
| 先行词 | 关系词前面有名词（短语） |
| 修饰功能 | 翻译时能变成"……的"或"作后置定语" |

#### 翻译定语从句的"两种方法"

| 方法 | 操作 | 适用场景 |
|------|------|----------|
| **前置翻译法** | 直接翻译成"……的"，放在被修饰名词之前 | 定语较短 |
| **后置翻译法（拆分）** | 把定语从句翻译成独立句子，用"他/她/它"等代词重复先行词 | 定语较长 |

**示例：**

```
原文：I love Tiechui who comes from Henan province with a large population.

前置：我喜欢来自有着很多人口的河南的铁锤。   ← 不通顺
后置：我喜欢铁锤。他来自有着很多人口的河南。← 通顺
```

#### 真题练习（1995 年阅读第三篇）

```
As families move away from their stable community, their friends of many years, 
and their extended family relationships, the informal flow of information 
is cut off, and (with it the confidence that information will be available 
when needed and will be trustworthy and reliable).
```

**分析过程：**
```
第一步：找谓语（4 个动词）
- move（As 引导的从句）
- is cut off（主句谓语）
- will be available（嵌套定从的谓语）
- will be（trustworthy 省略）

第二步：找所有 and（共 4 个）
- friends and extended family relationships（名词并列）
- cut off and (with it...)
- available and (will be) trustworthy
- that information... and (that information) will be trustworthy

第三步：找定语
- of many years 修饰 their friends（介词短语后置定语）
- (that) information will be available when needed and (will be) trustworthy and reliable 修饰 the confidence
```

## 五、定语从句与同位语从句的区别（最容易混淆）

| 特征 | 定语从句 | 同位语从句 |
|------|---------|-----------|
| 从句完整性 | 从句缺成分（关系词在从句中作成分） | 从句完整（that 无意义） |
| that 是否可替换为 which | 可以 | 不可以（that 必须是无意义的） |
| 能否去掉 | 去掉后先行词所指不明 | 去掉后先行词仍有具体内容 |
| 翻译 | "……的"或拆句 | 同位语翻译 |
| 先行词 | 任何名词 | 抽象名词（idea/fact/news 等） |

```
① The news that he won the game is true.    ← 同位语（that 无意义）
② The news that he told us shocked everyone. ← 定语（that 在 told 后作宾语）
```

**判定方法**：把 that 去掉，看从句是否成立。
- ① 去掉 that：He won the game.（成立）→ 同位语
- ② 去掉 that：He told us.（缺宾语）→ 定语

## 六、本章核心总结

### 关系词选择三步法

```
第一问：先行词是人还是物？
    - 人 → who / whom / whose / that
    - 物 → whose / which / that
第二问：从句是否缺主干成分？
    - 缺主语/宾语/表语 → 关系代词
    - 完整不缺 → 关系副词（where / when / why）
第三问：是否有特殊限制？
    - 最高级/序数词/all/everything 之后 → 必用 that
    - 非限定性 → 不能用 that
    - 介词后 → 不能用 that（用 which）
```

### 关系词三类口诀

```
代词（主/宾/表）：who whom that which
副词（作状语）  ：where when why
形代（作定语）  ：whose（既指人也指物）
```

### 写作必背定语从句模板

| 模板 | 用法 |
|------|------|
| ..., which is + adj + to..., | 描述特征 |
| ..., where + 主谓, ... | 描述场景 |
| ..., who/which + 谓语, ... | 描述人物/事物 |
| ..., when + 主谓, ... | 描述时间 |
| ..., whose + 名词 + 谓语, ... | 描述所属 |

### 最关键的"刘晓艳提醒"

> "长难句分析的关键就是找修饰。找定语就找关系词，找定语结束位置；找状语就找状语从句引导词。**定语找不对，长难句分析全盘皆输**。"

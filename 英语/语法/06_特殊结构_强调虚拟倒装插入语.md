# 第六章 唱着歌儿去考研——英语的特殊结构

> **本章目标**：掌握 4 大英语特殊结构——强调句型、虚拟语气、倒装句、插入语。这些结构虽然不在真题中直接出题，但在阅读、翻译、写作中频繁出现。

---

## 一、强调句型

### 强调句型的公式

**It is/was + 被强调部分 + that + 其余部分 = 强调句**

```
原句：I met your father in this room yesterday.
强调主语：It was I that met your father...
强调宾语：It was your father that I met...
强调时间状语：It was yesterday that I met your father...
强调地点状语：It was in this room that I met your father...
```

### 判断强调句的关键

**测试方法：把"it is/was...that..."去掉，看句子是否仍然完整成立。**

```
原句：It was in this room that I was born.
去掉：in this room I was born.  ← 不通顺
→ 但是：I was born in this room.  ← 通顺
→ 这就是强调句！
```

### 强调句的注意点

| 注意点 | 说明 |
|--------|------|
| be 动词时态 | 根据原句时态调整（一般现在 → is；一般过去 → was） |
| 被强调部分 | 可以是主语、宾语、状语（不能是谓语/表语） |
| that / who | 在强调句中只起连接作用，无意义 |
| not until 强调 | 特殊形式：`It was not until...that...` |

### not until 强调句

```
原句：I didn't realize the truth until I had my own daughter.

改为强调句：
It was not until I had my own daughter that I realized the truth.
                ↑强调从句↑           ↑主句↑
```

### 与状语从句的区别

| 强调句（强调时间） | 时间状语从句 |
|------------------|------------|
| It was yesterday that I met him. | When I met him, it was yesterday. |
| It was here that I first met her. | Here is where I first met her. |

**辨别方法**：去掉强调句的"It is/was...that..."，剩下的部分如果还能组成一个完整句子，则是强调句。

## 二、虚拟语气

### 什么是虚拟语气

**虚拟语气 = 说话人主观认为某事与事实相反、不会发生、或不可能实现。**

#### 真实 vs 虚拟对比

```
陈述语气：If he is late, he will miss the meeting.（一般条件）
虚拟语气：If he were late, he would miss the meeting.（不太可能）
```

### 虚拟语气的 3 大时态

| 时态 | 假设情形 | if 从句 | 主句 |
|------|---------|---------|------|
| 现在 | 与现在事实相反 | 动词过去式（be → were） | would/could/should + 动词原形 |
| 过去 | 与过去事实相反 | had + 过去分词 | would/could/should have + 过去分词 |
| 将来 | 与将来事实相反或不太可能 | should + 动词原形 / were to + 动词原形 | would/could/should + 动词原形 |

#### 现在（与现在事实相反）

```
If I **were** you, I **would** study harder.
   ↑ 与现在事实相反（我不是你）
```

#### 过去（与过去事实相反）

```
If I **had known** the truth, I **would have told** you.
   ↑ 与过去事实相反（我当时不知道）
```

#### 将来（与将来事实相反或不太可能）

```
If it **should rain** tomorrow, I **would** stay home.
   ↑ 与将来事实相反（不太可能下雨）
```

### 虚拟语气的特殊句型

#### A. wish 后接虚拟

| wish 后 | 时态 | 例 |
|---------|------|----|
| 与现在相反 | 过去式（be → were）| `I wish I were you.` |
| 与过去相反 | had + 过去分词 | `I wish I had studied harder.` |
| 与将来相反 | would/could + 动词原形 | `I wish I would be a doctor.` |

#### B. as if / as though 后接虚拟

```
He talks as if he **knew** everything.           ← 与现在相反
He talked as if he **had known** everything.    ← 与过去相反
```

#### C. would rather 后接虚拟

```
I would rather you **came** tomorrow.            ← 与将来相反
I would rather you **had come** yesterday.       ← 与过去相反
```

#### D. It's (high) time that 后接虚拟（用过去式）

```
It's high time that you **started** working hard.
                ↑ 距离现在"应该做"，"过了一定"的意思
```

#### E. if only 单独使用（虚拟感叹句）

```
If only I **were** rich!
If only I **hadn't** said that!
```

#### F. if 虚拟条件句的倒装（书面语）

```
原句：If I had known, I would have helped.
倒装：Had I known, I would have helped.

原句：If I were you, I would...
倒装：Were I you, I would...

原句：If it should rain, we would...
倒装：Should it rain, we would...
```

#### G. 混合虚拟（主句与从句时态不一致）

```
If I had studied hard (与过去相反), I would be confident now (与现在相反).
  ↑had studied 是过去完成     ↑would be 是现在时
  表示"如果当初学了，现在就自信了"
```

#### H. 虚拟语气的"含蓄条件句"（无 if）

```
But for your help, I would have failed.        ← 含蓄条件 = If you hadn't helped me
Without water, there would be no life.          ← 含蓄条件 = If there were no water
Given more time, I would have finished.         ← 含蓄条件 = If I had been given more time
```

### 三大特殊虚拟（重要考点）

#### ① 建议 / 命令 / 要求 后用 should + V

| 主句动词 | 用法 |
|---------|------|
| suggest, propose, recommend, advise | + should + V (should 可省略) |
| demand, require, insist, order, command | + should + V (should 可省略) |
| It's necessary/important/essential/suggested that... | + should + V |

```
① I suggest that he (should) study harder.
② It is essential that everyone (should) be present.
```

**注意：** 这是 that 从句的主谓一致规则 —— **从句谓语用 should + 动词原形（should 可省略，但意义不变）。**

#### ② wish 后用过去 / 过去完成 / would

```
① I wish I were a bird.        ← 与现在相反
② I wish I had studied harder. ← 与过去相反
③ I wish he would come.        ← 对将来的"不可能"的愿望
```

#### ③ would rather 后用过去 / 过去完成

```
① I would rather you came.       ← 宁愿你明天来
② I would rather you had come.   ← 宁愿你昨天来了
```

## 三、倒装句

### 什么是倒装句

**倒装句 = 谓语动词放在主语之前的句子**

```
正常：I have never seen such a beautiful place.
倒装：Never have I seen such a beautiful place.
```

### 倒装的 2 大类型

| 类型 | 特征 | 例 |
|------|------|----|
| **完全倒装** | 整个谓语提前 | `Here comes the bus.` |
| **部分倒装** | 仅助动词提前 | `Never have I seen...` |

### 完全倒装的 4 大情境

| 情境 | 例 |
|------|----|
| here / there / now / then 开头 | `Here comes the bus.` / `There lived an old man.` |
| 表示地点的介词短语提前 | `On the hill stands a temple.` |
| up / down / in / out / away 开头 | `Up went the rocket.` |
| such 放句首 | `Such was the result.` |

### 部分倒装的 6 大情境（重点）

#### ① 否定词 / 半否定词 放句首

| 词 | 例 |
|----|----|
| never | `Never have I been to Paris.` |
| hardly | `Hardly did I know what to do.` |
| scarcely | `Scarcely had I arrived when...` |
| not only...but also | `Not only does he speak English, but also he speaks French.` |
| neither / nor | `Neither did he understand the question.` |
| no sooner...than | `No sooner had I arrived than he left.` |

#### ② only + 状语放在句首

```
Only in this way can you learn English well.
Only when I got home did I realize the truth.
```

#### ③ so / such...that 结构中的 so / such 在句首

```
So beautiful is she that everyone loves her.
Such a clever boy is he that everyone admires him.
```

#### ④ 虚拟条件句的倒装

```
Had I known, I would have helped.
Were I you, I would...
Should it rain, I would stay home.
```

#### ⑤ as 引导让步状从的倒装

```
Young as he is, he knows a lot.
         ↑ 表语提前
```

#### ⑥ 比较状语从句中的倒装

```
The more you learn, the better you are.
本书六级考过：Harder you work, more progress you make. ← 错误
正确：The harder you work, the more progress you make.
```

### 倒装句的写作应用

**高级写作句型模板：**

```
① Never + 半助词 + 主语 + 谓语 + ...
② Not only...but also...（also 必带！）
③ Hardly...when / No sooner...than（一...就...）
④ Only + 状语 + 半助词 + 主语 + ...
⑤ So + adj/adv + 半助词 + 主语 + that...
```

## 四、插入语

### 什么是插入语

**插入语 = 插在句子中间，用双逗号或双破折号隔开的语言成分（单词、短语或句子）。**

> 删掉之后，剩下的内容是完整的句子。

### 插入语的作用

| 作用 | 例 |
|------|----|
| **解释、说明、总结**一句话 | `He is, I believe, a good man.` |
| **表示说话人的态度和看法** | `In my opinion, he is wrong.` |
| **强调作用或引起对方注意** | `Believe it or not, he is over 80.` |

### 什么可以做插入语

| 形式 | 举例 |
|------|------|
| 单词 | `indeed, certainly, surely, honestly, frankly, however, therefore` |
| 介词短语 | `in my opinion, in fact, in short, in general, on the whole, of course` |
| 现在分词 | `generally speaking, frankly speaking, judging from` |
| 不定式 | `to be frank, to tell the truth, to be sure` |
| 句子 | `I believe, I think, I suppose, I'm afraid, you know, that is to say` |

### 常见插入语速查表

| 类别 | 插入语 |
|------|-------|
| 表观点 | `in my opinion, in my view, personally, to my mind` |
| 表判断 | `I believe, I think, I suppose, I'm afraid, hopefully` |
| 表强调 | `indeed, certainly, surely, of course, no doubt, undoubtedly` |
| 表总结 | `in short, in brief, in a word, in conclusion, on the whole, all in all` |
| 表时间顺序 | `first of all, after all, meanwhile, eventually` |
| 表补充 | `what's more, furthermore, besides, in addition, also` |
| 表对比 | `on the contrary, in contrast, however, nevertheless` |
| 表因果 | `therefore, thus, as a result, consequently` |
| 表让步 | `after all, in spite of that` |

### 写作应用：用插入语包装句型

**原句：**
```
He is a hard-working student.
```

**升级（添加插入语）：**
```
He is, in my opinion, a hard-working student.
He is, I believe, one of the most hard-working students in our class.
```

**升级（添加多个插入语）：**
```
He is, I believe, one of the most hard-working students in our class, 
and, what's more, he often helps other students with their study.
```

### 长难句中的插入语处理

**关键步骤：先删掉插入语，再分析主干**

```
① He is, in my opinion, a good man.
   删掉 in my opinion → He is a good man.（主系表）

② The result, I believe, will satisfy everyone.
   删掉 I believe → The result will satisfy everyone.（主谓宾）

③ The book, which I bought yesterday, is interesting.
   删掉定语从句 → The book is interesting.（主系表）

④ He works hard, although he is old.
   删掉状语从句 → He works hard.（主谓状）
```

## 五、特殊结构的考点分析

### 考点 1：写作中的应用

#### A. 高分必杀技——三大特殊结构混用

**主题：考研的重要性**

| 结构 | 例句 |
|------|------|
| 强调 | `It is not the university that matters, but the efforts you make.` |
| 虚拟 | `If I had not prepared for the exam, I would have failed.` |
| 倒装 | `Not only does it test your knowledge, but also it evaluates your determination.` |
| 插入语 | `In my opinion, the key to success is persistence.` |

#### B. 翻译中需要正确识别

**误译陷阱：忽略特殊结构**

```
误译：It is in this room that I was born.
       ↓ 直接翻
错误：这是那个房间，我出生了。
       ↓ 识别强调句
正确：我是在这个房间里出生的。
```

### 考点 2：长难句分析中的应用

#### 真题综合例题（1993 年翻译 + 2021 年英二阅读）

**例题 1（1993 年翻译）：**

```
原文：You have all heard it repeated as mark so that men of science work by 
means of induction and deduction, that by the help of these operations, 
they, in a sort of sense, manage to extract from Nature certain natural laws, 
and that out of these, by some special skills of their own, they build up their theories.
```

**分析过程：**
```
第一步：找谓语
- have heard（主句谓语）
- men work（that 引导宾从的谓语）
- manage to extract（that 引导宾从的谓语）
- build up（and 并列宾从的谓语）

第二步：找特殊结构
- it 为形式宾语，真正宾语是 3 个 that 从句并列
- in a sort of sense 为插入语（可删）
- as mark 是 as 引导的方式状语

第三步：找主干
主句主干：You have heard it repeated as mark so that...
```

**例题 2（2021 年英二阅读）：**

```
原文：We know we are moving into a period where the jobs in demand will change rapidly, 
as will the requirements of the jobs that remain.
```

**分析过程：**
```
第一步：找谓语：know、are moving、will change（×2）
第二步：找特殊结构
- as 引导比较状从（as will change = ...也会改变）
- where 引导定语从句
- that remain 是 that 引导的定语从句

第三步：找主干
We know (that) we are moving into a period.
```

**例题 3（2001 年词汇与语法——so...that 倒装）：**

```
原文：So involved with their computers do the children become 
that leaders at summer computer camps often have to force them to break for sports and games.
```

**分析过程：**
```
这是一个 so...that 句型的倒装
正常语序：The children become so involved with their computers that...
倒装后：So involved...do the children become...
还原后，后半句是 that 引导的结果状语从句
```

## 六、本章核心总结

### 4 大特殊结构速记口诀

```
强调句：It is/was...that...         强调主宾状（不能强调谓语/表语）
虚拟语气：与事实相反               三时态（现在/过去/将来）
倒装：部分倒装助提前               六情境（否定/only/so/虚拟/as 让步/比较）
插入语：双逗号双破折隔开           删掉之后句子完整
```

### 倒装句 6 大情境

```
1. 否定词开头（never, hardly, not only, neither）
2. Only + 状语提前
3. So / such...that 中的 so / such 提前
4. 虚拟条件句
5. As 引导让步状从
6. 比较状从
```

### 虚拟语气万能公式

```
现在相反：主语 + were/V-ed + 主语 + would
过去相反：主语 + had done + 主语 + would have done
将来相反：主语 + should do / were to + 主语 + would
```

### 写作必背"四大王炸"

| 结构 | 例句模板 |
|------|---------|
| 强调 | `It is...that...` |
| 虚拟 | `If I had..., I would have...` |
| 倒装 | `Not only...but also...` / `Hardly...when...` |
| 插入语 | `I believe, ...` / `In my opinion, ...` |

### 最关键的"刘晓艳提醒"

> "识别强调句关键看是否能去掉 It's...that，剩下的还是不是完整句子。识别虚拟语气关键看是否与现实相反。识别倒装句关键看主谓顺序是否颠倒。识别插入语关键看能否删掉后句子仍完整。"

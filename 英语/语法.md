# 考研英语语法基础

> 考研英语不直接考查语法选择题，但阅读理解、翻译和写作都依赖扎实的语法基础。

---

## 一、五大基本句型

1. **主 + 谓** (S + V)
2. **主 + 谓 + 宾** (S + V + O)
3. **主 + 谓 + 间宾 + 直宾** (S + V + IO + DO)
4. **主 + 谓 + 宾 + 宾补** (S + V + O + OC)
5. **主 + 系 + 表** (S + V + P)

---

## 二、英语三大从句

### 1. 名词性从句
- **主语从句**：What he said is true.
- **宾语从句**：I believe that he is honest.
- **表语从句**：The question is whether we can finish on time.
- **同位语从句**：The news that we won the game excited everyone.

### 2. 定语从句（形容词性从句）
- **限制性**：The book **that you lent me** is great.
- **非限制性**：My brother, **who lives in Beijing**, is a doctor.
- **关系代词**：who, whom, whose, which, that, as
- **关系副词**：when, where, why

### 3. 状语从句（副词性从句）
| 类型 | 常用引导词 |
|------|-----------|
| 时间 | when, while, before, after, until, as soon as |
| 地点 | where, wherever |
| 原因 | because, since, as, now that |
| 条件 | if, unless, as long as |
| 让步 | although, though, even though, while |
| 目的 | so that, in order that |
| 结果 | so...that, such...that |
| 方式 | as, as if, as though |
| 比较 | than, as...as, not so...as |

---

## 三、特殊句式

### 1. 倒装句
- **完全倒装**：Here comes the bus.
- **部分倒装**：Never have I seen such a beautiful place.
- **否定词开头**：Not only...but also, Hardly...when, No sooner...than

### 2. 强调句
- **It is/was...that...**：It was in this room that I was born.

### 3. 虚拟语气
- **与现在事实相反**：If I were you, I would...
- **与过去事实相反**：If I had known, I would have...
- **与将来事实相反**：If it should rain, we would...

### 4. 非谓语动词
| 形式 | 用法 |
|------|------|
| 不定式 (to do) | 目的、将来、具体动作 |
| 动名词 (doing) | 主语、宾语、习惯动作 |
| 现在分词 (doing) | 主动、进行 |
| 过去分词 (done) | 被动、完成 |

---

## 四、长难句分析步骤

1. **找谓语动词** — 确定有几个分句
2. **找连词** — 确定分句间关系
3. **找修饰成分** — 定语、状语、插入语
4. **确定主干** — 主谓宾核心结构
5. **逐层翻译** — 先主干后修饰

---

## 五、考研高频语法考点

| 考点 | 出现频率 | 备注 |
|------|---------|------|
| 定语从句 | ★★★★★ | 必考，常与名词性从句结合 |
| 状语从句 | ★★★★☆ | 阅读理解和翻译中常见 |
| 虚拟语气 | ★★★☆☆ | 完形填空偶考 |
| 倒装句 | ★★★☆☆ | 写作中可加分 |
| 非谓语动词 | ★★★★★ | 长难句分析核心 |
| 强调句 | ★★☆☆☆ | 偶尔出现 |

# 考研英语二 · 大作文方法论（Part B）

> 15分。约150词的图表作文，要求描述图表并评论。

---

## 一、题型特点

- **必出图表作文**：柱状图、饼图、折线图、表格
- **三段式结构**：描述图表 → 分析原因 → 预测/评论
- **字数要求**：约150词（180词左右最佳）

---

## 二、三段式结构

### 第一段：描述图表（约50–60词）

**功能：** 客观描述图表数据，不加入个人观点。

**万能句式：**
- The bar chart above illustrates ... from ... to ...
- As is clearly shown in the chart, ... experienced a dramatic increase/decrease.
- The number of ... rose sharply from ... to ...
- By contrast, the figure for ... only increased slightly.
- It is noticeable that ... accounts for the largest proportion.

**注意：**
- 必须写出具体数据（数字、百分比）
- 不要只罗列所有数据，挑主要的写
- 对比突出趋势差异（上升vs下降，高vs低）

---

### 第二段：分析原因（约60–70词）

**功能：** 解释图表反映的现象背后的原因。

**万能句式：**
- This striking trend can be attributed to the following reasons.
- Primarily, ... has contributed to this change.
- Furthermore, ... plays an important role.
- In addition, ... should not be ignored.
- Several factors, both individual and social, contribute to this phenomenon.

**常见原因角度：**
| 角度 | 常见原因 |
|------|----------|
| 经济发展 | economic growth, rising income |
| 政策影响 | government policy, reform |
| 社会趋势 | social trend, lifestyle change |
| 技术进步 | technological advancement |
| 教育水平 | education level, awareness |

---

### 第三段：预测/评论（约40–50词）

**功能：** 预测趋势或发表评论。

**万能句式：**
- Given the current trend, it is predicted that ... will continue to ...
- Taking all these factors into consideration, we may safely draw the conclusion that ...
- From what has been discussed above, we can see that ...
- It is my firm belief that this trend will continue in the years to come.

---

## 三、高频词汇分类

### 描述趋势
| 上升 | 下降 | 平稳 |
|------|------|------|
| increase | decrease | remain stable |
| rise | decline | level off |
| grow | fall | stay constant |
| climb | drop | plateau |
| surge | plunge | |
| soar | | |

### 程度
- dramatically, sharply, significantly, substantially
- slightly, marginally, modestly
- rapidly, quickly, gradually, steadily

### 数据表达
- account for, make up, constitute, represent
- proportion, percentage, figure, number
- respectively, in contrast, by comparison

---

## 四、常见图表类型应对

### 1. 柱状图
- 对比不同类别之间的差异
- 突出增长最快/最多的类别

### 2. 饼图
- 描述各部分占比
- 突出最大占比和最小占比

### 3. 折线图
- 描述时间趋势（上升/下降/波动）
- 突出转折点

### 4. 表格
- 横向对比+纵向对比
- 找出最大值、最小值、变化最大项

---

## 五、备考建议

1. **背模板**：三段式万能框架背熟
2. **积累句型**：描述趋势、分析原因、预测评论的万能句式
3. **练书写**：卷面整洁，字迹工整
4. **控制字数**：150–200词，不要太短也不要太长
5. **真题练习**：2010–2025年大作文题目各写一遍，对照参考范文修改
6. **避免模板痕迹**：用自己的话改写模板，不要生硬套模板

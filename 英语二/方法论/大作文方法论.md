# 考研英语二 · 大作文方法论（Part B）

> 基于石雷鹏功能句法 + 英语二图表作文真题总结。15分，约150词图表作文。

---

## 〇、核心理念：功能句法

石雷鹏作文法的核心：**每句话都有其"功能"**（描述、对比、原因、建议、总结等），每个功能对应多个同义表达。背熟功能句，考场上按三段式拼接即可。

**七步带写法：**
1. **抄写范文**——先抄一遍，熟悉结构
2. **英译汉**——把范文翻成中文，理解意思
3. **汉译英**——看着中文翻回英文，自己写一遍
4. **对比找差异**——和原文对比，找自己的错误
5. **背写差异之处**——专门背写错的地方
6. **背写全文**——反复背，直到无错
7. **举一反三**——思考每句话还能用来写什么话题

---

## 一、题型特点

- **必出图表作文**：柱状图、饼图、折线图、表格
- **三段式结构**：描述图表 → 分析原因 → 预测/评论
- **字数要求**：约150词（180词左右最佳）
- **时间**：建议25–30分钟

---

## 二、三段式结构与功能句

### 第一段：描述图表（约50–60词）

**功能：** 客观描述图表数据，不加入个人观点。

**功能句1：图表引入**
| 功能句 | 适用图表 |
|--------|----------|
| This is a bar chart that clearly shows ... | 柱状图 |
| This is a pie chart that illustrates ... | 饼图 |
| This is a line graph that demonstrates ... | 折线图 |
| The table clearly presents ... | 表格 |
| As is clearly shown in the chart, ... | 通用 |

**功能句2：描述变化趋势**
| 趋势 | 功能句 |
|------|--------|
| 上升 | ... increased remarkably, reaching approximately ...% |
| 上升 | The number of ... rose sharply from ... to ... |
| 下降 | By contrast, ... declined from ... to ... |
| 平稳 | Meanwhile, ... remained stable at ...% |
| 占比 | ... accounts for the largest proportion, at ...% |

**功能句3：总体概括**
- Overall, ... have the largest proportion of ..., at ...%.
- The next are ... and ..., with ...% and ...% respectively.
- It is noticeable that ...

**注意：**
- 必须写出具体数据（数字、百分比）
- 不要只罗列所有数据，挑主要的写
- 对比突出趋势差异（上升vs下降，高vs低）

---

### 第二段：分析原因（约60–70词）

**功能：** 解释图表反映的现象背后的原因。

**功能句1：过渡句**
- What resulted in this trend above?
- This striking phenomenon can be attributed to the following reasons.
- Several factors, both individual and social, contribute to this change.

**功能句2：列举原因**
- Primarily, ... has contributed to this change.
- Furthermore, ... plays an important role.
- In addition, ... should not be ignored.
- For one thing, ... For another, ...

**功能句3：具体原因展开**
- In recent years, ... was characterized by its economic boom, which enables people to ...
- Compared with the past, ... became ..., so ...
- Due to ..., people tend to ...

**常见原因角度：**
| 角度 | 常见表达 |
|------|----------|
| 经济发展 | economic boom, rising income, extra money |
| 政策影响 | government policy, reform, support |
| 社会趋势 | social trend, lifestyle change, awareness |
| 技术进步 | technological advancement, digitalization |
| 教育水平 | education level, higher expectations |

---

### 第三段：预测/评论（约40–50词）

**功能：** 预测趋势或发表评论。

**功能句1：预测趋势**
- Given the current trend, it is predicted that ... will continue to ...
- It is my firm belief that this trend will continue in the years to come.

**功能句2：总结观点**
- Taking all these factors into consideration, we may safely draw the conclusion that ...
- From what has been discussed above, we can see that ...

**功能句3：建议措施**
- It is advisable for us to ...
- Society as a whole should foster a positive atmosphere to ...

## 三、高频词汇分类

### 描述趋势
| 上升 | 下降 | 平稳 |
|------|------|------|
| increase | decrease | remain stable |
| rise | decline | level off |
| grow | fall | stay constant |
| climb | drop | plateau |
| surge | plunge | |
| soar | | |

### 程度
- dramatically, sharply, significantly, substantially, remarkably
- slightly, marginally, modestly
- rapidly, quickly, gradually, steadily

### 数据表达
- account for, make up, constitute, represent
- proportion, percentage, figure, number
- respectively, in contrast, by comparison

## 四、常见图表类型应对

### 1. 柱状图
- 对比不同类别之间的差异
- 突出增长最快/最多的类别
- 用 By contrast / Meanwhile 做对比

### 2. 饼图
- 描述各部分占比
- 突出最大占比和最小占比
- 用 account for / the largest proportion

### 3. 折线图
- 描述时间趋势（上升/下降/波动）
- 突出转折点
- 用 from ... to ... / during the period

### 4. 表格
- 横向对比+纵向对比
- 找出最大值、最小值、变化最大项
- 用 Overall / The next are / Finally come

## 五、大作文万能模板

```
This is a bar chart that clearly shows [图表主题] from [时间] to [时间].

According to the chart, [数据1]. By contrast, [数据2]. Meanwhile, [数据3].

What resulted in this trend? Primarily, [原因1]. Furthermore, [原因2].

Given the current trend, it is predicted that [预测]. It is my firm belief that this trend will continue.
```

## 六、备考建议

1. **背功能句**：按功能分类背熟，每个功能背2–3个同义表达
2. **七步带写**：每篇范文走一遍七步流程
3. **练书写**：卷面整洁，字迹工整
4. **控制字数**：150–200词，不要太短也不要太长
5. **真题练习**：2010–2025年大作文题目各写一遍，对照参考范文修改
6. **避免模板痕迹**：用自己的话改写模板，不要生硬套模板
7. **主题词积累**：按话题积累高频主题词（环保/科技/教育/经济等）

# 考研英语二 · 翻译方法论（Translation）

> 基于唐静《拆分与组合翻译法》+ 英语二真题总结。英二翻译为段落翻译，约150词，15分，材料选自报刊文章，偏生活化。

---

## 〇、核心方法：拆分与组合

唐静翻译法的核心就是四个字：**拆分 → 组合**。

把长句子切成一个个小结构，分别理解，再连成通顺的中文。不是靠语感硬猜，每一步都有明确操作。

---

## 一、解题四步：拆 → 译 → 连 → 查

### 第一步：写汉字（拆）

对着英文，把认识的单词**尽可能写下来**，落到纸面上。
- 不要想太多，先写字面意思
- 遇到不会的词不要空着，结合上下文猜一个
- 名词、动词、形容词、介词大概什么意思都先写出来

### 第二步：组小句子（译）

当有3个左右的汉语词（一个主干或一个词组），就**凑成一个小句子**。
- 重点是调整单词的意义，使其符合语境
- 不要追求文采，先把意思说出来
- 一个长句拆成3–5个小分句

### 第三步：合成大句子（连）

把小句子**连贯成通顺的大句子**。连接时可能需要：
- 适当找汉语同义近义词替换
- 适当改变句子顺序（英语原顺序优先）
- 适当增加、减少、重复词语
- 词性转换

### 第四步：通读检查（查）

- 检查漏译
- 检查是否说"人话"（中文通顺）
- 检查错别字

---

## 二、拆分原则

### 拆分大原则

**拆出主句，分清从句；拆出主干，分清修饰。**

### 拆分小原则（划竖线信号）

以下位置就是划竖线断开的信号：
- **连词**：and, but, or, so...
- **引导词**：that, which, who, when, where...
- **介词**：in, on, at, by, with, for, of...
- **分词**：doing, done...
- **不定式符号 to**
- **标点符号**：逗号、分号、冒号

> **注意：不拆单个单词。** 拆分是为了把长句变成小结构，不是把单词一个个拆开。

### 拆分目的

**重合考点，提高分数。** 拆出来的每个小结构往往就是一个得分点。

---

## 三、六大翻译技巧

| 技巧 | 说明 | 举例 |
|------|------|------|
| **① 同义替换** | 适当找汉语近义词替换，避免生硬 | important → 至关重要/意义重大 |
| **② 调整语序** | 按中文习惯调整，英语原顺序优先 | 定语后置→前置 |
| **③ 适当增词** | 补充隐含信息让中文通顺 | With the development → 随着经济的**发展** |
| **④ 适当减词** | 减形不减意，不译复数/系动词 | books → 书（不译"很多书"） |
| **⑤ 词性转换** | 名词→动词，形容词→副词等 | application(n.) → 应用(v.) |
| **⑥ 四字成语** | 适当用四字格提升译文质感 | rapid development → 飞速发展 |

## 四、六大结构翻译法

### 1. 定语从句

**前置法（短从句）：** 把定语从句翻译到先行词前面，用"的"连接。
- 适用于：结构简单、信息负载量小的从句

> the book that I bought → 我买的书

**后置法（长从句）：** 另起一句，重复先行词或用代词。
- 适用于：结构复杂、前置太长不通顺的从句

> The report, which was published in Nature and is one of the most prestigious journals, suggests...
> → 这份报告发表在《自然》期刊上。《自然》是世界上最负盛名的期刊之一。报告表明……

**as 引导的特殊定语从句：**
> as we all know → 众所周知
> as is often the case → 通常情况下

---

### 2. 状语从句（六类）

| 类型 | 标志词 | 翻译位置 |
|------|--------|----------|
| **时间** | when, while, as, since, before, after, until | 主句前（"当……时"） |
| **原因** | because, since, as, now that, in that | 主句前（"因为/由于"） |
| **让步** | though, although, even if, while, whatever | 主句前（"虽然……但是……"） |
| **条件** | if, unless, provided that, as long as | 主句前（"如果/只要"） |
| **目的** | so that, in order that, lest, in case | 主句前（"为了"）/ 后（"以免"） |
| **结果** | so...that, such...that | 直接译（"如此……以至于"） |

**原因状语特殊句式：**
- 前因后果：把原因译到主句前
- 之所以……是因为……：原因太长时用此句式

---

### 3. 被动结构

**英语多用被动，汉语多用主动。**

| 处理方式 | 说明 | 举例 |
|----------|------|------|
| **省"被"字** | 主语不变，直接主动译 | The door opened. 门开了。 |
| **主宾颠倒** | by后面的执行者变主语 | The policy was announced by the government. 政府宣布了政策。 |
| **"是……的"结构** | 翻译为判断句 | It is written by Lu Xun. 这是鲁迅写的。 |
| **泛指主语** | 用"人们/我们/大家" | It is said that... 人们说…… |

**保留被动的情况：**
- 用"被、受、遭、让、给、由、得到、受到、加以、得以、为……所"
- 强调被动动作或突出受事者时

---

### 4. 同位语结构

| 情况 | 处理方法 |
|------|----------|
| **简单同位语** | 翻译到修饰的名词前面 |
| **复杂同位语** | 翻译在后面，独立成句，用"即/也就是/这"等词解释 |

**同位语从句 vs 定语从句：**
- 同位语从句：引导词 that 不充当句子成分，只起连接作用
- 定语从句：引导词 that/which 在从句中作主语或宾语

---

### 5. 形式主语

**It is + adj. + that... / It is + p.p. + that...**

| 处理方式 | 说明 |
|----------|------|
| **先译真正主语** | 把that后面的内容先译，再加"这是……的" |
| **用"人们/我们/大家"** | It is said/reported/believed that... → 据说/据报道/人们认为 |

**常见表达：**
- It is undeniable that... → 无可否认……
- It is reported that... → 据报道……
- It is universally accepted that... → 人们普遍认为……
- It is important that... → 重要的是……

---

### 6. 短语作定语

**常见类型：** 分词短语（doing/done）、不定式短语、形容词短语、介词短语

**处理方法：**
- 短短语 → 前置（"的"）
- 长短语 → 拆分独立成句

---

## 五、代词指代处理

碰到 it/they/this/that/these/those 等代词：

1. **直接对应试试**：直接译"它/他们/这"，前提是译文通顺
2. **指代明确**：不通顺则往前找，按"就近+一致原则"找到具体名词
3. **万能处理**：万不得已，用"这/这种情况/这种说法/这一点"

> 代词指代模糊是翻译扣分重灾区，**it/they/this 必须明确指代**。

## 六、英语二翻译特点

| 项目 | 说明 |
|------|------|
| **题型** | 段落翻译（约150词），不是单独划线句 |
| **材料** | 报刊文章，偏生活化，不考晦涩学术长难句 |
| **话题** | 社会生活、文化教育、经济管理等 |
| **时间** | 建议15–20分钟 |
| **平均分** | 近三年约8分（满分15） |

---

## 七、评分标准

| 档次 | 分数 | 标准 |
|------|------|------|
| 优秀 | 13–15分 | 译文准确流畅，无明显错译漏译 |
| 良好 | 10–12分 | 译文基本准确，有少量错译 |
| 中等 | 7–9分 | 译文勉强通顺，有错译 |
| 较差 | 4–6分 | 译文不通顺，错译较多 |
| 极差 | 0–3分 | 译文混乱，几乎不可理解 |

**评分三要素：** 准确（大意相同）→ 通顺（说人话）→ 完整（成句）

---

## 八、备考建议

1. **方法论先行**：先学拆分与组合法，再做题
2. **真题精练**：2010–2025年翻译真题，每句按"拆→译→连→查"走流程
3. **手译对照**：先自己写，再对照参考译文修改，标注错因
4. **积累高频词**：翻译高频词汇有重叠，逐步掌握
5. **不求文采**：考场只求准确通顺，不会的词按上下文猜，不要空着
6. **能力迁移**：翻译练好了，阅读长难句理解能力也会提升

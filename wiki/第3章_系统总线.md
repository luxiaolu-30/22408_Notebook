# 第3章 系统总线

> 408考研权重：⭐⭐⭐（常考章节，约5-10分）

## 考点概述

系统总线是连接计算机各部件的信息传输线。主要考点包括：
- 总线分类与性能指标
- 总线判优控制
- 总线通信控制（同步/异步/半同步/分离式）

## 关键知识点

### 3.1 总线基本概念

**总线**：连接多个部件的信息传输线，是各部件共享的传输介质。

**总线特点**：
- 某一时刻只允许一个部件发送信息
- 多个部件可同时接收信息

### 3.2 总线分类

| 分类方式 | 类型 |
|---|---|
| 连接部件 | 片内总线、系统总线、通信总线 |
| 传输方式 | 并行总线、串行总线 |
| 系统总线功能 | 数据总线、地址总线、控制总线 |

**系统总线三组**：
- **数据总线**：双向，传输数据
- **地址总线**：单向，传输地址
- **控制总线**：双向，传输控制信号

### 3.3 总线性能指标

| 指标 | 说明 |
|---|---|
| **总线宽度** | 数据总线根数（位） |
| **总线带宽** | 单位时间传输数据量（MBps） |
| **时钟同步/异步** | 是否与时钟同步 |
| **总线复用** | 一线分时传多种信号 |
| **信号线数** | 三类总线总数 |

**总线带宽计算**：
```
总线带宽 = 总线工作频率 × (总线宽度/8)
```

### 3.4 总线结构

| 结构 | 特点 |
|---|---|
| **单总线** | 所有部件共享一组总线，简单但易瓶颈 |
| **双总线** | 分离主存总线和I/O总线 |
| **三总线** | 主存总线、I/O总线、DMA总线 |
| **多总线** | 按速率分离，高性能设备靠近CPU |

### 3.5 总线控制

#### 总线判优控制（集中式）

| 方式 | 特点 | 优先级 | 灵敏度 |
|---|---|---|---|
| **链式查询** | BG串行传递 | 离控制器近者优先 | 对故障敏感 |
| **计数器定时查询** | 计数器轮询 | 可编程设置 | 较不敏感 |
| **独立请求方式** | 每设备一对BR/BG | 排队电路决定 | 响应最快 |

#### 总线通信控制

| 方式 | 特点 | 适用场景 |
|---|---|---|
| **同步通信** | 统一时钟控制 | 短距离、速度一致 |
| **异步通信** | 握手方式 | 长距离、速度差异大 |
| **半同步通信** | 同步+等待 | 中等速度差异 |
| **分离式通信** | 分离地址/数据阶段 | 大型系统 |

**同步通信时序**（读操作）：
- T1：主模块发地址
- T2：主模块发读命令
- T3：从模块提供数据
- T4：主模块撤销命令

**异步通信互锁**：
- 不互锁：双方不等待对方确认
- 半互锁：主模块等待从模块确认
- 全互锁：双方互相等待确认

## 典型例题

### 题型1：总线带宽计算

> **例题**：设总线时钟频率为100MHz，总线传输周期为4个时钟周期，总线宽度为32位，求总线数据传输率。

**解答**：
- 1个时钟周期 = 1/100MHz = 0.01μs
- 总线传输周期 = 0.01μs × 4 = 0.04μs
- 总线宽度 = 32位 = 4B
- 数据传输率 = 4B / 0.04μs = **100 MBps**

### 题型2：波特率与比特率

> **例题**：异步串行传输，字符格式：1起始位、8数据位、1奇校验位、1终止位，波特率1200bps，求比特率。

**解答**：
- 一帧位数 = 1+8+1+1 = 11位
- 有效数据位 = 8位
- 比特率 = 1200 × (8/11) = **872.72 bps**

## 易错点

1. **总线带宽**：注意单位换算（位→字节）
2. **同步vs异步**：同步用时钟，异步用握手
3. **链式查询优先级**：离控制器越近优先级越高
4. **波特率vs比特率**：波特率包含附加位，比特率只算有效数据

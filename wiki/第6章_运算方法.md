# 第6章 计算机的运算方法

> 408考研权重：⭐⭐⭐⭐⭐（必考章节，约15-20分）

## 考点概述

运算是计算机的基本功能，408考研每年必考。主要考点包括：
- IEEE 754单精度浮点数（15/15年必考）
- 浮点加减运算（必考）
- 定点数表示与运算
- ALU结构与快速进位链

## 关键知识点

### 6.1 数的表示

#### 无符号数
- 所有位都表示数值
- n位无符号数范围：0 ~ 2ⁿ-1

#### 有符号数（重要！）

| 表示形式 | 定义 | 特点 |
|---|---|---|
| **原码** | 符号位+绝对值 | 直观，但加减复杂 |
| **反码** | 正数不变，负数按位取反 | 较少使用 |
| **补码** | 正数不变，负数取反+1 | 加减统一，最常用 |
| **移码** | 补码符号位取反 | 用于浮点阶码 |

**补码性质**：
- 0的补码唯一：000...0
- 减法变加法：A - B = A + [-B]补
- n位补码范围：-2ⁿ⁻¹ ~ 2ⁿ⁻¹-1

### 6.2 定点数与浮点数

#### 定点表示
- **定点小数**：小数点固定在符号位后
- **定点整数**：小数点固定在最低位后
- 范围有限，但运算简单

#### 浮点表示（重要！）
```
浮点数 = 符号 + 阶码 + 尾数
```

**规格化浮点数**：
- 尾数最高位必须为1（二进制）
- 通过移动小数点实现规格化
- 规格化后隐含前导1（节省1位精度）

### 6.3 IEEE 754标准 ⭐⭐⭐⭐⭐

#### 单精度浮点数（32位）

| 部分 | 位数 | 说明 |
|---|---|---|
| **S（符号位）** | 1位 | 0正1负 |
| **E（阶码）** | 8位 | 移码表示，偏移量127 |
| **M（尾数）** | 23位 | 规格化时隐含前导1 |

**真值公式**：
```
X = (-1)^S × 1.M × 2^(E-127)
```

#### 特殊值对照表

| 阶码E | 尾数M | 含义 |
|---|---|---|
| 0 | 0 | ±0 |
| 0 | 非0 | 非规格化数（0.M × 2⁻¹²⁶） |
| 1~254 | 任意 | **规格化数** |
| 255 | 0 | ±∞ |
| 255 | 非0 | NaN（非数） |

#### 关键数值

| 数值 | 结果 |
|---|---|
| 最大正数 | ≈ 3.4 × 10³⁸ |
| 最小规格化正数 | 2⁻¹²⁶ ≈ 1.18 × 10⁻³⁸ |
| 最小非规格化正数 | 2⁻¹⁴⁹ |
| 偏移量 | 127（单精度）/ 1023（双精度） |

### 6.4 浮点运算 ⭐⭐⭐⭐⭐

#### 浮点加减运算步骤

1. **对阶**：小阶向大阶对齐，尾数右移
2. **尾数运算**：用补码进行加减
3. **规格化**：
   - 尾数最高位与符号位相同 → **左规**（尾数左移，阶码减1）
   - 尾数溢出 → **右规**（尾数右移，阶码加1）
4. **舍入**：0舍1入法 / 恒置1法
5. **溢出判断**：阶码上溢→溢出；阶码下溢→视为0

#### 浮点乘除运算

**乘法**：
1. 阶码相加
2. 尾数相乘
3. 规格化

**除法**：
1. 阶码相减
2. 尾数相除
3. 规格化

### 6.5 算术逻辑单元（ALU）

#### ALU功能
- 算术运算：加、减、乘、除
- 逻辑运算：与、或、非、异或

#### 快速进位链（重要！）

**串行进位**：逐级传递，延迟大

**并行进位**：
- 进位产生函数：Gi = Ai · Bi
- 进位传递函数：Pi = Ai ⊕ Bi
- 进位表达式：Ci+1 = Gi + Pi · Ci

**先行进位（CLA）**：
- 小组内并行，小组间串行
- 或小组内并行，小组间也并行

## 典型例题

### 题型1：十进制→IEEE 754表示

> **例题**：将-3.75转换为IEEE 754单精度浮点数（十六进制）。

**解答**：
1. 符号位：负数，S = 1
2. 转二进制：3.75 = 11.11B
3. 规格化：11.11 = 1.111 × 2¹，指数 = 1
4. 阶码 E = 1 + 127 = 128 = 10000000B
5. 尾数 M = 111 0000 0000 0000 0000 0000（去掉前导1，补0至23位）
6. 组合：1 10000000 11100000000000000000000
7. 十六进制：**0xC0700000**

### 题型2：IEEE 754→十进制真值

> **例题**：IEEE 754单精度浮点数0xC0A00000的真值是多少？

**解答**：
1. 转二进制：1100 0000 1010 0000 0000 0000 0000 0000
2. 拆分：S=1, E=10000001, M=01000000000000000000000
3. E = 129，规格化数
4. 实际指数 = 129 - 127 = 2
5. 真值 = (-1)¹ × 1.01 × 2² = -1.25 × 4 = **-5.0**

### 题型3：浮点加减运算

> **例题**：x = 2⁰¹⁰ × 0.1101，y = 2⁰⁰¹ × 0.1011，求x+y。

**解答**：
1. **对阶**：y的阶小，尾数右移1位
   - y = 2⁰¹⁰ × 0.01011
2. **尾数相加**：0.1101 + 0.01011 = 1.00101
3. **规格化**：尾数溢出，右规
   - 结果 = 2⁰¹¹ × 0.100101
4. **舍入**：0舍1入
   - 结果 = 2⁰¹¹ × 0.1001

## 易错点

1. **偏移量记错**：单精度偏移127，双精度偏移1023
2. **规格化判断**：尾数最高位必须为1，不是符号位
3. **对阶方向**：小阶向大阶对齐，不是大阶向小阶
4. **左规右规混淆**：
   - 左规：尾数左移，阶码减小（规格化时）
   - 右规：尾数右移，阶码增大（溢出时）
5. **移码与补码**：移码 = 补码符号位取反，不是数值取反

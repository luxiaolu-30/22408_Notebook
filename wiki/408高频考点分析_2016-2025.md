## 四、各科目绝对高频必考知识点精要

### 数据结构

#### 1. 图算法（出现频率：70%，每10年7次大题）
- **拓扑排序**：判定有向图是否有环；拓扑序列唯一性（2024、2023）
- **关键路径（AOE网）**：最早/最晚时间、关键活动判断（2025）
- **最小生成树**：Prim/Kruskal算法步骤；MST唯一性条件（2017）
- **最短路径**：Dijkstra、Floyd算法
- **欧拉路径**：度数奇偶判定（2021）

#### 2. 树与二叉树（出现频率：60%，选择题100%）
- **BST判定与操作**：中序遍历性质（2022）
- **哈夫曼树/编码**：WPL计算；前缀编码判定（2020）
- **AVL树旋转**：插入后的平衡调整
- **非递归遍历**：中序、前序、后序（2017表达式树）
- **B/B+树**：插入分裂规则（2025选择题）

#### 3. 查找与排序（大题出现频率：40%，选择题高频）
- **散列表**：H(key)冲突处理（线性探查、二次探查）；查找成功/失败比较次数（2024）
- **外部排序**：置换-选择排序；归并段生成（2023）
- **堆排序/归并**：排序过程模拟
- **KMP算法**：next数组计算（2024选择题）
- **折半查找**：判定树构造

#### 4. 线性表与链表（大题出现频率：50%）
- **链表操作**：逆置（头插法）、合并、三指针技巧（2019）
- **三指针/双指针**：三元组距离最小（2020）
- **循环队列**：判空/满条件

### 计算机组成原理

#### 1. 存储系统（大题出现频率：100%，每年必考）
- **Cache映射**：直接映射、组相联映射、全相联映射
  - 地址划分（标记位、组号、块内地址计算）（2025、2024、2023、2020…）
  - Cache命中率与平均访问时间计算
  - 替换算法：LRU（2021 TLB题）
  - 写策略：写直通（直写）vs 写回（回写）
- **虚拟存储**：
  - 虚拟地址→物理地址的翻译过程
  - 多级页表（一级/二级）地址结构划分
  - TLB组相联映射（2021、2018）
  - 缺页次数计算（2025、2023）
  - 页面置换算法：LRU/FIFO/改进CLOCK（2018）

#### 2. 数据表示与运算（大题出现频率：50%，选择题100%）
- **补码**：加减运算、溢出判断（CF、OF标志位）（2022、2025选择）
- **浮点数**：IEEE 754单精度表示；精度差异与舍入（2017）
- **补码乘法/除法**：运算过程（2020、2025）
- **大小端存储**：判定与地址计算（2023、2024）

#### 3. 指令系统（大题出现频率：80%）
- **指令格式**：R/I/J型；操作码扩展（2021）
- **寻址方式**：立即寻址、直接寻址、间接寻址、寄存器寻址、相对寻址
- **汇编级分析**：C代码↔汇编↔机器级分析（2024、2019）
- **CISC vs RISC**：特征判断（2017、2025）
- **流水线**：数据冒险（2024选择题）；CPI计算

#### 4. I/O系统（大题出现频率：40%）
- **中断机制**：中断响应过程；中断处理时间占比（2018、2016）
- **DMA方式**：周期挪用；总线请求次数（2022）
- **磁盘**：寻道/旋转延迟/传输时间；SSTF调度（2019）

### 操作系统

#### 1. 进程同步与互斥（大题出现频率：90%，几乎每年必考）
- **信号量机制**：P(wait)/V(signal)操作的正确设计
- **经典同步问题**：
  - 哲学家就餐问题（防死锁策略）（2019）
  - 生产者-消费者变形（缓冲区操作）（2024）
  - 三人协作同步（前驱图→信号量）（2025、2020）
  - 多线程互斥（最高并发度设计）（2017、2022）
- **死锁**：必要条件；银行家算法；资源分配图
- **互斥实现原理**：原子指令（swap/test-and-set）；关中断的权限问题（2023、2021）

#### 2. 内存管理（大题出现频率：80%）
- **分页存储**：
  - 虚拟地址结构（页号+页内地址）
  - 一级/二级页表地址转换计算（2020、2017）
  - 缺页异常处理流程（2024、2025）
- **页面置换算法**：LRU/FIFO/改进CLOCK（2018、2025选择题）
- **分段/段页式**：概念区别
- **进程内存空间**：代码段/数据段/堆/栈布局（2025大题）

#### 3. 文件系统（大题出现频率：50%）
- **多级索引节点**：直接/一级间接/二级间接地址项
  - 文件最大长度计算（2018）
  - 读文件磁盘I/O次数分析（2022）
- **FAT文件系统**：链接分配（2016）
- **磁盘调度**：SSTF（2019）；CSCAN（2024选择题）

#### 4. I/O管理（大题出现频率：40%）
- **中断处理**：驱动程序与中断处理程序区分（2023）
- **进程状态切换**：运行→阻塞→就绪→运行的I/O触发流程（2023、2017）
- **系统调用**：用户态→内核态切换

---

### 计算机网络

#### 1. 网络层（大题出现频率：80%）
- **IP地址与子网划分**：
  - 子网掩码计算；网络地址/广播地址（2018、2025）
  - CIDR变长子网划分（2025）
- **NAT**：地址转换表配置；IP首部变化追踪（2020、2019）
- **路由协议**：RIP（距离向量）/OSPF（链路状态）/BGP对比（2024）
- **IP分片**：分片数目；片偏移计算（2018）

#### 2. 传输层（大题出现频率：70%）
- **TCP可靠传输机制**：
  - 三次握手/四次挥手（序号/确认号计算）（2016）
  - 流量控制（接收窗口/发送窗口）（2016）
  - 拥塞控制（慢启动/拥塞避免/快速重传）（2023、2025选择题）
- **GBN/SR协议**：发送窗口大小；超时重传范围；信道利用率计算（2025、2017）
- **TCP/UDP比较**：校验和计算（2024选择题）

#### 3. 数据链路层（大题出现频率：60%）
- **以太网/CSMA/CD**：极限冲突距离计算（2022）
- **802.11 CSMA/CA**：退避算法（2025选择题）
- **ARP协议**：MAC地址解析；与交换机转发表结合（2021）
- **交换机**：交换表学习与更新（2021、2022）
- **帧格式**：海明距离/检错纠错能力（2025选择题）
- **GBN/SR协议**（见传输层）

#### 4. 应用层（大题出现频率：50%）
- **DNS**：递归/迭代查询；报文封装过程（2021）
- **FTP**：控制连接（持久）vs 数据连接（临时）（2023）
- **DHCP**：报文类型（Discover/Offer/Request/ACK）；广播范围（2022）
- **HTTP**：非持久/持久连接时延计算（2024选择题）

## 五、命题规律与趋势分析

### 大题命题固定框架

近10年大题结构高度稳定：

```
大题1（41题）：数据结构 → 算法设计题（线性表/树/图）
大题2（42题）：数据结构 → 综合应用题（图/排序/查找）
大题3（43题）：计算机组成原理 → 存储系统（Cache/虚存）
大题4（44题）：计算机组成原理 → 指令系统/数据表示
大题5（45题）：操作系统 → 进程同步（信号量）
大题6（46题）：操作系统 → 内存管理/文件系统
大题7（47题）：计算机网络 → 综合协议题
```

### 近5年显著趋势（2021-2025）

| 趋势 | 具体表现 |
|------|---------|
| **跨章节综合性增强** | 存储系统大题同时考Cache+TLB+虚存（2025、2023）；网络大题综合多层协议（2021） |
| **工程设计能力要求提升** | 要求设计算法+分析复杂度（2025、2024、2022） |
| **新技术考点出现** | 虚拟化（VMM/VFS）（2025选择题）；802.11无线网（2022） |
| **代码级分析深化** | 汇编+C代码+地址计算三合一（2024大题44） |
| **图算法持续高频** | 近5年拓扑排序出现3次（2025 AOE、2024、2023） |

### 轮换考察规律

- **操作系统大题**：进程同步与内存管理轮换（通常一题考同步，一题考内存或文件系统）
- **组成原理大题**：存储系统（Cache/虚存）固定出一题；另一题在指令系统/数据通路/I/O间轮换
- **网络大题**：传输层（TCP）和网络层（子网/路由）几乎每年必考，数据链路层隔年出现

## 六、复习优先级建议

### 第一优先级（必拿分，约80-90分对应知识点）

| 科目 | 必考内容 |
|------|---------|
| 数据结构 | 图算法（拓扑/最短路径/MST）、BST/AVL、链表操作、散列表 |
| 组成原理 | Cache组相联映射+地址计算、虚拟存储+TLB、数据表示（浮点/补码）、指令格式 |
| 操作系统 | 信号量PV操作（全类型同步问题）、分页地址转换、页面置换算法 |
| 计算机网络 | TCP拥塞控制/流量控制、子网划分、GBN/SR协议、DNS+ARP+交换机 |

### 第二优先级（高性价比，常出稳分区）

| 科目 | 内容 |
|------|------|
| 数据结构 | 哈夫曼树、外部排序、队列设计、堆排序 |
| 组成原理 | I/O系统（中断/DMA）、ALU设计（标志位）、流水线CPI计算 |
| 操作系统 | 文件系统（多级索引、磁盘I/O次数）、磁盘调度、进程状态转换 |
| 计算机网络 | IP分片、DHCP流程、HTTP时延计算、FTP协议 |

### 第三优先级（选择性复习）

- 数据结构：串（KMP），外部存储的B树
- 组成原理：总线带宽计算，阵列乘法器
- 操作系统：进程调度算法（各类算法时序模拟）
- 计算机网络：网络安全（加密/认证），移动IP

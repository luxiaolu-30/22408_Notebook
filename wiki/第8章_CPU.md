# 第8章 CPU的结构和功能

> 408考研权重：⭐⭐⭐⭐⭐（必考章节，约15-20分）

## 考点概述

CPU是计算机的核心，408考研每年必考。主要考点包括：
- 指令流水（15/15年必考）
- 中断系统（15/15年必考）
- 数据通路（15/15年必考）
- CPU结构与寄存器

## 关键知识点

### 8.1 CPU结构

#### CPU功能
- **指令控制**：取指、分析、执行
- **操作控制**：管理各部件操作
- **时间控制**：时序控制
- **数据加工**：算术逻辑运算
- **中断处理**：处理异常

#### CPU结构框图
```
CPU = 运算器 + 控制器
    = ALU + CU + 寄存器组
```

#### CPU寄存器

| 寄存器 | 功能 |
|---|---|
| **PC**（程序计数器） | 存放当前指令地址，自动+1 |
| **IR**（指令寄存器） | 存放当前指令 |
| **MAR**（存储器地址寄存器） | 存放访问地址 |
| **MDR**（存储器数据寄存器） | 存放读/写数据 |
| **ACC**（累加器） | 存放运算结果 |
| **MQ**（乘商寄存器） | 存放乘数/商 |
| **X**（操作数寄存器） | 存放操作数 |
| **PSW**（程序状态字） | 存放状态标志 |

### 8.2 指令周期

#### 指令周期概念
```
指令周期 = 取指周期 + 间址周期 + 执行周期 + 中断周期
```

#### 各周期操作

**取指周期**：
1. PC → MAR
2. 读内存 → MDR
3. MDR → IR
4. PC + 1 → PC

**间址周期**（间接寻址时）：
1. IR(地址码) → MAR
2. 读内存 → MDR
3. MDR → IR(地址码)

**执行周期**：
- 根据指令操作码执行相应操作

**中断周期**：
1. 保存断点（PC → 堆栈）
2. 转中断服务程序入口

### 8.3 指令流水 ⭐⭐⭐⭐⭐

#### 指令流水原理
将指令执行过程分解为多个阶段，多条指令重叠执行。

**非流水线**：每条指令串行执行
```
指令1: [取指] [分析] [执行]
指令2:          [取指] [分析] [执行]
指令3:                   [取指] [分析] [执行]
```

**流水线**：多条指令重叠执行
```
指令1: [取指] [分析] [执行]
指令2: [取指] [分析] [执行]
指令3: [取指] [分析] [执行]
```

#### 影响流水线性能的因素

1. **结构相关（资源冲突）**
   - 多条指令争用同一功能部件
   - 解决：增加资源、指令调度

2. **数据相关（数据冒险）**
   - **RAW**（读后写）：后一条指令需要前一条的结果
   - **WAR**（写后读）：后一条写，前一条读
   - **WAW**（写后写）：两条指令写同一寄存器
   - 解决：数据旁路、暂停、编译器调度

3. **控制相关（分支冒险）**
   - 分支指令改变PC值
   - 解决：分支预测、延迟分支

#### 流水线性能

**吞吐率（TP）**：
```
TP = 完成指令数 / 总执行时间
```

**加速比（S）**：
```
S = 非流水线时间 / 流水线时间
```

**效率（E）**：
```
E = 实际加速比 / 理论最大加速比
```

#### 多发技术
- **超标量**：每个周期发射多条指令
- **超流水线**：更多流水级，更高频率
- **VLIW**：超长指令字，编译器调度

### 8.4 中断系统 ⭐⭐⭐⭐⭐

#### 中断概念
- CPU暂停当前程序，转去处理异常/请求
- 处理完成后返回原程序继续

#### 中断分类

| 类型 | 来源 | 示例 |
|---|---|---|
| **内中断** | CPU内部 | 溢出、除零、非法指令 |
| **外中断** | 外部设备 | I/O请求、时钟中断 |
| **可屏蔽** | 可被屏蔽 | I/O中断 |
| **不可屏蔽** | 必须响应 | 电源故障 |

#### 中断请求与判优

**中断请求标记**：
- 每个中断源有一个请求触发器
- INTR = 1 表示有中断请求

**中断判优**：
- 硬件排队：链式查询、独立请求
- 软件查询：程序轮询

**优先级原则**：
1. 高速设备优先于低速设备
2. 输入优先于输出（避免数据丢失）

#### 中断响应

**响应条件**：
1. 中断请求信号有效
2. 允许中断触发器EINT = 1
3. 当前指令执行完毕

**响应过程**：
1. 关中断（EINT = 0）
2. 保存断点（PC → 堆栈）
3. 转中断服务程序入口

#### 中断服务程序流程

```
1. 保护现场（寄存器入栈）
2. 开中断（允许更高级中断嵌套）
3. 执行中断处理
4. 关中断
5. 恢复现场（寄存器出栈）
6. 开中断
7. 返回（RETI）
```

#### 中断屏蔽技术

**屏蔽字**：每个中断源对应一个屏蔽位
- 1 = 屏蔽该中断
- 0 = 允许该中断

**作用**：
- 改变中断优先级
- 实现中断嵌套

## 典型例题

### 题型1：流水线性能计算

> **例题**：某5级流水线，各阶段时间分别为100ns、80ns、100ns、120ns、100ns。求：
> (1) 流水线周期
> (2) 执行100条指令的总时间
> (3) 吞吐率
> (4) 加速比

**解答**：
(1) 流水线周期 = max(100,80,100,120,100) = **120ns**

(2) 总时间 = 5×120 + 99×120 = 600 + 11880 = **12480ns**

(3) 吞吐率 = 100 / 12480ns = **8.01 MIPS**

(4) 非流水线时间 = (100+80+100+120+100)×100 = 50000ns
    加速比 = 50000 / 12480 = **4.01**

### 题型2：中断响应

> **例题**：CPU响应I/O中断的条件是什么？中断服务程序的流程是什么？

**解答**：
响应条件：
1. 中断请求信号有效
2. 允许中断触发器EINT = 1
3. 当前指令执行完毕

中断服务程序流程：
1. 保护现场
2. 开中断
3. 执行中断处理
4. 关中断
5. 恢复现场
6. 开中断
7. 返回

### 题型3：数据相关判断

> **例题**：判断下列指令序列是否存在数据相关：
> ```
> ADD R1, R2, R3    ; R1 = R2 + R3
> SUB R4, R1, R5    ; R4 = R1 - R5
> AND R6, R1, R7    ; R6 = R1 AND R7
> ```

**解答**：
- ADD与SUB：**RAW相关**（SUB读R1，ADD写R1）
- ADD与AND：**RAW相关**（AND读R1，ADD写R1）
- SUB与AND：**无相关**（都读R1，不写R1）

## 易错点

1. **流水线周期**：取最慢的阶段时间，不是平均时间
2. **加速比计算**：非流水线时间 / 流水线时间，不是倒数
3. **中断响应条件**：必须当前指令执行完毕，不是立即响应
4. **中断屏蔽**：屏蔽字1=屏蔽，0=允许（容易记反）
5. **数据相关**：RAW是真正的数据相关，WAR和WAW是名相关

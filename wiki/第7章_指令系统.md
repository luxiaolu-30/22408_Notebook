# 第7章 指令系统

> 408考研权重：⭐⭐⭐⭐（必考章节，约10-15分）

## 考点概述

指令系统是CPU与软件的接口，408考研每年必考。主要考点包括：
- 寻址方式（15/15年必考）
- 指令格式设计
- RISC技术（15/15年必考）
- RISC vs CISC比较

## 关键知识点

### 7.1 机器指令格式

```
指令 = 操作码 + 地址码
```

- **操作码**：表示操作性质（取数、存数、加、减等）
- **地址码**：表示操作数地址（0~4个地址）

#### 指令字长
- 固定字长：简单，便于控制
- 可变字长：节省存储空间，但控制复杂
- 现代计算机：字节整数倍

### 7.2 操作数类型与操作类型

#### 操作数类型
- 无符号整数、有符号整数
- 浮点数、十进制数
- 字符、字符串
- 逻辑数

#### 数据在存储器中的存放方式
- **大端序**：高位字节在低地址
- **小端序**：低位字节在低地址（x86采用）

#### 操作类型
- 数据传送：取数、存数
- 算术运算：加、减、乘、除
- 逻辑运算：与、或、非、异或
- 移位运算：算术移位、逻辑移位
- 转移：无条件转移、条件转移
- 输入输出
- 其他：停机、复位

### 7.3 寻址方式 ⭐⭐⭐⭐⭐

#### 指令寻址
- **顺序寻址**：PC自动加1
- **跳跃寻址**：转移指令修改PC

#### 数据寻址（必考！）

| 寻址方式 | 地址计算 | 特点 |
|---|---|---|
| **立即寻址** | A = 操作数 | 最快，但操作数固定 |
| **直接寻址** | EA = A | 简单，但地址空间受限 |
| **间接寻址** | EA = (A) | 扩大地址空间，需多次访存 |
| **寄存器寻址** | EA = R | 速度快，但寄存器有限 |
| **寄存器间接寻址** | EA = (R) | 比间接寻址快 |
| **变址寻址** | EA = (R) + A | 适合数组访问 |
| **基址寻址** | EA = (R) + A | 适合多道程序 |
| **相对寻址** | EA = PC + A | 适合转移指令 |
| **堆栈寻址** | EA = SP | 适合子程序调用 |

**关键区别**：
- **变址寻址**：变址寄存器内容可变，形式地址固定 → 适合数组
- **基址寻址**：基址寄存器内容固定，形式地址可变 → 适合程序重定位
- **相对寻址**：以PC为基准 → 适合转移

### 7.4 指令格式设计

#### 设计考虑因素
- 指令字长（固定/可变）
- 操作码长度（定长/扩展）
- 地址码个数（0~4个）
- 寻址方式编码

#### 扩展操作码技术
- 短操作码留给地址数多的指令
- 长操作码留给地址数少的指令
- 例如：双地址用4位操作码，单地址用10位操作码，零地址用16位操作码

### 7.5 RISC技术 ⭐⭐⭐⭐⭐

#### RISC产生背景
- CISC指令系统庞大复杂
- 常用指令只占20%
- 控制器占芯片面积大

#### RISC主要特征
1. **指令系统简单**：只保留常用指令
2. **指令长度固定**：便于流水线处理
3. **寻址方式简单**：通常只有2~3种
4. **大量寄存器**：减少访存
5. **硬布线控制器**：速度快
6. **流水线技术**：提高执行效率
7. **优化编译器**：弥补指令简单

#### RISC vs CISC比较

| 特性 | RISC | CISC |
|---|---|---|
| 指令数量 | 少 | 多 |
| 指令长度 | 固定 | 可变 |
| 寻址方式 | 简单（2~3种） | 复杂（5~6种） |
| 寄存器 | 多 | 少 |
| 控制器 | 硬布线 | 微程序 |
| 访存指令 | 只有LOAD/STORE | 各种指令可访存 |
| 流水线 | 适合 | 较难 |
| 编译优化 | 重要 | 一般 |

## 典型例题

### 题型1：寻址方式分析

> **例题**：某计算机指令字长16位，操作码4位，地址码10位。若采用扩展操作码技术，最多可定义多少条双地址指令？多少条单地址指令？多少条零地址指令？

**解答**：
- 双地址：4位操作码 → 最多16条
- 单地址：用双地址的1条作为扩展标志，剩余12位操作码 → 最多2¹² = 4096条
- 零地址：用单地址的1条作为扩展标志，剩余22位操作码 → 最多2²²条

### 题型2：有效地址计算

> **例题**：设变址寄存器R=1000H，形式地址A=2000H，内存中(3000H)=4000H，求变址寻址的有效地址。

**解答**：
- 变址寻址：EA = (R) + A = 1000H + 2000H = **3000H**

### 题型3：RISC/CISC特点判断

> **例题**：下列哪项不是RISC的特点？
> A. 指令长度固定
> B. 寻址方式复杂
> C. 大量通用寄存器
> D. 硬布线控制器

**解答**：B（RISC寻址方式简单）

## 易错点

1. **变址 vs 基址**：变址寄存器内容可变（数组），基址寄存器内容固定（重定位）
2. **间接寻址**：需要两次访存，第一次取地址，第二次取数据
3. **相对寻址**：以PC为基准，转移目标 = PC + 偏移量
4. **RISC访存**：只有LOAD/STORE指令可以访存，其他指令只能操作寄存器
5. **扩展操作码**：短操作码留给地址数多的指令（哈夫曼编码思想）

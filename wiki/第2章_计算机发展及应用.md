# 第2章 计算机的发展及应用

> 408考研权重：⭐⭐（基础章节，约2-3分）

## 考点概述

本章主要介绍计算机的发展历程和应用领域。主要考点包括：
- 计算机发展历程（五代）
- 摩尔定律
- 计算机应用领域

## 关键知识点

### 2.1 计算机的发展史

#### 计算机发展历程

| 代 | 时间 | 硬件技术 | 速度（次/秒） |
|---|---|---|---|
| 第一代 | 1946-1957 | 电子管 | 40,000 |
| 第二代 | 1958-1964 | 晶体管 | 200,000 |
| 第三代 | 1965-1971 | 中、小规模集成电路 | 1,000,000 |
| 第四代 | 1972-1977 | 大规模集成电路 | 10,000,000 |
| 第五代 | 1978-现在 | 超大规模集成电路 | 100,000,000 |

#### 关键里程碑

**第一代电子管计算机**：
- ENIAC（1946年）：第一台通用电子计算机
- 18000个电子管，每秒5000次加法
- 十进制运算，手工编程

**第二代晶体管计算机**：
- 晶体管替代电子管
- IBM 7094：主存32K字，速度每秒50万次

**第三代集成电路计算机**：
- IBM System/360（1964）：兼容机概念
- DEC PDP-8：迷你机，总线结构

#### 微型计算机发展

| 微处理器 | 时间 | 位数 | 晶体管数 | 主频 |
|---|---|---|---|---|
| Intel 4004 | 1971 | 4位 | 2,300 | - |
| Intel 8080 | 1974 | 8位 | - | - |
| Intel 8086 | 1978 | 16位 | 29,000 | - |
| Intel 80286 | 1982 | 16位 | 134,000 | 6MHz |
| Intel 80386 | 1985 | 32位 | 275,000 | 12.5MHz |
| Intel 80486 | 1989 | 32位 | 1,200,000 | 25MHz |
| Pentium | 1993 | 32位 | 3,100,000 | 66MHz |
| Pentium Pro | 1995 | 64位 | 5,500,000 | 133MHz |
| Pentium II | 1997 | 64位 | 7,500,000 | 200MHz |
| Pentium 4 | 2000 | 64位 | 42,000,000 | 1.3GHz |

#### 摩尔定律
- 微芯片上集成的晶体管数目每3年翻两番
- 由Intel创始人Gordon Moore提出
- 该定律并非物理定律，而是经验预测

### 2.2 计算机的应用

| 领域 | 说明 |
|---|---|
| **科学计算** | 复杂数学运算，如天气预报、航天轨道 |
| **数据处理** | 事务处理，如银行、财务 |
| **工业控制** | 实时控制，如冶金、化工 |
| **网络技术** | Internet、电子商务、网络教育 |
| **虚拟现实** | 模拟环境，如飞行训练 |
| **办公自动化** | 替代"笔墨纸砚" |
| **CAD/CAM/CIMS** | 辅助设计/制造/集成制造 |
| **多媒体** | 文字、图形、音频、视频综合处理 |
| **人工智能** | 模式识别、语音识别、专家系统 |

### 2.3 计算机的展望

#### 未来计算机发展方向
1. **超级智能计算机**：模拟人脑功能
2. **量子计算机**：利用量子特性，速度极快
3. **光计算机**：光子取代电子
4. **生物计算机**：DNA计算
5. **嵌入式计算机**：无处不在

#### 硅芯片的局限
- 物理极限：线宽达到分子大小
- 制作成本：每代翻倍
- 功耗散热：集成度越高，功耗越大
- 线延迟：信号传输延迟

## 典型例题

### 题型1：摩尔定律理解

> **例题**：什么是摩尔定律？该定律是否永远生效？为什么？

**解答**：
- 摩尔定律：微芯片上集成的晶体管数目每3年翻两番
- 不会永远生效，原因：
  1. 物理极限：线宽达到分子大小
  2. 制作成本：每代翻倍，企业难以承受
  3. 功耗散热：集成度越高，功耗越大
  4. 线延迟：信号传输延迟

### 题型2：计算机更新换代依据

> **例题**：通常，计算机的更新换代以什么为依据？

**解答**：
- 早期：以组成计算机基本电路的元器件为依据（电子管→晶体管→集成电路）
- 现在：以微处理器的发展为依据

## 易错点

1. **计算机五代**：注意区分"第五代计算机"（智能计算机）与"超大规模集成电路"
2. **摩尔定律**：是经验预测，不是物理定律
3. **ENIAC特点**：十进制运算，不是二进制
4. **晶体管发明**：1947年贝尔实验室，不是Intel

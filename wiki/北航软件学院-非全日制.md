# 北京航空航天大学软件学院 — 非全日制硕士

> 北航软件学院是教育部示范性软件学院，软件工程学科为 **A+ 学科**，传统 IT 强校。

## 基本信息

| 项目 | 详情 |
|------|------|
| 专业代码 | **085405 软件工程** |
| 学位类型 | 专业学位（电子信息） |
| 学习方式 | 非全日制 |
| 2026 计划招生 | **88人** |
| 学制 | 3年 |
| 总学费 | **4.5万元**（1.5万/年） |
| 上课方式 | 周末班 / 集中班，面授 |
| 上课地点 | 北京（学院路 / 沙河） |
| 毕业要求 | 无强制论文要求 |

## 录取规则

- 总成绩 = 初试成绩 ÷ 5 × 50% + 复试成绩 × 50%
- 复试 60 分及格，不及格直接淘汰
- 差额复试，调剂线一般不低于310分
- 仅招收定向就业人员，录取后签定向协议

## 关键时间

| 环节 | 时间 |
|------|------|
| 网上报名 | 10月上旬 |
| 初试 | 12月下旬 |
| 复试 | 次年3月中旬 |
| 入学 | 次年9月 |

## 报考条件

- 国家承认学历的应届/往届本科毕业生
- 已获硕士/博士学位者
- 同等学力需辅修过本科主干课程（8门以上）
- 仅招收定向就业人员

## 学院资源

- 软件工程 **A+ 学科**
- 国家示范性软件学院
- 航天系 + 互联网行业校友网络强大

## 🎯 备考建议

### 政治
- ⭐⭐⭐⭐⭐ **毛中特**：分值最高（30分），分析题必考新思想
- ⭐⭐⭐⭐⭐ **马原**：辩证法/认识论是分析题高频考点
- 建议9月开始，后期重点背诵时政

### 英语
- 词汇：每天背100-150词（红宝书/墨墨背单词滚动记忆）
- 阅读：精读真题，每篇至少3遍
- 规划：三阶段备考见[[英语备考规划与资料推荐]]，考前速看[[英语考前速看]]

### 数学
- 高数是重中之重（120分），极限/中值定理/积分应用是解答题常客
- 线代重点掌握特征值/相似对角化/二次型

### 408
- 数据结构：二叉树遍历、图的最短路径、排序算法必考
- 组成原理：Cache映射、IEEE 754、数据通路
- 操作系统：PV操作、页面置换算法
- 计算机网络：TCP三次握手/拥塞控制、IP子网划分
